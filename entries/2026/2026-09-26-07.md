## Objetivo
Dominar la implementación del algoritmo de búsqueda en anchura (BFS) para explorar grafos no ponderados capa por capa, asegurando la visita ordenada de nodos y evitando ciclos mediante el uso de una cola y un conjunto visitado.

## Explicación
El BFS es ideal para encontrar el camino más corto en grafos sin pesos. Utiliza una estructura de datos tipo cola (FIFO) para procesar nodos nivel a nivel. Al iniciar desde un nodo raíz, se marca como visitado y se añaden sus vecinos no explorados a la cola. Cada iteración extrae un nodo, lo procesa y expande sus conexiones pendientes. Es crucial mantener un conjunto de nodos ya visitados para no reiniciar el recorrido infinitamente en grafos cíclicos. Este enfoque garantiza que todos los nodos a distancia k se procesen antes que los de distancia k+1, proporcionando una exploración sistemática y eficiente del grafo completo.

## Ejemplo (no ejecutado automáticamente)
Implementación de BFS en Python para recorrer un grafo no dirigido representado como diccionario de adyacencia, imprimiendo el orden de visita.

```python
from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    visited.add(start)
    while queue:
        node = queue.popleft()
        print(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
```
