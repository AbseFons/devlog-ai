## Objetivo
Comparar la sintaxis y estructura de las pruebas unitarias en Python, destacando cómo pytest simplifica la escritura de tests mediante decoradores implícitos y fixtures automáticos frente al enfoque más explícito de unittest.

## Explicación
En Python, unittest es parte del estándar pero requiere heredar clases y definir métodos específicos como setUp. Por el contrario, pytest permite escribir pruebas como funciones normales, usando decoradores como @pytest.fixture para gestionar dependencias. Esto reduce la verbosidad y mejora la legibilidad. pytest descubre automáticamente los archivos que terminan en test_*.py y las funciones con test_ al inicio. Esta serie comienza mostrando cómo migrar mentalmente de unittest a pytest, aprovechando su simplicidad para escribir pruebas más claras y mantenibles sin sacrificar funcionalidad.

## Ejemplo (no ejecutado automáticamente)
Función simple sumando dos números probada con pytest usando un fixture para inyectar valores.

```python
def test_suma(a, b):
    assert a + b == 5
```
