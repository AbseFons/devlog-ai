## Objetivo
Aprender a convertir objetos de Python a formato JSON legible y viceversa utilizando la biblioteca estándar json, esencial para el intercambio de datos en APIs y almacenamiento persistente.

## Explicación
La serialización transforma estructuras complejas como diccionarios y listas en texto plano compatible con múltiples lenguajes. En Python, el módulo json permite exportar objetos a archivos .json o cadenas mediante la función dump() y dumps(). La deserialización invierte este proceso con load() y loads(), recuperando los datos originales. Es crucial manejar correctamente los tipos de datos: las claves deben ser strings, los booleanos se mapean a true/false y None a null. Este conocimiento es vital para desarrollar servicios web robustos que consumen o producen respuestas en formato estándar.

## Ejemplo (no ejecutado automáticamente)
Conversión de un diccionario de usuario a cadena JSON

```python
import json
usuario = {'nombre': 'Ana', 'edad': 30}
json_str = json.dumps(usuario)
```
