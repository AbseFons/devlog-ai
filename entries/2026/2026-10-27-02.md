## Objetivo
Aprender a construir listas complejas en Python utilizando diccionarios dentro de la comprensión, filtrando elementos basados en múltiples condiciones lógicas para procesar datos estructurados de manera eficiente.

## Explicación
Esta microlección avanza en el uso de comprensiones de listas al integrar diccionarios como elementos a generar. En lugar de crear listas simples, transformaremos una lista de objetos (diccionarios) filtrando por atributos específicos. Esto es útil para limpiar datos o extraer registros que cumplan ciertos criterios de negocio. La sintaxis permite asignar valores a nuevas claves dentro del mismo bucle de comprensión, evitando código redundante y mejorando la legibilidad al mantener la lógica de transformación en una sola línea expresiva.

## Ejemplo (no ejecutado automáticamente)
Se crea una lista de usuarios ficticios y se filtra para obtener solo aquellos mayores de 18 años que tengan un rol de 'admin', generando un nuevo diccionario con su ID numérico y nombre en mayúsculas.

```python
usuarios = [{'id': 1, 'nombre': 'ana', 'edad': 25, 'rol': 'user'}, {'id': 2, 'nombre': 'carlos', 'edad': 17, 'rol': 'admin'}, {'id': 3, 'nombre': 'diana', 'edad': 22, 'rol': 'admin'}]
administrativos = [{'id_nuevo': u['id'], 'nombre_mayus': u['nombre'].upper()} for u in usuarios if u['edad'] >= 18 and u['rol'] == 'admin']
```
