## Objetivo
Comprender y aplicar principios básicos de Control de Acceso Basado en Roles (RBAC) utilizando middleware en una aplicación web, asegurando que solo usuarios autorizados puedan acceder a recursos específicos.

## Explicación
El control de acceso es fundamental para la seguridad de las aplicaciones. En este caso de uso, implementaremos un sistema RBAC simple en Node.js. Crearemos roles como 'admin' y 'usuario', asignando permisos distintos. Utilizaremos middleware para verificar si el token JWT del usuario contiene el rol necesario antes de permitir una solicitud a una ruta protegida. Si el rol no coincide con los requeridos, se devolverá un error 403. Este enfoque modular facilita la gestión de permisos y reduce la superficie de ataque al limitar las acciones posibles por cada tipo de usuario.

## Ejemplo (no ejecutado automáticamente)
Middleware de autenticación que verifica el rol del usuario en el token JWT antes de permitir el acceso a una ruta protegida.

```javascript
const checkRole = (allowedRoles) => {
  return async (req, res, next) => {
    if (!req.user || !allowedRoles.includes(req.user.role)) {
      return res.status(403).json({ error: 'Acceso denegado' });
    }
    next();
  };
};
```

## Ejercicio
Crea una ruta protegida en tu servidor que requiera el rol 'admin'. Implementa la función checkRole para validar el token del usuario antes de ejecutar la lógica de la ruta.

## Criterios de revisión
El código debe incluir un middleware funcional que verifique el rol del usuario. Debe devolver un estado HTTP 403 si el rol no es válido y permitir el paso si lo es.
