## Objetivo
Comprender el principio básico de las tablas hash mediante una función de enfoque simple que mapea claves arbitrarias a índices numéricos dentro de un array fijo, permitiendo acceso directo O(1) en tiempo promedio.

## Explicación
Una tabla hash es una estructura de datos que utiliza una función hash para calcular el índice donde se almacena un elemento. Imagina un diccionario donde cada palabra (clave) se convierte en un número de página específico. Si la clave es 'manzana' y la función devuelve 5, buscamos directamente en la posición 5 del array. El desafío principal son las colisiones, cuando dos claves distintas generan el mismo índice. En esta lección, exploraremos una implementación básica usando módulo para manejar el tamaño del array, sentando las bases para entender cómo se optimizan los sistemas de almacenamiento y recuperación rápida de datos.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python de una función hash simple que asigna un índice a una cadena de texto utilizando la suma de valores ASCII módulo el tamaño del array.

```python
def hash_func(clave, tamano):
    return sum(ord(c) for c in clave) % tamano
print(hash_func('hola', 10))
```
