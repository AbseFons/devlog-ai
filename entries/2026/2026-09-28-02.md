## Objetivo
Aprender a utilizar el módulo estándar argparse en Python para definir argumentos de línea de comandos, crear descripciones y manejar valores por defecto, transformando scripts básicos en herramientas profesionales y fáciles de usar.

## Explicación
El módulo argparse permite construir parsers de argumentos robustos. Se define un 'ArgumentParser' que gestiona la descripción general del programa. Luego, se añaden subcomandos o argumentos posicionales y opcionales usando add_argument(). Es crucial especificar nombres cortos (-o) para accesibilidad rápida, tipos de datos (como integers o strings) y valores por defecto. El parser genera automáticamente mensajes de ayuda detallados si el usuario no proporciona los parámetros correctos. Este enfoque es esencial para cualquier script que interactúe con usuarios externos o se ejecute en pipelines automatizados, asegurando una entrada de datos consistente y evitando errores comunes derivados de llamadas incorrectas al programa.

## Ejemplo (no ejecutado automáticamente)
Un script que acepta un nombre de archivo y un modo de procesamiento opcional, mostrando el mensaje correspondiente según la opción elegida.

```python
import argparse
parser = argparse.ArgumentParser(description='Procesador de archivos simple.')
parser.add_argument('archivo', help='Nombre del archivo a procesar')
parser.add_argument('-m', '--modo', choices=['leer', 'escribir'], default='leer', help='Modo de operación')
```

## Ejercicio
Crea un script llamado 'configurar.py' que acepte dos argumentos obligatorios: --host (dirección IP) y --puerto (número entero). Incluye una opción opcional -v/--verbose que imprima un mensaje de depuración si se activa. Usa add_argument para cada uno y define el parser correctamente.

## Criterios de revisión
El script debe ejecutarse sin errores con argumentos válidos, mostrar el mensaje de ayuda correcto al omitir parámetros y manejar tipos de datos adecuados (string para host, int para puerto). Debe incluir la opción -v que active la salida de depuración.
