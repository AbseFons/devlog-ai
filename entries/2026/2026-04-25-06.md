## Objetivo
Comprender la diferencia entre estructuras LIFO y FIFO, su implementación básica con listas nativas y sus aplicaciones prácticas en gestión de tareas y procesamiento de datos secuenciales.

## Explicación
Las pilas (Stack) siguen el principio LIFO (Last In, First Out), ideales para deshacer acciones o recursión. Las colas (Queue) operan bajo FIFO (First In, First Out), esenciales para colas de impresión o gestión de procesos. En Python, las listas nativas permiten simular ambas: usar append/pop para pilas y collections.deque con popleft para colas eficientes. Este conocimiento es vital para diseñar algoritmos que manejen flujos de datos ordenados sin bloqueos.

## Ejemplo (no ejecutado automáticamente)
Implementación de una cola simple usando deque para simular un sistema de tickets en una cafetería.

```python
from collections import deque

cola = deque()

# Agregar clientes a la cola
cola.append('Ana')
cola.append('Luis')

# Atender al primer cliente
atendido = cola.popleft()
print(f'Atendiendo a: {atendido}')
```
