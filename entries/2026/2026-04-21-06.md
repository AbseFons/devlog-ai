## Objetivo
Comprender los fundamentos de la paginación en APIs RESTful, identificando parámetros clave como offset y limit para gestionar grandes volúmenes de datos sin saturar la red o el servidor.

## Explicación
Las APIs modernas a menudo devuelven conjuntos de datos extensos que no caben en una sola respuesta. La paginación divide estos resultados en páginas manejables. Los parámetros más comunes son 'offset' (índice de inicio) y 'limit' (tamaño de página). Por ejemplo, una API puede devolver 20 registros por página. Para obtener la siguiente página, incrementas el offset en 20. Es crucial implementar este patrón para evitar tiempos de respuesta excesivos y problemas de memoria en el cliente. Además, las respuestas deben incluir metadatos como 'total', 'page' y 'per_page' para que el cliente pueda calcular cuántas páginas existen y si hay más datos por cargar.

## Ejemplo (no ejecutado automáticamente)
Consulta paginada a una API de usuarios simulada usando parámetros offset y limit en la URL.

```bash
curl 'https://api.ejemplo.com/usuarios?offset=0&limit=10'
response=$(curl -s 'https://api.ejemplo.com/usuarios?offset=10&limit=10')
```

## Ejercicio
Crea un script que solicite la primera página de una lista de productos y luego actualice el offset para obtener la segunda página, imprimiendo ambos resultados.

## Criterios de revisión
El código debe incluir los parámetros 'offset' y 'limit' en la URL. Debe manejar correctamente la respuesta JSON devuelta por la API sin errores de sintaxis.
