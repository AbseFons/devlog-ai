## Objetivo
Aprender a inicializar una conexión con sqlite3, crear un esquema básico de tabla y ejecutar inserciones simples sin dependencias externas.

## Explicación
Esta microlección introduce los fundamentos de la interacción con bases de datos SQLite usando el módulo nativo de Python. Comenzaremos importando la librería y estableciendo una conexión a un archivo local o en memoria. Posteriormente, definiremos una tabla 'empleados' con columnas para nombre y salario. Finalmente, insertaremos registros de prueba utilizando sentencias SQL parametrizadas para evitar inyecciones. Este enfoque garantiza que el código sea seguro, portátil y fácil de entender para principiantes que desean gestionar datos estructurados localmente.

## Ejemplo (no ejecutado automáticamente)
Script que crea una base de datos en memoria con una tabla de empleados e inserta dos registros.

```python
import sqlite3
conn = sqlite3.connect(':memory:')
cursor = conn.cursor()
cursor.execute('CREATE TABLE empleados (id INTEGER PRIMARY KEY, nombre TEXT, salario REAL)')
cursor.execute("INSERT INTO empleados (nombre, salario) VALUES (?, ?)", ('Ana', 5000.0))
conn.commit()
```
