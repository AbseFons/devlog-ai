## Objetivo
Aprender a ejecutar pruebas de regresión para asegurar que nuevas modificaciones no rompen funcionalidades existentes, manteniendo la estabilidad del software ante iteraciones continuas.

## Explicación
Las pruebas de regresión verifican que cambios recientes no introduzcan errores en partes no modificadas del sistema. En este caso, simulamos una actualización de un servicio de cálculo de impuestos. Antes de desplegar el nuevo algoritmo, ejecutamos un script que compara los resultados actuales con una base de datos de casos conocidos. Si alguna salida difiere, la prueba falla, indicando un posible error de regresión. Este enfoque permite detectar problemas temprano sin necesidad de probar manualmente cada escenario.

## Ejemplo (no ejecutado automáticamente)
Script en Python que valida si el cálculo de impuestos para un ingreso fijo coincide con el valor esperado tras una actualización del sistema.

```python
def calcular_impuesto(ingreso):
    return ingreso * 0.2

ingreso_prueba = 1000
valor_esperado = 200
resultado_actual = calcular_impuesto(ingreso_prueba)
assert resultado_actual == valor_esperado, f"Error: Se esperaba {valor_esperado}, pero se obtuvo {resultado_actual}"
print("Prueba de regresión aprobada")
```
