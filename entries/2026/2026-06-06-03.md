## Objetivo
Comprender la función de los hooks en Git, específicamente el pre-commit, para automatizar tareas como formateo o validación antes de cada commit.

## Explicación
Los hooks son scripts que Git ejecuta automáticamente en momentos específicos del flujo de trabajo. El hook 'pre-commit' se activa justo antes de realizar un commit. Es ideal para ejecutar herramientas de linting, formateo de código o verificación de tipos. Si el script falla, el commit se bloquea, asegurando que solo código limpio entre al repositorio. Esto mantiene el historial limpio y reduce errores en integración continua.

## Ejemplo (no ejecutado automáticamente)
Script bash que verifica si hay archivos con formato incorrecto antes de permitir el commit.

```bash
#!/bin/bash
if git diff --cached --name-only | grep -q '\.py$'; then
  echo 'Error: Revisa tu Python code'
  exit 1
fi
```
