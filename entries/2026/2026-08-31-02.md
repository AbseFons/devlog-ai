## Objetivo
El desarrollador aplicará el patrón de paginación basado en cursor para manejar grandes volúmenes de datos sin depender de índices numéricos, mejorando la consistencia ante inserciones concurrentes y reduciendo la complejidad del estado del cliente.

## Explicación
La paginación basada en cursor es superior a la numerada cuando los conjuntos de datos cambian dinámicamente. En lugar de usar un número de página, el servidor devuelve un token único que representa la posición exacta del último elemento procesado. Este token incluye los criterios de filtrado y ordenamiento necesarios para recuperar el siguiente lote. El cliente simplemente envía este cursor en la cabecera o parámetro de la siguiente solicitud. Este enfoque elimina errores de saltos o duplicados causados por nuevas inserciones entre peticiones, garantizando una iteración secuencial precisa incluso bajo alta carga concorrente.

## Ejemplo (no ejecutado automáticamente)
```python
import requests

def obtener_paginacion(cursor=None):
    url = "https://api.ejemplo.com/usuarios"
    params = {}
    if cursor:
        params['cursor'] = cursor
    
    response = requests.get(url, params=params)
    data = response.json()
    
    # Procesar items actuales
    for usuario in data['items']:
        print(f"ID: {usuario['id']}, Nombre: {usuario['nombre']}")
    
    # Obtener cursor para la siguiente página si existe
    next_cursor = data.get('next_cursor')
    return next_cursor

# Iniciar paginación
cursor_actual = None
while True:
    cursor_siguiente = obtener_paginacion(cursor=cursor_actual)
    if not cursor_siguiente:
        break
    cursor_actual = cursor_siguiente
```
