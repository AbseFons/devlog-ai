## Objetivo
Introducir el concepto de pruebas basadas en propiedades, donde se verifica que una función mantenga ciertas invariantes lógicas (como no devolver null) sin especificar casos de prueba exhaustivos, fomentando un diseño más robusto y declarativo del software.

## Explicación
Las pruebas basadas en propiedades son una técnica avanzada donde en lugar de definir entradas y salidas específicas, se establecen reglas generales que el sistema debe cumplir siempre. Por ejemplo, podemos afirmar que 'una función de suma nunca debe retornar null'. Herramientas como QuickCheck automatizan la generación de miles de casos de prueba aleatorios para verificar estas propiedades. Este enfoque es ideal para detectar errores sutiles en lógica compleja o algoritmos matemáticos donde los casos de borde son difíciles de predecir manualmente, mejorando la confiabilidad del código sin necesidad de escribir pruebas manuales extenuantes.

## Ejemplo (no ejecutado automáticamente)
Definición de una propiedad que asegura que la suma de dos números nunca sea null en JavaScript.

```javascript
function suma(a, b) {
  return a + b;
}
propiedad: suma(a, b) !== null
```
