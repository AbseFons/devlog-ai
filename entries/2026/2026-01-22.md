## Objetivo
Comprender el mecanismo básico de la inyección SQL mediante concatenación insegura y aprender a identificar vulnerabilidades en consultas dinámicas que exponen datos sensibles.

## Explicación
La inyección SQL ocurre cuando una aplicación construye consultas directamente usando entradas del usuario sin validación. Imagina una consulta simple: SELECT * FROM usuarios WHERE nombre = '

## Ejemplo (no ejecutado automáticamente)
Una consulta vulnerable en JavaScript que concatena el input directamente a la sentencia SQL, permitiendo alterar la lógica de la base de datos.

```javascript
const userInput = 'admin' + "'; DROP TABLE usuarios; --";
const query = `SELECT * FROM usuarios WHERE nombre = '${userInput}'`;
```
