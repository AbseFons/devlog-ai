## Objetivo
Aprender a utilizar bloques try-except para prevenir la terminación abrupta del programa ante errores comunes como división por cero o archivos inexistentes, permitiendo una ejecución más robusta.

## Explicación
En Python, las excepciones interrumpen el flujo normal cuando ocurren errores inesperados. El bloque try ejecuta código potencialmente problemático, mientras que except captura y maneja esos errores específicos. Esto evita que la aplicación se cierre repentinamente. Por ejemplo, intentar dividir por cero genera un ZeroDivisionError. Al envolver esta operación en un try-except, podemos mostrar un mensaje amigable o usar un valor predeterminado. Es fundamental ser específico con el tipo de excepción para manejar distintos escenarios sin ocultar errores críticos.

## Ejemplo (no ejecutado automáticamente)
Intenta dividir dos números; si hay error por cero, muestra un mensaje seguro.

```python
num1 = 10
num2 = 0
try:
    resultado = num1 / num2
except ZeroDivisionError:
    print("No se puede dividir por cero")
```
