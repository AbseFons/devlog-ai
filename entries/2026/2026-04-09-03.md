## Objetivo
Dominar la sintaxis básica de Common Table Expressions para simplificar consultas complejas mediante definiciones temporales nombradas que mejoran la legibilidad del código SQL.

## Explicación
Las Common Table Expressions o CTEs permiten definir un conjunto de resultados temporalmente disponible en el ámbito de una consulta específica. Se declaran antes de la cláusula FROM y pueden usarse con funciones agregadas, subconsultas o recursividad. Su principal ventaja es estructurar lógicamente consultas largas, facilitando el mantenimiento y la depuración. A diferencia de las subconsultas anidadas, las CTEs ofrecen una jerarquía clara de datos.

## Ejemplo (no ejecutado automáticamente)
Consulta que utiliza una CTE para calcular el salario total por departamento antes de filtrar los resultados finales.

```sql
WITH SalariosPorDepto AS (
  SELECT id_departamento, SUM(sueldo) as total_sueldo
  FROM empleados
  GROUP BY id_departamento
)
SELECT * FROM SalariosPorDepto WHERE total_sueldo > 50000;
```

## Ejercicio
Crea una CTE llamada 'VentasDiarias' que agrupe las ventas por fecha y producto, luego úsala para listar solo los productos con más de 100 unidades vendidas en el último mes.

## Criterios de revisión
La consulta debe incluir la cláusula WITH correctamente formada, usar GROUP BY para la agregación inicial y aplicar un filtro WHERE en la consulta final que referencia la CTE.
