## Objetivo
Aprender a exportar valores dinámicamente desde un módulo y cómo esos valores pueden ser reexportados a otros módulos, facilitando patrones de diseño flexibles como factories o configuraciones centralizadas sin acoplar dependencias estáticas.

## Explicación
En esta lección exploramos la capacidad de los módulos ES para exportar datos calculados en tiempo de ejecución. A diferencia de las exportaciones estáticas, podemos generar valores basados en el entorno actual al momento de la importación. Esto es útil para crear configuraciones específicas por entorno o factories que devuelven objetos únicos. El ejemplo muestra un módulo 'config' que decide qué valor exportar dependiendo de una variable de entorno, y otro módulo que importa ese valor específico. Esta técnica permite mantener la lógica de negocio limpia en los módulos consumidores, delegando la generación de datos complejos a un punto centralizado que se ejecuta solo cuando es necesario.

## Ejemplo (no ejecutado automáticamente)
Un módulo 'config' genera dinámicamente una variable 'modo' basada en el entorno y la exporta. Un segundo módulo importa este valor específico para usarlo en su lógica interna, demostrando cómo los datos pueden fluir entre módulos de forma condicional.

```javascript
export const modo = process.env.NODE_ENV === 'production' ? 'prod' : 'dev';
module.exports = { modo };

import { modo } from './config.js';
console.log(`Aplicación en modo: ${modo}`);
```

## Ejercicio
Crea un archivo 'utils.js' que exporte una función 'crearUsuario' que devuelva un objeto con nombre y rol. Luego, en 'app.js', importa esta función y usa la reexportación para enviar el usuario a una API simulada.

## Criterios de revisión
El código debe usar export/import estándar de ES6, no CommonJS. La función creada debe devolver un objeto literal válido. El archivo app.js debe demostrar el uso de la función importada sin errores de sintaxis.
