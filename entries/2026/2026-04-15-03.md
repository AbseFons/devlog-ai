## Objetivo
Introducir al ingeniero en el concepto de pruebas basadas en propiedades, donde se verifica que una propiedad lógica (como la conservación de datos) se mantenga verdadera para cualquier entrada válida, sin necesidad de definir casos de prueba exhaustivos manualmente.

## Explicación
Las pruebas basadas en propiedades difieren de las pruebas tradicionales al no depender de casos específicos predefinidos. En su lugar, se define una propiedad formal que describe el comportamiento correcto esperado del sistema (por ejemplo, 'la suma de los elementos debe ser igual a la entrada'). Un generador de entradas crea datos aleatorios y un motor de prueba verifica si la propiedad se cumple. Si falla, busca automáticamente un contraejemplo mínimo para demostrar dónde ocurre el error. Este enfoque es ideal para algoritmos complejos donde enumerar todos los casos es imposible.

## Ejemplo (no ejecutado automáticamente)
Verificación de que una función de suma reduce mantiene la propiedad de conservación: la suma acumulada debe ser igual a la suma total de los elementos procesados hasta ese punto.

```javascript
function verificarPropiedad(lista, resultado) {
  return lista.reduce((acumulado, valor) => acumulado + valor, 0) === resultado;
}
```

## Ejercicio
Implementa una función en Python que verifique si un árbol binario de búsqueda cumple con la propiedad de orden: todos los nodos a la izquierda deben ser menores y todos los de la derecha mayores.

## Criterios de revisión
El código debe incluir una función recursiva o iterativa que recorra el árbol, compare valores y devuelva true si todas las propiedades se cumplen o false en caso de violación.
