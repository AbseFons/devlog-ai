## Objetivo
Comprender el principio de dividir el espacio de búsqueda a la mitad en cada iteración para localizar un elemento en un arreglo ordenado, logrando una complejidad temporal logarítmica O(log n) y optimizando el rendimiento en grandes volúmenes de datos.

## Explicación
La búsqueda binaria es un algoritmo eficiente que requiere que los datos estén ordenados. Comienza comparando el elemento objetivo con el valor central del rango actual. Si coinciden, la búsqueda termina. Si el objetivo es menor, se descarta la mitad derecha; si es mayor, se descarta la mitad izquierda. Este proceso de reducción por la mitad continúa hasta encontrar el elemento o agotar las posibilidades. A diferencia de la búsqueda lineal que revisa cada ítem, esta técnica reduce drásticamente el número de comparaciones necesarias, siendo ideal para índices de bases de datos o catálogos masivos donde la velocidad es crítica.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python que busca un valor en una lista ordenada devolviendo su índice o -1 si no existe.

```python
def busqueda_binaria(arr, objetivo):
    izq, der = 0, len(arr) - 1
    while izq <= der:
        mid = (izq + der) // 2
        if arr[mid] == objetivo:
            return mid
        elif arr[mid] < objetivo:
            izq = mid + 1
        else:
            der = mid - 1
    return -1
```
