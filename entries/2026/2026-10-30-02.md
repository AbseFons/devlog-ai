## Objetivo
Aprender a gestionar errores complejos utilizando bloques try/except anidados y context managers para asegurar la limpieza de recursos como archivos, evitando fugas de memoria o bloqueos.

## Explicación
En Python avanzado, el manejo de excepciones no se limita al simple catch. Los context managers (con 'with') automatizan la apertura y cierre de recursos, liberando locks automáticamente. Cuando una operación interna falla dentro de un contexto, podemos anidar bloques try/except para capturar errores específicos sin interrumpir el flujo principal. Esto permite loguear detalles precisos del fallo interno mientras se mantiene la integridad del recurso externo abierto. Es crucial distinguir entre excepciones lógicas y de sistema para diseñar arquitecturas resilientes que informen al usuario sin exponer implementaciones internas sensibles.

## Ejemplo (no ejecutado automáticamente)
Un script que intenta leer un archivo de configuración y luego procesa una línea numérica, capturando errores de lectura de archivo y ValueError por datos inválidos de forma independiente.

```python
import os

def procesar_config(ruta_archivo):
    try:
        with open(ruta_archivo, 'r') as f:
            linea = f.readline()
            try:
                valor = int(linea.strip())
                print(f"Valor procesado: {valor}")
            except ValueError:
                print("Error: La línea no es un número entero válido.")
    except FileNotFoundError:
        print("Error: El archivo especificado no existe en el sistema.")

procesar_config('config.txt')
```
