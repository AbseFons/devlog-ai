## Objetivo
Aprender a utilizar el comando git cherry-pick para aplicar un commit específico de otra rama al repositorio actual sin fusionar todo su historial, manteniendo la integridad del flujo de trabajo.

## Explicación
El comando git cherry-pick permite seleccionar y aplicar uno o varios commits individuales desde una rama remota o local a la rama actual. Esto es útil cuando deseas incorporar una corrección específica o una característica concreta sin traer el resto de cambios asociados a ese commit. Al ejecutarlo, Git recrea el cambio en tu entorno local generando un nuevo commit con un ID diferente. Es fundamental verificar que no haya conflictos antes de aplicar el comando. Si surgen conflictos, Git los marcará y deberás resolverlos manualmente antes de finalizar la operación. Este proceso preserva la historia limpia del repositorio principal mientras integra solo lo necesario.

## Ejemplo (no ejecutado automáticamente)
Aplicar un commit específico desde una rama de desarrollo a la rama main para incluir una corrección puntual sin fusionar todo el historial.

```bash
git cherry-pick abc1234567890
# Resolver conflictos si los hay con git add y git commit
```
