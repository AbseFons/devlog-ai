## Objetivo
Aprender a convertir objetos de Python a formato JSON y viceversa utilizando la biblioteca estándar json, comprendiendo su utilidad para el intercambio de datos entre aplicaciones.

## Explicación
La serialización transforma estructuras complejas de Python como diccionarios y listas en cadenas de texto JSON legibles. Esto es esencial para guardar configuraciones o enviar datos a APIs web. El módulo json ofrece funciones nativas: dump() para escribir directamente en archivos, dumps() para obtener una cadena en memoria, load() y loads() para leer. Es crucial recordar que los diccionarios se convierten en objetos JSON, las listas en arrays y los tipos booleanos de Python coinciden con true/false de JSON. La serialización permite persistir datos estructurados sin dependencias externas.

## Ejemplo (no ejecutado automáticamente)
Conversión de un diccionario de usuario a una cadena JSON válida.

```python
import json
usuario = {'nombre': 'Ana', 'edad': 30}
json_str = json.dumps(usuario)
```
