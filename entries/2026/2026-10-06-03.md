## Objetivo
Aprender a implementar restricciones CHECK para rangos válidos y UNIQUE para integridad referencial, asegurando la calidad de los datos desde el diseño de tablas.

## Explicación
Las restricciones en SQL garantizan la integridad de los datos. La cláusula CHECK valida que una columna cumpla una condición lógica específica, como un rango numérico o un formato de fecha. Por ejemplo, se puede impedir registrar edades negativas. Por otro lado, UNIQUE asegura que todos los valores en una columna sean distintos, ideal para identificadores naturales como números de teléfono o DNI. Ambas restricciones se definen al crear la tabla con CREATE TABLE o alterando una existente con ALTER TABLE. Es crucial escribir las condiciones correctamente para evitar errores de sintaxis y asegurar que la base de datos rechace registros inválidos automáticamente.

## Ejemplo (no ejecutado automáticamente)
Creación de una tabla 'empleados' donde la columna 'edad' solo acepta valores entre 18 y 65, y el correo electrónico debe ser único en toda la tabla.

```sql
CREATE TABLE empleados (
    id INT PRIMARY KEY,
    nombre VARCHAR(50),
    edad INT CHECK (edad >= 18 AND edad <= 65),
    correo VARCHAR(100) UNIQUE
);
```
