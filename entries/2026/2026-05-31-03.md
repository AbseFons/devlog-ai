## Objetivo
Comprender la naturaleza del tipado dinámico en Python y cómo las anotaciones mejoran la legibilidad del código sin imponer restricciones estrictas de compilación.

## Explicación
Python utiliza un sistema de tipado dinámico donde el tipo de una variable se determina en tiempo de ejecución. Esto permite flexibilidad, como reasignar una variable a diferentes tipos, pero puede ocultar errores hasta que se ejecuta el programa. Las anotaciones de tipo, introducidas con PEP 484, son opcionales y sirven para documentar la intención del desarrollador. Aunque el intérprete ignora estas anotaciones en tiempo de ejecución estándar, herramientas como mypy las utilizan para realizar análisis estático avanzado. Incluir anotaciones facilita la refactorización segura, permite a otros desarrolladores entender los contratos de funciones rápidamente y mejora la detección temprana de errores lógicos sin sacrificar la agilidad característica del lenguaje.

## Ejemplo (no ejecutado automáticamente)
Definición de una función que calcula el área de un rectángulo con anotaciones explícitas en sus parámetros y valor de retorno, demostrando claridad sobre los tipos esperados.

def calcular_area(ancho: float, alto: float) -> float:
