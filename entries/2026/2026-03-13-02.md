## Objetivo
Aprender a identificar y resolver conflictos de merge mediante edición directa, utilizando herramientas como VS Code para comparar versiones y aplicar cambios específicos sin perder datos locales.

## Explicación
Cuando Git detecta un conflicto durante un merge o una actualización remota, marca las líneas afectadas con marcadores '<<<<<<<', '=======', y '>>>>>>>'. El desarrollador debe editar manualmente el archivo, manteniendo la lógica deseada de ambas versiones. Es crucial borrar los marcadores al finalizar la edición. Una vez resuelto, se ejecuta 'git add' para marcar el archivo como resuelto y luego 'git commit' o 'git merge --continue' para finalizar el proceso.
