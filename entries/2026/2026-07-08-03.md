## Objetivo
Comprender cómo el motor de base de datos decide optimizar consultas complejas mediante el análisis del plan de ejecución generado por la instrucción EXPLAIN, identificando cuellos de botella.

## Explicación
La sentencia EXPLAIN revela el algoritmo que el optimizador utiliza para procesar una consulta SQL. No ejecuta la tabla real, sino que simula el flujo de operaciones como escaneos de índices, uniones o agrupaciones. Esto permite detectar ineficiencias antes de afectar el rendimiento del sistema. Al analizar el plan, se identifican costos estimados y el orden de ejecución. Es fundamental para ajustar índices o reescribir consultas lentas sin necesidad de pruebas costosas en producción.

## Ejemplo (no ejecutado automáticamente)
Consulta que busca empleados con salario alto usando EXPLAIN para verificar el uso del índice.

```sql
EXPLAIN SELECT * FROM empleados WHERE salario > 50000;
SELECT * FROM empleados WHERE salario > 50000;
```

## Ejercicio
Ejecuta EXPLAIN en una consulta JOIN de dos tablas grandes y observa si el optimizador usa índices o escaneos completos.

## Criterios de revisión
El plan debe mostrar 'Index Scan' en lugar de 'Seq Scan' para las columnas filtradas, indicando un uso correcto de índices.
