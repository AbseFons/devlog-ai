## Objetivo
Aprender a identificar y probar valores extremos en entradas numéricas para prevenir errores de desbordamiento o lógica incorrecta. Esta microlección cubre la validación de límites superiores e inferiores en formularios web.

## Explicación
Los casos borde son pruebas diseñadas para verificar el comportamiento del sistema ante condiciones extremas, como valores máximos, mínimos o nulos. En este ejemplo, simulamos un formulario que calcula impuestos sobre una cantidad. Los casos borde incluyen ingresar exactamente el límite máximo permitido, uno por encima (para ver si se rechaza) y cero negativo. Esto asegura que la aplicación maneje correctamente los datos sin colapsar ni aceptar entradas inválidas.

## Ejemplo (no ejecutado automáticamente)
Script de prueba en JavaScript que valida límites numéricos simulando un formulario de pago con impuestos.

```javascript
const limiteMax = 1000;
const inputUsuario = 1001;
if (inputUsuario > limiteMax) { throw new Error('Valor excede el límite'); }
```

## Ejercicio
Crea una función en Python que reciba un número y devuelva 'aprobado' si está entre -50 y 50, o 'rechazado' si está fuera de ese rango.

## Criterios de revisión
El código debe manejar correctamente los valores exactos de los límites (-50 y 50) y devolver el mensaje correcto para cualquier otro valor.
