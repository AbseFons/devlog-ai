## Objetivo
Aprender a seleccionar elementos del documento HTML utilizando selectores CSS y modificar sus propiedades en tiempo real con JavaScript para crear interfaces dinámicas.

## Explicación
La manipulación del DOM permite interactuar con el contenido web. Utilizamos métodos como document.querySelector para obtener un único elemento basado en un selector CSS, o querySelectorAll para múltiples. Una vez seleccionado, podemos acceder a propiedades como innerText para cambiar texto o style para alterar colores y tamaños. Este enfoque es fundamental para construir aplicaciones interactivas donde la estructura visual responde a acciones del usuario, permitiendo feedback inmediato sin recargar la página.

## Ejemplo (no ejecutado automáticamente)
Selecciona un párrafo con clase 'destacado' y cambia su color de fondo al pasar el mouse por encima.

```javascript
const para = document.querySelector('.destacado');
para.addEventListener('mouseenter', () => para.style.backgroundColor = '#f0f0f0');
```
