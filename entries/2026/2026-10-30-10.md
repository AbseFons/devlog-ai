## Objetivo
Aprender a implementar colas con prioridad para gestionar tareas críticas versus rutinarias, optimizando el rendimiento del sistema al procesar primero las operaciones más urgentes sin bloquear la ejecución general.

## Explicación
En sistemas operativos y servidores, no todas las tareas tienen la misma urgencia. Una cola simple FIFO puede causar latencia innecesaria si una tarea lenta pero de baja prioridad bloquea procesos críticos. La solución es usar una estructura de datos que permita insertar elementos con niveles de prioridad. Al implementar esto en Python, podemos asignar un valor numérico a cada tarea: valores más bajos indican mayor urgencia. El algoritmo extrae siempre el elemento con la menor prioridad numérica. Este enfoque garantiza que las alertas de seguridad o actualizaciones del kernel se ejecuten antes que una limpieza de logs rutinaria, mejorando la estabilidad global del servicio sin requerir hardware adicional.

## Ejemplo (no ejecutado automáticamente)
Implementación de una cola con prioridad usando un diccionario en Python para simular el procesamiento de tareas de sistema.

```python
import heapq

tareas = []
heapq.heappush(tareas, (1, 'actualizar_kernel'))
heapq.heappush(tareas, (5, 'limpiar_logs'))
while tareas:
    prioridad, tarea = heapq.heappop(tareas)
    print(f'Procesando {tarea} con prioridad {prioridad}')
```
