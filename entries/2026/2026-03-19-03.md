## Objetivo
Aprender a utilizar la sentencia 'with' en Python para garantizar que los recursos, como archivos, se cierren automáticamente al finalizar el bloque de código, evitando fugas de memoria y errores comunes.

## Explicación
Los context managers permiten manejar recursos eficientemente mediante la sentencia 'with'. Al usarla, Python ejecuta el método '__enter__' para preparar el recurso y '__exit__' para limpiarlo automáticamente al salir del bloque, incluso si ocurre una excepción. Esto es crucial en operaciones de E/S como leer archivos. Sin este patrón, los desarrolladores deben recordar cerrar manualmente las conexiones, lo que puede llevar a errores difíciles de depurar. Este enfoque asegura la integridad del sistema y simplifica el código.

## Ejemplo (no ejecutado automáticamente)
Este script lee un archivo de texto seguro y muestra su contenido antes de cerrarlo automáticamente.

```python
with open('datos.txt', 'r') as f:
    contenido = f.read()
    print(contenido)
```
