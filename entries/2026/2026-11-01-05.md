## Objetivo
Comprender cómo implementar una función recursiva para generar la serie de Fibonacci, observando el patrón de llamada a sí misma y la base de casos necesaria para evitar bucles infinitos en el cálculo de números secuenciales.

## Explicación
La recursión permite resolver problemas complejos dividiéndolos en versiones más pequeñas del mismo problema. En la serie de Fibonacci, cada número es la suma de los dos anteriores. La función debe definir una condición base (n=0 o n=1) que devuelva el valor directamente. Para cualquier otro caso, la función llama a sí misma con argumentos decrecientes hasta alcanzar la base. Este enfoque es elegante pero puede ser ineficiente sin memoización, ya que recalcula valores repetidamente. Es fundamental entender cómo se construye la pila de llamadas y cuándo se detiene la recursión para garantizar la terminación correcta del algoritmo.

## Ejemplo (no ejecutado automáticamente)
Función en JavaScript que calcula el n-ésimo número de Fibonacci usando recursión directa, mostrando la lógica de suma de los dos términos anteriores.

```javascript
function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}
```
