## Objetivo
Aprender a identificar y probar casos borde en la validación de datos numéricos, asegurando que el sistema maneje correctamente valores mínimos, máximos y límites adyacentes para prevenir errores de desbordamiento o rechazo injustificado.

## Explicación
Los casos borde son pruebas críticas que verifican el comportamiento del software justo antes y después de los límites definidos en la especificación. En este ejemplo, analizamos una función que calcula un descuento basado en un monto total. El caso borde típico ocurre cuando el monto es exactamente igual al límite máximo permitido o ligeramente superior. Si el sistema no valida estos umbrales, podría calcular descuentos erróneos o lanzar excepciones inesperadas. Es fundamental incluir pruebas para valores como 0, el mínimo positivo, el máximo exacto y uno más allá del rango aceptado. Esto garantiza la robustez ante entradas extremas que los usuarios podrían introducir por error.

## Ejemplo (no ejecutado automáticamente)
Script en Python que define un límite máximo de descuento y prueba con valores dentro, en el borde y fuera del rango permitido para verificar las respuestas del sistema.

```python
MAX_MONTO = 1000
monto = MAX_MONTO + 1
descuento = monto * 0.1 if monto <= MAX_MONTO else 0
print(f"Monto: {monto}, Descuento: {descuento}")
```
