## Objetivo
Aprender a ejecutar pruebas de regresión para asegurar que nuevas modificaciones no rompen funcionalidades existentes, manteniendo la estabilidad del sistema ante iteraciones continuas.

## Explicación
Las pruebas de regresión son esenciales en el ciclo de vida del software para verificar que los cambios recientes no introduzcan errores en características previamente operativas. Se ejecutan tras cada actualización o corrección de bugs. Este proceso garantiza la integridad funcional a largo plazo, permitiendo a los equipos de desarrollo integrar nuevas funciones con confianza. Sin estas pruebas, un parche de seguridad podría romper el flujo de pago o una optimización podría afectar el rendimiento del usuario final.

## Ejemplo (no ejecutado automáticamente)
Script que simula la actualización de un precio en base de datos y verifica que otros módulos como el historial de órdenes sigan funcionando correctamente.

```javascript
const nuevoPrecio = 15.00;
const productoAnterior = { id: 1, precio: 10.00 };
productoAnterior.precio = nuevoPrecio;
console.log('Precio actualizado:', productoAnterior.precio);
if (productoAnterior.precio !== nuevoPrecio) throw new Error('Error de regresión');
```

## Ejercicio
Crea un script que modifique la configuración de una variable global y luego ejecute dos comprobaciones: una para asegurar que la nueva configuración se aplica y otra para verificar que una función dependiente anterior no falle.

## Criterios de revisión
El código debe modificar una variable, ejecutar al menos dos aserciones lógicas distintas y lanzar un error si alguna condición falla.
