## Objetivo
Comprender la estructura básica de una función recursiva aplicándola para calcular el factorial de un número entero positivo, identificando claramente la condición base y el caso general.

## Explicación
La recursión permite que una función se llame a sí misma para resolver subproblemas más pequeños. En este caso, calculamos el factorial (n!) multiplicando n por el factorial de (n-1). Es crucial definir una condición base donde la función deje de llamarse a sí misma; aquí, si n es 0 o 1, el resultado es 1. Sin esta condición, ocurriría un desbordamiento de pila. El caso general maneja números mayores que 1. Este enfoque divide el problema complejo en instancias más simples hasta llegar a la solución trivial.

## Ejemplo (no ejecutado automáticamente)
Función que recibe un número y devuelve su factorial usando llamada recursiva, manejando correctamente el caso base para evitar errores de ejecución.

```javascript
function factorial(n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}
```
