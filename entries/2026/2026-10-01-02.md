## Objetivo
Introducir el concepto de programación dinámica resolviendo el problema de Fibonacci mediante memoización para evitar recálculos exponenciales y optimizar la complejidad temporal a lineal.

## Explicación
La programación dinámica es una técnica que descompone problemas complejos en subproblemas más simples, almacenando sus resultados para reutilizarlos. En este caso, analizamos la secuencia de Fibonacci donde cada número depende de los dos anteriores. Un enfoque recursivo puro recalcula valores repetidamente, resultando ineficiente. Mediante memoización, guardamos el resultado de cada llamada en un array antes de calcularlo nuevamente. Esto transforma la complejidad de exponencial a lineal, demostrando cómo optimizar algoritmos evitando trabajo redundante.

## Ejemplo (no ejecutado automáticamente)
Implementación en JavaScript que calcula el n-ésimo número de Fibonacci usando un array para almacenar resultados previos y evitar recálculos innecesarios.

```javascript
function fibonacci(n, memo = {}) {
  if (memo[n]) return memo[n];
  if (n <= 1) return n;
  memo[n] = fibonacci(n - 1, memo) + fibonacci(n - 2, memo);
  return memo[n];
}
console.log(fibonacci(10));
```
