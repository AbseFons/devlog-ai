## Objetivo
Comprender la estructura básica de una tabla hash, el rol de la función hash para mapear claves a índices y cómo se manejan las colisiones mediante encadenamiento simple en un contexto de gestión de inventario.

## Explicación
Una tabla hash es una estructura de datos que permite acceso directo a los elementos mediante una clave. Utiliza una función hash que transforma cualquier clave (como un ID de producto) en un índice numérico dentro de un array. Cuando dos claves generan el mismo índice, ocurre una colisión. Para resolverla, se emplea encadenamiento: cada celda del array contiene una lista enlazada con todos los elementos que comparten ese índice. Este método garantiza tiempos de búsqueda promedio O(1). Es ideal para sistemas de caché o directorios telefónicos donde la velocidad de inserción y recuperación es crítica.

## Ejemplo (no ejecutado automáticamente)
Implementación de una tabla hash simple en JavaScript para gestionar un inventario de productos, resolviendo colisiones con listas enlazadas implícitas usando arrays.

```javascript
const tabla = new Array(10).fill(null);
function insertar(clave, valor) {
  const indice = clave % tabla.length;
  if (!tabla[indice]) { tabla[indice] = [{clave, valor}]; } else { tabla[indice].push({clave, valor}); }
}
```
