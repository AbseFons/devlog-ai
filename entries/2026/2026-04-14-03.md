## Objetivo
Comprender cómo el motor de JavaScript maneja asíncronía mediante el event loop, diferenciando entre microtareas y macrotareas para evitar bloqueos en la interfaz.

## Explicación
El event loop es el mecanismo que permite a JavaScript ser no bloqueante. Opera monitoreando dos pilas: la pila de llamadas (síncrono) y la cola de tareas (macrotareas). Cuando una función asíncrona se resuelve, su callback se mueve a la cola de tareas. Solo se ejecuta cuando la pila de llamadas está vacía. Además, existe una cola de microtareas que tiene prioridad sobre las macrotareas. Esto significa que si hay tareas pendientes en ambas colas, el loop procesará primero las microtareas antes de volver a revisar las macrotareas o ejecutar código síncrono nuevo.

## Ejemplo (no ejecutado automáticamente)
Un script que demuestra la ejecución diferida de una promesa contra un setTimeout estándar, mostrando el orden correcto de ejecución en la consola.

```javascript
console.log('Inicio');
setTimeout(() => console.log('Timeout'), 0);
promise.then(() => console.log('Promise'));
console.log('Fin');
```
