## Objetivo
Comprender la estructura básica de una prueba de integración que valida la comunicación entre un cliente y un servicio backend, asegurando que los datos se procesan correctamente a través de las capas del sistema.

## Explicación
Las pruebas de integración verifican que los módulos individuales funcionen bien juntos. En este caso, simulamos una solicitud HTTP POST a un endpoint '/api/users' para crear un nuevo usuario. La prueba valida que el servidor responde con un estado 201 (Creado) y que el cuerpo de la respuesta contiene el ID generado del recurso. Esto asegura que la lógica de validación del backend y la serialización de datos funcionan en conjunto sin errores.

## Ejemplo (no ejecutado automáticamente)
Script que envía una petición POST con un objeto JSON a un servidor local y verifica la respuesta exitosa.

```bash
curl -X POST http://localhost:3000/api/users \
  -H "Content-Type: application/json" \
  -d '{"nombre": "Ana", "email": "ana@ejemplo.com"}'
```

## Ejercicio
Modifica el script para incluir un encabezado de autenticación 'Authorization: Bearer <token>' y verifica que la respuesta falle con un estado 401 si el token es inválido.

## Criterios de revisión
El script debe ejecutarse sin errores de sintaxis, enviar los datos correctamente y manejar la respuesta del servidor mostrando el código de estado en la consola.
