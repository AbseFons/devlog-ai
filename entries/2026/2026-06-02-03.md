## Objetivo
Comprender cómo las funciones internas acceden a variables del ámbito exterior incluso después de que esa función ha terminado de ejecutarse, permitiendo crear funciones con estado privado.

## Explicación
Un closure es una función que recuerda su entorno léxico original. En JavaScript, cuando una función se define dentro de otra, puede acceder a las variables de la función externa (su ámbito). Aunque la función externa termine, la interna mantiene referencias a esas variables. Esto permite encapsular datos y lógica sin exponerlos globalmente. Por ejemplo, podemos crear un contador simple donde el valor interno nunca se pierde, ya que el closure lo preserva en memoria mientras exista la referencia a la función.

## Ejemplo (no ejecutado automáticamente)
Se define una función 'crearContador' que devuelve otra función con acceso al estado privado 'contador'. Cada llamada incrementa ese valor oculto sin exponerlo.

```javascript
function crearContador() {
  let contador = 0;
  return function() { return ++contador; };
}
```
