## Objetivo
Comprender la diferencia entre imagen (plantilla inmutable) y contenedor (instancia ejecutable), y cómo Docker utiliza capas para crear entornos aislados eficientes sin modificar el sistema anfitrión.

## Explicación
Docker permite empaquetar aplicaciones con sus dependencias en imágenes, que son archivos de solo lectura. Al ejecutar una imagen, se crea un contenedor, una instancia mutable y efímera. Las imágenes se construyen mediante instrucciones Dockerfile que definen capas optimizadas. Los contenedores comparten el kernel del sistema operativo anfitrión pero mantienen su propio espacio de usuario aislado. Esta arquitectura facilita la portabilidad, la consistencia entre entornos y la escalabilidad rápida, permitiendo despliegues rápidos sin conflictos de librerías o versiones de software.

## Ejemplo (no ejecutado automáticamente)
Creación de una imagen base personalizada con un contenedor de Python que ejecuta un script de salud simple para validar el entorno.

```bash
# Crear archivo Dockerfile
FROM python:3.12-slim
COPY app.py /app/
CMD ["python", "/app/app.py"]
# Construir imagen y ejecutar contenedor
docker build -t mi-app .
docker run --rm mi-app
```
