## Objetivo
Al finalizar esta lección, el desarrollador será capaz de implementar una tabla hash básica en Python utilizando la estrategia de encadenamiento para resolver colisiones, comprendiendo cómo se almacenan múltiples elementos en un mismo índice mediante listas anidadas.

## Explicación
Las tablas hash mapean claves a índices numéricos. Sin embargo, dos claves distintas pueden generar el mismo índice (colisión). La estrategia de encadenamiento resuelve esto almacenando una lista de elementos en cada celda del array principal. Cuando ocurre una colisión, simplemente se añade el nuevo elemento al final de la lista existente en ese índice. Este método es sencillo de implementar y evita la sobreescritura de datos. En Python, las listas anidadas son ideales para este propósito. A diferencia de la rehashing o la direccionamiento abierto que requieren cálculos complejos o estructuras auxiliares, el encadenamiento mantiene la integridad de los datos de forma natural. Es fundamental entender que el rendimiento promedio sigue siendo O(1), aunque en casos de muchas colisiones puede degradarse a O(n).

## Ejemplo (no ejecutado automáticamente)
```python
class HashTable:
    def __init__(self, size=5):
        self.size = size
        self.table = [[] for _ in range(size)]
    
    def _hash(self, key):
        return hash(key) % self.size
    
    def insert(self, key, value):
        index = self._hash(key)
        # Verificamos si la clave ya existe para actualizarla
        for i, item in enumerate(self.table[index]):
            if item[0] == key:
                self.table[index][i] = (key, value)
                return
        # Si no existe, añadimos a la lista de colisiones
        self.table[index].append((key, value))
    
    def get(self, key):
        index = self._hash(key)
        for k, v in self.table[index]:
            if k == key:
                return v
        return None

# Caso de uso: Registro de usuarios por ID
ht = HashTable()
ht.insert(101, 'Ana')
ht.insert(205, 'Carlos')  # Sin colisión
ht.insert(101, 'Ana_Garcia')  # Colisión: actualiza valor
print(ht.get(101))  # Salida: Ana_Garcia
```
