## Objetivo
Aprender a almacenar credenciales sensibles fuera del código fuente utilizando variables de entorno, evitando exponer claves en repositorios públicos y comprendiendo los principios básicos de seguridad para desarrolladores.

## Explicación
Los secretos como contraseñas o tokens nunca deben hardcodearse. La práctica estándar es usar variables de entorno proporcionadas por el sistema operativo o herramientas como Docker. Esto separa la lógica de la aplicación de los datos sensibles. Al iniciar un proceso, el lenguaje de programación lee estas variables sin escribir su valor en archivos de texto plano visibles. Es crucial no incluir estas variables en el historial del terminal ni en logs públicos. Para producción, se recomienda usar gestores dedicados como HashiCorp Vault o AWS Secrets Manager que rotan credenciales automáticamente y auditan accesos. En desarrollo local, se pueden definir manualmente pero nunca subir al control de versiones.

## Ejemplo (no ejecutado automáticamente)
Definición de una variable de entorno con un token ficticio en bash y lectura segura desde Python.

```bash
export MI_TOKEN_SECRETO="sk_test_1234567890abcdef"
python -c "import os; print(os.getenv('MI_TOKEN_SECRETO'))"
```
