## Objetivo
Comprender cómo las APIs protegen recursos mediante límites de tasa y aprender a interpretar cabeceras clave como X-RateLimit-Limit para gestionar el consumo responsable en aplicaciones cliente.

## Explicación
El rate limiting es un mecanismo esencial para prevenir abusos y garantizar la estabilidad del servidor. Las APIs modernas informan estos límites mediante cabeceras HTTP específicas. El encabezado X-RateLimit-Limit indica el número máximo de solicitudes permitidas en una ventana de tiempo, mientras que X-RateLimit-Remaining muestra cuántas quedan disponibles. Si este valor llega a cero, la API suele devolver un estado 429 Too Many Requests. Implementar esta lógica en el cliente permite evitar bloqueos innecesarios y mejorar la experiencia del usuario al implementar backoff exponencial cuando se alcanza el límite.

## Ejemplo (no ejecutado automáticamente)
Script que simula una solicitud a una API protegida y lee los headers de rate limiting para mostrar el estado actual del consumo.

```bash
curl -s https://api.ejemplo.com/datos | head -n 1
response=$(curl -sI https://api.ejemplo.com/datos)
echo "Limit: $(echo $response | grep -i 'X-RateLimit-Limit' | cut -d: -f2)"
echo "Remaining: $(echo $response | grep -i 'X-RateLimit-Remaining' | cut -d: -f2)"
```
