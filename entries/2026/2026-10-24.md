## Objetivo
Comprender la estructura básica de una tabla hash, el rol de la función hash para mapear claves a índices y cómo se gestionan las colisiones mediante encadenamiento simple en un caso de uso práctico.

## Explicación
Una tabla hash es una estructura de datos que permite acceso rápido O(1) a los elementos. Utiliza una función hash para transformar una clave arbitraria en un índice numérico dentro de un array. Cuando dos claves generan el mismo índice, ocurre una colisión. En este ejemplo, implementaremos encadenamiento simple: cada celda del array contendrá una lista enlazada de elementos que comparten ese índice. Esto permite almacenar múltiples registros sin perder integridad. Es fundamental elegir funciones hash distribuidas uniformemente para minimizar colisiones y mantener el rendimiento óptimo en aplicaciones como cachés o diccionarios.

## Ejemplo (no ejecutado automáticamente)
Implementación de una tabla hash con encadenamiento simple usando un objeto JavaScript que simula el array de listas, insertando pares clave-valor y mostrando la estructura interna resultante.

```javascript
const tabla = new Array(10).fill(null).map(() => []);
function insertar(tabla, clave, valor) {
  const indice = clave % tabla.length;
  if (tabla[indice]) { tabla[indice].push({clave, valor}); }
  else { tabla[indice] = [{clave, valor}]; }
}
insertar(tabla, 'usuario1', 100);
insertar(tabla, 'usuario2', 200);
```
