## Objetivo
Comprender por qué almacenar credenciales en código fuente es inseguro y aprender el concepto básico de usar variables de entorno para inyectar secretos sin exponerlos en repositorios públicos.

## Explicación
En ingeniería de software, los secretos incluyen contraseñas, claves API o tokens de autenticación. Nunca deben hardcodearse directamente en archivos fuente como .py, .js o .go, ya que estos suelen subirirse a controladores de versiones como Git. Si el repositorio es público, cualquiera puede robar tus credenciales. La práctica estándar es utilizar variables de entorno del sistema operativo. Estas se leen dinámicamente por la aplicación en tiempo de ejecución y no aparecen en el historial de commits. Herramientas como Docker o Kubernetes también gestionan secretos de forma segura. El objetivo es separar la lógica del negocio de los datos sensibles, asegurando que incluso si alguien accede al código, no pueda obtener las claves reales.

## Ejemplo (no ejecutado automáticamente)
Script en Python que lee una clave API desde una variable de entorno llamada 'API_KEY' y la utiliza para hacer una petición HTTP simulada, evitando escribir la clave directamente en el código.

```python
import os
import requests

clave = os.getenv('API_KEY')
if not clave:
    raise ValueError('Falta la variable de entorno API_KEY')
```
