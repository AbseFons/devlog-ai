## Objetivo
Comprender y aplicar los principios básicos de la normalización en bases de datos relacionales, específicamente enfocándose en la eliminación de dependencias funcionales parciales para garantizar la integridad de los datos desde el primer nivel de diseño.

## Explicación
La normalización es un proceso sistemático para organizar tablas y reducir la redundancia. En esta primera lección, nos centramos en la Primera Forma Normal (1FN). Una tabla cumple con la 1FN si cada celda contiene exactamente un valor atómico e indivisible, sin listas o conjuntos dentro de una sola columna. Esto implica que todas las filas deben ser únicas y que no existan grupos repetidos. Por ejemplo, evitar almacenar múltiples teléfonos en una sola celda separada por comas. Al cumplir la 1FN, aseguramos que la estructura base sea sólida antes de avanzar a formas normales superiores como la 2FN o 3FN, previniendo anomalías de inserción, actualización y borrado.

## Ejemplo (no ejecutado automáticamente)
Transformación de una tabla desnormalizada con múltiples valores en una columna a una estructura relacional válida en 1FN.

```sql
CREATE TABLE Clientes_Incorrecto (
  id INT,
  nombre VARCHAR(50),
  telefonos TEXT
);
INSERT INTO Clientes_Incorrecto VALUES (1, 'Ana', '555-0199, 555-0200');
CREATE TABLE Clientes_Correcto (
  id INT,
  nombre VARCHAR(50),
  telefono VARCHAR(20)
);
INSERT INTO Clientes_Correcto VALUES (1, 'Ana', '555-0199');
INSERT INTO Clientes_Correcto VALUES (1, 'Ana', '555-0200');
```
