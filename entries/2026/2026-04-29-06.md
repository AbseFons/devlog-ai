## Objetivo
Aprender a utilizar la sentencia 'with' en Python para automatizar el cierre de archivos, evitando errores comunes y garantizando que los recursos se liberen correctamente incluso si ocurren excepciones durante la lectura.

## Explicación
En Python, los context managers permiten ejecutar código dentro de un bloque específico asegurando que las tareas de limpieza, como cerrar un archivo, se realicen automáticamente. Al usar 'with open(...) as f:', el sistema gestiona el ciclo de vida del recurso. Si una excepción ocurre dentro del bloque, el archivo se cierra inmediatamente antes de propagar el error. Esto es crucial en ingeniería de software para prevenir fugas de recursos y mantener la integridad del sistema de archivos.

## Ejemplo (no ejecutado automáticamente)
Lectura segura de un archivo de configuración sin riesgo de dejarlo abierto si falla la lectura.

```python
with open('config.json', 'r') as f:
    datos = f.read()
    print(datos)
```
