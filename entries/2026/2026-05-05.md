## Objetivo
Dominar la sintaxis básica de Common Table Expressions para simplificar consultas complejas y mejorar la legibilidad del código SQL en entornos de producción.

## Explicación
Las Common Table Expressions o CTE permiten definir un subconjunto de datos temporalmente antes de ejecutar una consulta principal. A diferencia de las subconsultas anidadas, las CTE se leen de arriba a abajo, facilitando el mantenimiento. Son ideales para cálculos recursivos o cuando se necesita referenciar resultados intermedios múltiples veces. En esta primera entrega, exploraremos la estructura WITH y cómo encapsular lógica repetitiva sin sobrecargar la consulta final.

## Ejemplo (no ejecutado automáticamente)
Consulta que utiliza una CTE para filtrar empleados por departamento antes de calcular promedios salariales.

```sql
WITH alta_premio AS (
SELECT id, nombre FROM empleados WHERE salario > 5000)
SELECT * FROM alta_premio;
```
