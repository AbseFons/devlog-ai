## Objetivo
Aprender a utilizar bloques try-except para prevenir que el programa se detenga abruptamente ante errores comunes como la división por cero o acceso a claves inexistentes, mejorando la robustez del código.

## Explicación
En Python, las excepciones interrumpen la ejecución normal. El bloque try ejecuta el código de riesgo. Si ocurre un error específico, el bloque except correspondiente captura la excepción y permite ejecutar una alternativa segura. Esto evita que la aplicación se cierre inesperadamente. Es fundamental ser específico con los tipos de excepción para manejar diferentes escenarios sin ocultar errores graves. Este patrón es esencial en cualquier sistema de producción para garantizar una experiencia de usuario estable y proporcionar mensajes de error claros.

## Ejemplo (no ejecutado automáticamente)
Intenta dividir dos números; si el denominador es cero, muestra un mensaje amigable en lugar de lanzar un error fatal.

```python
num1 = 10
num2 = 0
try:
    resultado = num1 / num2
except ZeroDivisionError:
    print("No se puede dividir por cero.")
print(f"Resultado: {resultado}" if 'resultado' in locals() else "Operación fallida")
```
