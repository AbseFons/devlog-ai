## Objetivo
Comprender cómo restringir el acceso a recursos específicos asignando roles predefinidos como administrador, editor y lector dentro de una aplicación web.

## Explicación
El Control de Acceso Basado en Roles (RBAC) es un modelo fundamental para la seguridad informática. Consiste en definir roles con permisos específicos y asignar usuarios a esos roles. En este ejemplo, simularemos un sistema donde el rol 'admin' puede eliminar registros, mientras que 'editor' solo puede modificarlos y 'lector' únicamente consultarlos. La lógica se implementa verificando si el usuario actual posee el rol necesario antes de ejecutar la acción solicitada sobre los datos sensibles.

## Ejemplo (no ejecutado automáticamente)
Script en Python que simula una verificación de permisos para eliminar un registro, permitiendo solo al rol administrador.

```python
def verificar_permiso(rol_usuario, accion):
    if rol_usuario == 'admin' and accion == 'eliminar':
        return True
    return False

if verificar_permiso('editor', 'eliminar'):
    print("Acceso denegado")
```

## Ejercicio
Crea un script que defina tres roles y una función que determine si un usuario puede editar un archivo.

## Criterios de revisión
El código debe devolver true solo para el rol 'editor' o 'admin' al intentar editar, y false para cualquier otro caso.
