## Objetivo
Aprender a cancelar peticiones asíncronas en JavaScript para evitar bloqueos de UI y optimizar el rendimiento al manejar múltiples solicitudes simultáneas.

## Explicación
En aplicaciones modernas, las peticiones asíncronas pueden colgar si la interfaz se detiene. El AbortController permite cancelar una petición activa mediante su método abort(). Al llamar a este método, se dispara un evento de error en la promesa del fetch con el motivo 'AbortError'. Esto es crucial para limpiar recursos cuando el usuario navega rápidamente entre páginas o cambia de pestaña. La implementación estándar implica crear una instancia de AbortController, pasar su señal al fetch y manejar el error específico para no mostrar mensajes confusos al usuario.

## Ejemplo (no ejecutado automáticamente)
Se crea un controlador, se inicia una petición a una API pública con timeout simulado y se cancela manualmente tras 2 segundos.

```javascript
const controller = new AbortController();
fetch('https://jsonplaceholder.typicode.com/posts/1', { signal: controller.signal })
```
