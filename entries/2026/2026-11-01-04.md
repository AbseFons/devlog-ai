## Objetivo
Aprender a crear context managers personalizados que encapsulen lógica compleja, como cálculos matemáticos o gestión de recursos efímeros, utilizando closures para mantener estado sin variables globales.

## Explicación
Los context managers en Python permiten automatizar la limpieza de recursos. Hoy exploraremos cómo definir un contexto personalizado usando una clase con métodos __enter__ y __exit__, pero añadiendo un giro: utilizaremos un closure interno para encapsular el estado del recurso. Esto evita fugas de memoria o errores de estado al reiniciar el contexto. El ejemplo simula un cálculo numérico seguro donde el contexto asegura que los datos intermedios se liberan correctamente al salir, incluso si ocurre una excepción.

## Ejemplo (no ejecutado automáticamente)
Un context manager que calcula la raíz cuadrada segura y limpia variables temporales al finalizar el bloque.

```python
import math

class SafeRoot:
    def __init__(self, valor):
        self._valor = valor
        self._temp = None
    
    def __enter__(self):
        self._temp = self._valor ** 0.5
        return self._temp
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        if self._temp is not None:
            del self._temp
        return False
```
