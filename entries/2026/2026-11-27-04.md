## Objetivo
Comprender cómo el motor de JavaScript diferencia entre microtareas y macrotareas para determinar el orden de ejecución del hilo principal, optimizando así la respuesta del usuario.

## Explicación
El event loop procesa las tareas pendientes en una cola. Las microtareas (setImmediate, Promise.then) tienen prioridad sobre las macrotareas (setTimeout, DOM events). Cuando se ejecuta una función asíncrona, el motor verifica si hay microtareas pendientes; si existen, las ejecuta antes de pasar a la siguiente macrotarea. Esto es crucial para evitar bloqueos visuales: usar Promises para cálculos rápidos asegura que la interfaz se actualice lo antes posible, mientras que setTimeout permite planificar acciones futuras sin interferir con la fluidez inmediata del hilo principal.

## Ejemplo (no ejecutado automáticamente)
Ejemplo de renderizado diferido usando microtareas para asegurar que el DOM se actualice antes de ejecutar una lógica pesada.

```javascript
const btn = document.getElementById('btn');
btn.addEventListener('click', () => {
  Promise.resolve().then(() => console.log('DOM actualizado primero'));
  setTimeout(() => console.log('Tarea de timeout'), 0);
});
```
