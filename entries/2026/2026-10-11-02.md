## Objetivo
Comprender el funcionamiento básico de una tabla hash, su estructura de arrays indexados por claves calculadas mediante funciones hash, y cómo estas permiten acceso directo O(1) a los datos almacenados.

## Explicación
Una tabla hash es una estructura de datos que mapea claves a valores utilizando una función hash para calcular un índice en un array. Al insertar un elemento, la función procesa la clave (como una cadena o número) y devuelve un entero que representa la posición del bucket correspondiente. Esto permite búsquedas, inserciones y eliminaciones extremadamente rápidas, con complejidad promedio constante. Sin embargo, si múltiples claves generan el mismo índice, ocurren colisiones, las cuales deben resolverse mediante encadenamiento o direccionamiento abierto para mantener la integridad de los datos.

## Ejemplo (no ejecutado automáticamente)
Implementación básica en JavaScript que define una tabla hash simple usando un array y resuelve colisiones con listas enlazadas implícitas dentro del mismo array.

```javascript
const table = new Array(10).fill(null);
function insert(key, value) {
  const index = key % table.length;
  if (table[index] === null) {
    table[index] = { key, value };
  } else {
    // Manejo simple de colision: reemplazo o encadenamiento
    table[index].value = value;
  }
}
insert('apple', 'rojo');
insert('banana', 'amarillo');
```
