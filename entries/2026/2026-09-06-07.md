## Objetivo
Aprender a implementar lógica personalizada tras la creación de instancias en dataclasses, validando datos críticos como emails o rangos numéricos sin escribir código repetitivo.

## Explicación
Los dataclasses facilitan la definición rápida de estructuras de datos, pero carecen de validación nativa. Para añadir reglas post-creación, utilizamos el método especial __post_init__. Este se ejecuta automáticamente después de inicializar los campos definidos con @dataclass. Dentro, podemos verificar tipos o formatos; si fallan, lanzar ValueError. Es ideal para asegurar integridad antes de que la instancia entre en producción. Por ejemplo, validar que un email tenga '@' o que una edad esté entre 0 y 120.

## Ejemplo (no ejecutado automáticamente)
Definición de un dataclass con validación de email usando __post_init__

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class Usuario:
    nombre: str
    email: str
    edad: int

    def __post_init__(self):
        if '@' not in self.email:
            raise ValueError("Email inválido")
        if not 0 <= self.edad <= 120:
            raise ValueError("Edad fuera de rango")
```
