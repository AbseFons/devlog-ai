## Objetivo
Aprender a utilizar la biblioteca estándar argparse en Python para crear scripts que acepten argumentos desde la línea de comandos, facilitando la automatización y el uso profesional de herramientas de ingeniería.

## Explicación
La librería argparse permite definir parámetros como nombres de archivos o opciones booleanas. Al ejecutar un script con estos argumentos, Python genera automáticamente mensajes de ayuda y valida los datos ingresados. Esto evita errores comunes al pasar variables manualmente y hace que el código sea reutilizable en diferentes entornos sin modificar su lógica interna.

## Ejemplo (no ejecutado automáticamente)
Script que acepta una ruta de archivo y un modo de procesamiento para demostrar la captura de argumentos básicos.

```python
import argparse
parser = argparse.ArgumentParser()
parser.add_argument("archivo", help="Ruta del archivo a procesar")
args = parser.parse_args()
```

## Ejercicio
Crea un script llamado 'analizador.py' que acepte dos argumentos obligatorios: --input (ruta del archivo de entrada) y --output (ruta del archivo de salida). El programa debe imprimir en consola el mensaje 'Procesando [input] -> [output]' sin realizar operaciones reales de lectura o escritura.

## Criterios de revisión
El script debe ejecutarse correctamente con argumentos proporcionados, mostrar un mensaje de uso al no recibir parámetros y fallar con error claro si faltan los argumentos obligatorios.
