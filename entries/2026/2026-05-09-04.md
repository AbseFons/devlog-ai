## Objetivo
Comprender la función de los códigos de respuesta HTTP en el rango 1xx, conocidos como respuestas informativas, y su papel en guiar al cliente durante el procesamiento de una solicitud antes de recibir un resultado final.

## Explicación
Los códigos HTTP 1xx indican que el servidor está procesando la solicitud pero aún no ha completado la acción. El más común es el 100 Continue, que le dice al cliente que continúe enviando los datos del cuerpo de la petición. Otros incluyen 102 Processing, usado en operaciones largas como consultas a bases de datos complejas. Estos códigos son eficientes porque evitan que el cliente espere innecesariamente o envíe demasiados datos si la solicitud será rechazada posteriormente. Son esenciales para optimizar la comunicación entre clientes y servidores, especialmente en aplicaciones con tiempos de respuesta variables.

## Ejemplo (no ejecutado automáticamente)
Un script en Python que simula una petición HTTP incluyendo un encabezado de estado 100 Continue para mostrar cómo el cliente debe proceder tras recibir esta señal.

```python
import requests
response = requests.get('https://api.ejemplo.com/dato', headers={'X-Continue': '100'})
if response.status_code == 100:
    print('El servidor está procesando, continúa enviando datos.')
else:
    print(f'Estado recibido: {response.status_code}')
```
