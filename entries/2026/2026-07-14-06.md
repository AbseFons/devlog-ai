## Objetivo
Comprender la diferencia entre estructuras LIFO (pilas) y FIFO (colas), identificando sus aplicaciones prácticas como gestión de llamadas o historial de navegación.

## Explicación
Las pilas siguen el principio 'último en entrar, primero en salir', ideales para deshacer acciones. Las colas operan con 'primero en entrar, primero en salir', perfectas para tareas en espera. En Python, las listas nativas permiten simular ambas: usar append/pop para pilas y collections.deque para colas eficientes. Esta distinción es crucial para diseñar sistemas concorrentes o interfaces de usuario reactivas sin bloquear recursos.

## Ejemplo (no ejecutado automáticamente)
Implementación de una cola simple usando deque para simular un sistema de tickets en una cafetería.

```python
from collections import deque
cola = deque()
cola.append('Cliente A')
cola.append('Cliente B')
print(cola.popleft())
```
