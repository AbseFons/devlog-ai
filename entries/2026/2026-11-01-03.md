## Objetivo
Implementar un agente local que solicite y renueve credenciales cifradas automáticamente cada hora, eliminando la necesidad de almacenar claves estáticas en el código fuente o variables de entorno.

## Explicación
La gestión segura de secretos requiere evitar su almacenamiento permanente. En esta lección, utilizamos Vault Agent para inyectar credenciales efímeras directamente en el proceso de la aplicación. El agente se conecta a un servidor Vault, solicita un secreto específico y lo entrega al cliente mediante un canal seguro (socket o archivo). Al configurar una política de renovación automática, Vault reemplaza los archivos con nuevas credenciales antes de que caduquen, manteniendo la aplicación siempre activa sin intervención manual. Este enfoque reduce la superficie de ataque y cumple con principios de seguridad como el mínimo privilegio y la rotación continua.

## Ejemplo (no ejecutado automáticamente)
Script de bash que inicia un agente Vault local para obtener un token de acceso renovable automáticamente cada hora.

```bash
vault agent -config=agent.hcl
# El archivo agent.hcl contiene el endpoint del servidor y la ruta del secreto
```

## Ejercicio

## Criterios de revisión
El agente debe conectarse exitosamente, descargar el secreto inicial y generar un nuevo archivo con credenciales renovadas sin detener la aplicación. No deben existir credenciales estáticas en el código.
