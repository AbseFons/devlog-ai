## Objetivo
El desarrollador comprenderá la sintaxis básica de importación dinámica en JavaScript, diferenciando entre módulos ES y CommonJS, y aplicará el patrón para reutilizar lógica en archivos distintos sin efectos secundarios inmediatos.

## Explicación
Los módulos ES modernos utilizan la palabra clave 'import' para traer dependencias directamente al alcance del script. A diferencia de 'require()' de CommonJS, que se ejecuta síncronamente y bloquea el hilo, 'import' es estático y se resuelve en tiempo de compilación. Esto permite una carga más eficiente y un análisis de dependencias por parte de herramientas como Webpack o Vite. En este contexto, la importación dinámica facilita la creación de componentes reutilizables donde la lógica de negocio se encapsula en archivos separados, mejorando la mantenibilidad del código.

## Ejemplo (no ejecutado automáticamente)
```javascript
// utils.js: Función auxiliar para formatear fechas
export function formatearFecha(fecha) {
  return new Date(fecha).toLocaleDateString();
}

// app.js: Punto de entrada que importa la utilidad
import { formatearFecha } from './utils.js';

const hoy = formatearFecha(new Date());
console.log('Hoy es:', hoy);
```
