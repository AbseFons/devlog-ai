## Objetivo
Aprender a validar datos y ejecutar lógica tras la creación automática de instancias en dataclasses, asegurando integridad sin código redundante.

## Explicación
Los dataclasses generan automáticamente el constructor y métodos __init__, pero permiten inyectar comportamiento personalizado mediante __post_init__. Este método se ejecuta después de crear los atributos. Útil para validar que un campo 'edad' no sea negativo o calcular propiedades derivadas como 'mayor_de_edad'. Evita escribir setters manuales. Ideal para modelos de dominio donde las reglas de negocio dependen de múltiples campos.

## Ejemplo (no ejecutado automáticamente)
Clase Usuario con validación automática de edad y cálculo de estado civil basado en años.

```python
@dataclass
class Usuario:
    def __post_init__(self):
        if self.edad < 0:
            raise ValueError('Edad inválida')
        self.estado = 'adulto' if self.edad >= 18 else 'menor'
```
