## Objetivo
Comprender la asincronía en JavaScript mediante promesas, evitando callbacks anidados y escribiendo código legible con async/await para operaciones de red o disco.

## Explicación
En JavaScript moderno, las promesas gestionan tareas asíncronas sin bloquear el hilo principal. Evitan el 'callback hell' al permitir encadenar operaciones. Con async/await, se escribe código secuencial que parece síncrono, mejorando la mantenibilidad. Este enfoque es esencial para APIs REST o llamadas a bases de datos.

## Ejemplo (no ejecutado automáticamente)
Simulación de una llamada asíncrona a un servicio externo usando fetch y manejo de errores con try-catch.

```javascript
const obtenerDatos = async () => {
  const respuesta = await fetch('https://jsonplaceholder.typicode.com/posts/1');
  if (!respuesta.ok) throw new Error('Error en la red');
  return respuesta.json();
};
```

## Ejercicio
Crea una función asíncrona que simule una llamada a API con setTimeout de 1 segundo. Maneja errores si el tiempo excede los 2 segundos y devuelve un mensaje de éxito o fallo.

## Criterios de revisión
El código debe usar async/await, incluir try-catch para errores, no contener callbacks anidados y tener al menos dos líneas de lógica asíncrona.
