## Objetivo
Comprender la organización fundamental de un repositorio Git, identificando las carpetas .git, src y tests como pilares del control de versiones en proyectos modernos.

## Explicación
Un repositorio Git se estructura típicamente con una carpeta oculta llamada .git que almacena el historial completo, los metadatos y la configuración del proyecto. Dentro del árbol de trabajo visible, es común encontrar una carpeta src para el código fuente principal y otra dedicada a tests para asegurar la calidad. Esta separación lógica facilita la navegación, permite un flujo de trabajo eficiente entre desarrolladores y ayuda a mantener el código limpio al aislar las pruebas del código de producción. Entender esta jerarquía es esencial antes de realizar operaciones como commits o ramas.

## Ejemplo (no ejecutado automáticamente)
Estructura de directorios típica en un nuevo proyecto Git con separación clara entre código fuente y pruebas.

```bash
mkdir -p mi-proyecto/src
mkdir -p mi-proyecto/tests
cd mi-proyecto
```

## Criterios de revisión
El directorio raíz debe contener exactamente dos subdirectorios: 'src' y 'tests'. Ambos deben existir como carpetas válidas. Deben existir los archivos 'main.py' en la ruta correcta y 'test_main.py' en su ubicación correspondiente.
