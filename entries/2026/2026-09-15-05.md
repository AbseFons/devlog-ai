## Objetivo
Aprender a cancelar peticiones asíncronas en JavaScript para evitar bloqueos de interfaz y optimizar el rendimiento al manejar múltiples solicitudes simultáneas.

## Explicación
En aplicaciones modernas, las peticiones fetch pueden tardar mucho. Si el usuario cambia de página o cancela una acción, la petición anterior sigue ejecutándose en segundo plano, desperdiciando recursos. La solución es usar AbortController junto con fetch. Al crear un controlador y pasar su señal abort a la opción de fetch, podemos cancelar la solicitud enviando una señal específica. Esto lanza un error nativo en el bloque catch, permitiendo limpiar estados y liberar memoria inmediatamente.

## Ejemplo (no ejecutado automáticamente)
Se crea un controlador, se inicia una petición lenta simulada y se cancela tras 500ms para demostrar la limpieza automática.

```javascript
const controller = new AbortController();
fetch('https://jsonplaceholder.typicode.com/posts/1', { signal: controller.signal })
```

## Ejercicio
Crea una función que lance una petición fetch a un endpoint público. Dentro de la función, programa un temporizador que llame a controller.abort() después de 2 segundos para simular una cancelación por parte del usuario.

## Criterios de revisión
El código debe importar o instanciar correctamente AbortController, pasar el objeto signal en las opciones de fetch y manejar el evento de error generado por la cancelación sin mostrar alertas al usuario.
