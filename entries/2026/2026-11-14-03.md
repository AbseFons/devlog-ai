## Objetivo
Aprender a crear clases contextuales personalizadas que implementen el método __enter__ y __exit__ para automatizar la limpieza de recursos o cambios de estado dentro de bloques 'with', mejorando la robustez del código sin sobrecargar la lógica de negocio.

## Explicación
Los gerenciotres de contexto permiten encapsular operaciones de entrada y salida. Para crear uno propio, define una clase con los métodos __enter__ (ejecutado al entrar) y __exit__ (al salir). El método __exit__ recibe excepciones como argumento; si retorna True, la excepción se suprime. Este patrón es vital para gestionar temporizadores de prueba, cambiar el directorio de trabajo o establecer conexiones efímeras. Al usar 'with', garantizas que la lógica de limpieza se ejecute incluso ante errores, manteniendo el entorno del programa estable y predecible sin necesidad de bloques try-except explícitos en cada punto de uso.

## Ejemplo (no ejecutado automáticamente)
Clase ContextoTemporizador que limita la ejecución de un bloque a 5 segundos. Si se excede, lanza una excepción y limpia el recurso.

```python
import time

class ContextoTemporizador:
    def __enter__(self):
        self.inicio = time.time()
        return self
    
    def __exit__(self, exc_type, exc_val, exc_tb):
        if time.time() - self.inicio > 5:
            raise TimeoutError("Tiempo agotado")
        return True
```
