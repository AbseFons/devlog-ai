## Objetivo
Comprender el mecanismo básico de las tablas hash para almacenamiento eficiente de datos mediante funciones que mapean claves a índices, optimizando la búsqueda en tiempo constante.

## Explicación
Una tabla hash es una estructura de datos que permite acceso directo a registros usando una función hash. Esta función transforma una clave arbitraria, como un nombre o ID, en un índice numérico dentro de un array. El objetivo principal es lograr tiempos de inserción y búsqueda O(1). Sin embargo, si dos claves diferentes generan el mismo índice, ocurre una colisión. Existen estrategias para resolver esto, como encadenamiento o direccionamiento abierto. En este nivel inicial, nos enfocamos en cómo la función hash distribuye los datos y por qué elegir un tamaño de tabla adecuado es crucial para minimizar las colisiones y mantener el rendimiento del sistema.

## Ejemplo (no ejecutado automáticamente)
Implementación básica de una tabla hash usando un array simple y una función hash que toma el módulo del tamaño del array.

```javascript
const size = 10;
const table = new Array(size).fill(null);
function hash(key) { return key.length % size; }
table[hash('usuario')] = 'Ana';
table[hash('admin')] = 'Carlos';
```
