## Objetivo
Comprender por qué almacenar contraseñas en texto plano es inseguro y cómo las funciones hash unidireccionales protegen los datos de usuarios ante filtraciones, estableciendo la base para prácticas de seguridad robustas.

## Explicación
Almacenar contraseñas en texto plano expone a los sistemas a robos masivos. Si una base de datos se filtra, los atacantes obtienen credenciales válidas inmediatamente. El hashing transforma la contraseña en una cadena alfanumérica única e irreversible mediante funciones criptográficas como bcrypt o Argon2. A diferencia del cifrado reversible, el hash no puede descifrarse; solo se verifica si coincide con el original. Esto obliga a los atacantes a realizar costosos ataques de fuerza bruta o diccionario contra cada hash individualmente. Además, el uso de 'salts' (valores aleatorios únicos por usuario) evita que hashes idénticos revelen contraseñas idénticas, neutralizando ataques precalculados con tablas rainbow.

## Ejemplo (no ejecutado automáticamente)
Implementación básica en Python utilizando la librería bcrypt para generar un hash seguro de una contraseña de ejemplo.

```python
import bcrypt
password = 'MiContraseñaSegura123'
hash_password = bcrypt.hashpw(password.encode('utf-8'), bcrypt.gensalt())
print(hash_password.decode('utf-8'))
```
