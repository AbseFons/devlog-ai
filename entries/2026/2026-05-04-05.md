## Objetivo
Comprender los fundamentos de la paginación en APIs REST para manejar grandes volúmenes de datos eficientemente, evitando saturar la memoria del cliente y optimizando el rendimiento de la aplicación mediante el uso de parámetros estándar.

## Explicación
Las APIs modernas a menudo devuelven conjuntos de datos extensos que no caben en una sola respuesta. La paginación divide estos datos en bloques manejables, conocidos como páginas. Los parámetros comunes incluyen 'page' o 'offset' para indicar el punto de inicio y 'limit' o 'per_page' para definir la cantidad de registros por página. Es crucial que la API devuelva metadatos en cada respuesta, como el número total de páginas, el total de elementos y los indicadores de navegación (siguiente/anterior). Esto permite al cliente construir interfaces de usuario fluidas sin necesidad de cargar todo el dataset de una vez, mejorando significativamente la experiencia del usuario final y la estabilidad del sistema.

## Ejemplo (no ejecutado automáticamente)
Solicitud GET a una API ficticia de usuarios con parámetros de paginación para obtener solo los primeros 10 registros.

```bash
curl -X GET "https://api.ejemplo.com/usuarios?page=1&limit=10" \
  -H "Accept: application/json"
```
