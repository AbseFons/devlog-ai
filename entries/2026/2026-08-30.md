## Objetivo
Al finalizar esta lección, el desarrollador será capaz de implementar una función de búsqueda binaria eficiente en arrays ordenados, comprendiendo la reducción del espacio de búsqueda a O(log n) y aplicándola correctamente para encontrar índices o determinar rangos.

## Explicación
La búsqueda binaria es un algoritmo fundamental que opera sobre datos ordenados. A diferencia de la búsqueda lineal, divide el rango de búsqueda por la mitad en cada iteración, descartando siempre la mitad donde no puede residir el elemento buscado. Esto garantiza una complejidad temporal logarítmica O(log n). El núcleo del algoritmo reside en calcular el índice medio y comparar el valor en ese punto con la meta: si coinciden, se devuelve el índice; si el valor es mayor, se busca en la mitad izquierda; si es menor, en la derecha. Es crucial actualizar los límites inferior y superior correctamente para evitar bucles infinitos o errores de indexación.

## Ejemplo (no ejecutado automáticamente)
```python
def buscar_binario(arr, objetivo):
    izq, der = 0, len(arr) - 1
    while izq <= der:
        mid = (izq + der) // 2
        if arr[mid] == objetivo:
            return mid
        elif arr[mid] < objetivo:
            izq = mid + 1
        else:
            der = mid - 1
    return -1

datos = [3, 5, 8, 9, 12, 16]
indice = buscar_binario(datos, 12)
print(f"Elemento encontrado en el índice: {indice}" if indice != -1 else "No encontrado")
```
