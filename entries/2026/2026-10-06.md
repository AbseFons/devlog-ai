## Objetivo
Comprender la inyección de dependencias como patrón para desacoplar componentes, facilitando pruebas unitarias y mantenimiento del código en aplicaciones modernas.

## Explicación
La inyección de dependencias es un patrón de diseño que permite pasar las dependencias de una clase desde el exterior en lugar de crearlas internamente. Esto promueve la inversión de control (IoC), donde el contenedor o el constructor se encargan de instanciar los objetos necesarios. Al hacerlo, el código se vuelve más modular y fácil de probar, ya que podemos inyectar 'mocks' o stubs fácilmente durante las pruebas unitarias. Este enfoque reduce la acoplamiento fuerte entre clases, mejorando la reutilización del código y la claridad arquitectónica en proyectos de gran escala.

## Ejemplo (no ejecutado automáticamente)
Clase Servicio con constructor que recibe un repositorio inyectado para realizar operaciones de datos.

```java
public class Servicio {
    private final Repositorio repositorio;

    public Servicio(Repositorio repositorio) {
        this.repositorio = repositorio;
    }
}
```
