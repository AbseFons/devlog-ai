## Objetivo
Comprender la sintaxis y utilidad básica de las Common Table Expressions para simplificar consultas complejas mediante la definición temporal de subconsultas legibles.

## Explicación
Las Common Table Expressions o CTE permiten definir una tabla temporal nombrada que existe solo durante la ejecución de una consulta. Esto mejora significativamente la legibilidad al evitar anidaciones excesivas de subconsultas. Sintácticamente, se define con la palabra clave WITH seguida del nombre y la consulta entre paréntesis. Posteriormente, esta tabla puede ser referenciada en un SELECT, INSERT o DELETE. Es ideal para cálculos recursivos o cuando se necesita desglosar una lógica compleja en pasos lógicos claros.

## Ejemplo (no ejecutado automáticamente)
Consulta que calcula el total de ventas por categoría usando una CTE intermedia para agrupar datos antes del select final.

```sql
WITH VentasPorCategoria AS (
    SELECT Categoria, SUM(Monto) as TotalVentas
    FROM Facturas
    GROUP BY Categoria
)
SELECT * FROM VentasPorCategoria ORDER BY TotalVentas DESC;
```
