## Objetivo
Aprender a estructurar objetos complejos con diccioniones anidados y listas para generar un JSON válido que represente una jerarquía de usuarios y sus roles asociados.

## Explicación
En esta lección exploramos la serialización de estructuras de datos complejas en Python. A diferencia de los casos simples, aquí manejaremos diccionarios que contienen otras listas o diccionarios, simulando un perfil de usuario con múltiples permisos. La función json.dumps() convierte automáticamente estos objetos nativos en una cadena JSON legible. Es crucial recordar que las claves deben ser cadenas y que el orden de los elementos en Python 3.7+ se preserva, lo cual es útil para la consistencia del output. Este enfoque permite modelar datos reales de APIs REST.

## Ejemplo (no ejecutado automáticamente)
Creación de un objeto usuario con lista de roles anidados y conversión a JSON

```python
import json
usuario = {
    "nombre": "Ana",
    "roles": ["admin", "editor"]
}
print(json.dumps(usuario, indent=2))
```
