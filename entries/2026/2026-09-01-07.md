## Objetivo
Al finalizar esta lección, el desarrollador podrá implementar una variante de búsqueda binaria que identifica y maneja segmentos ordenados dentro de un array parcialmente desordenado, logrando recuperar elementos específicos sin asumir un orden global estricto en toda la estructura de datos.

## Explicación
La búsqueda binaria clásica falla si el array no está totalmente ordenado. Esta microlección aborda un caso donde solo subsegmentos consecutivos están ordenados. La estrategia implica verificar primero si el punto medio y sus vecinos forman una secuencia creciente. Si la clave objetivo es menor que el inicio del segmento ordenado, se busca en la izquierda; si es mayor que el final, se busca a la derecha. De lo contrario, se aplica la lógica estándar de reducción del espacio de búsqueda dentro del segmento válido. Este enfoque permite recuperar datos en estructuras con ruido controlado o rotaciones parciales, ampliando la utilidad del algoritmo más allá de los casos ideales.

## Ejemplo (no ejecutado automáticamente)
```python
def buscar_en_segmento_ordenado(arr, objetivo):
    if not arr: return None
    izq, der = 0, len(arr) - 1
    while izq <= der:
        medio = (izq + der) // 2
        # Verificar si el segmento [medio-1, medio+1] está ordenado
        if medio > 0 and arr[medio-1] < arr[medio] and arr[medio] < arr[medio+1]:
            if arr[medio] == objetivo: return medio
            elif objetivo < arr[medio]: der = medio - 1
            else: izq = medio + 1
        elif medio > 0 and arr[medio-1] > arr[medio] and arr[medio] > arr[medio+1]:
            # Segmento descendente, buscar solo si la clave está en el rango
            if arr[medio-1] <= objetivo <= arr[medio+1]:
                if arr[medio] == objetivo: return medio
                elif objetivo < arr[medio]: der = medio - 1
                else: izq = medio + 1
        # Si no es un segmento ordenado ni descendente, ajustar límites genéricamente
        elif arr[medio] == objetivo: return medio
        elif objetivo < arr[medio]: der = medio - 1
        else: izq = medio + 1
    return None
```
