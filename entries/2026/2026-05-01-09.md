## Objetivo
Aprender a implementar restricciones CHECK para rangos válidos y UNIQUE para integridad referencial, asegurando la calidad de los datos desde el diseño de tablas.

## Explicación
Las restricciones CHECK y UNIQUE son fundamentales para mantener la integridad de los datos. CHECK permite definir condiciones lógicas que una columna debe cumplir, como un rango de edad entre 18 y 65. UNIQUE garantiza que no haya duplicados en una columna o conjunto de columnas, ideal para identificadores únicos sin necesidad de ser claves primarias. Al combinar ambas, se logra un control estricto sobre la entrada de información.

## Ejemplo (no ejecutado automáticamente)
Creación de una tabla de empleados con validación de edad y nombre único.

```sql
CREATE TABLE Empleados (
  id INT PRIMARY KEY,
  nombre VARCHAR(100) UNIQUE,
  edad INT CHECK (edad >= 18 AND edad <= 65)
);
```
