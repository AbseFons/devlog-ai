## Objetivo
Aprender a definir clases con atributos automáticos, métodos especiales y validaciones básicas para simplificar el código de datos estructurales en aplicaciones Python modernas.

## Explicación
Los dataclasses permiten crear clases que se centran únicamente en los datos. Al usar la función @dataclass, Python genera automáticamente el __init__, __repr__ y otros métodos útiles. Esto reduce drásticamente la boilerplate code. Ideal para modelos de datos simples o DTOs. Se pueden añadir parámetros como field(default=...) para valores por defecto o metadata para validaciones. Es una herramienta estándar desde Python 3.7, integrada en el lenguaje sin necesidad de librerías externas.

## Ejemplo (no ejecutado automáticamente)
Definición de un dataclass para representar un usuario con nombre y edad, incluyendo un campo opcional con valor por defecto.

```python
from dataclasses import dataclass

@dataclass
class Usuario:
    nombre: str
    edad: int = 18
```
