## Objetivo
Aprender a utilizar context managers y bloqueos de escritura para garantizar la integridad de datos al ejecutar operaciones complejas en bases de datos SQLite mediante Python.

## Explicación
En SQLite, las transacciones son esenciales para mantener la consistencia cuando se realizan múltiples cambios. Python ofrece un contexto manager nativo que maneja automáticamente el bloqueo de escritura y el commit o rollback. Esto previene errores comunes como lecturas sucias o corrupción de datos. Al usar 'with', el sistema asegura que los recursos se liberen correctamente, incluso si ocurre una excepción durante la ejecución del bloque. Este enfoque es ideal para aplicaciones que requieren fiabilidad en operaciones de persistencia.

## Ejemplo (no ejecutado automáticamente)
Ejecución segura de inserción y actualización dentro de una transacción atómica.

```python
with sqlite3.connect('db.db') as conn:
    cursor = conn.cursor()
    cursor.execute('INSERT INTO usuarios (nombre) VALUES (?)', ('Ana',))
    cursor.execute('UPDATE usuarios SET edad = 25 WHERE nombre = ?', ('Ana',))
```
