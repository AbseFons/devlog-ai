## Objetivo
Comprender por qué almacenar contraseñas en texto plano es inseguro y cómo las funciones hash con sal protegen la integridad de los datos de autenticación en sistemas modernos.

## Explicación
Almacenar contraseñas en texto plano expone a los usuarios a robos masivos si se filtra la base de datos. La solución estándar es usar funciones hash criptográficas como bcrypt o Argon2, que son lentas por diseño para dificultar ataques de fuerza bruta. Es crucial añadir una 'sal' (salt) aleatoria única por usuario antes de hashear. Esto impide que atacantes utilicen tablas arcoiris precalculadas para descifrar múltiples cuentas simultáneamente. Nunca uses MD5 o SHA-1 para contraseñas, ya que son demasiado rápidos y vulnerables a colisiones.

## Ejemplo (no ejecutado automáticamente)
Generación de un hash seguro con sal usando la librería estándar de Python (hashlib) simulando el proceso de almacenamiento en base de datos.

```python
import hashlib
import os
sal = os.urandom(16)
contrasena = 'mi_password_secreta'
vector = sal + contrasena.encode()
hash_final = hashlib.sha256(vector).hexdigest()
```
