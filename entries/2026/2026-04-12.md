## Objetivo
Comprender cómo la concatenación insegura permite inyectar comandos maliciosos y aprender a utilizar parámetros para construir consultas robustas que protejan los datos de la base de datos contra ataques comunes.

## Explicación
La inyección SQL ocurre cuando se insertan entradas no filtradas directamente en una consulta. Si un atacante controla el valor de 'usuario', puede alterar la lógica de la sentencia. Por ejemplo, ingresar "admin'--" cierra la cita y comenta el resto de la consulta, logrando acceso sin contraseña. La defensa fundamental es usar parámetros o prepared statements. Esto separa la estructura de la consulta del dato, obligando a la base de datos a tratar cualquier entrada como texto literal, neutralizando así intentos de manipulación sintáctica.

## Ejemplo (no ejecutado automáticamente)
Consulta segura usando parámetros en Python para evitar inyección SQL al buscar un usuario.

```python
import sqlite3
conn = sqlite3.connect('db.sqlite')
cursor = conn.cursor()
usuario = "admin"
query = "SELECT * FROM usuarios WHERE nombre = ?"
cursor.execute(query, (usuario,))
```
