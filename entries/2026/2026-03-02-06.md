## Objetivo
Comprender la función del rate limiting para proteger recursos compartidos y garantizar equidad en el acceso a servicios API, evitando saturación por peticiones excesivas.

## Explicación
El rate limiting es un mecanismo de control que restringe el número de solicitudes que un cliente puede realizar a una API en un periodo determinado. Su propósito principal es prevenir abusos, ataques DDoS o sobrecarga del servidor, asegurando que todos los usuarios tengan acceso justo al servicio. Se implementa comúnmente mediante tokens deslizantes, ventanas fijas o algoritmos basados en IP y usuario. Sin esta medida, una sola aplicación mal configurada podría consumir toda la capacidad de la API, dejando a otros sin servicio.

## Ejemplo (no ejecutado automáticamente)
Implementación básica de rate limiting usando middleware en Node.js para contar peticiones por cliente.

```javascript
const express = require('express');
const app = express();
let requestCount = 0;
app.use((req, res, next) => {
  requestCount++;
  if (requestCount > 100) return res.status(429).send('Too Many Requests');
  next();
});
```
