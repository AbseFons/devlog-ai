## Objetivo
Aprender a crear la primera prueba unitaria en Python utilizando el framework estándar unittest, definiendo una clase de prueba y un método que verifique la suma correcta de dos números.

## Explicación
En esta microlección exploraremos los fundamentos de las pruebas unitarias con unittest. Crearemos una función simple llamada sumar que devuelve la suma de dos enteros. Luego, definiremos una clase heredada de unittest.TestCase. Dentro de esta clase, implementaremos un método llamado test_suma_correcta que debe comenzar por 'test_'. Este método usará assertEqual para comparar el resultado real de sumar(2, 3) con el valor esperado 5. Si los valores coinciden, la prueba pasa; de lo contrario, falla. Esta estructura modular permite ejecutar pruebas individuales y aislar errores en el código fuente.

## Ejemplo (no ejecutado automáticamente)
Definición de una función suma y una clase de prueba que verifica si la suma de dos números es correcta utilizando assertEqual.

```python
def sumar(a, b):
    return a + b

class TestSuma(unittest.TestCase):
    def test_suma_correcta(self):
        self.assertEqual(sumar(2, 3), 5)
```
