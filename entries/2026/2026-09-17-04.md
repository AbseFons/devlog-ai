## Objetivo
Comprender la organización básica de un repositorio Git, identificando el directorio raíz, el archivo .git oculto y los archivos de configuración esenciales como .gitignore para gestionar exclusiones desde el inicio del proyecto.

## Explicación
Un repositorio Git se estructura en torno a un directorio raíz que contiene todos los archivos del proyecto. Dentro de este, existe un subdirectorio oculto llamado '.git' que almacena la base de datos interna con el historial de cambios, ramas y referencias. Este directorio no debe ser modificado manualmente por el desarrollador. Además, es crucial incluir un archivo '.gitignore' en la raíz para especificar patrones de archivos (como nod_modules o logs) que Git debe ignorar, evitando contaminar el historial con datos innecesarios o sensibles. Esta separación entre contenido del proyecto y metadatos del control de versiones es fundamental para mantener repositorios limpios y eficientes.

## Ejemplo (no ejecutado automáticamente)
Creación de la estructura inicial de un repositorio Git con archivos de configuración básicos.

```bash
# Inicializar el repositorio
git init
# Crear archivo .gitignore para ignorar nodulos y logs
echo 'node_modules/' > .gitignore
echo '*.log' >> .gitignore
```

El repositorio debe estar inicializado correctamente, mostrando la carpeta oculta .git al listar el contenido. El archivo .gitignore debe existir en la raíz y contener exactamente las dos líneas especificadas sin caracteres adicionales.
