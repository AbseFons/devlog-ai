## Objetivo
Comprender y aplicar los principios básicos de la normalización en bases de datos relacionales, específicamente la Primera Forma Normal (1FN), para eliminar grupos repetidos y garantizar que cada columna contenga valores atómicos únicos.

## Explicación
La normalización es el proceso de organizar una base de datos para reducir la redundancia y mejorar la integridad. La Primera Forma Normal (1FN) exige que cada celda de la tabla contenga exactamente un valor único, eliminando arrays o grupos repetidos en una sola columna. Por ejemplo, si una tabla 'Clientes' tiene una columna 'Hobbies' con múltiples valores separados por comas, no cumple la 1FN. Para corregirlo, debemos crear una tabla relacionada donde cada fila represente un solo hobby. Esto transforma datos ambiguos en una estructura relacional clara, optimizando consultas y facilitando el mantenimiento del esquema sin perder información.

## Ejemplo (no ejecutado automáticamente)
Transformación de una tabla con columnas repetidas a una estructura normalizada usando SQL INSERT para poblar la tabla desnormalizada y luego un SELECT JOIN para visualizar la corrección.

```sql
CREATE TABLE ClientesDesnormalizados (id INT, nombre VARCHAR(50), hobbies TEXT);
INSERT INTO ClientesDesnormalizados VALUES (1, 'Ana', 'Lectura,Cocina');
SELECT c.nombre, h.hobby FROM ClientesDesnormalizados c
JOIN UNNEST(string_to_array(c.hobbies, ',')) AS h ON true;
```
