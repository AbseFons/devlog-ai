## Objetivo
Comprender cómo aislar la lógica de interfaz del usuario de la lógica de negocio para mejorar el mantenimiento y la escalabilidad del sistema.

## Explicación
En este módulo exploramos la separación de responsabilidades aplicando el patrón MVC. La capa de presentación se encarga exclusivamente de capturar datos, validar formatos básicos y renderizar respuestas al cliente. Debe evitar cualquier lógica compleja o acceso directo a bases de datos. Al delegar estas tareas a capas inferiores, garantizamos que cambios en la interfaz no rompan la funcionalidad central. Este enfoque reduce acoplamientos innecesarios y facilita pruebas unitarias aisladas.

## Ejemplo (no ejecutado automáticamente)
Un controlador simple que recibe una solicitud HTTP, valida el formato de entrada y delega el procesamiento a un servicio externo sin realizar consultas directas a la base de datos.

```javascript
async function handleRequest(req) {
  const data = await validateInput(req.body);
  return { status: 'ok', message: 'Datos recibidos' };
}
```

## Ejercicio
Crea una función que acepte un objeto JSON con campos 'nombre' y 'edad'. Valida que 'nombre' no esté vacío y que 'edad' sea un número positivo. Si la validación falla, devuelve un error específico; si pasa, retorna el objeto original sin modificarlo.

## Criterios de revisión
El código debe validar solo tipos de datos básicos sin usar librerías externas. No debe acceder a bases de datos ni realizar operaciones de red. Debe manejar errores de forma explícita y clara.
