## Objetivo
Comprender cómo la concatenación insegura permite inyectar comandos maliciosos en bases de datos y aprender a prevenirlo usando parámetros, una práctica esencial para proteger aplicaciones web.

## Explicación
La inyección SQL ocurre cuando entradas del usuario se insertan directamente en consultas sin validación. Un atacante puede alterar la lógica de la consulta para filtrar datos o ejecutar comandos no autorizados. La solución fundamental es utilizar parámetros o prepared statements. Esto separa el código SQL de los datos, asegurando que el motor de base de datos interprete siempre las entradas como valores literales y nunca como parte de la sintaxis del comando, bloqueando así cualquier intento de manipulación maliciosa.

## Ejemplo (no ejecutado automáticamente)
Consulta segura en Python usando parámetros para evitar inyección SQL al buscar un usuario por nombre.

```python
import sqlite3
conn = sqlite3.connect('db.sqlite')
cursor = conn.cursor()
usuario = input("Nombre:")
query = "SELECT * FROM usuarios WHERE nombre = ?"
cursor.execute(query, (usuario,))
```
