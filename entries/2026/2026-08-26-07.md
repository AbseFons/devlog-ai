## Objetivo
El desarrollador identificará cuándo usar context managers para gestionar recursos como archivos o conexiones, evitando fugas de memoria y errores por cierre incompleto en Python.

## Explicación
En Python, los context managers permiten automatizar la limpieza de recursos al finalizar un bloque de código. La estructura 'with' asegura que el método __exit__ se ejecute incluso si ocurre una excepción. Esto es crucial para archivos, bases de datos o sockets. En lugar de llamar manualmente a close(), delegamos esta tarea al objeto. Python 3.10+ permite la sintaxis 'with ... as ...' para asignar variables al recurso dentro del bloque. Este patrón reduce código repetitivo y aumenta la robustez del software frente a fallos inesperados durante la ejecución.

## Ejemplo (no ejecutado automáticamente)
```python
import os

def leer_archivo_seguro(ruta):
    try:
        with open(ruta, 'r', encoding='utf-8') as archivo:
            contenido = archivo.read()
            return contenido
    except FileNotFoundError:
        print(f"El archivo {ruta} no existe.")
        return None

resultado = leer_archivo_seguro('datos/config.json')
if resultado is not None:
    print("Contenido cargado correctamente.")
```
