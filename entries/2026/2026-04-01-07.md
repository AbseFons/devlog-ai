## Objetivo
Comprender la lógica recursiva del algoritmo Merge Sort, su estrategia de dividir para conquistar y cómo fusionar subarrays ordenados eficientemente en un solo paso.

## Explicación
El ordenamiento por mezcla divide el array original hasta obtener sublistas de un elemento. Luego, fusiona pares de sublistas ordenadas recursivamente. La función merge compara los elementos más pequeños de cada sublista y construye una nueva lista ordenada. Este enfoque garantiza un tiempo complejo O(n log n) en todos los casos, independientemente del orden inicial de los datos. Es ideal para grandes volúmenes de información donde la estabilidad del algoritmo es crucial.

## Ejemplo (no ejecutado automáticamente)
Implementación recursiva que divide el array y fusiona subarrays ordenados usando dos punteros.

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```
