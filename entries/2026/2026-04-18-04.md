## Objetivo
Comprender la definición de árbol binario, sus nodos raíz e hijos, y cómo realizar recorridos básicos como preorden para extraer información estructurada de manera eficiente.

## Explicación
Un árbol binario es una estructura jerárquica donde cada nodo tiene a lo sumo dos hijos: izquierdo y derecho. La raíz es el punto de entrada. Para navegar, utilizamos recursión o pilas. El recorrido preorden (Raíz-Left-Right) es útil para copiar la estructura del árbol. Imagina un sistema de archivos donde cada carpeta puede tener subcarpetas a la izquierda y derecha. Al visitar primero la carpeta actual, luego sus subcarpetas en orden específico, obtenemos una lista plana que representa todo el contenido. Este enfoque permite procesar datos jerárquicos sin necesidad de cargar toda la estructura en memoria simultáneamente.

## Ejemplo (no ejecutado automáticamente)
Implementación de un árbol binario simple con nodos y un recorrido preorden en JavaScript para listar los valores.

```javascript
class Nodo {
  constructor(val) { this.val = val; this.izq = null; this.der = null; }
}
const arbol = new Nodo(1);
arbol.izq = new Nodo(2); arbol.der = new Nodo(3);
```

## Ejercicio
Crea un árbol binario con la raíz valor 10, hijo izquierdo 5 y derecho 15. Luego, escribe una función recursiva que imprima los valores en orden preorden.

## Criterios de revisión
El código debe definir correctamente la clase Nodo, instanciar el árbol con los valores especificados e implementar la lógica de recorrido sin errores de sintaxis.
