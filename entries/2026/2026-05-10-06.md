## Objetivo
Comprender y aplicar los principios básicos de la primera forma normal en bases de datos relacionales para eliminar grupos repetidos y asegurar que cada columna contenga valores atómicos, mejorando así la integridad estructural de los datos.

## Explicación
La normalización es el proceso de organizar una base de datos para reducir la redundancia y mejorar la integridad. La Primera Forma Normal (1FN) exige que cada celda contenga un único valor atómico, sin listas o grupos repetidos dentro de una misma columna. Por ejemplo, si una tabla 'Clientes' tiene una columna 'Productos' con múltiples artículos separados por comas, no cumple la 1FN. Para corregirlo, se debe crear una tabla hija relacionada mediante claves foráneas, transformando los datos en filas individuales. Este paso es fundamental antes de avanzar a formas superiores, garantizando que las consultas sean eficientes y que la actualización de datos sea coherente sin generar anomalías.

## Ejemplo (no ejecutado automáticamente)
Transformación de una tabla con columnas repetidas a una estructura relacional normalizada en SQL.

```sql
CREATE TABLE Clientes (
  id INT PRIMARY KEY,
  nombre VARCHAR(100)
);

CREATE TABLE Productos (
  id INT PRIMARY KEY,
  cliente_id INT,
  producto VARCHAR(50),
  FOREIGN KEY (cliente_id) REFERENCES Clientes(id)
);
```
