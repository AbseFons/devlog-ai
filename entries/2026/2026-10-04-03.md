## Objetivo
Aprender a estructurar mensajes de commit claros usando la convención angular brackets para describir cambios de tipo feature, mejorando la trazabilidad del historial y facilitando la generación automática de changelogs en proyectos colaborativos.

## Explicación
La convención de commits estandariza el formato de los mensajes para que sean legibles y procesables automáticamente. En este primer ejercicio, nos enfocamos en commits de tipo 'feat', que indican una nueva característica visible para el usuario. La estructura básica incluye un verbo en infinitivo seguido del impacto del cambio. Por ejemplo, 'Añade validación de email al formulario' es más informativo que simplemente 'nuevo campo'. Este formato permite a las herramientas CI/CD detectar automáticamente nuevas funcionalidades y generar reportes sin intervención manual. Mantener esta consistencia desde el inicio ahorra tiempo en revisiones de código y documentación futura.

## Ejemplo (no ejecutado automáticamente)
Ejecución de un comando git commit con mensaje que sigue la convención para añadir una nueva funcionalidad de validación de entrada de usuario.

```bash
git add src/validacion.py
git commit -m "feat: añade validacion de email al formulario"
```

## Ejercicio
Crea un nuevo archivo llamado 'calculadora.py' con una función básica que sume dos números. Luego, haz un commit siguiendo la convención para registrar esta nueva herramienta matemática.

## Criterios de revisión
El mensaje del commit debe comenzar con 'feat:' seguido de una descripción clara en presente y sin mayúsculas innecesarias. El archivo creado debe contener al menos una función pública que realice una operación aritmética simple.
