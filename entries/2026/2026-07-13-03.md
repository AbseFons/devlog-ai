## Objetivo
Aprender a seleccionar elementos del documento HTML utilizando selectores CSS y modificar sus propiedades en tiempo real para crear interactividad básica.

## Explicación
La manipulación del DOM permite interactuar con el contenido dinámico. Utilizamos document.querySelector() para obtener un elemento por su selector CSS, como una clase o etiqueta. Una vez seleccionado, podemos acceder a sus atributos internos mediante propiedades como innerHTML o textContent. Para cambiar estilos visuales, asignamos valores directamente a propiedades de la caja de estilo, como color o background-color. Este enfoque es fundamental para construir interfaces reactivas donde el estado de la aplicación altera la presentación visual sin recargar la página.

## Ejemplo (no ejecutado automáticamente)
Selecciona un párrafo con clase 'destacado' y cambia su fondo a azul al hacer clic en un botón.

```javascript
const btn = document.getElementById('miBoton');
const texto = document.querySelector('.destacado');
texto.style.backgroundColor = 'lightblue';
```
