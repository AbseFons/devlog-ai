## Objetivo
Comprender la sintaxis básica y el propósito de los decoradores en Python para extender funcionalidad a funciones existentes sin modificar su código interno.

## Explicación
Los decoradores son una herramienta poderosa que permite alterar el comportamiento de una función antes de que se ejecute. Se definen usando la palabra clave 'def' seguida del nombre y dos puntos, creando una función que recibe otra como argumento. Al colocar el símbolo '@' sobre una definición de función, le aplicamos automáticamente un decorador. Esto es útil para tareas comunes como medir tiempos de ejecución, manejar errores o añadir logging. El proceso implica que Python reemplaza la función original por el resultado de llamar al decorador con esa función. Esencialmente, encapsula lógica transversal manteniendo el código limpio y legible.

## Ejemplo (no ejecutado automáticamente)
Un decorador simple que imprime un mensaje antes y después de ejecutar una función objetivo.

```python
def mi_decorador(func):
    def wrapper():
        print('Antes de la funcion')
        func()
        print('Despues de la funcion')
    return wrapper

@mi_decorador
def saludar():
    print('Hola mundo')
```
