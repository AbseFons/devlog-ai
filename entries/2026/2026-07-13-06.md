## Objetivo
Comprender cómo las funciones internas acceden a variables externas incluso después de que la función externa haya terminado de ejecutarse, aprovechando el cierre del ámbito léxico.

## Explicación
Un closure es una función que recuerda su entorno léxico. En JavaScript, cuando una función se define dentro de otra, puede acceder a las variables de la función exterior. Incluso si esa función exterior termina, la interna mantiene referencias a esas variables. Esto ocurre porque el objeto closure incluye tanto el código como el ámbito capturado. Es útil para crear funciones con estado privado, como contadores o validadores de contraseñas sin exponer lógica global.

## Ejemplo (no ejecutado automáticamente)
Se define una función que crea un contador privado usando un closure, permitiendo incrementar su valor sin acceder directamente a la variable interna.

```javascript
function crearContador() {
  let cuenta = 0;
  return function() {
    cuenta++;
    console.log(cuenta);
  };
}
const miContador = crearContador();
miContador();
```
