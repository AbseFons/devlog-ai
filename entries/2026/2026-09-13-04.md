## Objetivo
Comprender cómo SQL Server decide ejecutar las consultas y optimizar el rendimiento mediante la inspección del plan de ejecución antes de que los datos se procesen.

## Explicación
El comando EXPLAIN (o SHOWPLAN en versiones antiguas) genera un gráfico visual o texto que detalla el orden de operaciones, índices utilizados y costos estimados. Esto permite identificar cuellos de botella como escaneos de tabla completos innecesarios o uniones ineficientes. Al analizar estos planes, los desarrolladores pueden ajustar índices, reescribir consultas o cambiar estadísticas para guiar al optimizador hacia la estrategia más rápida, mejorando significativamente el tiempo de respuesta en aplicaciones críticas.

## Ejemplo (no ejecutado automáticamente)
Consulta que selecciona usuarios activos con un filtro por fecha y región, mostrando el plan de ejecución generado.

```sql
SELECT * FROM Usuarios WHERE Estado = 'Activo' AND FechaRegistro > '2025-01-01' AND Region = 'Norte';
SET SHOWPLAN_TEXT ON;
GO
-- Ejecutar la consulta anterior para ver el plan en texto.
SET SHOWPLAN_TEXT OFF;
```

## Ejercicio
Escribe una consulta SQL que busque productos con stock inferior a 10 y utiliza EXPLAIN (o SET SHOWPLAN_TEXT) para visualizar cómo el motor accede a la tabla Productos.

## Criterios de revisión
El plan debe mostrar un uso de índice si existe uno adecuado, evitar escaneos completos innecesarios y reflejar una lógica de filtrado eficiente antes de la proyección final.
