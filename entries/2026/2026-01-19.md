## Objetivo
Comprender cómo las funciones internas acceden a variables externas incluso después de que la función externa haya terminado su ejecución, aprovechando el cierre del ámbito.

## Explicación
Un closure es una función que recuerda y mantiene acceso a sus variables léxicas, incluso cuando se ejecuta fuera del ámbito donde fueron definidas. Esto ocurre porque la función interna 'cierra' o encapsula el contexto de la función padre junto con su código. En JavaScript, esto permite crear funciones de orden superior y mantener estado privado sin usar clases. Por ejemplo, si una función externa define una variable y retorna una interna, esa interna conserva el valor de la variable externa. Este mecanismo es fundamental para patrones como factories o módulos simples, permitiendo encapsulamiento robusto y lógica funcional pura dentro del lenguaje.

## Ejemplo (no ejecutado automáticamente)
Se define una función que crea un contador privado incrementando un valor interno en cada llamada, demostrando el estado persistente gracias al closure.

```javascript
function crearContador() {
  let cuenta = 0;
  return function() { cuenta++; return cuenta; };
}
const miContador = crearContador();
console.log(miContador()); // 1
console.log(miContador()); // 2
```
