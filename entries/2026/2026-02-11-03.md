## Objetivo
Comprender qué es un decorador, cómo se define con la función @wrapper y su utilidad para modificar el comportamiento de otras funciones sin alterar su código interno.

## Explicación
Un decorador es una función que recibe otra como argumento y devuelve una nueva versión modificada. Se usa comúnmente para añadir funcionalidades transversales como logging o seguridad. La sintaxis @nombre_funcion es un atajo para envolver la definición de la función. Este concepto permite escribir código más limpio y modular, separando la lógica principal de las responsabilidades adicionales.

## Ejemplo (no ejecutado automáticamente)
Se define una función decoradora que imprime un mensaje antes y después de ejecutar la función original, demostrando cómo interceptar la ejecución.

```python
def mi_decorador(func):
    def envoltorio(*args, **kwargs):
        print("Antes")
        func(*args, **kwargs)
        print("Despues")
    return envoltorio

@mi_decorador
def saludar():
    print("Hola")
```
