## Objetivo
Aprender a implementar paginación eficiente utilizando cursores para evitar problemas de ordenamiento y manejar grandes volúmenes de datos sin sobrecargar el cliente.

## Explicación
La paginación por cursor es superior a la paginación por número de página cuando los datos no están estrictamente ordenados o cambian frecuentemente. En lugar de pasar un 'page' y un 'limit', se utiliza un token único que representa el punto exacto donde terminó la consulta anterior. Este token suele ser una combinación de campos como ID, fecha y otros identificadores únicos. Al enviar este cursor en la cabecera o parámetro 'after', la API devuelve los siguientes registros inmediatamente después de ese punto. Este método garantiza consistencia incluso si nuevos datos se insertan entre consultas, evitando duplicados o saltos en la lista.

## Ejemplo (no ejecutado automáticamente)
Consulta paginada usando un cursor basado en ID y timestamp para obtener usuarios subsiguientes.

```javascript
const response = await fetch('https://api.ejemplo.com/usuarios?cursor=eyJpZCI6MTAwLCJ0aW1lc3RhbXAiOjE2OTk5OTk5OTB9');
const data = await response.json();
console.log(data.items); console.log(data.nextCursor);
```
