## Objetivo
Comprender la lógica recursiva del ordenamiento por mezcla, su funcionamiento paso a paso y analizar su complejidad temporal y espacial para aplicar técnicas de divide y vencerás en problemas de ordenación.

## Explicación
El ordenamiento por mezcla es un algoritmo recursivo que aplica la estrategia de dividir y conquistar. Divide el arreglo original en dos mitades hasta llegar a subarreglos de longitud uno, considerados ya ordenados. Luego, mediante una función auxiliar de fusión, combina estos subarreglos ordenados de manera eficiente para formar el arreglo completo ordenado. Este método garantiza un rendimiento consistente de O(n log n) en todos los casos, aunque requiere espacio adicional proporcional al tamaño del arreglo para almacenar las copias temporales durante la fusión.

## Ejemplo (no ejecutado automáticamente)
Implementación recursiva que divide el array hasta sublistas de longitud uno y fusiona resultados ordenados.

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```
