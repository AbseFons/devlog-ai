## Objetivo
Aprender a crear listas filtradas eficientemente usando sintaxis de comprensión, evitando bucles explícitos y mejorando la legibilidad del código al extraer elementos que cumplen una condición específica.

## Explicación
La comprensión de listas permite construir nuevas colecciones iterando sobre secuencias existentes. En este caso, tomamos una lista de números enteros y generamos una nueva lista conteniendo únicamente los valores pares. La sintaxis [x for x in numeros if x % 2 == 0] define la estructura: por cada elemento x en la lista original, si cumple la condición de ser divisible entre dos sin residuo, se incluye en el resultado. Este enfoque es más conciso y rápido que usar append dentro de un bucle for tradicional.

## Ejemplo (no ejecutado automáticamente)
Se define una lista con números mixtos y se aplica comprensión para obtener solo los pares.

```python
numeros = [1, 2, 3, 4, 5, 6]
pares = [x for x in numeros if x % 2 == 0]
print(pares)
```
