## Objetivo
Comprender y aplicar los principios básicos de la normalización en bases de datos relacionales, específicamente enfocándose en la eliminación de grupos repetidos para lograr la Primera Forma Normal (1FN) y mejorar la integridad de los datos.

## Explicación
La normalización es el proceso de organizar una base de datos para reducir la redundancia y mejorar la integridad. La Primera Forma Normal (1FN) exige que cada celda contenga exactamente un valor atómico, sin listas o grupos repetidos dentro de una misma columna. Por ejemplo, si una tabla 'Clientes' tiene una columna 'Productos' con múltiples ítems separados por comas, no cumple la 1FN. Para corregirlo, debemos transformar esa estructura plana en una relación normalizada donde cada fila represente un producto específico para un cliente, creando así una tabla de intersección o tabla hija. Esto permite consultas más precisas y evita anomalías de actualización.

## Ejemplo (no ejecutado automáticamente)
Transformación de una tabla con columnas repetidas a una estructura relacional normalizada en SQL.

```sql
CREATE TABLE Clientes_Produitos (
  id_cliente INT,
  nombre_producto VARCHAR(50),
  cantidad INT
);

INSERT INTO Clientes_Produitos VALUES (1, 'Laptop', 2);
```
