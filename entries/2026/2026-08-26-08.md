## Objetivo
El desarrollador aplicará técnicas para reducir el uso de memoria en Merge Sort, comprendiendo cómo fusionar subarrays in-place y analizando el impacto del stack de llamadas en entornos con restricciones de recursos.

## Explicación
Merge Sort es un algoritmo divide-y-conquista estable que garantiza O(n log n). Sin embargo, su implementación clásica consume memoria extra para los arrays temporales. En esta lección exploramos cómo optimizar la fusión minimizando asignaciones repetitivas. La clave reside en pre-asignar un buffer auxiliar único y reutilizarlo durante todo el proceso de recursión, evitando crear nuevos objetos en cada nivel del árbol de descomposición. Esto reduce significativamente la presión sobre el heap y mejora el rendimiento en aplicaciones con grandes volúmenes de datos.

## Ejemplo (no ejecutado automáticamente)
```python
def merge_sort_optimizado(arr, temp):
    n = len(arr)
    if n <= 1:
        return arr
    mid = n // 2
    izq = merge_sort_optimizado(arr[:mid], temp)
    der = merge_sort_optimizado(arr[mid:], temp)
    i = j = k = 0
    while i < len(izq) and j < len(der):
        if izq[i] <= der[j]:
            temp[k] = izq[i]
            i += 1
        else:
            temp[k] = der[j]
            j += 1
        k += 1
    while i < len(izq):
        temp[k] = izq[i]
        i += 1
        k += 1
    while j < len(der):
        temp[k] = der[j]
        j += 1
        k += 1
    arr[:] = temp[:n]
    return arr
```
