## Objetivo
Aprender a utilizar el reflog para recuperar estados perdidos en Git tras un reset o commit accidental, protegiendo el historial de trabajo sin necesidad de archivos externos.

## Explicación
El comando git reflog registra cada cambio en la referencia HEAD, incluso si se eliminan commits mediante reset o rebase. Es vital cuando se comete un error y se necesita deshacer acciones recientes. A diferencia del log normal, el reflog muestra estados intermedios ocultos. Para recuperar un estado anterior, localiza la entrada deseada usando git reflog, extrae su hash de commit y ejecuta git reset --hard <hash>. Este proceso restaura tu directorio al estado exacto del commit seleccionado, eliminando cambios locales no deseados pero preservando el historial lógico del proyecto. Es una herramienta esencial para ingenieros que trabajan con ramas complejas o realizan ajustes rápidos.

## Ejemplo (no ejecutado automáticamente)
Recuperar un commit anterior tras un reset accidental usando el reflog y restaurar el estado del directorio.

```bash
git reflog
HEAD@{1} -> HEAD (reset, moving to commit 8f3a2b1)
HEAD@{2} -> HEAD@{1}
git reset --hard HEAD@{2}
```

## Criterios de revisión
El usuario debe identificar correctamente la entrada del reflog correspondiente al estado deseado y ejecutar el comando de recuperación sin perder datos adicionales.
