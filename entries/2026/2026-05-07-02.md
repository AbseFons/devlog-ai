## Objetivo
Aprender a localizar elementos del DOM utilizando la API moderna querySelector, facilitando el acceso directo a nodos específicos mediante selectores CSS.

## Explicación
En esta lección exploramos el método querySelector, una herramienta esencial para interactuar con la estructura de documentos HTML. A diferencia de métodos antiguos, este permite escribir selectores CSS concisos dentro de un string y obtener el primer elemento coincidente. Es ideal para iniciar manipulaciones como cambiar estilos o contenido. Su sintaxis es flexible: acepta clases, IDs, atributos y combinaciones complejas. Al usarlo correctamente, evitamos iteraciones innecesarias y mejoramos la legibilidad del código JavaScript, asegurando que las aplicaciones web sean más eficientes y mantenibles.

## Ejemplo (no ejecutado automáticamente)
Selecciona el primer elemento con clase 'boton' y cambia su color de fondo a azul.

```javascript
const boton = document.querySelector('.boton');
if (boton) {
  boton.style.backgroundColor = '#007bff';
}
```
