## Objetivo
Aprender a utilizar bloques try-except para prevenir que errores inesperados detengan la ejecución del programa, permitiendo manejar fallos específicos como división por cero o archivos inexistentes de forma elegante.

## Explicación
En Python, las excepciones interrumpen el flujo normal cuando ocurren errores. El bloque try ejecuta código potencialmente arriesgado, mientras que except captura la excepción específica si se produce. Esto evita cierres abruptos y permite mostrar mensajes personalizados o ejecutar lógica de recuperación. Por ejemplo, intentar dividir por cero genera ZeroDivisionError. Al envolver esta operación en un try-except, el programa puede informar al usuario amablemente sin colapsar. Es fundamental ser específico con los tipos de excepción para no ocultar errores críticos innecesariamente.

## Ejemplo (no ejecutado automáticamente)
Intenta dividir dos números; si hay error por división por cero, muestra un mensaje seguro.

```python
num1 = 10
num2 = 0
try:
    resultado = num1 / num2
except ZeroDivisionError:
    print("No se puede dividir por cero")
```
