## Objetivo
Analizar cómo la elección del elemento pivot afecta el rendimiento del algoritmo de ordenamiento por mezcla, evitando casos peores y mejorando la eficiencia en conjuntos de datos con patrones repetitivos.

## Explicación
En esta microlección exploramos la variante avanzada del Quicksort donde el pivot no se elige aleatoriamente ni como primer/último elemento. Se propone usar la mediana de tres (primer, medio y último elementos) para seleccionar el pivot. Esta técnica reduce drásticamente la probabilidad de obtener un árbol de partición desbalanceado en datos casi ordenados o con muchos duplicados. Al garantizar que el pivot esté cerca de la mediana real del rango actual, logramos una profundidad de recursión más uniforme, acercándonos al caso óptimo O(n log n) incluso en escenarios adversos.

## Ejemplo (no ejecutado automáticamente)
Implementación de Quicksort con selección de mediana de tres para evitar desbalanceo en datos ordenados.

```python
def quicksort_mediana(arr):
    if len(arr) <= 1:
        return arr
    pivot = (arr[0] + arr[len(arr)//2] + arr[-1]) // 3
```
