## Objetivo
Comprender cómo configurar roles y permisos para restringir el acceso a recursos críticos, asegurando que solo usuarios autorizados puedan ejecutar operaciones sensibles en aplicaciones modernas.

## Explicación
El Control de Acceso Basado en Roles (RBAC) es un modelo fundamental para la seguridad informática. Consiste en asignar permisos específicos a roles funcionales y luego otorgar esos roles a los usuarios. Por ejemplo, un rol 'Administrador' puede tener acceso total, mientras que un rol 'Lector' solo puede visualizar datos. Este enfoque simplifica la gestión de identidades al evitar la configuración individualizada de permisos para cada usuario. En sistemas operativos y contenedores, esto se logra mediante listas de control de acceso (ACLs) o archivos como /etc/passwd y /etc/group en Linux. La implementación correcta previene el acceso no autorizado a datos sensibles y limita el daño en caso de compromiso de una cuenta. Es crucial revisar periódicamente los roles para eliminar privilegios innecesarios.

## Ejemplo (no ejecutado automáticamente)
Script bash que crea un grupo 'auditors' y asigna permisos de lectura solo a ese grupo en un directorio de logs confidenciales, simulando una política de seguridad básica.

```bash
groupadd auditors
chmod 750 /var/log/secure
chgrp auditors /var/log/secure
```
