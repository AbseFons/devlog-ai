## Objetivo
Comprender y aplicar los principios de la primera forma normal en bases de datos relacionales para eliminar grupos repetidos y asegurar que cada celda contenga un valor atómico único, mejorando la integridad de los datos.

## Explicación
La normalización es el proceso de organizar una base de datos para reducir la redundancia y mejorar la integridad. La Primera Forma Normal (1FN) exige que cada columna en una tabla contenga valores únicos y atómicos, sin listas o grupos repetidos dentro de una sola celda. Por ejemplo, si una tabla 'Clientes' tiene una columna 'Hobbies' con múltiples intereses separados por comas, no cumple la 1FN. Para corregirlo, debemos crear una tabla secundaria relacionada donde cada fila represente un solo hobby. Esto transforma datos ambiguos en una estructura relacional clara, permitiendo consultas más precisas y actualizaciones eficientes sin afectar otros registros.

## Ejemplo (no ejecutado automáticamente)
Transformación de una tabla con columnas repetidas a una estructura normalizada usando SQL.

```sql
CREATE TABLE Clientes_Hobbies (
  id_cliente INT,
  hobby VARCHAR(50)
);

INSERT INTO Clientes_Hobbies VALUES (1, 'Lectura');
INSERT INTO Clientes_Hobbies VALUES (1, 'Cocina');
```

## Ejercicio
Diseña una tabla SQL llamada 'Pedidos' que contenga las columnas 'id_pedido', 'fecha' y 'productos'. Luego, reestructúrala para cumplir con la Primera Forma Normal, asegurando que cada producto en un pedido ocupe su propia fila.

## Criterios de revisión
El resultado debe mostrar una tabla donde cada fila representa un único producto dentro de un pedido específico, eliminando cualquier celda con múltiples valores y garantizando que los datos sean atómicos.
