## Objetivo
Comprender la lógica fundamental del algoritmo de búsqueda por anchura (BFS) para encontrar el camino más corto en grafos no ponderados, utilizando una cola y un conjunto visitado.

## Explicación
La Búsqueda por Anchura (BFS) es un algoritmo fundamental para explorar grafos. Funciona procesando los nodos nivel por nivel. Se inicia desde un nodo raíz, se añade a una cola y se marcan como visitados. En cada iteración, se extrae el primer elemento de la cola y se revisan sus vecinos no visitados, añadiéndolos a la cola. Este proceso garantiza que el primer camino encontrado hacia cualquier nodo sea el más corto en términos de número de aristas. Es ideal para problemas de conectividad o rutas mínimas en redes sociales y mapas.

## Ejemplo (no ejecutado automáticamente)
Implementación de BFS en Python para encontrar el camino más corto desde un nodo 'A' a un nodo 'E' en un grafo no ponderado definido por listas de adyacencia.

```python
from collections import deque

def bfs(graph, start, end):
    queue = deque([start])
    visited = {start}
    path = {start: None}
    while queue:
        node = queue.popleft()
        if node == end:
            return reconstruct_path(path)
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                path[neighbor] = node
                queue.append(neighbor)
    return None

def reconstruct_path(path):
    current = 'E'
    result = []
    while current is not None:
        result.append(current)
        current = path[current]
    return result[::-1]
```
