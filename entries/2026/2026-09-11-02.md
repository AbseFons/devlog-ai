## Objetivo
Comprender la lógica fundamental del algoritmo de búsqueda por anchura (BFS) para encontrar el camino más corto en grafos no ponderados, utilizando una cola y marcando nodos visitados.

## Explicación
El BFS explora un grafo nivel a nivel. Comienza desde un nodo raíz, lo marca como visitado y lo añade a una cola. Luego, mientras la cola tenga elementos, extrae el primer nodo, revisa sus vecinos no visitados, los marca y los encola. Este proceso garantiza que se encuentre el camino más corto en grafos sin pesos, ya que siempre se procesan nodos de distancia menor antes que los de mayor distancia.

## Ejemplo (no ejecutado automáticamente)
Implementación básica de BFS para encontrar un camino desde el nodo 'A' hasta el 'D' en un grafo simple representado como adyacencia.

```python
from collections import deque

def bfs(graph, start):
    visited = {node: False for node in graph}
    queue = deque([start])
    path = []
    while queue:
        current = queue.popleft()
        if current not in path:
            path.append(current)
        if current in graph and not visited[current]:
            visited[current] = True
            for neighbor in graph[current]:
                if not visited[neighbor]:
                    queue.append(neighbor)
```
