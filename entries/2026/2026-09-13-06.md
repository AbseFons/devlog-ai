## Objetivo
Aprender a capturar excepciones asíncronas utilizando bloques try-catch para evitar que el programa se detenga inesperadamente al procesar datos externos.

## Explicación
En la programación asíncrona, las promesas pueden rechazarse. Si no se manejan, estos errores propagan y colapsan la aplicación. El patrón estándar consiste en envolver llamadas a funciones asíncronas dentro de un bloque try-catch. Dentro del try, ejecutamos la operación; si falla, el control pasa al catch donde podemos registrar el error o mostrar un mensaje amigable. Esto garantiza una experiencia de usuario robusta. Es crucial no omitir el finally para liberar recursos como conexiones de red o cerrar archivos tras cualquier resultado, exitoso o fallido.

## Ejemplo (no ejecutado automáticamente)
Función que intenta obtener datos de una API simulada y maneja errores de conexión.

```javascript
async function obtenerDatos() {
  try {
    const respuesta = await fetch('https://api.ejemplo.com/datos');
    if (!respuesta.ok) throw new Error('Error en la API');
    return await respuesta.json();
  } catch (error) {
    console.error('Fallo:', error.message);
  }
}
```

## Ejercicio

## Criterios de revisión
