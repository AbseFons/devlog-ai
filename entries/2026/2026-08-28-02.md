## Objetivo
Al finalizar esta lección, el desarrollador será capaz de utilizar la clase Path de pathlib para construir rutas absolutas y relativas sin errores de separadores de directorio, evitando código no portable y asegurando que las operaciones de sistema funcionen correctamente en Windows, Linux y macOS.

## Explicación
La librería estándar pathlib simplifica el manejo de rutas en Python. A diferencia de concatenar cadenas con '/', pathlib utiliza clases como Path para construir rutas de manera intuitiva. Esto garantiza que el código funcione independientemente del sistema operativo, ya que la clase maneja automáticamente los separadores correctos (\ en Windows o / en Unix). Además, métodos como .resolve() normalizan las rutas eliminando puntos y dos puntos innecesarios, mientras que .exists() permite verificar la existencia de archivos antes de operar. Esta aproximación reduce drásticamente los errores comunes al mover código entre diferentes entornos.

## Ejemplo (no ejecutado automáticamente)
```python
from pathlib import Path

# Definir una ruta base relativa
base = Path('proyectos') / 'analisis' / 'datos'

# Construir una ruta absoluta completa
directorio_completo = Path.home() / base

# Verificar si el directorio existe antes de operar
if directorio_completo.exists():
    print(f'Directorio encontrado: {directorio_completo}')
else:
    print('El directorio no existe en este sistema.')
```
