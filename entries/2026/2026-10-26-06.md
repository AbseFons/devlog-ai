## Objetivo
Aprender a definir tipos de datos específicos para argumentos, manejar valores nulos y personalizar mensajes de error personalizados usando la clase ArgumentParser de Python.

## Explicación
En esta lección avanzamos sobre la robustez de los scripts. El método add_argument permite especificar el tipo 'type' (como int o float) para validar automáticamente la entrada del usuario. Si se introduce un valor inválido, argparse lanza una excepción con un mensaje claro. Para argumentos opcionales que pueden no existir, usamos default=None. Tambien podemos usar nargs='?' junto con const=None para distinguir entre un argumento ausente y uno explícitamente proporcionado como nulo. Esto es crucial en APIs donde la diferencia entre 'no dado' y 'cero' o 'vacío' cambia el comportamiento del programa.

## Ejemplo (no ejecutado automáticamente)
Script que acepta una edad como entero opcional y un nombre de archivo, mostrando cómo manejar valores faltantes versus nulos explícitos.

```python
import argparse
parser = argparse.ArgumentParser()
parser.add_argument('--edad', type=int, default=None)
args = parser.parse_args()
```
