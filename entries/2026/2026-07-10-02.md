## Objetivo
Aprender a configurar un parser básico para aceptar argumentos posicionales y opciones con valores, permitiendo crear scripts interactivos robustos que validan entradas del usuario desde la línea de comandos sin necesidad de interfaces gráficas.

## Explicación
El módulo argparse facilita la creación de interfaces de línea de comandos en Python. Define un parser que interpreta argumentos pasados al ejecutar el script. Se pueden establecer argumentos obligatorios (posicionales) y opcionales (con flags como -o o --opcion). El sistema genera automáticamente mensajes de ayuda si faltan parámetros requeridos. Es ideal para herramientas de automatización, scripts de procesamiento de datos o administradores de sistemas que necesitan recibir configuraciones dinámicas sin modificar el código fuente cada vez.

## Ejemplo (no ejecutado automáticamente)
Script que acepta un nombre de archivo y una extensión opcional para validar tipos de entrada.

```python
import argparse
parser = argparse.ArgumentParser()
parser.add_argument('archivo', help='Nombre del archivo a procesar')
args = parser.parse_args()
```
