## Objetivo
Aprender a encapsular lógica de limpieza en funciones que retornan context managers, permitiendo reutilizar patrones de apertura y cierre sin duplicar código ni exponer detalles internos.

## Explicación
Los context managers permiten automatizar la adquisición y liberación de recursos. En esta lección, exploramos cómo crear una función que devuelva un objeto con el método __enter__ y __exit__. Esto es útil para operaciones como abrir archivos temporales o gestionar conexiones a bases de datos. Al usar 'with', Python llama automáticamente a estos métodos. La ventaja principal es la reutilización: una sola función puede generar múltiples instancias de contexto, cada una gestionando su propio estado interno sin necesidad de repetir bloques de código de limpieza en cada lugar donde se necesite.

## Ejemplo (no ejecutado automáticamente)
Una funcion que crea un archivo temporal y lo limpia automaticamente al salir del bloque con

```python
import tempfile
import os

def crear_archivo_temporal():
    fd, path = tempfile.mkstemp()
    os.close(fd)
    return _ContextFile(path)

class _ContextFile:
    def __init__(self, path):
        self.path = path
    def __enter__(self):
        return open(self.path, 'w')
    def __exit__(self, exc_type, exc_val, exc_tb):
        os.remove(self.path)
        return False
```

## Criterios de revisión
El objeto retornado debe tener los metodos __enter__ y __exit__. El metodo __enter__ debe devolver un valor utilizable. El metodo __exit__ debe imprimir el mensaje especificado independientemente de si ocurre una excepcion o no.
