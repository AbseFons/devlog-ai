## Objetivo
Aprender a diseñar pruebas para valores extremos en entradas numéricas, asegurando que la aplicación maneje correctamente números negativos, cero y valores muy grandes sin colapsar ni devolver errores inesperados.

## Explicación
Los casos borde son fundamentales para garantizar la robustez del software. En este ejercicio, simularemos una función de cálculo de intereses donde el usuario puede ingresar cualquier número. Debes probar con un valor negativo (deuda), cero (sin inversión) y un entero positivo estándar. El sistema debe rechazar valores negativos si la lógica requiere solo depósitos, o calcular correctamente si permite deuda. También verifica que no haya desbordamientos con números extremadamente grandes. Esta práctica previene fallos críticos en transacciones financieras reales.

## Ejemplo (no ejecutado automáticamente)
Script de Python que define una función para calcular intereses y la prueba con tres casos borde: un valor negativo, cero y un valor positivo normal.

```python
def calcular_interes(capital, tasa):
    if capital < 0:
        return "Error: Capital no válido"
    return capital * (1 + tasa)

print(calcular_interes(-100, 0.05))
print(calcular_interes(0, 0.05))
print(calcular_interes(1000, 0.05))
```
