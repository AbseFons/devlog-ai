## Objetivo
Aprender a cancelar peticiones asíncronas en JavaScript para evitar bloqueos de UI y optimizar el rendimiento al manejar múltiples llamadas simultáneas.

## Explicación
En aplicaciones modernas, las peticiones fetch pueden tardar demasiado o ser innecesarias si el usuario cambia de página. El AbortController permite cancelar una petición específica enviando un error controlado. Se crea un controller y se pasa su señal al fetch. Si el usuario abandona la vista antes de que termine la carga, se llama a controller.abort(). Esto lanza un error 'AbortError' en la promesa, permitiendo manejar la cancelación con try/catch sin interrumpir la lógica principal.

## Ejemplo (no ejecutado automáticamente)
Se realiza una petición a una API pública de retraso simulado. Si el usuario hace clic en cancelar después de 2 segundos, la petición se detiene y se muestra un mensaje amigable en lugar de esperar indefinidamente.

```javascript
const controller = new AbortController();
fetch('https://httpbin.org/delay/5', { signal: controller.signal })
```

## Ejercicio
Crea una función que llame a fetch con un timeout de 3 segundos. Si el usuario hace clic en un botón 'Cancelar' dentro de ese tiempo, detén la petición y muestra un mensaje de 'Operación cancelada'.

## Criterios de revisión
El código debe instanciar correctamente AbortController, pasar la señal al fetch y manejar el evento abort() para ejecutar una acción específica sin dejar la promesa colgada.
