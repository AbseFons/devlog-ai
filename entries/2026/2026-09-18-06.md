## Objetivo
Comprender cómo la propiedad de consistencia garantiza que una transacción mantenga la base de datos en un estado válido, aplicando reglas de integridad referencial durante operaciones concurrentes.

## Explicación
La consistencia asegura que cada transacción transforme el sistema desde un estado válido a otro. Si una operación falla o viola una restricción (como una clave foránea), la transacción completa se descarta. En este caso, intentamos transferir fondos de una cuenta con saldo insuficiente. El motor de base de datos detecta la violación de integridad y aborta la transacción, dejando los saldos inalterados. Esto previene estados corruptos donde el dinero podría desaparecer o duplicarse sin registro válido.

## Ejemplo (no ejecutado automáticamente)
Intento de transferencia bancaria que falla debido a saldo insuficiente, demostrando cómo la consistencia aborta la operación para mantener la integridad del sistema.

```sql
BEGIN TRANSACTION;
UPDATE cuentas SET saldo = saldo - 500 WHERE id = 1 AND saldo >= 500;
```

## Criterios de revisión
