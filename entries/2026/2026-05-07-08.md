## Objetivo
Aprender a convertir objetos de Python a formato JSON legible y viceversa utilizando la librería estándar json, esencial para el intercambio de datos entre aplicaciones.

## Explicación
La serialización permite transformar estructuras complejas de Python como diccionarios y listas en cadenas de texto JSON estandarizadas. Esto facilita la persistencia de datos o su envío por redes. La función json.dumps() convierte objetos a texto, mientras que json.loads() realiza el proceso inverso. Es crucial manejar correctamente los tipos de datos: las claves deben ser strings, los booleanos se mapean a true/false y None a null. Este conocimiento base es vital para desarrollar APIs robustas y consumir servicios web externos sin errores de formato.

## Ejemplo (no ejecutado automáticamente)
Conversión de un diccionario de usuario a JSON y lectura inversa

```python
import json
usuario = {'nombre': 'Ana', 'edad': 30}
json_str = json.dumps(usuario)
print(json_str)
```
