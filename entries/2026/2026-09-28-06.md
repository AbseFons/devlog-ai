## Objetivo
Aprender a implementar paginación eficiente utilizando cursores para evitar problemas de ordenamiento y manejar grandes volúmenes de datos sin cargar todo el conjunto en memoria.

## Explicación
La paginación por cursor es superior a la paginación tradicional basada en índices cuando los datos no están estrictamente ordenados o cambian frecuentemente. En lugar de usar 'offset' y 'limit', se devuelve un token único que representa el punto exacto donde terminó la consulta anterior. Para implementar esto, la API debe devolver este cursor junto con los datos. El cliente utiliza este valor en el parámetro de solicitud para obtener la siguiente página. Este método garantiza consistencia incluso si nuevos registros se insertan entre páginas, evitando saltos o duplicados comunes en esquemas offset.

## Ejemplo (no ejecutado automáticamente)
Solicitud GET a una API de usuarios que devuelve un cursor 'next_page_token' y los primeros 10 registros. El cliente usa este token para la siguiente petición.

```javascript
const response = await fetch('https://api.ejemplo.com/users?cursor=abc123&limit=10');
const data = await response.json();
console.log(data.next_page_token); // Usar este valor en la siguiente llamada
```

## Ejercicio
Crea una función asíncrona 'fetchNextPage' que tome un token de cursor y un límite. Devuelva los datos de la página siguiente y el nuevo token, manejando errores si no hay más páginas.

## Criterios de revisión
El código debe manejar correctamente la ausencia de un token 'next_page_token' indicando fin de paginación, usar fetch para las peticiones HTTP y no exponer credenciales ni realizar llamadas destructivas.
