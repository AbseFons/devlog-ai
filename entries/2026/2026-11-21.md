## Objetivo
Aprender a identificar y resolver conflictos de código mediante edición directa, preservando la lógica original de ambas ramas antes de crear una versión unificada funcional.

## Explicación
Cuando Git detecta un conflicto, inserta marcadores '<<<<<<<', '=======', y '>>>>>>>'. El objetivo es editar el archivo para mantener solo el código deseado. Primero, elimina los marcadores. Luego, decide qué lógica conservar o fusionar ambas. Si se mezcla código de JavaScript, asegúrate de que las variables no estén duplicadas y la sintaxis sea válida. Guarda los cambios y ejecuta 'git add' seguido de 'git commit'. Esta práctica manual es esencial para entender el flujo de datos y evitar errores sutiles en la integración continua.

## Ejemplo (no ejecutado automáticamente)
Se muestra un fragmento de código JavaScript donde se fusionan dos funciones que manejan el mismo objeto, eliminando los marcadores de conflicto y manteniendo la lógica correcta.

```javascript
function procesarDatos(datos) {
  if (datos.valor > 10) {
    return datos.valor * 2;
  }
}
```

## Criterios de revisión
El código resultante debe ser sintácticamente válido, no contener marcadores de conflicto y reflejar una lógica unificada sin duplicaciones innecesarias.
