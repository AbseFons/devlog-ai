## Objetivo
Aprender a prevenir inyecciones SQL y XSS mediante la validación estricta de tipos, longitud y caracteres permitidos antes de procesar cualquier dato recibido por el usuario.

## Explicación
La seguridad de las aplicaciones web depende fundamentalmente de validar cada entrada del usuario. No basta con confiar en la intención del desarrollador; los datos deben ser tratados como no confiables hasta que se verifiquen explícitamente. En esta lección, exploraremos cómo implementar validaciones de tipo y longitud para campos críticos como nombres de usuarios o correos electrónicos. Utilizaremos expresiones regulares y funciones nativas de JavaScript para asegurar que las cadenas no contengan caracteres peligrosos antes de insertarlos en una base de datos o renderizarlos en el DOM. Este enfoque proactivo reduce la superficie de ataque y cumple con estándares de seguridad modernos.

## Ejemplo (no ejecutado automáticamente)
Función que valida un nombre de usuario asegurando que solo contenga letras, números y guiones bajos, rechazando caracteres especiales.

```javascript
function validarNombre(nombre) {
  const patron = /^[a-zA-Z0-9_]{3,20}$/;
  if (!patron.test(nombre)) throw new Error('Formato inválido');
}
```

## Ejercicio
