## Objetivo
Comprender cómo optimizar algoritmos recursivos mediante el almacenamiento de subproblemas resueltos para evitar cálculos redundantes en series numéricas.

## Explicación
La programación dinámica transforma soluciones exponenciales en polinomiales almacenando resultados intermedios. En este caso, analizamos la serie de Fibonacci. Un enfoque recursivo puro recalcula F(n-1) y F(n-2) múltiples veces. La técnica 'bottom-up' construye una tabla iterativa donde cada celda depende de las anteriores. Esto reduce la complejidad temporal de O(2^n) a O(n). Es esencial para problemas de optimización como rutas más cortas o mochilas.

## Ejemplo (no ejecutado automáticamente)
Implementación iterativa en Python que calcula el n-ésimo número de Fibonacci usando un array para guardar estados previos y evitar recálculos.

```python
def fibonacci_dp(n):
    if n <= 1: return n
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```
