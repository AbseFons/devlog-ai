## Objetivo
Comprender la importancia de las pruebas de regresión para asegurar que nuevas modificaciones no rompan funcionalidades previamente operativas, manteniendo la estabilidad del sistema ante iteraciones continuas.

## Explicación
Las pruebas de regresión son esenciales en el ciclo de vida del desarrollo de software. Su propósito principal es verificar que los cambios recientes, como nuevas características o correcciones de errores, no hayan introducido defectos inesperados en partes del sistema que funcionaban correctamente antes. Este tipo de prueba se ejecuta frecuentemente después de cada integración de código. Un conjunto de pruebas de regresión típicamente cubre flujos críticos de negocio, asegurando que la calidad general del producto se preserve a medida que evoluciona. Ignorar estas pruebas puede llevar a fallos en producción difíciles de rastrear y costosos de reparar.

## Ejemplo (no ejecutado automáticamente)
Script de Python que ejecuta una suite de regresión básica verificando operaciones matemáticas y manejo de errores en una calculadora simple.

```python
def test_calculadora():
    assert 2 + 2 == 4
    assert 10 / 2 == 5
    try:
        1 / 0
        assert False, "Error de división por cero no capturado"
    except ZeroDivisionError:
        pass
```

## Ejercicio
Crea un script en Python que incluya tres casos de prueba para una función de login: uno con credenciales válidas, otro con contraseña incorrecta y un tercero con usuario inexistente. Asegúrate de que cada caso termine con un mensaje claro indicando si la prueba pasó o falló.

## Criterios de revisión
El script debe ejecutar sin errores de sintaxis, manejar las excepciones adecuadamente para el caso de usuario no encontrado y generar salidas legibles que confirmen el resultado de cada uno de los tres escenarios probados.
