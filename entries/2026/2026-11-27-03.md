## Objetivo
Aprender a mejorar la eficiencia de algoritmos recursivos mediante el almacenamiento intermedio de resultados, evitando cálculos redundantes en series matemáticas como Fibonacci.

## Explicación
La recursión directa puede ser ineficiente si recalcula los mismos valores repetidamente. En este caso, utilizaremos memoización para guardar los resultados de llamadas anteriores a la función. Al calcular el n-ésimo número de Fibonacci, almacenamos cada resultado en un diccionario antes de devolverlo. Esto reduce la complejidad temporal exponencial a lineal. Es una técnica fundamental en ingeniería de software para optimizar funciones recursivas sin alterar su lógica base.

## Ejemplo (no ejecutado automáticamente)
Implementación de Fibonacci con memoización en Python para calcular el n-ésimo término rápidamente.

```python
def fib(n, memo={}):
    if n in memo:
        return memo[n]
    memo[n] = fib(n-1, memo) + fib(n-2, memo)
    return memo[n]
```
