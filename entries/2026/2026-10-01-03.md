## Objetivo
Aprender a seleccionar elementos del documento HTML utilizando selectores CSS y modificar sus propiedades de estilo o contenido directamente desde JavaScript para crear interfaces dinámicas.

## Explicación
La manipulación del DOM es fundamental para la interactividad web. Comenzaremos seleccionando un elemento específico mediante su ID usando document.getElementById, que devuelve el nodo correspondiente o null si no existe. Una vez obtenido el objeto, podemos alterar sus atributos como innerHTML para cambiar el contenido textual o style.color para ajustar el color de fondo. Es crucial entender que estos cambios ocurren en tiempo real en el navegador. Además, se pueden utilizar selectores más avanzados como querySelector para buscar por clases o etiquetas, ofreciendo mayor flexibilidad en la construcción de aplicaciones complejas sin necesidad de recargar la página.

## Ejemplo (no ejecutado automáticamente)
Selecciona un div con id 'contenido' y cambia su fondo a azul oscuro junto con el texto dentro.

```javascript
const elemento = document.getElementById('miDiv');
elemento.style.backgroundColor = '#333';
elemento.innerHTML = '<h2>Nuevo Título</h2>';
```
