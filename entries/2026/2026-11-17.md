## Objetivo
Aprender a capturar excepciones asíncronas utilizando bloques try-catch para garantizar la estabilidad del flujo de datos y prevenir que fallos individuales colapsen toda la aplicación.

## Explicación
En JavaScript moderno, las promesas pueden resolver en error. Cuando usamos async/await, si una promesa dentro del bloque falla, se lanza una excepción. Para manejar esto, envuelvemos el código asíncrono en un try-catch. Dentro del catch, podemos registrar el error, mostrar un mensaje amigable al usuario o reintentar la operación con lógica de backoff exponencial. Es crucial no omitir el bloque catch si se espera que las operaciones fallen ocasionalmente, como llamadas a APIs externas. Esto permite mantener la aplicación funcional incluso ante fallos de red o servidores.

## Ejemplo (no ejecutado automáticamente)
Función asíncrona que intenta obtener datos de una API simulada y maneja el error devolviendo un estado por defecto.

```javascript
async function obtenerDatos() {
  try {
    const respuesta = await fetch('https://api.ejemplo.com/datos');
    return await respuesta.json();
  } catch (error) {
    console.error('Error de red:', error.message);
    return { estado: 'disponible', datos: [] };
  }
}
```

## Ejercicio
