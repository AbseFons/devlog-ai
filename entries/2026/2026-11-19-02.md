## Objetivo
Aprender a implementar paginación robusta utilizando cursores para evitar problemas de duplicados o saltos en conjuntos de datos dinámicos, asegurando una navegación consistente y eficiente en aplicaciones modernas.

## Explicación
La paginación con cursores es superior a la numeración cuando los datos cambian entre solicitudes. En lugar de un índice numérico que puede volverse obsoleto si se insertan o eliminan registros, el cursor utiliza valores únicos (como IDs) del último elemento procesado para indicar dónde continuar. Este método garantiza que, incluso con actualizaciones concurrentes, la aplicación siempre recupere los mismos datos esperados sin duplicar ni perder entradas. Es ideal para feeds de noticias o listas de chat donde el orden y la integridad temporal son críticos.

## Ejemplo (no ejecutado automáticamente)
Consulta paginada usando un cursor basado en ID para obtener los siguientes registros de una lista dinámica.

```javascript
const nextCursor = response.headers.get('X-Next-Cursor');
if (nextCursor) {
  fetch(`/api/items?cursor=${nextCursor}&limit=10`);
}
```
