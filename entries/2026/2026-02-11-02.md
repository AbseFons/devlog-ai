## Objetivo
Comprender cómo el motor de base de datos optimiza consultas mediante el análisis del plan de ejecución generado por la instrucción EXPLAIN, identificando cuellos de botella como escaneos completos o uniones ineficientes para mejorar el rendimiento.

## Explicación
La instrucción EXPLAIN revela el algoritmo que el motor SQL utilizará para ejecutar una consulta antes de procesar los datos. Al analizar este plan, podemos detectar operaciones costosas como 'Seq Scan' (escaneo secuencial) en tablas grandes o uniones mal optimizadas. El objetivo es identificar oportunidades de reestructuración, como añadir índices adecuados o modificar el orden de las cláusulas JOIN. Este conocimiento permite transformar consultas lentas en operaciones eficientes, asegurando que la base de datos utilice los recursos de manera óptima y mantenga un rendimiento estable bajo carga.

## Ejemplo (no ejecutado automáticamente)
Consulta que busca empleados por departamento con EXPLAIN para verificar el uso del índice en la columna 'departamento_id'.

```sql
EXPLAIN SELECT e.nombre, d.nombre_depto
FROM empleados e
JOIN departamentos d ON e.departamento_id = d.id
WHERE e.departamento_id = 5;
```
