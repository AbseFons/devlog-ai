## Objetivo
Aprender a identificar y probar escenarios críticos donde el manejo de archivos puede fallar, como permisos insuficientes o rutas inexistentes, asegurando la robustez del software ante errores comunes de E/S.

## Explicación
Los casos borde en operaciones de archivo no solo cubren archivos vacíos, sino también situaciones donde el sistema operativo deniega acceso. Un ejemplo común es intentar leer un archivo que existe pero al que el usuario no tiene permisos. Otro caso crítico es cuando la ruta de destino está ocupada o es un directorio en lugar de un archivo. Es vital simular estas condiciones para evitar fallos en producción. La prueba debe verificar que la aplicación maneje las excepciones adecuadamente, logueando el error y mostrando un mensaje amigable al usuario sin detener el proceso completo si es posible.

## Ejemplo (no ejecutado automáticamente)
Script en Python que intenta leer un archivo con permisos restringidos y captura la excepción de acceso denegado para mostrar un mensaje de error controlado.

```python
import os
try:
    with open('/etc/passwd', 'r') as f:
        content = f.read()
except PermissionError:
    print('Error: No tienes permisos para leer este archivo.')
```

## Ejercicio
Crea un script que intente escribir en una ruta protegida como '/root/test.txt' y maneje la excepción de permiso denegado imprimiendo un mensaje específico.

## Criterios de revisión
El código debe lanzar una excepción de tipo PermissionError al intentar abrir el archivo, capturar dicha excepción y ejecutar el bloque except para imprimir exactamente: 'Acceso denegado por seguridad del sistema'.
