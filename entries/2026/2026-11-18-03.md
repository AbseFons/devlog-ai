## Objetivo
Aprender a configurar un logger en Python que genere registros en formato JSON para facilitar el análisis de datos, implementando rotación automática de archivos para gestionar grandes volúmenes de información sin saturar el disco.

## Explicación
En esta lección avanzamos sobre el logging estructurado. Utilizaremos la biblioteca estándar 'logging' junto con un formateador personalizado que serializa cada registro como un objeto JSON. Esto permite capturar campos clave como 'nivel', 'mensaje', 'funcion', 'linea' y 'timestamp'. Para manejar archivos grandes, configuraremos un handler de archivo con una política de rotación (por ejemplo, por tamaño). Este enfoque es esencial en microservicios y aplicaciones de alto rendimiento donde las herramientas de monitoreo como ELK o Splunk consumen logs estructurados para detectar anomalías rápidamente.

## Ejemplo (no ejecutado automáticamente)
Configuración de un logger que escribe en JSON con rotación por tamaño, ideal para entornos de producción.

```python
import logging
from logging.handlers import RotatingFileHandler
import json

def json_formatter(record):
    return json.dumps({
        'timestamp': record.created,
        'level': record.levelname,
        'message': record.getMessage(),
        'module': record.module
    })

logger = logging.getLogger('app')
logger.setLevel(logging.INFO)
handler = RotatingFileHandler('app.log', maxBytes=5*1024*1024, backupCount=3)
handler.setFormatter(logging.Formatter(json_formatter))
logger.addHandler(handler)
```
