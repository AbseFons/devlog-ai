## Objetivo
Aprender a identificar y probar valores extremos en entradas numéricas para prevenir errores de desbordamiento o lógica incorrecta en aplicaciones financieras y de inventario.

## Explicación
Los casos borde son pruebas diseñadas para verificar el comportamiento del sistema ante valores límite. En este ejemplo, analizamos una función que calcula impuestos sobre un monto. Los casos críticos incluyen: cero (monto nulo), el valor máximo permitido por el tipo de dato y valores ligeramente superiores al límite. Es crucial probar no solo los límites exactos, sino también uno por encima y otro por debajo, ya que las condiciones de negocio suelen fallar en estos puntos. Por ejemplo, si el sistema acepta 999.99 pero rechaza 1000.00, un usuario podría intentar ingresar 999.995 para saltarse la regla. Esta técnica asegura robustez y evita vulnerabilidades por desbordamiento de buffer o lógica inconsistente en los márgenes operativos.

## Ejemplo (no ejecutado automáticamente)
Función en JavaScript que valida si un monto está dentro del rango permitido (0 a 1000) antes de calcular impuestos, incluyendo pruebas para valores justo fuera del límite.

```javascript
function calcularImpuesto(monto) {
  if (monto < 0 || monto > 1000) { throw new Error('Monto fuera de rango'); }
  return monto * 0.21;
}
calcularImpuesto(1000); // OK
calcularImpuesto(1001); // Error
```

## Ejercicio
Crea una función en Python que calcule el descuento de un producto solo si la cantidad comprada es mayor o igual a 5 y menor o igual a 10. Prueba con cantidades de 4, 5, 10 y 11.

## Criterios de revisión
El código debe lanzar una excepción clara si la cantidad está fuera del rango [5, 10]. Debe incluir al menos tres casos de prueba: uno dentro del rango válido, uno justo por debajo del límite inferior y otro justo por encima del límite superior.
