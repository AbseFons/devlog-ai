## Objetivo
Aprender a capturar excepciones en JavaScript utilizando bloques try-catch-finally para evitar que fallos inesperados detengan la ejecución del programa, asegurando una respuesta elegante al usuario.

## Explicación
En JavaScript, los errores no controlados pueden colapsar aplicaciones enteras. El patrón estándar es envolver código potencialmente fallido en un bloque 'try'. Si ocurre un error, se ejecuta el bloque 'catch', donde puedes manejar el mensaje de error específico. Finalmente, el bloque 'finally' siempre se ejecuta, ideal para liberar recursos como cerrar conexiones de red o archivos. Este enfoque garantiza que la aplicación siga funcionando incluso ante fallos locales.

## Ejemplo (no ejecutado automáticamente)
Intento de división por cero capturado y manejado con un mensaje amigable al usuario.

```javascript
function dividir(a, b) {
  try {
    return a / b;
  } catch (error) {
    console.error('Error:', error.message);
    return null;
  }
}
dividir(10, 0);
```
