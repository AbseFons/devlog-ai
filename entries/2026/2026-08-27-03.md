## Objetivo
Al finalizar esta lección, el desarrollador será capaz de definir una clave foránea en SQL para vincular tablas relacionadas, garantizando la integridad referencial y evitando datos huérfanos mediante el uso correcto de las cláusulas FOREIGN KEY y REFERENCES.

## Explicación
Las claves foráneas son fundamentales en bases de datos relacionales para mantener la consistencia entre tablas. Una clave foránea en una tabla hija hace referencia a la clave primaria de una tabla padre, asegurando que cada registro en la tabla hija exista realmente en la tabla padre. Esto previene la inserción de datos inválidos. SQL permite definir esta relación directamente al crear la tabla o mediante alteraciones posteriores. Es crucial entender las acciones de cascada (ON DELETE CASCADE/SET NULL) para manejar la eliminación de registros del padre sin romper la integridad de los datos hijos.

## Ejemplo (no ejecutado automáticamente)
```sql
CREATE TABLE Departamentos (
    id_departamento INT PRIMARY KEY,
    nombre VARCHAR(100)
);

CREATE TABLE Empleados (
    id_empleado INT PRIMARY KEY,
    nombre_empleado VARCHAR(100),
    id_departamento INT,
    FOREIGN KEY (id_departamento)
        REFERENCES Departamentos(id_departamento)
        ON DELETE SET NULL
);
```
