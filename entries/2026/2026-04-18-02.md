## Objetivo
Comprender cómo las pruebas de integración verifican la comunicación correcta entre componentes del sistema, asegurando que los datos fluyan sin errores a través de las interfaces definidas.

## Explicación
Las pruebas de integración evalúan la interacción entre módulos o servicios externos. En este caso, simularemos una llamada a una API REST para obtener un usuario y validar que el cuerpo de respuesta coincide con el contrato esperado. Esto detecta fallos en la serialización de datos o en la lógica del servidor antes de llegar al usuario final.

## Ejemplo (no ejecutado automáticamente)
Script que utiliza requests para llamar a una endpoint ficticia y asertiva sobre el estado HTTP y los campos JSON devueltos.

```python
import requests
response = requests.get('https://api.ejemplo.com/usuarios/1')
assert response.status_code == 200 and 'nombre' in response.json()
```
