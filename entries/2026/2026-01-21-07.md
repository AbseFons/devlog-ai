## Objetivo
Comprender cómo las funciones internas acceden a variables externas incluso después de que la función externa haya terminado de ejecutarse, aprovechando el cierre del ámbito lexical.

## Explicación
Un closure es una función que recuerda su entorno léxico. Cuando definimos una función dentro de otra, esta interna puede acceder a las variables de la externa. Al finalizar la ejecución de la función externa, sus variables no se liberan inmediatamente si hay funciones internas que las necesiten. El motor de JavaScript crea un objeto closure que mantiene referencias a esas variables. Esto permite crear funciones con estado privado o callbacks personalizados sin necesidad de pasar parámetros constantemente.

## Ejemplo (no ejecutado automáticamente)
Se define una función factory que crea contadores individuales. Cada llamada devuelve una función closure que recuerda su propio contador, permitiendo múltiples instancias independientes.

```javascript
function crearContador(inicial) {
  let cuenta = inicial;
  return function() {
    return ++cuenta;
  };
}
const c1 = crearContador(0);
const c2 = crearContador(5);
```
