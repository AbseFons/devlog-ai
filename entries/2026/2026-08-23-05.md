## Objetivo
Entender cómo la programación dinámica resuelve problemas de optimización mediante subproblemas superpuestos, aplicando el principio de optimalidad para construir soluciones eficientes paso a paso en lugar de usar fuerza bruda.

## Explicación
La programación dinámica es esencial cuando un problema grande se descompone en partes más pequeñas repetidas. En este caso, usaremos la técnica 'bottom-up' para calcular el máximo valor alcanzable con una mochila limitada. Primero definimos una tabla donde cada celda representa el mejor resultado posible hasta ese peso. Luego iteramos sobre los objetos disponibles, actualizando la tabla si incluir un objeto mejora el valor total sin exceder el límite de peso. Esta estrategia evita recalcular soluciones idénticas, reduciendo la complejidad exponencial a polinómica. Es fundamental identificar el estado y la transición correcta entre estados para garantizar que cada decisión local contribuya al óptimo global.

## Ejemplo (no ejecutado automáticamente)
```python
def knapsack_max_value(weights, values, capacity):
    n = len(weights)
    dp = [[0 for _ in range(capacity + 1)] for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i-1][w], dp[i-1][w - weights[i-1]] + values[i-1])
            else:
                dp[i][w] = dp[i-1][w]
    return dp[n][capacity]

# Caso realista: optimizar carga de suministros médicos
pesos = [2, 3, 4, 5]
valores = [10, 15, 20, 25]
capacidad_mochila = 8
print(f"Valor máximo: {knapsack_max_value(pesos, valores, capacidad_mochila)}")
```
