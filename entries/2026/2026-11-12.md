## Objetivo
Aprender a definir excepciones propias para encapsular errores de dominio específicos, mejorando la claridad del código y permitiendo un manejo de errores más granular que las clases estándar de Python.

## Explicación
Las excepciones personalizadas permiten modelar errores específicos del negocio. Creando una clase que herede de Exception, podemos lanzar errores con mensajes contextuales únicos. Esto facilita la depuración al identificar rápidamente el origen del problema sin depender de códigos genéricos. En este ejemplo, definimos 'SaldoInsuficiente' para validar transacciones bancarias. Al levantar esta excepción, el sistema puede reaccionar de manera específica (ej. bloquear tarjeta) en lugar de mostrar un error genérico de sintaxis o lógica general.

## Ejemplo (no ejecutado automáticamente)
Definición y uso de una excepción personalizada para validar saldos bancarios antes de realizar un retiro.

```python
class SaldoInsuficiente(Exception):
    def __init__(self, saldo_actual, monto_solicitado):
        super().__init__(f"Saldo insuficiente: {saldo_actual} < {monto_solicitado}")

try:
    SaldoInsuficiente(100, 200)
except SaldoInsuficiente as e:
    print(e)
```
