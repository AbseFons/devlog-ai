## Objetivo
Comprender cómo evitar mutaciones de estado global y efectos secundarios para garantizar que las funciones sean predecibles, fáciles de probar y composables en aplicaciones Python robustas.

## Explicación
Una función pura no debe modificar variables externas ni depender de ellas. En Python, esto implica evitar el uso de 'global' o mutar listas compartidas dentro de la lógica de negocio. Para lograrlo, devuelve siempre nuevos objetos inmutables o crea copias explícitas de las estructuras de datos antes de operar sobre ellas. Esto simplifica el flujo de control y permite paralelizar tareas sin riesgo de condiciones de carrera. Al mantener la pureza, el código se vuelve más legible porque el comportamiento es determinista: mismas entradas siempre producen mismas salidas.

## Ejemplo (no ejecutado automáticamente)
Función que calcula un descuento aplicándolo a una copia de la lista de precios original sin alterar los datos fuente.

```python
def aplicar_descuento_precios(precios, porcentaje):
    precios_nuevos = [p * (1 - porcentaje / 100) for p in precios]
    return precios_nuevos

lista_original = [100, 200, 300]
resultado = aplicar_descuento_precios(lista_original, 10)
print(f"Original: {lista_original}")
print(f"Nueva lista: {resultado}")
```
