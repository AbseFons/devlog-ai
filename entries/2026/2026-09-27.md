## Objetivo
Dominar la sintaxis fundamental para crear archivos modulares en JavaScript, exportando funciones específicas e importándolas en otros módulos sin conflictos de ámbito global.

## Explicación
Los módulos ES permiten encapsular lógica en archivos independientes. Para compartir código, se usa 'export' dentro del archivo origen y 'import' en el destino. Es crucial recordar que las variables declaradas con 'const' o 'let' no son accesibles desde fuera de su módulo por defecto, a menos que se exporten explícitamente. Esto previene colisiones de nombres y mantiene el código limpio. Al importar, JavaScript resuelve la ruta relativa del archivo automáticamente. Este patrón es esencial para aplicaciones escalables donde múltiples archivos deben colaborar sin interferir entre sí, facilitando pruebas unitarias y mantenimiento del código fuente.

## Ejemplo (no ejecutado automáticamente)
Un archivo calculadora.js exporta funciones de suma y resta, mientras que main.js las importa para ejecutar operaciones básicas.

```javascript
export const sumar = (a, b) => a + b;
export const restar = (a, b) => a - b;
```

## Ejercicio
Crea un archivo 'utils.js' que exporte una función 'saludar(nombre)' y otro llamado 'app.js' que importe esa función y muestre el saludo de 'Mundo'.

## Criterios de revisión
El código debe usar la sintaxis correcta de export e import, no utilizar variables globales para compartir datos entre archivos y mantener las funciones puras.
