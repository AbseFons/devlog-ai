## Objetivo
Comprender los fundamentos de la paginación en APIs REST, identificando sus patrones comunes como query parameters y headers para manejar grandes volúmenes de datos de manera eficiente.

## Explicación
Las APIs modernas a menudo devuelven conjuntos de datos extensos que no pueden transmitirse en una sola respuesta. La paginación divide estos resultados en bloques manejables, mejorando el rendimiento y la estabilidad del cliente. Los patrones más frecuentes incluyen el uso de parámetros de consulta como ?page=1&limit=20 o encabezados HTTP como Link para indicar la navegación entre páginas. Es crucial implementar lógica de control en el lado del cliente para iterar hasta agotar los resultados, evitando bucles infinitos o sobrecargas de red.

## Ejemplo (no ejecutado automáticamente)
Consulta paginada a una API ficticia de usuarios utilizando parámetros de consulta estándar y manejo básico de respuestas JSON.

```javascript
const url = 'https://api.ejemplo.com/usuarios?page=1&limit=10';
fetch(url).then(res => res.json()).then(data => console.log(data.items));
```

## Ejercicio
Implementa una función asíncrona que reciba una URL base y un tamaño de página, devolviendo un array con todos los usuarios disponibles mediante paginación automática hasta el final.

## Criterios de revisión
El código debe manejar correctamente la detección del fin de los datos (cuando no hay más items o el header indica ausencia de siguiente página) y no debe generar errores si la API devuelve menos elementos que el límite solicitado.
