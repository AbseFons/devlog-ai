## Objetivo
Que el desarrollador entienda el concepto de Token Bucket para controlar la tasa de solicitudes a una API, evitando saturar recursos y manteniendo la estabilidad del servicio ante picos de tráfico inesperados.

## Explicación
El algoritmo de Token Bucket es ideal para permitir ráfagas controladas mientras se mantiene un límite promedio. Funciona almacenando 'tokens' en un búfer; cada solicitud consume un token. Si el búfer está vacío, la solicitud se rechaza o espera. A diferencia del Leaky Bucket que suaviza todo el flujo, este permite picos breves. Es fundamental para APIs públicas donde los usuarios legítimos pueden necesitar enviar múltiples peticiones rápidas (ej. autenticación), pero sin permitir ataques de fuerza bruta masiva.

## Ejemplo (no ejecutado automáticamente)
```python
import time
from collections import deque

class TokenBucket:
    def __init__(self, rate, capacity):
        self.rate = rate  # Tokens por segundo
        self.capacity = capacity
        self.tokens = capacity
        self.last_update = time.time()

    def consume(self, amount=1):
        now = time.time()
        elapsed = now - self.last_update
        self.tokens = min(self.capacity, self.tokens + elapsed * self.rate)
        self.last_update = now
        if self.tokens >= amount:
            self.tokens -= amount
            return True
        return False

# Configuración: 10 solicitudes por segundo, capacidad de ráfaga de 20
bucket = TokenBucket(rate=10, capacity=20)

# Simulación de tráfico
for i in range(5):
    if bucket.consume():
        print(f"Solicitud {i+1}: Aprobada")
    else:
        print(f"Solicitud {i+1}: Rechazada (límite alcanzado)")
```
