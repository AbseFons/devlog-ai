## Objetivo
Dominar la implementación de restricciones CHECK para rangos numéricos y UNIQUE para integridad referencial, asegurando la calidad de los datos desde el diseño inicial de las tablas.

## Explicación
Las restricciones CHECK y UNIQUE son fundamentales para mantener la integridad de los datos. La cláusula CHECK permite definir condiciones lógicas que deben cumplirse siempre al insertar o actualizar registros, como verificar que un salario no sea negativo o que una edad esté dentro de un rango válido. Por otro lado, UNIQUE garantiza que ninguna columna contenga valores duplicados, ideal para identificadores secundarios como números de teléfono o correos electrónicos. Ambas restricciones se definen en la definición de tabla (DDL) y actúan como filtros automáticos del motor de base de datos, previniendo errores humanos antes de que contaminen el conjunto de datos.

## Ejemplo (no ejecutado automáticamente)
Creación de una tabla de empleados con restricción CHECK para salario positivo y UNIQUE para el número de teléfono.

```sql
CREATE TABLE Empleados (
    id INT PRIMARY KEY,
    nombre VARCHAR(100),
    salario DECIMAL(10,2) CHECK (salario > 0),
    telefono VARCHAR(20) UNIQUE
);
```
