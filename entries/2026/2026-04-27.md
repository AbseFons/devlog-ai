## Objetivo
Comprender cómo descomponer problemas matemáticos complejos, como el cálculo de series, en casos base y pasos recursivos para simplificar su implementación algorítmica.

## Explicación
La recursión permite definir una función que se llama a sí misma para resolver subproblemas más pequeños. En este contexto, calculamos la suma de una serie geométrica. El caso base detiene la llamada infinita cuando el índice alcanza cero. Cada paso actualiza el acumulador sumando el término correspondiente y reduce el problema llamando a la función con un índice decrementado. Este enfoque divide y conquista facilita la lectura del código al expresar directamente la definición matemática de la serie sin bucles explícitos, aunque requiere cuidado para evitar desbordamientos de pila en casos profundos.

## Ejemplo (no ejecutado automáticamente)
Cálculo iterativo de la suma de una serie geométrica simple usando recursión directa.

```python
def suma_series(n, r=2):
    if n == 0:
        return 1
    return (r ** n) + suma_series(n - 1, r)
print(suma_series(3))
```
