## Objetivo
Comprender la naturaleza del tipado dinámico en Python y aprender a utilizar anotaciones para mejorar la legibilidad del código, documentar intenciones explícitas y facilitar la detección temprana de errores en proyectos colaborativos.

## Explicación
Python es un lenguaje de tipado dinámico donde las variables no tienen un tipo fijo al momento de su declaración. Esto permite flexibilidad, pero puede ocultar errores hasta la ejecución. Las anotaciones, introducidas con PEP 484, son opcionales y sirven para documentar el tipo esperado de los datos sin afectar la lógica del programa. Por ejemplo, declarar una variable como 'nombre: str' indica claramente que se espera un texto. Estas herramientas son esenciales en bibliotecas modernas como Pandas o FastAPI, donde la precisión de los tipos mejora la robustez del software y permite a los editores de código ofrecer autocompletado inteligente.

## Ejemplo (no ejecutado automáticamente)
Definición de una función que calcula el área de un círculo, utilizando anotaciones para especificar que el radio es un número flotante y el resultado también lo será.

```python
def calcular_area(radio: float) -> float:
    return 3.14159 * radio ** 2
```
