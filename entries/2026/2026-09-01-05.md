## Objetivo
Al finalizar esta lección, el desarrollador podrá seleccionar la estrategia de versionado más adecuada (URL, header o query) para su API, implementando un endpoint v1 y explicando cómo mantener la compatibilidad hacia atrás sin romper clientes existentes.

## Explicación
El versionado es esencial para gestionar cambios en una API sin interrumpir a los consumidores actuales. Existen tres enfoques principales: incluir la versión en la URL (ej. /api/v1/users), usar un encabezado HTTP (Accept) o parámetros de consulta. La estrategia por URL es la más explícita y fácil de depurar, ideal para APIs públicas. El uso de headers permite mantener URLs limpias pero añade complejidad al cliente. Los parámetros de consulta son menos recomendados por su impacto en el caché y la legibilidad. Para una API empresarial, se sugiere comenzar con URL (/v1) y planificar la migración a headers o rutas dinámicas en futuras iteraciones. Siempre documenta claramente los cambios entre versiones.

## Ejemplo (no ejecutado automáticamente)
```python
from flask import Flask, jsonify, request

app = Flask(__name__)

# Simulación de datos de usuario
usuarios_db = [
    {"id": 1, "nombre": "Ana", "email": "ana@ejemplo.com"}
]

@app.route('/api/v1/usuarios', methods=['GET'])
def obtener_usuarios_v1():
    # Lógica de la versión 1: devuelve solo nombre y email
    return jsonify([{"id": u["id"], "nombre": u["nombre"], "email": u["email"]} for u in usuarios_db])

@app.route('/api/v2/usuarios', methods=['GET'])
def obtener_usuarios_v2():
    # Lógica de la versión 2: añade campo 'activo'
    return jsonify([{"id": u["id"], "nombre": u["nombre"], "email": u["email"], "activo": True} for u in usuarios_db])

if __name__ == '__main__':
    app.run(debug=True)
```

## Criterios de revisión
El código debe ejecutar sin errores en un entorno local. Ambas versiones deben devolver JSON válido con los campos especificados. No se permiten comandos destructivos ni credenciales expuestas. El archivo debe ser reproducible copiando y pegando el código en una nueva carpeta.
