## Objetivo
Aprender a configurar el módulo logging de Python para generar registros estructurados en formato JSON, facilitando la integración con sistemas de monitoreo modernos como ELK o Splunk, asegurando que los datos sean parseables automáticamente.

## Explicación
En esta lección avanzamos desde el registro básico hacia un formato estructurado. Utilizaremos el diccionario 'extra' dentro del método log() para inyectar metadatos específicos como IDs de transacción o niveles de severidad personalizados. Además, implementaremos una estrategia de rotación de archivos basada en tamaño usando RotatingFileHandler, lo cual es crucial para evitar el agotamiento del disco en aplicaciones de producción. Este enfoque permite transformar logs caóticos en datos accionables sin necesidad de parsers externos complejos.

## Ejemplo (no ejecutado automáticamente)
Configuración de un logger que escribe eventos en JSON puro con metadatos extra y rotación automática por tamaño.

```python
import logging
import json
from logging.handlers import RotatingFileHandler

def log_event(event_type, data):
    handler = RotatingFileHandler('app.log', maxBytes=50000, backupCount=3)
    formatter = logging.Formatter(json.dumps(data))
    handler.setFormatter(formatter)
    logger = logging.getLogger('structured')
    logger.addHandler(handler)
    logger.info(event_type, extra={'user_id': data.get('user_id'), 'trace_id': data.get('trace_id')})
```
