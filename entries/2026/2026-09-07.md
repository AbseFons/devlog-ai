## Objetivo
Aprender a identificar y probar valores extremos en entradas numéricas para prevenir errores de desbordamiento o lógica incorrecta en aplicaciones que procesan cantidades, precios o índices.

## Explicación
Los casos borde son esenciales cuando una función recibe números. Debes verificar no solo el valor ideal, sino los límites exactos del tipo de dato y valores adyacentes. Por ejemplo, si un campo acepta hasta 1000, prueba con 999, 1000, 1001 y valores negativos mínimos. Esto asegura que la aplicación maneje correctamente el desbordamiento o rechace entradas inválidas sin colapsar. Ignorar estos casos puede llevar a fallos en transacciones financieras o corrupción de datos.

## Ejemplo (no ejecutado automáticamente)
Script en Python que valida si un número entero está dentro del rango permitido [0, 1000] y maneja los casos borde como -1, 1000 y 1001.

```python
def validar_rango(valor):
    if valor < 0 or valor > 1000:
        return False
    return True
print(validar_rango(1000))
print(validar_rango(1001))
```
