## Objetivo
Aprender a utilizar el patrón adaptador para permitir la interoperabilidad entre clases con interfaces incompatibles, facilitando la integración de sistemas legacy sin modificar su código original.

## Explicación
El patrón adaptador actúa como un puente entre dos interfaces que no coinciden. Imagina una impresora antigua que solo acepta comandos en ASCII y un sistema moderno que usa JSON. El adaptador encapsula la lógica del dispositivo legacy, traduciendo las solicitudes modernas a su formato nativo. Esto permite reutilizar código existente sin violar el principio de responsabilidad única. Al crear una clase adaptadora, se define una interfaz estándar que el cliente espera, mientras internamente se delega al objeto legacy. Este enfoque es crucial en arquitecturas microservicios donde diferentes servicios pueden tener contratos de API distintos pero deben colaborar.

## Ejemplo (no ejecutado automáticamente)
Un adaptador que traduce llamadas JSON a comandos ASCII para controlar una impresora antigua.

```javascript
class LegacyPrinter {
  print(text) { console.log('ASCII:', text.toUpperCase()); }
}
class ModernAdapter {
  constructor(legacy) { this.legacy = legacy; }
  print(jsonData) { this.legacy.print(jsonData.message); }
}
```

## Ejercicio
Crea una clase adaptadora para un sensor de temperatura analógico que devuelve valores en voltaje, permitiendo que tu aplicación lea directamente como grados Celsius.

## Criterios de revisión
El código debe implementar la interfaz estándar del sistema, encapsular el objeto legacy sin modificarlo y realizar la conversión matemática correcta dentro del método adaptador.
