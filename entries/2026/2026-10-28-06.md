## Objetivo
Aprender a implementar un algoritmo de Token Bucket para controlar el tráfico API, protegiendo recursos backend de sobrecargas y asegurando equidad entre clientes.

## Explicación
El algoritmo Token Bucket permite picos de tráfico controlados. Funciona acumulando 'tokens' en un bucket hasta un límite máximo; cada solicitud consume un token. Si no hay tokens, la solicitud se rechaza o espera. Esto suaviza el uso de recursos sin bloquear completamente a usuarios legítimos durante breves periodos. Es ideal para APIs públicas que deben manejar tráfico irregular sin colapsar la infraestructura.

## Ejemplo (no ejecutado automáticamente)
Script en Python que simula un bucket de tokens y decide si permitir o denegar una solicitud basada en la disponibilidad de tokens.

```python
import time
max_tokens = 10
tokens = max_tokens
request_count = 0
for i in range(5):
    if tokens > 0:
        tokens -= 1
        request_count += 1
        print(f"Solicitud {i+1} permitida")
    else:
        print(f"Solicitud {i+1} denegada (sin tokens)")
```
