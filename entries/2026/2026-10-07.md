## Objetivo
Aprender a utilizar bloques try-catch para interceptar excepciones, prevenir fallos inesperados y ejecutar lógica alternativa segura al manejar datos no válidos o recursos que fallan.

## Explicación
En JavaScript, los errores no manejados pueden detener la ejecución de una aplicación. El patrón estándar consiste en envolver el código potencialmente problemático dentro de un bloque try. Si ocurre una excepción, se captura inmediatamente en el bloque catch, permitiendo mostrar mensajes amigables o valores por defecto sin colapsar todo el sistema. Es crucial no omitir el catch si hay riesgo de error, y evitar lanzar errores arbitrariamente con throw a menos que sea necesario para propagar fallos controlados.

## Ejemplo (no ejecutado automáticamente)
Intenta obtener un usuario del servidor; si falla, devuelve un objeto vacío seguro.

```javascript
async function obtenerUsuario(id) {
  try {
    const respuesta = await fetch(`/api/usuarios/${id}`);
    if (!respuesta.ok) throw new Error('Usuario no encontrado');
    return await respuesta.json();
  } catch (error) {
    console.log(`Error controlado: ${error.message}`);
    return {};
  }
}
```

## Ejercicio
Crea una función que divida dos números ingresados por el usuario. Usa try-catch para manejar la división por cero y lanza un error personalizado si los inputs no son números.

## Criterios de revisión
El código debe incluir al menos un bloque try, un catch que loguee el mensaje de error y una sentencia throw personalizada cuando se detecten entradas inválidas.
