## Objetivo
Aprender a sobrescribir métodos mágicos en dataclasses para controlar la representación de objetos, mejorar el debuggability y personalizar comportamientos como la comparación o la conversión a diccionario sin usar librerías externas.

## Explicación
Los dataclasses simplifican la creación de clases POJO, pero Python permite sobrescribir métodos especiales. El método __repr__ define cómo se muestra un objeto en consola, crucial para depurar. __str__ ofrece una representación más amigable para usuarios finales. También podemos definir __eq__, __lt__ o __hash__ para comparar instancias basadas en sus campos. Esto es vital cuando los datos tienen reglas de negocio específicas que no son puramente estructurales. Por ejemplo, dos objetos pueden ser iguales si sus IDs coinciden, ignorando otros campos. Además, se puede implementar __post_init__ para validar datos tras la creación o transformar valores automáticamente. Estas extensiones mantienen el código limpio y declarativo mientras añaden lógica compleja donde es necesaria.

## Ejemplo (no ejecutado automáticamente)
Un dataclass que sobrescribe __repr__ para mostrar un ID único y __eq__ para comparar solo por nombre, útil en sistemas de usuarios donde el ID interno no debe exponerse directamente.

```python
@dataclass
class Usuario:
    id: int
    nombre: str
    
    def __repr__(self):
        return f'Usuario(id={self.id}, {self.nombre})'
    
    def __eq__(self, other):
        return self.nombre == other.nombre
```

Luego, sobrescribe __hash__ para que los objetos sean hashables basándose únicamente en el campo 'sku', permitiendo usarlos como claves de diccionarios.
