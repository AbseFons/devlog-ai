## Objetivo
Comprender cuándo utilizar INNER JOIN para filtrar coincidencias exactas y LEFT JOIN para conservar todos los registros de una tabla principal, incluso sin coincidencias. Aprender a interpretar resultados nulos en columnas secundarias para tomar decisiones basadas en datos incompletos o ausentes.

## Explicación
El INNER JOIN devuelve solo las filas donde hay coincidencia en ambas tablas, ideal para reportes estrictos. Por el contrario, el LEFT JOIN preserva todas las filas de la tabla izquierda; si no hay coincidencia en la derecha, los valores se muestran como NULL. Esta distinción es vital cuando necesitas identificar clientes sin pedidos o productos sin stock asociado. En este caso práctico, analizaremos una base de datos de ventas para determinar qué productos no han sido vendidos nunca, utilizando LEFT JOIN y filtrando explícitamente los resultados nulos.

## Ejemplo (no ejecutado automáticamente)
Consulta SQL que une tablas de Productos y Ventas para identificar artículos sin registros de venta alguna.

```sql
SELECT p.nombre, COUNT(v.id_venta) as total_ventas
FROM productos p
LEFT JOIN ventas v ON p.id = v.producto_id
GROUP BY p.id, p.nombre
HAVING COUNT(v.id_venta) = 0;
```
