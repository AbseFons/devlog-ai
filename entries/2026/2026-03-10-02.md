## Objetivo
Comprender el principio de dividir y conquistar en arrays ordenados para reducir la complejidad temporal de O(n) a O(log n), aplicando comparaciones lógicas eficientes.

## Explicación
La búsqueda binaria es un algoritmo fundamental que requiere que los datos estén previamente ordenados. En lugar de revisar cada elemento secuencialmente, el algoritmo compara el valor objetivo con el elemento central del rango actual. Si coinciden, se ha encontrado el dato. Si el objetivo es menor, la búsqueda se restringe a la mitad izquierda; si es mayor, a la derecha. Este proceso de reducción del espacio de búsqueda por la mitad en cada iteración garantiza una eficiencia excepcional para grandes volúmenes de datos.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python que busca un número en una lista ordenada devolviendo su índice o -1 si no existe.

```python
def busqueda_binaria(arr, objetivo):
    izq, der = 0, len(arr) - 1
    while izq <= der:
        mid = (izq + der) // 2
        if arr[mid] == objetivo: return mid
        elif arr[mid] < objetivo: izq = mid + 1
        else: der = mid - 1
    return -1
```
