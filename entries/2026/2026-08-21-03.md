## Objetivo
Al finalizar esta lección, el desarrollador será capaz de explicar cómo una función interna accede a variables del ámbito exterior incluso después de que ese ámbito haya terminado su ejecución, y aplicará este concepto para crear funciones con estado privado.

## Explicación
Un closure en JavaScript es la capacidad de una función para recordar y acceder al ámbito léxico en el cual fue definida, incluso cuando se ejecuta fuera de ese contexto. Esto ocurre porque la función encapsula no solo su código, sino también las referencias a las variables locales del entorno donde nació. Este comportamiento es fundamental para crear patrones de diseño como módulos o funciones con estado persistente sin necesidad de usar clases o variables globales. Cuando una función externa devuelve otra función interna, el closure mantiene viva la referencia a las variables capturadas, permitiendo que la función devuelta manipule esos datos en llamadas posteriores.

## Ejemplo (no ejecutado automáticamente)
```javascript
function crearSaludo(nombre) {
  const mensaje = 'Hola '; // Variable capturada
  return function() {
    console.log(mensaje + nombre);
  };
}

const saludarAna = crearSaludo('Ana');
const saludarCarlos = crearSaludo('Carlos');

saludarAna(); // Imprime: Hola Ana
saludarCarlos(); // Imprime: Hola Carlos
```

## Ejercicio
Crea una función llamada 'contador' que acepte un número inicial. Esta función debe devolver otra función que, al ser invocada sin argumentos, incremente y retorne el valor actual del contador.

## Criterios de revisión
1. La función externa debe recibir un parámetro numérico.
2. La función interna debe incrementar una variable capturada en cada llamada.
3. Deben existir dos instancias distintas con valores iniciales diferentes que muestren estados independientes al ser ejecutadas.
