## Objetivo
Aprender a usar la clase Path de pathlib para construir rutas de archivos de manera portable, evitando errores comunes con separadores de directorios y codificación de caracteres en sistemas operativos diferentes.

## Explicación
En Python, el módulo pathlib ofrece una forma moderna y limpia de manejar rutas de archivos. La clase Path permite concatenar rutas sin preocuparse por los separadores específicos de cada sistema operativo (como / o \\). Esto hace que el código sea portable entre Windows, Linux y macOS. Además, facilita operaciones como verificar si un directorio existe, crear nuevos subdirectorios o listar archivos en una carpeta. En esta lección, exploraremos cómo usar Path para construir rutas dinámicas y realizar operaciones básicas de sistema de archivos de manera segura y eficiente.

## Ejemplo (no ejecutado automáticamente)
Crear una ruta absoluta relativa a la ubicación actual y verificar si existe un subdirectorio.

```python
from pathlib import Path
ruta = Path('datos')
if not ruta.exists():
    ruta.mkdir()
```
