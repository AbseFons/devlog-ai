## Objetivo
Aprender a utilizar bloques try, catch y finally para prevenir que fallos inesperados detengan la ejecución de una aplicación web, asegurando una experiencia de usuario estable.

## Explicación
En desarrollo moderno, los errores son inevitables. El bloque try ejecuta código potencialmente arriesgado; si falla, el catch captura el error específico evitando el colapso total del script. Finalmente, el finally asegura limpieza o notificaciones siempre que se ejecute. Esto permite mostrar mensajes amigables en lugar de pantallas blancas. Es crucial no re-lanzar errores innecesariamente y registrar los fallos para depuración futura.

## Ejemplo (no ejecutado automáticamente)
Intenta dividir un número por cero dentro de un bloque try, capturando el error en catch y mostrando un mensaje seguro al usuario.

```javascript
try {
  const resultado = 10 / 0;
} catch (error) {
  console.log('Error controlado: ' + error.message);
}
```

## Ejercicio
Crea una función que acepte dos números y devuelva su división. Si el denominador es cero o no es un número, lanza un Error personalizado con el mensaje 'División inválida'. Envuelve la llamada a esta función en un bloque try-catch que loguee el mensaje del error.

## Criterios de revisión
El código debe incluir al menos un bloque try, un catch y una función personalizada. El mensaje de error debe ser claro y no exponer detalles técnicos internos innecesarios.
