## Objetivo
Comprender la sintaxis básica de los decoradores en Python para modificar el comportamiento de funciones existentes sin alterar su código interno, facilitando la reutilización y la lógica transversal.

## Explicación
Los decoradores son una herramienta poderosa en Python que permite envolver funciones para añadir funcionalidad adicional. Utilizan la sintaxis @nombre_decorador justo encima de la definición de la función. Internamente, un decorador es una función que recibe otra función como argumento y devuelve una nueva función. Esto es ideal para tareas como medir tiempos de ejecución, manejar errores o gestionar permisos. En esta lección aprenderás a crear tu primer decorador simple que imprima mensajes antes y después de que se ejecute la función decorada.

## Ejemplo (no ejecutado automáticamente)
Un decorador básico que registra el nombre de la función y su hora de ejecución antes y después de que la función original se complete.

```python
def mi_decorador(func):
    def envoltura(*args, **kwargs):
        print(f'Ejecutando {func.__name__}')
        resultado = func(*args, **kwargs)
        print('Función terminada')
        return resultado
    return envoltura

@mi_decorador
def saludar(nombre):
    return f'Hola, {nombre}'

print(saludar('Ana'))
```
