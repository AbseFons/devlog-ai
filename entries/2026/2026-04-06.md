## Objetivo
Comprender los fundamentos de la paginación en APIs REST para manejar grandes volúmenes de datos eficientemente, evitando sobrecargar clientes y optimizando el rendimiento de la red mediante el uso de parámetros estándar.

## Explicación
Las APIs modernas a menudo retornan conjuntos de datos extensos que no caben en una sola respuesta. La paginación divide estos resultados en bloques manejables. El patrón estándar utiliza parámetros como 'page' o 'offset' junto con 'limit' o 'size'. La respuesta debe incluir metadatos como el número total de páginas y registros para permitir la navegación completa. Este enfoque mejora la experiencia del usuario al cargar datos progresivamente y reduce el consumo de ancho de banda.

## Ejemplo (no ejecutado automáticamente)
Consulta a una API ficticia de usuarios paginando los resultados con parámetros offset y limit, interpretando los metadatos en la respuesta JSON para navegar entre páginas.

```javascript
fetch('https://api.ejemplo.com/usuarios?offset=0&limit=10')
  .then(response => response.json())
  .then(data => console.log(data.items, data.totalPages))
```
