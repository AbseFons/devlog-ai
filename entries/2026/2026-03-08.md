## Objetivo
Comprender la estructura recursiva de un árbol binario simple y aplicar el algoritmo de recorrido preorden para extraer datos jerárquicos de manera eficiente.

## Explicación
Un árbol binario es una estructura donde cada nodo tiene como máximo dos hijos: izquierdo y derecho. El recorrido preorden visita primero la raíz, luego el subárbol izquierdo y finalmente el derecho. Este método es útil para copiar árboles o generar expresiones prefixadas. La implementación recursiva es directa: se imprime el valor actual, luego se llama a la función en el hijo izquierdo y después en el derecho. Es fundamental manejar correctamente los nodos nulos para evitar errores de ejecución.

## Ejemplo (no ejecutado automáticamente)
Se define una clase Node con valores numéricos y referencias a hijos, creando un árbol con raíz 10, hijo izquierdo 5 y derecho 20. Se ejecuta el recorrido preorden.

```javascript
class Node { constructor(val) { this.val = val; this.left = null; this.right = null; } }
const root = new Node(10);
root.left = new Node(5);
root.right = new Node(20);
```

## Ejercicio
Implementa una función recursiva que recorra un árbol binario en orden preorden y devuelva un array con los valores visitados.
