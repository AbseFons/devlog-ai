## Objetivo
Comprender la diferencia entre sets (conjuntos) y diccionarios, sus operaciones básicas de inserción, búsqueda y cómo utilizarlos para optimizar búsquedas y gestionar datos no ordenados o con claves únicas.

## Explicación
En Python, los sets son colecciones no ordenadas de elementos únicos, ideales para eliminar duplicados y realizar operaciones matemáticas como uniones o intersecciones. Los diccionarios, por otro lado, mapean claves a valores, permitiendo acceso rápido O(1) mediante una clave específica. Ambos usan tablas hash internamente. Un caso práctico es validar si un usuario ya existe en un sistema usando un set de IDs para comprobación rápida, o almacenar configuración de servidor donde la clave sea el puerto y el valor la descripción.

Creacion de un set con elementos repetidos y un diccionario con configuracion de red.

