## Objetivo
Aprender a implementar lógica personalizada tras la creación de instancias en dataclasses, validando datos críticos como emails o rangos numéricos sin escribir código repetitivo en cada campo.

## Explicación
Los dataclasses simplifican la definición de clases POJO, pero a veces requieren validación post-construcción. El método __post_init__ se ejecuta automáticamente después de crear el objeto con su constructor. Aquí puedes añadir lógica para verificar integridad de datos: por ejemplo, asegurar que un email tenga formato válido o que una edad esté entre 0 y 120. Si la validación falla, lanzas un ValueError. Esto mantiene el código limpio y centraliza las reglas de negocio relacionadas con la estructura del dato. Es ideal para modelos de dominio donde la consistencia es obligatoria antes de persistir o procesar.

## Ejemplo (no ejecutado automáticamente)
Definición de una clase Usuario con validación de email y edad en __post_init__

```python
from dataclasses import dataclass
from typing import Optional

@dataclass
class Usuario:
    nombre: str
    email: str
    edad: int
    
    def __post_init__(self):
        if '@' not in self.email:
            raise ValueError("Email inválido")
        if not 0 <= self.edad <= 120:
            raise ValueError("Edad fuera de rango")
```
