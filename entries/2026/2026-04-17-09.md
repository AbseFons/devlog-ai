## Objetivo
Introducir el concepto de pruebas basadas en propiedades, donde se verifica que una función cumpla invariantes lógicas (como conservación de datos) sin especificar casos de prueba exhaustivos, fomentando un diseño más robusto y declarativo del software.

## Explicación
Las pruebas basadas en propiedades son una técnica avanzada que valida el comportamiento de un sistema verificando si cumple con ciertas reglas o invariantes lógicas definidas por el desarrollador, en lugar de enumerar casos de prueba específicos. Por ejemplo, al implementar una función de transferencia de fondos, la propiedad fundamental es que la suma total del dinero en el sistema debe permanecer constante antes y después de la operación. Este enfoque permite detectar errores sutiles como fugas de datos o corrupción de estado que podrían pasar desapercibidos con pruebas tradicionales. La herramienta clave para esto es QuickCheck, que genera automáticamente miles de casos de prueba aleatorios para intentar refutar las propiedades declaradas. Si alguna prueba falla, el sistema proporciona un contraejemplo concreto que ayuda a depurar la lógica del código.

## Ejemplo (no ejecutado automáticamente)
Se define una propiedad en Haskell que asegura que la suma de los elementos de una lista nunca cambie tras aplicar una función de permutación aleatoria, validando así la integridad de los datos mediante generación automática de casos.

```haskell
import Test.QuickCheck
prop_sumaConservada :: [Int] -> Bool
prop_sumaConservada lista = sum (permutar lista) == sum lista
```

## Ejercicio
Implemente una propiedad en Python usando la librería Hypothesis que verifique que, al ordenar una lista de números enteros, el conteo de cada valor individual permanezca inalterado respecto a la lista original.

## Criterios de revisión
El código debe importar Hypothesis, definir una función llamada 'prop_contenido_inalterado' y utilizar la estrategia @given con listas generadas aleatoriamente. La propiedad debe comparar la longitud de la lista ordenada con la original y asegurar que no haya duplicados ni pérdidas.
