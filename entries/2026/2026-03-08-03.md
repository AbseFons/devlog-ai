## Objetivo
Aprender a usar la clase Path de pathlib para construir rutas absolutas y relativas, evitando errores comunes con separadores de directorios y mejorando la portabilidad del código en Python.

## Explicación
En lugar de concatenar strings con '/' o '\\', utiliza Path desde el módulo pathlib. Esto permite operaciones intuitivas como unir directorios, cambiar niveles y verificar existencia sin importar el sistema operativo. El ejemplo muestra cómo crear una ruta absoluta a un archivo de configuración dentro de la carpeta actual, verificando si existe antes de intentar leerlo. Este enfoque es más limpio y menos propenso a errores en proyectos multiplataforma.

## Ejemplo (no ejecutado automáticamente)
Crear una ruta absoluta a un archivo config.json y verificar su existencia usando pathlib.

```python
from pathlib import Path
ruta = Path(__file__).parent / 'config.json'
if ruta.exists():
    print('Archivo encontrado')
```
