## Objetivo
Aprender a convertir objetos Python complejos, como diccionarios y listas, en cadenas de texto JSON válidas utilizando la biblioteca estándar json. Comprender la sintaxis básica para exportar datos estructurados.

## Explicación
En Python, la serialización transforma estructuras de datos nativas en formato JSON intercambiable. La función json.dumps() convierte diccionarios y listas en cadenas legibles por máquinas o humanos. Es vital recordar que los diccionarios se mapean a objetos JSON {}, las listas a arrays [], y las claves deben ser strings. Los tipos booleanos True/False pasan a true/false, y None a null. Este proceso es esencial para APIs REST, almacenamiento de configuración o intercambio de datos entre servicios.

## Ejemplo (no ejecutado automáticamente)
Conversión de un diccionario de usuario a JSON

```python
import json
usuario = {"nombre": "Ana", "activo": True}
json_str = json.dumps(usuario)
```
