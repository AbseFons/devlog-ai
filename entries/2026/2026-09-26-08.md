## Objetivo
Aprender a capturar excepciones asíncronas utilizando el bloque try-catch con promesas, evitando que fallos inesperados detengan la ejecución del programa.

## Explicación
En JavaScript moderno, las operaciones asíncronas como llamadas a APIs suelen devolver promesas. Si una promesa se resuelve en estado 'rejected', es crucial interceptar el error para manejarlo adecuadamente. El patrón estándar implica envolver la llamada asíncrona dentro de un bloque try y capturar cualquier rechazo en el catch. Esto permite mostrar mensajes amigables, registrar logs detallados o reintentar la operación automáticamente. Sin este mecanismo, los errores no capturados generarían una pila de llamadas (stack trace) completa en la consola, dificultando el diagnóstico y degradando la experiencia del usuario final.

## Ejemplo (no ejecutado automáticamente)
Ejemplo de llamada a una API simulada que falla y se maneja con try-catch para mostrar un mensaje alternativo.

```javascript
fetch('https://api.ejemplo.com/datos')
  .then(response => response.json())
  .catch(error => console.log('Error de red:', error.message));
```
