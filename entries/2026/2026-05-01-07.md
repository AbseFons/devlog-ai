## Objetivo
Comprender el concepto fundamental de inyección de dependencias y cómo la inversión de control desacopla las clases, facilitando pruebas unitarias y un mantenimiento más sencillo en aplicaciones modernas.

## Explicación
La inyección de dependencias (IoC) es un patrón de diseño que permite a una clase recibir sus dependencias desde el exterior en lugar de crearlas internamente. Este enfoque promueve la inversión de control, donde el flujo de control se invierte respecto al modelo tradicional de creación de objetos. Al delegar la creación de dependencias a un contenedor o framework externo, las clases se vuelven más simples y enfocadas en su lógica principal. Esto reduce la complejidad acoplada y mejora significativamente la testabilidad del código, ya que permite sustituir fácilmente implementaciones reales por mocks o stubs durante las pruebas unitarias.

## Ejemplo (no ejecutado automáticamente)
Una clase de servicio que recibe un reproductor de audio como dependencia inyectada en su constructor para poder reproducir música.

```javascript
class ServicioMusica {
  constructor(reproductor) {
    this.reproductor = reproductor;
  }
  tocar() {
    return this.reproductor.reproducir();
  }
}
const musica = new ServicioMusica(new ReproductorFisico());
```
