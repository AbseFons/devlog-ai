## Objetivo
Aprender a manipular rutas de archivos utilizando pathlib para evitar errores comunes con separadores de directorios y construir estructuras de carpetas dinámicas sin depender del sistema operativo.

## Explicación
En esta lección exploramos la utilidad de Pathlib para manejar rutas relativas. A diferencia de las cadenas de texto, los objetos Path permiten operaciones intuitivas como unir directorios o cambiar nombres de archivos. Es crucial usar el método resolve() cuando se necesita una ruta absoluta normalizada, asegurando que siempre apunte al archivo correcto independientemente de cómo se haya escrito la ruta inicial. Esto previene errores en entornos multiplataforma donde los separadores de directorio varían entre Windows y Linux.

## Ejemplo (no ejecutado automáticamente)
Creación de un objeto Path relativo y resolución a ruta absoluta normalizada.

```python
from pathlib import Path
ruta = Path('datos/config.json')
absoluta = Path.cwd() / ruta.resolve()
```
