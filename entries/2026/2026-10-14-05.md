## Objetivo
Comprender cómo los closures permiten encapsular estado mutable dentro de funciones anidadas, facilitando la creación de contadores privados y controladores de eventos sin exponer variables globales innecesarias al ámbito principal del programa.

## Explicación
Un closure en JavaScript no solo recuerda su entorno léxico, sino que puede manipular variables externas para mantener un estado persistente. En este caso práctico, creamos una función 'crearContador' que devuelve otra función con acceso a la variable privada 'contador'. Cada vez que se invoca la función devuelta, incrementa el valor interno sin afectar al ámbito global. Esto es ideal para implementar patrones de diseño como singletons o controladores de eventos donde el estado debe ser oculto pero accesible desde una interfaz pública específica.

## Ejemplo (no ejecutado automáticamente)
Implementación de un contador privado encapsulado mediante closure que incrementa su valor interno en cada llamada sin exponer la variable base.

```javascript
function crearContador() {
  let contador = 0;
  return function() { contador++; return contador; };
}
const miContador = crearContador();
console.log(miContador()); // 1
console.log(miContador()); // 2
```
