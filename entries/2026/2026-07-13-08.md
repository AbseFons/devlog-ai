## Objetivo
Dominar la sintaxis básica de Common Table Expressions para simplificar consultas complejas, mejorar la legibilidad del código y reutilizar lógica temporal en bases de datos relacionales modernas.

## Explicación
Las Common Table Expressions o CTEs permiten definir un conjunto de resultados temporalmente disponible para una consulta principal. Sintácticamente se declaran con la palabra clave WITH antes del SELECT, INSERT o UPDATE. Esto facilita descomponer problemas complejos en pasos lógicos claros, evitando subconsultas anidadas excesivas que dificultan el mantenimiento. En este nivel inicial, aprenderás a estructurar consultas paso a paso, nombrando cada etapa para que el flujo de datos sea transparente. La CTE se elimina automáticamente tras su uso inmediato, garantizando seguridad y rendimiento adecuado en entornos productivos sin necesidad de crear vistas permanentes.

## Ejemplo (no ejecutado automáticamente)
Consulta que calcula el total de ventas por categoría usando una CTE intermedia para filtrar productos activos antes de agrupar los resultados.

```sql
WITH VentasActivas AS (
  SELECT categoria, SUM(precio * cantidad) as total
  FROM pedidos
  WHERE estado = 'completado'
)
SELECT categoria, total FROM VentasActivas ORDER BY total DESC;
```

## Criterios de revisión
