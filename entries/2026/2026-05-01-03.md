## Objetivo
Comprender la definición fundamental de un árbol binario, sus nodos raíz e hijos, y cómo realizar recorridos básicos como el inorden para extraer datos de manera estructurada.

## Explicación
Un árbol binario es una estructura jerárquica donde cada nodo tiene a lo sumo dos hijos: izquierdo y derecho. La raíz es el punto de entrada. En este contexto, exploraremos la representación mediante clases o objetos. Cada nodo contiene un valor y referencias a sus subnodos. El recorrido inorden (izquierdo, raíz, derecho) es esencial para ordenar datos si el árbol está balanceado. Esta estructura permite búsquedas eficientes en conjuntos de datos ordenados, siendo la base para implementaciones de tablas hash avanzadas o árboles AVL.

## Ejemplo (no ejecutado automáticamente)
Definición de un nodo y creación de un árbol binario simple con tres elementos usando clases en Python.

```python
class Nodo:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None

raiz = Nodo(10)
raiz.izquierdo = Nodo(5)
```

## Ejercicio
Crea un árbol binario con una raíz de valor 20, un hijo izquierdo de 10 y un hijo derecho de 30. Luego, implementa una función que imprima los valores en orden inorden.

El código debe definir correctamente la clase Nodo con atributos para valor e hijos. Debe instanciar al menos tres nodos conectados entre sí. La función de recorrido debe visitar primero el subárbol izquierdo, luego el nodo actual y finalmente el derecho.
