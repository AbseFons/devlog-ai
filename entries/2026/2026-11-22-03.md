## Objetivo
Aprender a estructurar un sistema de control de acceso basado en roles (RBAC) que soporte jerarquías, permitiendo la delegación segura de permisos sin duplicar reglas ni comprometer la integridad del modelo de autorización.

## Explicación
En esta microlección exploramos cómo diseñar una matriz de permisos escalonada. Comenzaremos definiendo roles base como 'Analista' y 'Gerente', donde el segundo hereda las capacidades del primero. Implementaremos una lógica de validación que verifica si un usuario posee un rol directo o uno superior en la jerarquía antes de conceder acceso a recursos críticos. Este enfoque reduce la complejidad administrativa al centralizar la asignación de privilegios y minimiza errores humanos comunes como el olvido de revocar accesos en cambios de puesto. El código presentado utiliza una estructura de datos simple para representar la jerarquía y un algoritmo de recursión o búsqueda ascendente para determinar los permisos efectivos, asegurando que la seguridad sea robusta frente a la evolución organizacional.

## Ejemplo (no ejecutado automáticamente)
Script en Python que define una jerarquía de roles (Analista, Gerente, Director) y verifica si un usuario tiene permiso para aprobar presupuestos basándose en su rol actual o superior.

```python
def verificar_permiso(rol_usuario, permisos_requeridos):
    jerarquia = {'Analista': [], 'Gerente': ['Analista'], 'Director': ['Gerente', 'Analista']}
    if rol_usuario in permisos_requeridos:
        return True
    for rol_superior in jerarquia.get(rol_usuario, []):
        if verificar_permiso(rol_superior, permisos_requeridos):
            return True
    return False
```
