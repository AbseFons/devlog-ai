## Objetivo
Aprender a configurar un registro de eventos en Python que incluya metadatos clave como ID de usuario, nivel de severidad y mensaje, facilitando el análisis posterior con herramientas estándar.

## Explicación
El logging tradicional suele generar texto plano difícil de filtrar. La estructuración permite capturar datos específicos (como 'user_id' o 'action') en cada registro. En esta lección, utilizaremos la biblioteca stdlib para crear un logger que emita diccionarios JSON en lugar de cadenas. Esto se logra definiendo un formato personalizado que serializa los campos extra como atributos del objeto de registro. Al hacerlo, cualquier herramienta de monitoreo puede indexar y buscar rápidamente por el ID del usuario sin necesidad de parsear texto complejo. Este enfoque es fundamental para sistemas escalables donde la trazabilidad es crítica.

## Ejemplo (no ejecutado automáticamente)
Configuración de un logger que emite registros en formato JSON incluyendo campos personalizados como user_id y action.

```python
import logging
import json
logger = logging.getLogger('app')
logger.setLevel(logging.INFO)
handler = logging.StreamHandler()
formatter = logging.Formatter(json.dumps, default=str)
handler.setFormatter(formatter)
```
