## Objetivo
Al finalizar, el desarrollador implementará una búsqueda en anchura (BFS) en grafos no ponderados para encontrar la distancia mínima entre nodos, evitando recursión profunda y optimizando la complejidad temporal a O(V+E).

## Explicación
La Búsqueda por Anchura (BFS) es el algoritmo estándar para resolver problemas de caminos más cortos en grafos sin pesos. Utiliza una cola FIFO para visitar nodos capa por capa, garantizando que el primer camino encontrado sea el óptimo. A diferencia del DFS, que puede profundizar excesivamente y causar desbordamiento de pila en grafos grandes, la BFS mantiene un control estricto sobre la profundidad actual. Es fundamental añadir cada nodo a una lista de visitados al procesarlo para evitar ciclos infinitos en grafos cíclicos. Este enfoque es ideal para redes sociales (amigos de grado) o mapeo de rutas donde el costo por arista es uniforme.

## Ejemplo (no ejecutado automáticamente)
```python
from collections import deque

def bfs_shortest_path(graph, start, end):
    if start not in graph or end not in graph:
        return None
    queue = deque([(start, [start])])
    visited = {start}
    while queue:
        node, path = queue.popleft()
        if node == end:
            return path
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, path + [neighbor]))
    return None

# Caso de uso: Red de servidores
red = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': ['D', 'E'],
    'D': [],
    'E': []
}
print(bfs_shortest_path(red, 'A', 'E'))  # Salida: ['A', 'C', 'E']
```
