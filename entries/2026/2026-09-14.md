## Objetivo
Comprender la diferencia entre tipado dinámico implícito y las anotaciones estáticas opcionales en Python, mejorando la legibilidad del código y facilitando la detección temprana de errores en proyectos colaborativos.

## Explicación
Python utiliza un sistema de tipado dinámico donde el tipo se infiere al asignar valores. Sin embargo, desde Python 3, las anotaciones permiten declarar tipos explícitamente sin afectar la ejecución. Esto es útil para documentar intenciones y usar herramientas como mypy. Las anotaciones son opcionales; si no se especifican, el intérprete determina el tipo automáticamente. Por ejemplo, al definir una función que suma dos números, podemos anotar los parámetros como enteros y el retorno como entero. Esto no cambia la lógica del programa, pero ayuda a otros desarrolladores a entender rápidamente las expectativas de entrada y salida. Además, estas anotaciones son esenciales para frameworks modernos de validación de datos y generación de documentación automática.

## Ejemplo (no ejecutado automáticamente)
Función que calcula el área de un rectángulo con parámetros tipados explícitamente.

```python
def calcular_area(ancho: float, alto: float) -> float:
    return ancho * alto
```
