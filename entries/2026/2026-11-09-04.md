## Objetivo
Aprender a aplicar roles y permisos mediante middleware para proteger endpoints críticos sin exponer lógica interna ni credenciales, asegurando que solo usuarios autorizados accedan a recursos específicos en una arquitectura moderna.

## Explicación
El Control de Acceso basado en Roles (RBAC) se implementa comúnmente usando middleware que intercepta solicitudes antes de llegar al controlador. Este enfoque separa la lógica de autorización del procesamiento de datos. El middleware verifica el rol del usuario autenticado contra una política definida, permitiendo o denegando la solicitud dinámicamente. Esto evita fugas de información y reduce la superficie de ataque. Es crucial definir principios de mínimo privilegio desde el inicio.

## Ejemplo (no ejecutado automáticamente)
Un middleware en Node.js que verifica si el usuario tiene el rol 'admin' antes de permitir el acceso a una ruta protegida, devolviendo un error 403 si no cumple.

```javascript
const checkRole = (roles) => async (req, res, next) => {
  if (!req.user || !roles.includes(req.user.role)) return res.status(403).json({ error: 'Acceso denegado' });
  next();
};
```

## Ejercicio
Crea un middleware similar para una aplicación Python usando Flask que verifique si el encabezado 'X-Role' contiene 'analista' antes de permitir la llamada a /api/reports.
