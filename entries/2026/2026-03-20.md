## Objetivo
Aprender a estructurar una prueba unitaria básica en Python utilizando el framework estándar unittest, definiendo métodos que heredan de TestCase para validar la lógica de negocio.

## Explicación
En esta lección exploraremos los fundamentos de unittest. Primero, importamos la clase TestCase y creamos una subclase llamada TestCalculadora. Dentro, definimos un método test_suma que verifica si la suma de dos números es correcta. Utilizamos assertEqual para comparar el resultado esperado con el real. Es crucial nombrar los métodos con 'test_' seguido del nombre de la acción a probar. Al ejecutar el script, unittest descubrirá automáticamente estos métodos y ejecutará las pruebas, mostrando resultados claros de éxito o fallo.

## Ejemplo (no ejecutado automáticamente)
Un script que define una clase TestCalculadora con un método test_suma que valida la operación suma usando assertEqual.

```python
from unittest import TestCase
class TestCalculadora(TestCase):
    def test_suma(self):
        self.assertEqual(2 + 2, 4)
```
