## Objetivo
Al finalizar esta lección, el desarrollador será capaz de identificar dependencias transitivas en tablas existentes y aplicar transformaciones para alcanzar la Tercera Forma Normal, eliminando redundancia de datos y mejorando la integridad referencial sin perder información crítica.

## Explicación
La normalización busca organizar datos para evitar anomalías. Tras la Segunda Forma Normal (2FN), nos enfocamos en la Tercera Forma Normal (3FN). Una tabla está en 3FN si no tiene dependencias transitivas: esto ocurre cuando un atributo no clave depende de otro atributo no clave, y no directamente de la clave primaria. Por ejemplo, si 'Ciudad' depende de 'Estado', y 'Estado' depende de la clave, entonces 'Ciudad' depende transitivamente de la clave. Para corregir esto, creamos una nueva tabla para el par (Estado, Ciudad) y actualizamos las claves foráneas. Este proceso reduce el almacenamiento duplicado y asegura que los datos sean consistentes al actualizar un solo registro en lugar de múltiples.

## Ejemplo (no ejecutado automáticamente)
```sql
-- Tabla original con dependencia transitiva: Estado -> Ciudad -> ZonaPostal
CREATE TABLE Clientes_Incorrectos (
    id_cliente INT PRIMARY KEY,
    nombre VARCHAR(100),
    estado VARCHAR(50),
    ciudad VARCHAR(50),
    zona_postal VARCHAR(10)
);

-- Inserción de datos redundantes
INSERT INTO Clientes_Incorrectos VALUES (1, 'Ana', 'CDMX', 'Juárez', '06600');
INSERT INTO Clientes_Incorrectos VALUES (2, 'Luis', 'CDMX', 'Juárez', '06600');

-- Corrección: Crear tabla intermedia para romper la dependencia transitiva
CREATE TABLE Ubicaciones (
    estado VARCHAR(50),
    ciudad VARCHAR(50),
    zona_postal VARCHAR(10),
    PRIMARY KEY (estado, ciudad)
);

-- Actualizar datos en la nueva tabla y modificar la estructura original
INSERT INTO Ubicaciones VALUES ('CDMX', 'Juárez', '06600');
ALTER TABLE Clientes_Incorrectos DROP COLUMN estado, ciudad, zona_postal;
ALTER TABLE Clientes_Incorrectos ADD ubicacion_id INT;
-- Nota: En producción se usaría una clave foránea hacia Ubicaciones
```
