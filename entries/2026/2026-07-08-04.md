## Objetivo
Aprender a usar decoradores para extender la funcionalidad de funciones sin alterar su código interno, aplicando lógica reutilizable como validación o registro.

## Explicación
Los decoradores son funciones especiales que toman otra función como argumento y devuelven una nueva versión modificada. Esto permite inyectar comportamientos transversales como logging, autenticación o manejo de errores sin ensuciar el código principal. En Python, se definen usando la sintaxis @decorador justo encima de la definición de la función. El decorador intercepta la ejecución, ejecuta su propia lógica antes o después de llamar a la función original, y finalmente devuelve el resultado. Es una herramienta poderosa para mantener el código limpio y modular.

## Ejemplo (no ejecutado automáticamente)
Un decorador que registra la hora de inicio y fin de cada llamada a una función.

```python
import time

def registrar_tiempo(func):
    def envoltura(*args, **kwargs):
        print(f"Inicio: {time.time()}")
        resultado = func(*args, **kwargs)
        print(f"Fin: {time.time()}")
        return resultado
    return envoltura

@registrar_tiempo
def calcular_cuadrado(x):
    return x * x
```
