## Objetivo
Comprender cómo una función hash transforma claves arbitrarias en índices numéricos para acceso O(1) a datos, identificando el rol del tamaño del array y la distribución uniforme.

## Explicación
Una tabla hash es una estructura de datos que permite acceder a elementos casi instantáneamente. Funciona mediante una función hash que toma una clave (como un nombre o ID) y la convierte en un número entero. Este número se usa como índice para guardar el valor en un array interno. El desafío principal es evitar colisiones, donde dos claves distintas generan el mismo índice. Una estrategia básica es asignar el índice usando el operador módulo: indice = hash(clave) % tamano_array. Esto asegura que el resultado siempre caiga dentro de los límites del array. Aunque simple, esta técnica sienta las bases para estructuras más complejas como listas encadenadas o árboles balanceados.

## Ejemplo (no ejecutado automáticamente)
Implementación básica en Python que calcula el índice de almacenamiento para una clave usando la función hash nativa y el operador módulo sobre un tamaño fijo de 10.

```python
tamano = 10
codigo = "usuario_123"
indice = hash(codigo) % tamano
print(f"Clave: {codigo} -> Indice: {indice}")
```
