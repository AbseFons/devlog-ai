## Objetivo
Al finalizar esta lección, el desarrollador comprenderá cómo el Event Loop gestiona tareas asíncronas, diferenciando la pila de llamadas del colón de tareas y sabrá predecir el orden de ejecución en código real.

## Explicación
El Event Loop es el mecanismo que permite a JavaScript ser no bloqueante. Cuando una tarea asíncrona (como una petición HTTP) se inicia, se delega al sistema operativo o navegador. Mientras tanto, el hilo principal ejecuta tareas síncronas de la pila de llamadas. Una vez completadas estas, si hay promesas pendientes en el colón de tareas, el Event Loop transfiere su resolución a la pila para ser ejecutado inmediatamente. Este ciclo continuo asegura que la interfaz de usuario no se congele mientras esperan respuestas externas.

## Ejemplo (no ejecutado automáticamente)
```javascript
console.log('1. Inicio');

setTimeout(() => {
  console.log('2. Timeout (asíncrono)');
}, 0);

Promise.resolve().then(() => {
  console.log('3. Microtarea (promesa)');
});

console.log('4. Fin inicial');
// Salida esperada: 1, 4, 2, 3
```

## Ejercicio
Crea un script que loguee 'Inicio', espere 1 segundo con setTimeout, luego ejecute una microtarea con Promise.resolve().then() y termine con 'Fin'. Verifica el orden de salida en la consola.

## Criterios de revisión
El código debe ejecutar sin errores, mostrar el mensaje del timeout antes que la microtarea (debido a la prioridad del colón), y terminar correctamente. No usar setTimeout con tiempos mayores a 1 segundo para mantener la simplicidad.
