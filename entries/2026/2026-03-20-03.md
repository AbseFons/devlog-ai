## Objetivo
Comprender cómo las claves foráneas establecen relaciones entre tablas, garantizando que los datos referenciados existan realmente y manteniendo la consistencia de la base de datos.

## Explicación
Una clave foránea es una columna o conjunto de columnas en una tabla que referencia la clave primaria de otra tabla. Su función principal es asegurar la integridad referencial, impidiendo que se inserten registros con valores inexistentes en la tabla padre. Por ejemplo, si tenemos una tabla 'Clientes' y otra 'Pedidos', la columna 'cliente_id' en 'Pedidos' debe coincidir con un ID válido en 'Clientes'. Esto evita datos huérfanos. Al definir esta restricción, el motor de base de datos controla automáticamente las operaciones de borrado o actualización para preservar la coherencia lógica del esquema.

## Ejemplo (no ejecutado automáticamente)
Definición de una clave foránea en una tabla de pedidos que referencia a la tabla de clientes.

```sql
CREATE TABLE Pedidos (
    id_pedido INT PRIMARY KEY,
    cliente_id INT NOT NULL,
    FOREIGN KEY (cliente_id) REFERENCES Clientes(id_cliente)
);
```
