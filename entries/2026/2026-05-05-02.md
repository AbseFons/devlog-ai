## Objetivo
Aprender a convertir objetos de Python complejos, como diccionarios y listas, en una cadena de texto válida JSON utilizando la función nativa json.dump para almacenamiento o transmisión de datos.

## Explicación
La serialización transforma estructuras de datos internas de Python en un formato universal legible por máquinas. La librería estándar 'json' ofrece la función dump() que escribe directamente el objeto a un archivo o buffer, evitando crear cadenas intermedias innecesarias. Es crucial especificar el indentador para mejorar la legibilidad humana al inspeccionar archivos de configuración. Este proceso es fundamental en APIs REST donde los datos se envían como texto plano. Python maneja automáticamente la conversión de tipos nativos a sus equivalentes JSON, como convertir None a null y True/False a true/false.

## Ejemplo (no ejecutado automáticamente)
Conversión de un diccionario de usuario a formato JSON escrito en consola con indentación para legibilidad.

```python
import json
usuario = {"nombre": "Ana", "edad": 30}
print(json.dumps(usuario, indent=2))
```
