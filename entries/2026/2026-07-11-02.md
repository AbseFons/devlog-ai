## Objetivo
Dominar la sintaxis básica de Common Table Expressions para simplificar consultas complejas, mejorar la legibilidad del código y reutilizar lógica en SQL Server, PostgreSQL y MySQL modernos.

## Explicación
Las CTE permiten definir un subconjunto de datos temporalmente antes de ejecutar una consulta principal. A diferencia de las subconsultas anidadas, las CTE mejoran la claridad estructural. Se definen con la palabra clave AS y pueden usarse en JOINs o UNIONs. Ideal para recursividad o desglose paso a paso de transformaciones de datos.

## Ejemplo (no ejecutado automáticamente)
Consulta que utiliza una CTE para filtrar empleados por departamento y luego ordenarlos por salario.

```sql
WITH alta_premios AS (
    SELECT nombre, salario FROM empleados WHERE id_dept = 10
)
SELECT * FROM alta_premios ORDER BY salario DESC;
```
