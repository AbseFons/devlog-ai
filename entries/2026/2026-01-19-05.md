## Objetivo
Comprender el propósito de las pruebas de regresión para asegurar que nuevas modificaciones no rompan funcionalidades existentes, manteniendo la estabilidad del software ante iteraciones continuas.

## Explicación
Las pruebas de regresión son esenciales en ingeniería de software para verificar que los cambios recientes no introduzcan errores en partes no modificadas del sistema. Al ejecutar este tipo de pruebas, se confirma que las nuevas características coexisten armoniosamente con la lógica previa. Este proceso es crítico durante el desarrollo ágil, donde los ciclos de entrega son rápidos y constantes. Sin ellas, pequeños ajustes podrían degradar el rendimiento o romper flujos de trabajo establecidos. La automatización de estas pruebas permite ejecutarlas frecuentemente sin consumir recursos humanos excesivos, garantizando una calidad robusta a lo largo del tiempo.

## Ejemplo (no ejecutado automáticamente)
Script que valida que un cálculo de suma sigue funcionando correctamente después de agregar una nueva función de resta en el mismo módulo.

```javascript
function testSuma() {
  const resultado = 5 + 3;
  if (resultado !== 8) throw new Error('Prueba de regresión fallida');
}
testSuma();
```
