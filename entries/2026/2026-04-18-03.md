## Objetivo
Comprender el concepto básico de concurrencia en Python mediante hilos (threads) y cómo ejecutar múltiples tareas simultáneas para mejorar la eficiencia del programa sin bloquear la ejecución principal.

## Explicación
En Python, la concurrencia permite que un programa ejecute múltiples tareas al mismo tiempo. Los hilos son una forma común de lograr esto dentro de un proceso. Aunque Python tiene GIL (Global Interpreter Lock), que limita la paralelización real en CPU para código bloqueante, los threads son ideales para I/O. Este ejemplo crea dos hilos: uno imprime números pares y otro impares. Se usa Thread para iniciar cada tarea y join para esperar su finalización. Es fundamental entender que el orden de salida no está garantizado debido a la naturaleza concurrente del sistema operativo.

## Ejemplo (no ejecutado automáticamente)
Dos hilos imprimen secuencias numéricas alternadas.

```python
import threading

def tarea_pares():
    for i in range(10):
        print(f"Pare: {i*2}")

def tarea_impares():
    for i in range(10):
        print(f"Impar: {i*2+1}")

hilo_pares = threading.Thread(target=tarea_pares)
hilo_impares = threading.Thread(target=tarea_impares)
hilo_pares.start()
hilo_impares.start()
hilo_pares.join()
hilo_impares.join()
```
