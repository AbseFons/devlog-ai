## Objetivo
Comprender cómo una función hash transforma claves arbitrarias en índices numéricos para acceso O(1) a datos, identificando el rol del módulo en la gestión del tamaño del array base.

## Explicación
Las tablas hash permiten búsquedas extremadamente rápidas mediante funciones que mapean claves complejas a posiciones enteras. El algoritmo básico aplica un operador módulo entre el valor hash generado y la capacidad del array. Esto asegura que cualquier índice resultante sea válido dentro de los límites de memoria asignados. Aunque eficiente, este método puede generar colisiones cuando múltiples claves producen el mismo residuo, lo cual se resuelve posteriormente con técnicas como encadenamiento o direccionamiento abierto.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python de una tabla hash simple que almacena nombres y sus índices calculados usando módulo.

```python
tabla = [None] * 10
def insertar(clave, valor):
    indice = hash(clave) % len(tabla)
    tabla[indice] = valor
insertar("Ana", "Ingeniera")
```
