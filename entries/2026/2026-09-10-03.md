## Objetivo
Comprender los fundamentos del patrón de inyección de dependencias para desacoplar componentes, facilitando pruebas unitarias y mantenimiento del código en aplicaciones modernas.

## Explicación
La inyección de dependencias es un patrón de diseño que permite pasar las dependencias necesarias a una clase desde el exterior, evitando la creación manual de objetos. Esto promueve un acoplamiento bajo, donde las clases no necesitan conocer los detalles de implementación de sus dependencias, sino solo sus interfaces. Al utilizar contenedores o frameworks de inyección, se simplifica la configuración y se mejora la modularidad del sistema. Este enfoque es esencial para construir arquitecturas escalables y mantenibles, permitiendo reemplazar fácilmente implementaciones reales con mocks durante las pruebas.

## Ejemplo (no ejecutado automáticamente)
Clase Servicio que recibe un repositorio a través de su constructor en lugar de instanciarlo internamente.

```javascript
class Repositorio {
  buscar() { return ["item1", "item2"]; }
}
class Servicio {
  constructor(repositorio) {
    this.repositorio = repositorio;
  }
  obtenerDatos() {
    return this.repositorio.buscar();
  }
}
```

## Ejercicio

## Criterios de revisión
El código debe mostrar claramente la inyección del objeto Operador en el constructor de Calculadora. Debe existir al menos una instancia de Calculadora usando Suma y otra usando Resta sin modificar las clases internas.
