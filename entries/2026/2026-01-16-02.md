## Objetivo
Aprender a utilizar el patrón adaptador para permitir que clases con interfaces incompatibles colaboren sin modificar su código original, facilitando la integración de sistemas heredados en arquitecturas modernas.

## Explicación
El patrón adaptador actúa como un puente entre dos interfaces distintas. Imagina una clase legacy 'MotorViejo' que solo acepta comandos de arranque tipo 'startLegacy'. Tu sistema moderno requiere 'startModern'. El adaptador envuelve al objeto legacy, traduce la llamada externa a la interna y gestiona los errores específicos del sistema antiguo. Esto permite reutilizar código existente sin violar el principio de no modificar clases heredadas. Es ideal cuando necesitas integrar librerías obsoletas o hardware con protocolos propietarios en una aplicación nueva, manteniendo la cohesión del diseño.

## Ejemplo (no ejecutado automáticamente)
Clase adaptadora que traduce una llamada moderna a un método legacy de arranque de motor.

```javascript
class MotorLegacy {
  start() { console.log('Motor antiguo arrancado'); }
}
class AdaptadorMotor {
  constructor(motor) { this.motor = motor; }
  iniciar() { return this.motor.start(); }
}
```
