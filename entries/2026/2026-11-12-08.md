## Objetivo
Aprender a validar datos y ejecutar lógica adicional automáticamente tras la creación de una instancia, asegurando la integridad del objeto desde su origen.

## Explicación
Los dataclasses en Python son útiles para definir estructuras de datos rápidamente. Sin embargo, a veces necesitamos validar que los valores introducidos sean correctos antes de permitir la creación del objeto. Para esto, utilizamos el método especial __post_init__. Este método se ejecuta automáticamente después de que el constructor haya asignado los valores a las variables de clase. Dentro de él, podemos implementar lógica personalizada, como verificar rangos numéricos o tipos de datos. Si la validación falla, lanzamos una excepción para evitar crear objetos inválidos. Esta técnica mejora la robustez del código y evita errores en tiempo de ejecución más adelante.

## Ejemplo (no ejecutado automáticamente)
Definición de un dataclass que valida que el salario sea positivo al instantiarlo.

```python
from dataclasses import dataclass
from typing import Any

@dataclass
class Empleado:
    nombre: str
    salario: float
    
    def __post_init__(self):
        if self.salario <= 0:
            raise ValueError("El salario debe ser positivo")
```
