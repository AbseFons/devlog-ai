## Objetivo
Aprender a prevenir inyecciones SQL y XSS mediante la validación estricta de patrones en las entradas del usuario antes de procesarlas, asegurando que los datos sean seguros para su almacenamiento o ejecución.

## Explicación
La validación de entradas es la primera línea de defensa contra vulnerabilidades críticas. En esta serie, nos enfocamos en la sanitización proactiva. No basta con confiar en el cliente; siempre se debe validar en el servidor. Utilizamos expresiones regulares para asegurar que los datos ingresados coincidan con un formato esperado (ej. solo números para IDs). Si la entrada no coincide, se rechaza inmediatamente. Esto evita que scripts maliciosos o caracteres de escape lleguen a las bases de datos o al renderizado del navegador. La implementación correcta implica definir reglas estrictas y aplicarlas antes de cualquier consulta o manipulación de strings.

## Ejemplo (no ejecutado automáticamente)
Función en JavaScript que valida si una cadena contiene solo dígitos numéricos para un ID de usuario, rechazando cualquier otro carácter.

```javascript
function validarId(id) {
  const patron = /^[0-9]+$/;
  if (!patron.test(id)) throw new Error('ID inválido');
}
```
