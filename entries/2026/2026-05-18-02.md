## Objetivo
Comprender que las pruebas de regresión verifican que nuevas modificaciones no rompan funcionalidades existentes, asegurando estabilidad en el ciclo de vida del software mediante la ejecución selectiva de casos críticos.

## Explicación
Las pruebas de regresión son esenciales cuando se introduce un cambio en el código. Su propósito es confirmar que la corrección aplicada resuelve el defecto original sin introducir errores secundarios en otras partes del sistema. No se ejecutan todas las pruebas cada vez, sino un subconjunto estratégico diseñado para cubrir flujos clave. Esto optimiza el tiempo de desarrollo y mantiene la confianza en la calidad del producto ante iteraciones frecuentes.

## Ejemplo (no ejecutado automáticamente)
Script que valida que una función de suma sigue funcionando correctamente después de modificar la lógica de validación de entrada.

```javascript
function testSuma() {
  const resultado = 5 + 3;
  if (resultado === 8) { console.log('Prueba de regresión: PASADA'); } else { throw new Error('Fallo en regresión'); }
}
```
