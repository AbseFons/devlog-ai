## Objetivo
Comprender las diferencias fundamentales entre el framework estándar unittest y pytest en Python, identificando ventajas de descubrimiento automático, fixtures declarativos y aserciones más legibles para acelerar la escritura de pruebas.

## Explicación
Python ofrece dos ecosistemas principales para pruebas: unittest, incluido en el estándar desde hace años, y pytest, una herramienta externa extremadamente popular. Aunque unittest sigue siendo válido, pytest simplifica drásticamente el proceso. No requiere heredar clases ni definir métodos con nombres específicos como 'test_'. En su lugar, cualquier función que empiece por 'test_' se ejecuta automáticamente. Los fixtures en pytest son más flexibles y declarativos, permitiendo configuración de entorno limpia sin anidación excesiva. Las aserciones de pytest ofrecen mensajes de error detallados y soportan parametrización nativa con @pytest.mark.parametrize. Esta serie explorará cómo migrar mentalidad hacia pytest para escribir pruebas más mantenibles y rápidas.

## Ejemplo (no ejecutado automáticamente)
Ejemplo de fixture que inicializa una lista vacía antes de cada prueba y la limpia después, demostrando el uso de autouse en pytest.

```python
import pytest

@pytest.fixture
def datos():
    return []

@pytest.mark.parametrize('valor', [1, 2])
def test_suma(datos, valor):
    datos.append(valor)
    assert len(datos) == 1
```

## Ejercicio
Crea un archivo llamado 'test_calculadora.py' con una función 'suma(a, b)' que devuelva la suma de dos números. Escribe tres pruebas: una para sumar 2+2, otra para sumar -1+5 y una tercera que verifique que la suma de 0 sea 0. Usa el decorador @pytest.mark.parametrize para pasar las entradas.

## Criterios de revisión
El archivo debe contener exactamente tres funciones decoradas con @pytest.mark.parametrize o definiciones directas, todas iniciando con 'test_'. Cada prueba debe importar la función suma y realizar una aserción assert que verifique el resultado correcto. No deben existir errores de sintaxis ni dependencias externas.
