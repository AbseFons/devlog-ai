## Objetivo
El desarrollador podrá definir clases de datos concisas utilizando decoradores, evitando boilerplate manual y asegurando la inmutabilidad o mutabilidad según necesidad mediante parámetros específicos del dataclass.

## Explicación
Los dataclasses en Python permiten generar automáticamente métodos como __init__, __repr__ y __eq__. Ideal para modelos de datos simples, evitan escribir código repetitivo. Se definen con @dataclass, opcionalmente con frozen=True para inmutabilidad o order=True para ordenar campos. Esto mejora la legibilidad y reduce errores de tipeo al inicializar objetos. Es fundamental recordar que los argumentos deben tener nombres explícitos en Python 3.10+ o usar *args si se requiere compatibilidad antigua.

## Ejemplo (no ejecutado automáticamente)
```python
from dataclasses import dataclass, field

@dataclass(frozen=True)
class Usuario:
    id: int
    nombre: str
    email: str = field(default='', metadata={'example': 'usuario@ejemplo.com'})

u1 = Usuario(id=1, nombre='Ana', email='ana@test.com')
print(u1)  # Salida: Usuario(id=1, nombre='Ana', email='ana@test.com')
```
