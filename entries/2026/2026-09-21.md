## Objetivo
Aprender a usar 'with' en Python para garantizar que los recursos, como archivos, se cierren automáticamente al finalizar el bloque, evitando fugas y errores comunes.

## Explicación
En Python, los context managers permiten gestionar recursos eficientemente. Usando la sentencia 'with', el código asegura que el método '__enter__' se ejecute antes del bloque y '__exit__' después, incluso si hay excepciones. Esto es crucial para archivos: evita dejarlos abiertos accidentalmente. Sin esto, podrías perder datos o bloquear recursos en sistemas con muchas conexiones. El patrón simplifica el código y mejora la robustez.

## Ejemplo (no ejecutado automáticamente)
Abre un archivo de texto, escribe una línea y cierra automáticamente al salir del bloque 'with'.

```python
with open('diario.txt', 'w') as f:
    f.write('Hola mundo')
```

## Ejercicio
Crea un script que use 'with' para leer un archivo existente y contar las líneas, manejando errores si el archivo no existe.

## Criterios de revisión
El código debe usar 'with open(...)', incluir manejo de excepciones con 'try-except', y no dejar archivos abiertos.
