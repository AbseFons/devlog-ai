## Objetivo
Aprender a realizar un recorrido in-order en un árbol binario de búsqueda para obtener sus elementos ordenados de forma ascendente, aprovechando la propiedad fundamental de su estructura.

## Explicación
En esta microlección exploramos el algoritmo de recorrido in-order. Este método visita primero el subárbol izquierdo, luego el nodo actual y finalmente el subárbol derecho. Gracias a esta secuencia específica, los nodos se procesan en orden ascendente de sus claves, lo cual es esencial para operaciones como la serialización ordenada o la validación de propiedades del árbol. La implementación recursiva es intuitiva y eficiente, con una complejidad temporal lineal respecto al número de nodos.

## Ejemplo (no ejecutado automáticamente)
Función recursiva que imprime los valores del árbol en orden ascendente utilizando el patrón izquierdo-nodo-derecho.

```javascript
function inOrder(node) {
  if (node) {
    inOrder(node.left);
    console.log(node.value);
    inOrder(node.right);
  }
}
```
