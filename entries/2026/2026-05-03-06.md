## Objetivo
Aprender a configurar registros estructurados en Python para facilitar el análisis de datos y la depuración mediante herramientas como JSON, mejorando la trazabilidad del sistema.

## Explicación
El logging estructurado almacena eventos en formato JSON dentro de los mensajes de registro. Esto permite que las aplicaciones capturen metadatos clave como IDs de usuario, códigos de error o nombres de servicios sin necesidad de escribirlos manualmente en cada llamada. Al usar el diccionario 'extra' del método log(), se inyectan automáticamente estos campos en la salida. Este enfoque es esencial para sistemas distribuidos donde múltiples componentes generan registros que luego se agregan en un único almacén centralizado. La consistencia del formato simplifica enormemente las consultas de análisis y la visualización en dashboards.

## Ejemplo (no ejecutado automáticamente)
Configuración básica de logger con salida JSON y metadatos extra

```python
import logging
import json
logging.basicConfig(format='%(message)s', stream=open('app.log', 'w'))
logger = logging.getLogger()
logger.info('Inicio servicio', extra={'servicio': 'api-gateway', 'version': '1.0'})
```
