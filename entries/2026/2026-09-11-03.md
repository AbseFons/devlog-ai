## Objetivo
Aprender a utilizar bloques try-catch para interceptar excepciones, evitar que las aplicaciones se detengan abruptamente y mostrar mensajes de error amigables al usuario.

## Explicación
En desarrollo web, los errores son inevitables. El patrón estándar es envolver código potencialmente fallido en un bloque try. Si ocurre una excepción, el control pasa inmediatamente al catch, donde podemos manejar la situación sin detener la ejecución. Esto permite mantener la funcionalidad parcial del sistema. Es crucial no ignorar los errores silenciosamente; siempre loguea el mensaje de error para depuración futura. Este enfoque mejora la robustez y la experiencia del usuario final.

## Ejemplo (no ejecutado automáticamente)
Intento de división por cero que dispara un error numérico, capturado para mostrar un mensaje personalizado en lugar de una página blanca.

```javascript
try {
  const resultado = 10 / 0;
} catch (error) {
  console.error('Error controlado:', error.message);
}
```
