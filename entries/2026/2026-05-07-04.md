## Objetivo
Comprender el concepto de atomicidad en bases de datos, asegurando que las operaciones transaccionales se ejecuten completamente o no se ejecuten en absoluto para mantener la integridad de los datos.

## Explicación
La atomicidad es la primera propiedad de las transacciones ACID. Garantiza que una transacción sea tratada como una unidad indivisible: todas sus operaciones deben completarse con éxito o ninguna debe aplicarse. Si ocurre un fallo durante el proceso, el sistema utiliza mecanismos de recuperación para revertir los cambios parciales realizados, devolviendo la base de datos a su estado anterior. Esto previene inconsistencias críticas donde solo parte de una operación se haya aplicado. Por ejemplo, en una transferencia bancaria, si el débito al cliente A falla, el crédito al cliente B también debe deshacerse automáticamente.

## Ejemplo (no ejecutado automáticamente)
Script SQL que simula una transacción atómica fallida y su reversión automática mediante un bloque de código con rollback.

```sql
BEGIN TRANSACTION;
UPDATE cuentas SET saldo = saldo - 100 WHERE id = 1;
UPDATE cuentas SET saldo = saldo + 100 WHERE id = 2;
ROLLBACK;
```
