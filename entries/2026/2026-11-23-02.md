## Objetivo
Aprender a estructurar una cola FIFO utilizando un array en JavaScript, gestionando correctamente el desplazamiento del índice frontal para optimizar la memoria y evitar fugas al eliminar elementos.

## Explicación
En esta lección exploramos la implementación de una estructura de datos tipo Cola (FIFO) usando un array estándar. A diferencia de las pilas, donde solo operamos en la cima, las colas requieren gestionar dos extremos: el frente para sacar elementos y el fondo para ingresarlos. Un desafío común es que eliminar el primer elemento con splice puede ser costoso en memoria. Para resolverlo, utilizaremos un índice 'head' que se incrementa cada vez que extraemos un dato, manteniendo los datos en el array pero ignorando la parte vacía del frente. Este enfoque simula el comportamiento de una cola circular básica sin la complejidad de redimensionar el array constantemente, ideal para buffers de entrada/salida o gestión de tareas asíncronas simples.

## Ejemplo (no ejecutado automáticamente)
Clase Cola que implementa enqueue y dequeue con desplazamiento de indice head para eficiencia en memoria.

```javascript
class Queue {
  constructor() { this.data = []; this.head = 0; }
  enqueue(item) { this.data.push(item); }
  dequeue() { return this.data[this.head++]; }
}
```
