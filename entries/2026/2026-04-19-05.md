## Objetivo
Dominar la sintaxis moderna de JavaScript para manejar operaciones asíncronas, evitando el uso de callbacks anidados y mejorando la legibilidad del código mediante promesas y await.

## Explicación
En JavaScript, las operaciones que toman tiempo (como leer un archivo o consultar una API) son asíncronas. Las Promesas representan el resultado final de estas operaciones: pueden estar pendientes, resueltas o rechazadas. La sintaxis async/await simplifica enormemente el manejo de promesas, permitiendo escribir código secuencial y legible en lugar de usar .then(). Una función marcada como async devuelve automáticamente una promesa. Dentro de ella, await pausa la ejecución hasta que la promesa se resuelva. Es crucial manejar errores con try/catch para evitar que la aplicación falle silenciosamente.

## Ejemplo (no ejecutado automáticamente)
Ejemplo de función asíncrona que simula una llamada a API y maneja errores correctamente.

```javascript
async function obtenerDatos() {
  try {
    const respuesta = await fetch('https://jsonplaceholder.typicode.com/posts/1');
    return await respuesta.json();
  } catch (error) {
    console.error('Error:', error);
  }
}
```

## Ejercicio
Crea una función asíncrona llamada 'buscarUsuario' que utilice fetch para obtener datos de https://jsonplaceholder.typicode.com/users/1. Usa try/catch para capturar errores de red y devuelve el objeto usuario o null si falla.

## Criterios de revisión
El código debe usar la palabra clave async, await dentro de una función asíncrona, incluir un bloque try/catch válido y no contener callbacks anidados.
