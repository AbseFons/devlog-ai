## Objetivo
Comprender la estructura recursiva de un árbol binario y aplicar el algoritmo de recorrido preorden para extraer datos jerárquicos de manera eficiente.

## Explicación
Un árbol binario es una estructura donde cada nodo tiene como máximo dos hijos: izquierdo y derecho. El recorrido preorden visita primero el nodo actual, luego el subárbol izquierdo y finalmente el derecho. Este método es ideal para copiar estructuras o generar expresiones en prefijo. La implementación recursiva simplifica la lógica al delegar el procesamiento de los subárboles a llamadas funcionales sucesivas, evitando pilas manuales.

## Ejemplo (no ejecutado automáticamente)
Definición de un árbol binario simple y ejecución de recorrido preorden para obtener una lista plana de valores.

```python
class Nodo:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None

def preorden(nodo):
    if nodo is None:
        return []
    return [nodo.valor] + preorden(nodo.izquierdo) + preorden(nodo.derecho)
```
