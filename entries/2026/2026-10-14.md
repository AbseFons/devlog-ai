## Objetivo
Comprender la esencia de la programación dinámica resolviendo un problema de optimización secuencial donde las decisiones actuales afectan el estado futuro, evitando recálculos innecesarios mediante almacenamiento de subproblemas.

## Explicación
La programación dinámica es ideal para problemas con subestructura óptima y solapamiento de subproblemas. En este caso, calcularemos la máxima altura alcanzable apilando ladrillos de diferentes anchos. Definimos un array donde cada índice representa el ancho del ladrillo y su valor la altura máxima posible hasta ese punto. Iteramos sobre los ladrillos disponibles; para cada uno, verificamos si puede colocarse sobre otros ya construidos. Si es viable, actualizamos la altura máxima acumulada sumando la altura del ladrillo actual a la mejor solución previa encontrada. Este enfoque garantiza que exploremos todas las combinaciones válidas sin repetir cálculos costosos, transformando una búsqueda exponencial en un proceso lineal eficiente.

## Ejemplo (no ejecutado automáticamente)
Cálculo de la máxima altura apilando ladrillos de anchos 1 y 2 con alturas respectivas 3 y 5.

```python
def max_altura(ladrillos):
    dp = [0] * len(ladrillos)
    for i in range(len(ladrillos)):
        for j in range(i):
            if ladrillos[j][1] >= ladrillos[i][0]:
                dp[i] = max(dp[i], dp[j] + ladrillos[i][1])
    return max(dp) if dp else 0
print(max_altura([(1,3), (2,5)]))
```
