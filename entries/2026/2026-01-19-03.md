## Objetivo
Dominar el uso de Common Table Expressions (CTEs) para simplificar consultas recursivas y organizar lógica compleja en bases de datos relacionales sin sacrificar legibilidad.

## Explicación
Las Common Table Expressions (CTEs) permiten definir subconsultas temporales nombradas que existen solo durante la ejecución de la consulta principal. Son ideales para descomponer problemas complejos en pasos lógicos claros. En este caso, utilizaremos una CTE recursiva para trazar el árbol organizacional completo de una empresa desde un CEO hasta los empleados más bajos. La sintaxis requiere definir la tabla con AS y luego ejecutarla dentro de una consulta SELECT final. Este enfoque mejora significativamente la mantenibilidad del código comparado con múltiples UNIONs anidados, facilitando la comprensión de la jerarquía de datos y permitiendo operaciones como el cálculo de profundidad o la búsqueda de directos.

## Ejemplo (no ejecutado automáticamente)
Consulta recursiva que lista todos los niveles de una jerarquía organizacional usando una CTE para unir empleados con sus jefes directos.

```sql
WITH Organigrama AS (
  SELECT id, nombre, jefe_id FROM empleados WHERE jefe_id IS NULL
  UNION ALL
  SELECT e.id, e.nombre, e.jefe_id FROM empleados e INNER JOIN Organigrama o ON e.jefe_id = o.id
)
SELECT * FROM Organigrama ORDER BY nivel;
```
