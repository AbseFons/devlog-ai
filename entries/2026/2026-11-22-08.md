## Objetivo
Dominar el uso de typing para definir estructuras complejas, uniones tipadas y validaciones pre-ejecución que mejoran la mantenibilidad del código sin sacrificar la flexibilidad dinámica de Python.

## Explicación
En esta lección exploramos cómo las anotaciones de tipo en Python van más allá de simples declaraciones. Utilizamos el módulo typing para definir listas heterogéneas, uniones de tipos y clases genéricas que permiten a herramientas como mypy detectar errores antes de la ejecución. Esto es crucial en proyectos grandes donde la claridad del código es vital. Al anotar funciones con tipos específicos, facilitamos la refactorización segura y documentamos el contrato de la API implícitamente. Python 3.10+ introduce mejoras como las uniones literales '|', permitiendo escribir código más conciso y expresivo.

## Ejemplo (no ejecutado automáticamente)
Definición de una función que acepta múltiples tipos de entrada y devuelve un objeto genérico, demostrando la interoperabilidad con herramientas de análisis estático.

```python
from typing import Union, List, Generic, TypeVar

T = TypeVar('T')

def procesar_datos(valores: Union[int, str], lista: List[T]) -> List[T]:
    if isinstance(valores, int):
        return [valores * 2 for _ in lista]
    return [valores.upper() for _ in lista]
```
