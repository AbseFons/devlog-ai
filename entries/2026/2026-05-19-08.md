## Objetivo
Aprender a cancelar peticiones asíncronas en JavaScript para evitar bloqueos de UI y optimizar el rendimiento al manejar redes lentas o conexiones inestables.

## Explicación
Las peticiones fetch pueden colgar indefinidamente si la red falla. Para resolver esto, se utiliza AbortController junto con un signal. Al crear una instancia de controller y pasar su signal a fetch, cualquier llamada a abort() cancelará la petición inmediatamente. Esto permite limpiar recursos y actualizar el estado de la interfaz sin dejar procesos zombi. Es esencial para aplicaciones modernas que requieren respuestas rápidas ante cambios de red.

## Ejemplo (no ejecutado automáticamente)
Se crea un controller, se inicia una fetch a una API pública con timeout simulado y se aborta manualmente tras 1 segundo para demostrar la cancelación limpia.

```javascript
const controller = new AbortController();
fetch('https://jsonplaceholder.typicode.com/posts/1', { signal: controller.signal })
```

## Ejercicio
Crea una función que realice una petición a una API y la cancele automáticamente si tarda más de 3 segundos en responder.

## Criterios de revisión
