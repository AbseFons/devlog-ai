## Objetivo
Al finalizar esta lección, podrás identificar datos repetidos innecesarios en una tabla y aplicar las reglas de normalización para transformar un diseño denormalizado en una estructura relacional eficiente, reduciendo anomalías de actualización.

## Explicación
La normalización es el proceso de organizar los datos para minimizar la redundancia. En esta primera serie, nos enfocamos en la Primera Forma Normal (1FN). Una tabla cumple la 1FN si cada celda contiene exactamente un valor atómico y no existen grupos o arrays repetidos dentro de una columna. Por ejemplo, almacenar múltiples teléfonos en una sola celda separados por comas viola la 1FN. El objetivo es que cada fila sea única y represente un solo registro lógico. Al cumplir esto, garantizamos que las consultas sean más rápidas y que los cambios de datos (insertar o actualizar) no generen inconsistencias accidentales.

## Ejemplo (no ejecutado automáticamente)
```python
# Tabla denormalizada: Violacion de la Primera Forma Normal
# Columna 'contactos' contiene un array de strings en una sola celda.
usuarios_denormalizados = [
    {'id': 1, 'nombre': 'Ana', 'contactos': '999-0001; 999-0002'},
    {'id': 2, 'nombre': 'Luis', 'contactos': '888-1111'}
]

# Transformacion hacia la Primera Forma Normal
# Se crea una tabla de relacion donde cada fila es un contacto unico.
usuarios_normalizados = [
    {'usuario_id': 1, 'telefono': '999-0001'},
    {'usuario_id': 1, 'telefono': '999-0002'},
    {'usuario_id': 2, 'telefono': '888-1111'}
]
```
