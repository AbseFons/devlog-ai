## Objetivo
Aprender a inicializar una conexión segura con la librería estándar sqlite3, crear un esquema básico de tabla y ejecutar inserciones de datos sin dependencias externas.

## Explicación
Esta microlección introduce los fundamentos para interactuar con bases de datos SQLite en Python. Comenzaremos importando el módulo nativo sqlite3 y estableciendo una conexión a un archivo local o memoria. Es crucial gestionar la conexión mediante un bloque 'with' para asegurar que los recursos se liberen correctamente al finalizar. Posteriormente, definiremos una tabla 'empleados' con columnas tipo texto e entero, demostrando cómo usar el método execute() para crear esquemas y luego insertar registros iniciales. Este enfoque garantiza que el código sea robusto y listo para producción en aplicaciones de backend ligeras.

## Ejemplo (no ejecutado automáticamente)
Script que crea una base de datos en memoria con una tabla de empleados e inserta dos registros de prueba.

```python
import sqlite3
conn = sqlite3.connect(':memory:')
cursor = conn.cursor()
cursor.execute('CREATE TABLE empleados (id INTEGER PRIMARY KEY, nombre TEXT, puesto TEXT)')
cursor.execute("INSERT INTO empleados VALUES (1, 'Ana', 'Desarrolladora')")
cursor.execute("INSERT INTO empleados VALUES (2, 'Carlos', 'Diseñador')")
conn.commit()
print(cursor.fetchall())
```
