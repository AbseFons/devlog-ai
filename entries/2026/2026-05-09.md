## Objetivo
Comprender la separación de responsabilidades en el desarrollo de software mediante la implementación de una estructura básica de tres capas: presentación, lógica y datos.

## Explicación
La arquitectura por capas organiza el sistema en niveles independientes que se comunican a través de interfaces definidas. La capa de presentación maneja la interacción con el usuario, la capa de negocio encapsula la lógica crítica y las reglas de operación, mientras que la capa de datos gestiona el acceso persistente a la información. Este enfoque promueve la modularidad, facilitando el mantenimiento, las pruebas unitarias y la escalabilidad del sistema sin acoplar funcionalidades dispares.

## Ejemplo (no ejecutado automáticamente)
Implementación básica en Python que define clases separadas para manejar la entrada de usuario, procesar datos y simular una base de datos.

```python
class CapaDatos:
    def guardar(self, dato):
        print(f'Dato guardado: {dato}')

class CapaNegocio(CapaDatos):
    def procesar(self, valor):
        return valor * 2

class CapaPresentacion(CapaNegocio):
    def mostrar(self):
        self.procesar(10)
```

## Ejercicio
Crea una clase 'CapaDatos' que guarde un diccionario en una lista local, luego define 'CapaNegocio' que filtre esos datos y finalmente 'CapaPresentacion' que imprima los resultados filtrados.

## Criterios de revisión
El código debe mostrar tres clases distintas sin herencia innecesaria entre capas de presentación y datos. La capa de negocio no debe acceder directamente a la estructura interna de la capa de datos, solo mediante métodos públicos.
