## Objetivo
Al finalizar esta lección, podrás diferenciar cuándo usar WHERE frente a HAVING y aplicar cláusulas de agregación para filtrar grupos resultantes con precisión.

## Explicación
En SQL, GROUP BY agrupa filas basándose en valores comunes. Mientras que WHERE filtra antes del agrupamiento, HAVING actúa después, permitiendo condicionar sobre funciones agregadas como COUNT o SUM. Es crucial usar HAVING cuando necesitas excluir grupos enteros (ej. departamentos con menos de 3 empleados). Sin esta cláusula, las condiciones sobre totales fallarán. Esta distinción evita errores lógicos comunes en reportes complejos donde el filtro depende del resultado del cálculo, no de los datos crudos individuales.

## Ejemplo (no ejecutado automáticamente)
```sql
SELECT departamento, COUNT(*) como total_empleados
FROM empleados
GROUP BY departamento
HAVING COUNT(*) >= 3;
```

## Ejercicio
Dada una tabla 'ventas' con columnas 'vendedor' y 'monto', escribe una consulta que agrupe por vendedor y muestre solo aquellos cuyo ingreso total sea mayor a 1000.

## Criterios de revisión
La consulta debe usar GROUP BY en 'vendedor', SUM(monto) para el cálculo, HAVING con la condición > 1000 y SELECT apropiado. No uses WHERE para filtrar el monto antes del agrupamiento.
