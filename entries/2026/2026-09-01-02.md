## Objetivo
El desarrollador comprenderá que Python es dinámico pero permite anotaciones para claridad, mejorando la mantenibilidad del código sin alterar su ejecución estándar.

## Explicación
Python utiliza tipado dinámico, lo que significa que el tipo de una variable se infiere en tiempo de ejecución. Sin embargo, desde Python 3, las anotaciones permiten declarar tipos explícitamente (ej: x: int). Estas anotaciones no afectan la lógica del programa ni su velocidad, ya que son ignoradas por la máquina virtual estándar. Su valor reside en la documentación automática y en herramientas estáticas como mypy o pyright, que detectan errores antes de ejecutar el script. Es crucial distinguir entre 'int' (tipo) y 'Int' (clase genérica para listas), aunque Python 3.9+ permite sintaxis simplificada. Las anotaciones son esenciales en APIs públicas y bibliotecas grandes para garantizar contratos claros entre módulos.

## Ejemplo (no ejecutado automáticamente)
```python
def calcular_promedio(valores: list[float]) -> float:
    """Calcula el promedio de una lista de números."""
    if not valores:
        return 0.0
    return sum(valores) / len(valores)

# Uso realista con datos numéricos
resultados = [85.5, 90.2, 78.9]
promedio = calcular_promedio(resultados)
print(f"El promedio es: {promedio}")
```
