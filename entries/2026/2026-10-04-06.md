## Objetivo
Aprender a construir consultas SQL utilizando métodos parametrizados para evitar la inyección SQL, asegurando que el usuario nunca pueda alterar la lógica de la consulta mediante entradas maliciosas en los campos de formulario.

## Explicación
La inyección SQL ocurre cuando se concatenan directamente las entradas del usuario a una cadena de consulta. Para mitigarlo, debemos utilizar parámetros preparados o placeholders. En lugar de construir el string SQL manualmente, pasamos los valores como argumentos separados al motor de base de datos. Esto obliga al sistema a tratar la entrada del usuario estrictamente como un valor literal y no como parte de la sintaxis SQL. Por ejemplo, en Python con SQLAlchemy o psycopg2, se define la consulta con '?' o '%s' y se pasan los valores en una tupla. El motor de base de datos escapa automáticamente caracteres especiales como comillas simples o puntos y coma, neutralizando cualquier intento de inyección.

## Ejemplo (no ejecutado automáticamente)
Consulta parametrizada segura para buscar un usuario por nombre usando Python con psycopg2

```python
cursor.execute("SELECT * FROM usuarios WHERE nombre = %s", (nombre_usuario,))
resultados = cursor.fetchall()
```
