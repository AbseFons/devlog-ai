## Objetivo
Aprender a capturar excepciones asíncronas utilizando bloques try/catch para evitar que fallos en operaciones de red o archivos detengan la ejecución del programa, asegurando una experiencia de usuario robusta.

## Explicación
En JavaScript moderno, las promesas permiten realizar tareas asíncronas. Sin embargo, si una función asíncrona falla, la promesa se resuelve con un error. Para manejar esto sin usar .catch() en cada llamada, envuelvemos el código asíncrono en un bloque try/catch. Dentro del try, ejecutamos nuestra lógica; si ocurre un error (como una conexión perdida), el control salta al catch, donde podemos mostrar mensajes amigables o reintentar la operación. Esto mantiene el flujo limpio y evita que el script se detenga abruptamente.

## Ejemplo (no ejecutado automáticamente)
Función asíncrona que simula una llamada a API fallida y captura el error para mostrar un mensaje al usuario sin detener la aplicación.

```javascript
async function obtenerDatos() {
  try {
    const respuesta = await fetch('https://api.ejemplo.com/datos');
    return await respuesta.json();
  } catch (error) {
    console.error('Error de red:', error.message);
    return null;
  }
}
```

## Ejercicio
Crea una función asíncrona llamada 'buscarUsuario' que simule una búsqueda en base de datos. Usa setTimeout para simular la espera y lanza un nuevo Error si el ID es menor a 10. Implementa un try/catch que muestre por consola 'Usuario no encontrado' solo cuando falle.

## Criterios de revisión
El código debe usar async/await, lanzar un error condicionalmente y capturar la excepción en un bloque catch para ejecutar lógica de recuperación o notificación al usuario.
