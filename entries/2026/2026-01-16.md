## Objetivo
Comprender los fundamentos de la paginación en APIs REST para manejar grandes volúmenes de datos eficientemente, evitando saturar la memoria del cliente y optimizando el rendimiento de la red mediante la división de respuestas.

## Explicación
Las APIs modernas a menudo retornan conjuntos de datos extensos que no caben en una sola respuesta HTTP. Para mitigar esto, se implementa la paginación, dividiendo los resultados en bloques manejables. El cliente solicita un número específico de registros por página y utiliza parámetros como 'page' o 'offset'. La respuesta incluye metadatos cruciales: el total de elementos, el número actual de página y si existen más páginas disponibles. Este patrón es esencial para construir aplicaciones escalables que respondan rápidamente a los usuarios sin consumir excesivos recursos del servidor ni bloquear la interfaz gráfica mientras se procesan miles de registros.

## Ejemplo (no ejecutado automáticamente)
Solicitud GET con parámetros de paginación y respuesta JSON estructurada incluyendo metadatos de navegación.

```javascript
fetch('https://api.ejemplo.com/usuarios?page=1&limit=10')
  .then(response => response.json())
```

## Criterios de revisión
