## Objetivo
Aprender a cancelar peticiones asíncronas en JavaScript para evitar bloqueos de UI y optimizar el rendimiento al manejar múltiples solicitudes simultáneas.

## Explicación
En aplicaciones modernas, las peticiones fetch pueden colgar si el usuario navega antes de que se complete la respuesta. La clase AbortController resuelve esto generando un objeto AbortSignal. Al pasar este signal a fetch, el navegador cancela la petición internamente si se llama a controller.abort(). Esto lanza una excepción específica en el bloque catch, permitiendo limpiar recursos y actualizar el estado de la interfaz sin dejar procesos zombi consumiendo memoria.

## Ejemplo (no ejecutado automáticamente)
Se crea un controlador, se inicia una petición con su señal y se aborta manualmente tras 2 segundos simulando una navegación rápida del usuario.

```javascript
const controller = new AbortController();
fetch('https://jsonplaceholder.typicode.com/posts/1', { signal: controller.signal })
```
