## Objetivo
Aprender a usar el comando git reflog para recuperar accidentalmente eliminados o revertidos commits sin necesidad de puntos de restauración externos, protegiendo el historial local ante errores humanos comunes durante la reescritura de código.

## Explicación
El comando git reflog registra cada cambio en la referencia HEAD, incluso si se borran los commits asociados. Cuando un usuario ejecuta 'git reset --hard' o 'git revert' por error, el commit original sigue accesible en el reflog. Para recuperarlo, primero consulta el historial con 'git reflog'. Identifica el hash del commit deseado y luego usa 'git reset --hard <hash>' para restaurar la rama actual a ese estado exacto. Este método es crucial en entornos de desarrollo donde se realizan múltiples intentos de refactorización antes de un push exitoso, permitiendo deshacer cambios drásticos sin perder el trabajo realizado.

## Ejemplo (no ejecutado automáticamente)
Consulta el reflog para encontrar el hash del commit eliminado y restaura la rama actual a ese estado específico utilizando reset hard.

```bash
git reflog
HEAD@{1} -> HEAD (commit_hash)
git reset --hard HEAD@{1}
```
