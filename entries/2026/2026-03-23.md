## Objetivo
Comprender el principio de división y conquista en arrays ordenados para reducir la complejidad temporal a logarítmica, optimizando la localización de elementos en grandes conjuntos de datos.

## Explicación
La búsqueda binaria es un algoritmo eficiente que requiere que los datos estén ordenados. En lugar de revisar cada elemento secuencialmente como en una búsqueda lineal, este método compara el valor objetivo con el elemento central del rango actual. Si coinciden, se encuentra la posición; si el objetivo es menor, se busca en el mitad izquierda; si es mayor, en la derecha. Este proceso se repite recursivamente o iterativamente hasta encontrar el elemento o agotar las opciones. Su complejidad temporal es O(log n), lo que la hace ideal para bases de datos y sistemas de archivos donde el tiempo de respuesta es crítico.

## Ejemplo (no ejecutado automáticamente)
Implementación iterativa en Python que busca un número en una lista ordenada devolviendo su índice o -1 si no existe.

```python
def busqueda_binaria(lista, objetivo):
    izq, der = 0, len(lista) - 1
    while izq <= der:
        mid = (izq + der) // 2
        if lista[mid] == objetivo:
            return mid
        elif lista[mid] < objetivo:
            izq = mid + 1
        else:
            der = mid - 1
    return -1
```
