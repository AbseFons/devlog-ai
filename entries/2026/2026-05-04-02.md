## Objetivo
Comprender el concepto básico de una tabla hash, cómo mapea claves a índices mediante funciones y la importancia de distribuir los datos uniformemente para evitar colisiones.

## Explicación
Una tabla hash es una estructura de datos que permite acceso directo a elementos usando una clave. Utiliza una función hash para transformar cualquier clave en un índice numérico dentro de un array fijo. El objetivo principal es lograr un tiempo de búsqueda promedio constante, O(1). Sin embargo, si dos claves generan el mismo índice, ocurre una colisión. Existen estrategias como encadenamiento o direccionamiento abierto para resolverlas. La calidad de la función hash determina la eficiencia; una mala distribución provoca agrupamientos que degradan el rendimiento a O(n). En sistemas reales, se busca minimizar estas colisiones mediante tablas grandes y funciones robustas.

## Ejemplo (no ejecutado automáticamente)
Implementación básica en Python usando un array de listas para manejar colisiones por encadenamiento, insertando pares clave-valor.

```python
hash_table = [[] for _ in range(10)]
def insertar(tabla, clave, valor):
    indice = hash(clave) % len(tabla)
    tabla[indice].append((clave, valor))
```
