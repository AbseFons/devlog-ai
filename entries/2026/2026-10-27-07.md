## Objetivo
Aprender a convertir objetos complejos de Python a formato JSON utilizando la librería estándar json, manejando tipos de datos nativos y estructuras anidadas para el intercambio de datos.

## Explicación
En esta lección exploraremos la serialización profunda en Python. La función json.dumps() transforma diccionarios y listas en cadenas JSON válidas. Es crucial conocer los parámetros como ensure_ascii para controlar caracteres unicode y indent para formatear la salida legible. Python maneja automáticamente tipos como None (null), True/False (true/false) y rangos numéricos. Sin embargo, objetos personalizados requieren un convertidor personalizado o el uso de @json_serializer si se desea incluir métodos específicos en la salida del archivo.

## Ejemplo (no ejecutado automáticamente)
Conversión de un diccionario con datos mixtos a JSON formateado

```python
import json

data = {
    "usuario": "Ana",
    "activo": True,
    "edad": 28,
    "roles": ["admin", "editor"]
}

json_str = json.dumps(data, indent=4)
print(json_str)
```
