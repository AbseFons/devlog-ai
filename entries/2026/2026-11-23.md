## Objetivo
Aprender a validar datos y realizar cálculos automáticos al instanciar una clase dataclass utilizando el método especial __post_init__, asegurando la integridad de los objetos desde su creación.

## Explicación
Los dataclasses en Python son útiles, pero a veces necesitamos lógica adicional tras la inicialización. El método __post_init__ se ejecuta automáticamente después de que el constructor asigne los valores a los atributos. Aquí puedes validar que un campo no sea nulo o calcular un valor derivado como una suma total basada en otros campos. Esto mantiene el código limpio y centraliza la lógica de negocio dentro del modelo de datos, evitando errores de consistencia antes de que el objeto entre en producción.

## Ejemplo (no ejecutado automáticamente)
Definición de un dataclass para un producto que calcula el precio final incluyendo impuestos automáticamente al instanciarlo.

```python
@dataclass
class Producto:
    def __post_init__(self):
        if self.precio < 0:
            raise ValueError('El precio no puede ser negativo')
        self.precio_final = self.precio * 1.21
```
