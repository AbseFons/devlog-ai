## Objetivo
Comprender la definición y beneficios de las funciones puras, enfocándose en la ausencia de efectos secundarios y la dependencia exclusiva de sus parámetros para garantizar resultados predecibles y fáciles de probar.

## Explicación
Una función pura en Python es aquella que cumple dos condiciones estrictas: siempre devuelve el mismo resultado para los mismos argumentos de entrada y no produce efectos secundarios, como modificar variables globales o realizar operaciones I/O. Esto contrasta con las funciones impuras, comunes en scripts de automatización, donde el estado externo cambia la salida. Implementar funciones puras mejora la mantenibilidad del código al permitir pruebas unitarias sencillas sin necesidad de configurar entornos complejos. Además, facilita la composición funcional y el paralelismo, ya que cada llamada es independiente. En este contexto, evitamos mutaciones de estado para mantener la claridad lógica.

## Ejemplo (no ejecutado automáticamente)
Calcula el área de un círculo basándose únicamente en el radio proporcionado, sin alterar variables externas ni depender del tiempo actual.

```python
import math

def calcular_area_radio(radio):
    return math.pi * (radio ** 2)

area = calcular_area_radio(5)
```
