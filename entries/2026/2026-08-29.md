## Objetivo
El desarrollador comprenderá la naturaleza asíncrona de las promesas, evitará el uso excesivo de .then() en cadena y escribirá funciones asíncronas legibles con async/await para manejar errores de forma robusta.

## Explicación
Las promesas representan el estado final de una operación asíncrona: pendiente, resuelta o rechazada. Aunque son poderosas, las cadenas de .then() pueden oscurecer el flujo lógico. Async/await ofrece una sintaxis imperativa que hace que el código asíncrono parezca síncrono, mejorando la legibilidad. Este enfoque permite detener la ejecución hasta que una promesa se resuelva y manejar errores con bloques try/catch estándar, facilitando la depuración en aplicaciones modernas.

## Ejemplo (no ejecutado automáticamente)
```javascript
async function obtenerDatosUsuario(id) {
  try {
    const respuesta = await fetch(`https://api.ejemplo.com/usuarios/${id}`);
    if (!respuesta.ok) throw new Error('Error de red');
    return await respuesta.json();
  } catch (error) {
    console.error('Fallo al obtener datos:', error.message);
    return null;
  }
}

obtenerDatosUsuario(123).then(data => {
  if (data) console.log(data.nombre);
});
```

## Ejercicio
Crea una función asíncrona llamada 'buscarProducto' que use fetch para obtener un producto por ID. Implementa un bloque try/catch que devuelva null si el servidor falla o devuelve un mensaje de error específico.

## Criterios de revisión
El código debe usar la palabra clave async antes de la función, await dentro del cuerpo de la función y un bloque try/catch para capturar errores de red o lógica.
