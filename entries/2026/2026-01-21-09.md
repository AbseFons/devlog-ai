## Objetivo
Dominar la sintaxis básica de Common Table Expressions para simplificar consultas complejas mediante subconsultas nombradas y reutilizables en el contexto de SQL estándar.

## Explicación
Las Common Table Expressions o CTEs permiten definir una subconsulta temporal con un nombre, facilitando la lectura de queries anidadas. Se declaran antes del SELECT principal usando la palabra clave WITH. Esto es ideal para desglosar lógica compleja en pasos legibles. A diferencia de las vistas, las CTEs no persisten y solo existen durante la ejecución de la consulta actual. En esta serie aprenderemos a estructurar datos jerárquicos y filtrar resultados paso a paso sin sacrificar claridad.

## Ejemplo (no ejecutado automáticamente)
Consulta que utiliza una CTE para calcular el salario bruto antes de aplicar un filtro por departamento.

```sql
WITH calculo_salario AS (
    SELECT id_empleado, nombre, sueldo_base * 1.2 as sueldo_bruto
    FROM empleados
)
SELECT * FROM calculo_salario WHERE sueldo_bruto > 5000;
```
