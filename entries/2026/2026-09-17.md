## Objetivo
Comprender la diferencia entre estructuras LIFO y FIFO, identificar sus aplicaciones prácticas en gestión de memoria y tareas, y reconocer cuándo utilizar cada una para optimizar el flujo de datos en sistemas concurrentes.

## Explicación
Las pilas (stacks) siguen el principio LIFO (Last In, First Out), ideales para deshacer acciones o recursión. Las colas (queues) operan bajo FIFO (First In, First Out), esenciales para gestionar tareas en espera como impresión o mensajes. Ambas son fundamentales en algoritmos de recorrido de grafos y gestión de memoria. Elegir la correcta depende del orden de procesamiento requerido: si el último elemento añadido es el primero a procesar, usa pila; si el primero añadido debe ir primero, usa cola.

## Ejemplo (no ejecutado automáticamente)
Implementación básica de una cola FIFO en JavaScript para simular un sistema de tickets de atención al cliente.

```javascript
const cola = [];
function agregarCliente(nombre) {
  cola.push(nombre);
}
function atenderCliente() {
  return cola.shift();
}
```
