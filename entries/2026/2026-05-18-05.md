## Objetivo
Aprender a modularizar código JavaScript utilizando la sintaxis estándar import/export para evitar duplicidad y mejorar el mantenimiento del proyecto.

## Explicación
Los módulos ES permiten dividir una aplicación en archivos independientes. Para compartir datos, se usa export para definir variables o funciones en un archivo fuente, e import para traerlas a otro. Esto crea un sistema de encapsulamiento donde cada módulo es responsable de su propia lógica. Al usar const al importar, se asegura que las referencias sean inmutables, previniendo cambios accidentales en el estado global del programa.

## Ejemplo (no ejecutado automáticamente)
Un archivo utils.js exporta funciones matemáticas y un main.js las importa para realizar cálculos sin depender de variables globales.

```javascript
export const sumar = (a, b) => a + b;
import { sumar } from './utils.js';
console.log(sumar(2, 3));
```

## Ejercicio
Crea un archivo 'calculadora.js' que exporte una función 'restar'. Luego, en 'index.js', importa esta función y muestra el resultado de restar 10 a 5.

## Criterios de revisión
El código debe usar la sintaxis correcta de export e import. Debe haber dos archivos distintos. No se deben usar variables globales para los datos compartidos.
