## Objetivo
Comprender la diferencia estructural entre pilas (LIFO) y colas (FIFO), identificando sus aplicaciones prácticas en gestión de tareas y procesamiento de datos secuenciales mediante estructuras de datos estándar.

## Explicación
Las pilas operan bajo el principio 'último en entrar, primero en salir', ideales para deshacer acciones o recursión. Las colas siguen 'primero en entrar, primero en salir', cruciales para colas de impresión o mensajes asíncronos. Python ofrece listas para implementar ambas: usar append/pop para pilas y collections.deque para colas eficientes. La elección depende del flujo lógico del algoritmo.

## Ejemplo (no ejecutado automáticamente)
Implementación de una cola FIFO usando deque para simular un sistema de tickets en una cafetería.

```python
from collections import deque
queue = deque()
queue.append('Cliente A')
queue.append('Cliente B')
print(queue.popleft())
```
