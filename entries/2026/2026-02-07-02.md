## Objetivo
Introducir el concepto de pruebas basadas en propiedades, donde se definen invariantes lógicos que deben cumplirse siempre, permitiendo detectar errores sutiles sin especificar comportamientos detallados paso a paso.

## Explicación
Las pruebas basadas en propiedades verifican que un sistema mantenga ciertas condiciones verdaderas bajo cualquier circunstancia. En lugar de definir cómo debe comportarse el código exactamente, se establecen reglas generales como 'la suma de entradas nunca es menor que la salida'. Este enfoque es poderoso porque revela fallos inesperados al probar con datos aleatorios o extremos. Es ideal para algoritmos matemáticos y sistemas críticos donde la lógica interna puede ser compleja pero los resultados esperados son claros.

## Ejemplo (no ejecutado automáticamente)
Script en Python que verifica si una función de suma cumple la propiedad conmutativa (a + b == b + a) para números aleatorios.

```python
import random

def suma(a, b):
    return a + b

for _ in range(100):
    x = random.randint(-100, 100)
    y = random.randint(-100, 100)
    assert suma(x, y) == suma(y, x), "Propiedad conmutativa falló"
```
