## Objetivo
Aprender a construir rutas de archivos robustas en Python utilizando pathlib, evitando errores comunes con separadores de directorio y manejando correctamente la mezcla de rutas relativas y absolutas sin depender de la ubicación del sistema operativo.

## Explicación
En esta lección exploraremos cómo combinar rutas relativas y absolutas usando el módulo pathlib. A diferencia de las cadenas de texto, los objetos Path permiten operaciones matemáticas seguras como concatenación y resolución de componentes. Utilizaremos el método joinpath para unir segmentos sin preocuparnos por si el sistema usa barras o slashes. También veremos como normalizar la ruta resultante eliminando puntos redundantes. Este enfoque es esencial cuando se desarrollan scripts que deben ejecutarse en diferentes entornos, desde un editor local hasta un servidor de producción, garantizando que el programa siempre encuentre los recursos necesarios independientemente de cómo se llame al proyecto.

## Ejemplo (no ejecutado automáticamente)
Se crea una ruta base absoluta y se le anexa una subcarpeta relativa para construir la ubicación final de un archivo de configuración.

```python
from pathlib import Path
base = Path('/home/usuario/proyecto')
config = base / 'datos' / 'config.json'
print(config)
```
