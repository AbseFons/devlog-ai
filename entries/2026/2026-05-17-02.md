## Objetivo
Aprender a cancelar peticiones asíncronas en JavaScript para evitar bloqueos de interfaz y mejorar la experiencia del usuario ante conexiones lentas o cancelaciones manuales.

## Explicación
Las peticiones fetch pueden colgar indefinidamente si el usuario abandona una página mientras se cargan datos. Para solucionar esto, utilizamos AbortController junto con fetch. Al crear un controlador y pasar su señal de abort a la opción de fetch, podemos cancelar la solicitud enviando una señal específica. Esto permite limpiar recursos y evitar que el hilo del evento principal se bloquee esperando una respuesta que nunca llegará. Es fundamental establecer un límite de tiempo o permitir al usuario detener la carga para mantener la aplicación responsiva.

## Ejemplo (no ejecutado automáticamente)
Se crea un controlador, se inicia una petición a una URL pública con un timeout simulado y se cancela manualmente después de unos segundos para demostrar el comportamiento.

```javascript
const controller = new AbortController();
fetch('https://jsonplaceholder.typicode.com/posts/1', { signal: controller.signal })
```
