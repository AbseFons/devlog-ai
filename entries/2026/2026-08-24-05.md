## Objetivo
Entender que una función pura depende solo de sus argumentos, no tiene efectos secundarios y siempre devuelve el mismo resultado para la misma entrada, facilitando pruebas y depuración.

## Explicación
En Python, las funciones puras son fundamentales para escribir código robusto. Una función es pura si su salida depende exclusivamente de sus entradas y nunca modifica variables externas ni produce efectos colaterales como I/O. Esto contrasta con funciones impuras que pueden cambiar el estado global o depender del tiempo. Implementar funciones puras permite paralelizar tareas fácilmente, ya que no hay dependencias ocultas entre ellas. Además, simplifican enormemente las pruebas unitarias porque no necesitas configurar un entorno específico antes de ejecutarlas. Al evitar mutaciones de datos compartidos, reduces la probabilidad de errores sutiles difíciles de rastrear en aplicaciones complejas.

## Ejemplo (no ejecutado automáticamente)
```python
def calcular_descuento(precio_base, porcentaje):
    """Calcula el precio final aplicando un descuento puro."""
    return round(precio_base * (1 - porcentaje / 100), 2)

precio_original = 100.0
porcentaje_aplicado = 20
precio_final = calcular_descuento(precio_original, porcentaje_aplicado)
print(f'Precio final: {precio_final}')
```
