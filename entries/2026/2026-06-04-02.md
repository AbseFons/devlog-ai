## Objetivo
Comprender el propósito de los códigos de respuesta HTTP en la serie 100, conocidos como indicadores de procesamiento, y su rol en la comunicación asíncrona entre cliente y servidor.

## Explicación
Los códigos HTTP que comienzan con 1 (serie 1xx) son respuestas intermedias. No indican éxito ni error final, sino que informan al cliente sobre el estado actual del proceso de solicitud. Por ejemplo, un código 100 Continue le dice al navegador que puede enviar el cuerpo de la petición sin problemas. Estos códigos son esenciales para protocolos como HTTP/2 y HTTP/3, donde permiten optimizar el flujo de datos evitando bloqueos innecesarios. Aunque raramente se ven en navegadores web estándar, son vitales en herramientas de desarrollo avanzado y sistemas distribuidos que requieren control granular sobre la transferencia de datos.

## Ejemplo (no ejecutado automáticamente)
Solicitud HTTP con encabezado de respuesta intermedio 100 Continue para confirmar recepción del encabezado antes del cuerpo.

```bash
curl -v https://api.ejemplo.com/datos \
     -H 'Content-Type: application/json' \
     -d '{"clave": "valor"}'
```
