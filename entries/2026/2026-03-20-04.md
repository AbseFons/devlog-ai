## Objetivo
Comprender la diferencia entre conjuntos (sets) y diccionarios, sus operaciones básicas de inserción, consulta y cómo utilizarlos para optimizar búsquedas y almacenar datos relacionales de manera eficiente.

## Explicación
En Python, los sets son colecciones no ordenadas de elementos únicos, ideales para verificar membresía rápida o eliminar duplicados. Los diccionarios mapean claves a valores, permitiendo acceso directo por índice lógico. Mientras que un set usa hash interno para O(1) en búsquedas sin estructura fija, un dict mantiene pares clave-valor ordenados (desde Python 3.7). Ejemplo: filtrar usuarios activos con un set de IDs y guardar sus perfiles en un dict.
