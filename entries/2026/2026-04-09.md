## Objetivo
Comprender cómo las funciones internas acceden a variables del ámbito exterior incluso después de que esa función haya terminado de ejecutarse, permitiendo crear funciones con estado privado.

## Explicación
Un closure es una función que recuerda su contexto léxico original. En JavaScript, cuando una función se define dentro de otra, puede acceder a las variables de la función externa. Incluso si la función externa termina, la interna mantiene referencias a esas variables. Esto permite encapsular datos y crear funciones especializadas sin exponer el estado interno. Por ejemplo, podemos generar un contador que incremente su valor privado cada vez que se llama a una función derivada, logrando un comportamiento de estado persistente sin usar variables globales.

## Ejemplo (no ejecutado automáticamente)
Se define una función factory que crea un contador con estado privado accesible mediante llamadas sucesivas.

```javascript
function crearContador() {
  let cuenta = 0;
  return function() {
    cuenta++;
    return cuenta;
  };
}
const miContador = crearContador();
console.log(miContador()); // 1
console.log(miContador()); // 2
```
