## Objetivo
Comprender y aplicar los principios básicos de la normalización en bases de datos relacionales, específicamente enfocándose en la eliminación de grupos repetidos para lograr la Primera Forma Normal (1FN) y garantizar la integridad estructural de los datos.

## Explicación
La normalización es el proceso de organizar una base de datos para reducir la redundancia y mejorar la integridad. La Primera Forma Normal (1FN) exige que cada celda contenga un único valor atómico, eliminando grupos repetidos o arrays dentro de una columna. Por ejemplo, si una tabla 'Ventas' tiene una columna 'Productos' con múltiples ítems separados por comas, no cumple la 1FN. Para corregirlo, debemos crear una tabla hija relacionada mediante claves foráneas, donde cada fila represente una venta individual de un producto específico. Esto transforma datos ambiguos en una estructura relacional clara, optimizando consultas y facilitando el mantenimiento a largo plazo del sistema informático.

## Ejemplo (no ejecutado automáticamente)
Transformación de una tabla con columnas repetidas a una estructura normalizada mediante SQL INSERT.

```sql
CREATE TABLE Ventas_Normalizadas (
  id_venta INT PRIMARY KEY,
  producto VARCHAR(50),
  cantidad INT
);
INSERT INTO Ventas_Normalizadas VALUES (1, 'Laptop', 2);
```
