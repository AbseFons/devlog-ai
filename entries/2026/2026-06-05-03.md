## Objetivo
Comprender cómo la concatenación insegura permite inyectar comandos maliciosos y aprender a utilizar parámetros para construir consultas robustas que protejan los datos de la base de datos contra ataques comunes.

## Explicación
La inyección SQL ocurre cuando se insertan entradas no filtradas directamente en una consulta. Un atacante puede modificar el comportamiento del sistema alterando la lógica de la sentencia. La defensa fundamental es usar parámetros o prepared statements. En lugar de concatenar strings, el motor de base de datos trata los valores como datos puros, ignorando cualquier carácter especial que intente alterar la sintaxis. Esto asegura que una entrada como 'admin'-- no se interprete como un comentario SQL, sino simplemente como texto dentro del campo de usuario.

## Ejemplo (no ejecutado automáticamente)
Consulta segura en Python usando parámetros para evitar inyección al buscar un usuario.

```python
import sqlite3
conn = sqlite3.connect('db.sqlite')
cursor = conn.cursor()
usuario = 'admin'
pasword = '12345'
query = "SELECT * FROM usuarios WHERE usuario = ? AND password = ?"
cursor.execute(query, (usuario, password))
```
