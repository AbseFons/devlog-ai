## Objetivo
Comprender la estructura básica de una función recursiva aplicándola para calcular el factorial de un número entero positivo, identificando claramente la condición base y el caso recursivo en el código.

## Explicación
La recursión permite que una función se llame a sí misma para resolver problemas más pequeños. En este ejemplo, calculamos el factorial (n!) multiplicando n por el factorial de n-1 hasta llegar al caso base donde n es 1 o 0. Es crucial definir la condición de parada para evitar un bucle infinito que agotaría la memoria del sistema. Este patrón es fundamental en algoritmos como árboles de búsqueda y ordenamiento divide-y-vencerás.

## Ejemplo (no ejecutado automáticamente)
Función que recibe un número entero y devuelve su factorial usando recursión directa.

```javascript
function factorial(n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}
```
