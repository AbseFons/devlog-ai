## Objetivo
Aprender a usar 'with' en Python para garantizar que los recursos, como archivos, se cierren automáticamente al finalizar el bloque, evitando errores comunes de gestión de memoria y bloqueos.

## Explicación
Los context managers permiten automatizar la limpieza de recursos. En lugar de abrir y cerrar un archivo manualmente con try/finally, usamos 'with open(...) as f'. Esto asegura que el método close() se invoque incluso si ocurre una excepción dentro del bloque. Python implementa esto mediante la clase contextlib o clases personalizadas con los métodos __enter__ y __exit__. Este patrón es esencial para manipular archivos, conexiones de base de datos o locks de hilos sin riesgo de dejar recursos abiertos.

## Ejemplo (no ejecutado automáticamente)
Lectura segura de un archivo de texto que se cierra automáticamente al terminar la ejecución del bloque 'with'.

```python
with open('datos.txt', 'r') as archivo:
    contenido = archivo.read()
    print(contenido)
```
