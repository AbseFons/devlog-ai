## Objetivo
Comprender por qué almacenar contraseñas en texto plano es un riesgo crítico y aprender a utilizar funciones de hash para proteger la integridad de los datos de autenticación en aplicaciones modernas.

## Explicación
Almacenar contraseñas como texto plano permite que cualquier atacante acceda a cuentas inmediatamente si roba la base de datos. Las funciones de hash, como bcrypt o Argon2, transforman la contraseña irreversiblemente. Si se compromete el sistema, solo se pierden los hashes, no las credenciales originales. Es vital usar salting para evitar ataques de diccionario y rainbow tables. Nunca utilice MD5 o SHA-1 por ser obsoletos. Implemente siempre algoritmos lentos diseñados específicamente para contraseñas.

## Ejemplo (no ejecutado automáticamente)
Generación de un hash seguro usando la librería bcrypt en Python con una sal automática.

```python
import bcrypt
password = 'MiContraseñaSegura123'
salt = bcrypt.gensalt()
hashed_password = bcrypt.hashpw(password.encode('utf-8'), salt)
```
