## Objetivo
Aprender a filtrar elementos complejos en una lista utilizando expresiones condicionales anidadas dentro de la sintaxis de comprensión, optimizando el código para validar múltiples criterios simultáneamente sin necesidad de bucles explícitos.

## Explicación
La comprensión de listas permite crear colecciones eficientes mediante iteraciones concisas. En esta lección, exploramos cómo integrar condiciones lógicas complejas directamente en la sintaxis. Al usar una expresión condicional dentro del corchete, podemos filtrar elementos que cumplan varios requisitos a la vez, como verificar rangos numéricos y tipos de datos específicos. Este enfoque reduce la verbosidad del código y mejora la legibilidad para operaciones de transformación de datos comunes en análisis o preprocesamiento.

## Ejemplo (no ejecutado automáticamente)
Se genera una lista de diccionarios con usuarios, filtrando solo aquellos que tienen más de dos años de experiencia y cuyo rol es 'desarrollador'.

```python
usuarios = [{'nombre': 'Ana', 'experiencia': 3, 'rol': 'dev'}, {'nombre': 'Luis', 'experiencia': 1, 'rol': 'dev'}, {'nombre': 'Carla', 'experiencia': 5, 'rol': 'analista'}]
filtrados = [u for u in usuarios if u['experiencia'] > 2 and u['rol'] == 'dev']
```
