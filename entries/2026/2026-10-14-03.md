## Objetivo
Aprender a filtrar y transformar datos complejos en Python utilizando funciones integradas dentro de la sintaxis de comprensión, optimizando el código para procesamiento de listas.

## Explicación
En esta microlección avanzamos más allá del filtrado básico. Utilizaremos una función lambda anidada junto con un condicional ternario dentro de la expresión de comprensión. Esto permite asignar valores por defecto o transformar elementos dinámicamente basándose en condiciones específicas, como convertir números negativos a cero y positivos al doble valor. Este patrón es esencial para limpiar datos sucios antes de su análisis.

## Ejemplo (no ejecutado automáticamente)
Transformación de una lista de temperaturas donde los valores negativos se ajustan a cero y los positivos se duplican.

```python
temperaturas = [-5, 10, -2, 20]
resultados = [x if x > 0 else 0 for x in temperaturas]
```
