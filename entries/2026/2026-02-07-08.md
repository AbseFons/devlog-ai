## Objetivo
Comprender la estructura básica de una aplicación monolítica dividida en capas lógicas para facilitar el mantenimiento, la escalabilidad y la reutilización del código en sistemas empresariales modernos.

## Explicación
El diseño por capas organiza el software en niveles funcionales independientes. La capa de presentación maneja la interacción con el usuario, mientras que la capa de negocio encapsula la lógica crítica y las reglas de operación. Finalmente, la capa de acceso a datos se encarga exclusivamente de la persistencia de información. Esta separación permite modificar una parte del sistema sin afectar a las demás. Por ejemplo, cambiar la base de datos no requiere alterar la lógica de negocio. Además, facilita pruebas unitarias aisladas y despliegues escalables donde cada capa puede optimizarse según sus necesidades específicas.

## Ejemplo (no ejecutado automáticamente)
Implementación básica en Python que define clases separadas para la interfaz de usuario, la lógica de cálculo de impuestos y el almacenamiento en memoria, demostrando cómo los datos fluyen entre capas sin acoplamiento directo.

```python
class Presentacion:
    def procesar(self, nombre):
        return self.negocio.calcular(nombre)

class Negocio:
    def calcular(self, nombre):
        return f'Usuario: {nombre}, Impuesto: 10%'

app = Presentacion()
print(app.procesar('Ana'))
```
