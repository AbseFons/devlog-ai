## Objetivo
Comprender la separación entre persistencia, lógica de negocio y presentación para mejorar el mantenimiento y la escalabilidad del software.

## Explicación
En esta microlección exploramos cómo estructurar una aplicación web moderna utilizando un enfoque por capas. La capa de datos se encarga exclusivamente de interactuar con la base de datos mediante consultas seguras, evitando inyecciones SQL. La capa de lógica de negocio procesa las reglas del dominio, como cálculos de precios o validaciones de inventario, manteniéndolas independientes de la interfaz. Finalmente, la capa de presentación maneja la interacción con el usuario. Esta separación permite que cada componente evolucione a su propio ritmo; por ejemplo, cambiar de base de datos no afecta a la lógica ni a la vista. Además, facilita las pruebas unitarias al poder aislar la lógica sin depender de una base de datos real.
