## Objetivo
Aprender a diseñar casos de prueba que cubran valores extremos y transiciones críticas en funciones matemáticas financieras, asegurando la robustez del sistema ante entradas inesperadas como montos negativos o divisas inexistentes.

## Explicación
En esta microlección exploramos el testing de casos borde aplicado a una función de conversión de moneda. Los casos borde típicos incluyen valores mínimos (cero), máximos permitidos por el tipo de dato, y transiciones entre estados válidos e inválidos. Por ejemplo, probar con un monto de 0.01 para verificar si la aplicación redondea correctamente o lanza una excepción. También es crucial validar que no se acepten divisas ficticias o montos negativos cuando el negocio lo prohíbe. Estos escenarios previenen fallos en producción derivados de entradas malformadas.

## Ejemplo (no ejecutado automáticamente)
Script en Python que define casos de prueba para una función de conversión, cubriendo valores nulos, negativos y límites superiores del tipo float.

```python
def test_conversion(monto, moneda_origen, moneda_destino):
    assert monto >= 0, "El monto no puede ser negativo"
    assert len(moneda_origen) == 3, "La moneda debe tener 3 caracteres"
```
