## Objetivo
Aprender a aislar la lógica de negocio probando funciones que dependen de servicios externos como bases de datos o APIs, utilizando el módulo unittest y la librería mock para evitar efectos secundarios no deseados.

## Explicación
En esta lección exploraremos cómo simular llamadas a una base de datos dentro de un test unitario. En lugar de conectar a un servidor real, creamos un objeto 'mock' que imita el comportamiento de la conexión. Esto permite ejecutar pruebas rápidamente y de forma aislada. Definiremos una función que consulta usuarios y luego verificaremos si se llama al mock con los argumentos correctos. El enfoque garantiza que la prueba falle solo si la lógica interna falla, no por problemas de red o permisos del servidor.

## Ejemplo (no ejecutado automáticamente)
Se define una clase MockUserDatabase que simula el método fetch_user. Luego se crea un objeto mock y se asigna a la variable global db para probar la funcion get_user_info sin conexión real.

```python
from unittest.mock import MagicMock

class MockUserDatabase:
    def fetch_user(self, user_id):
        return {'id': user_id, 'name': 'Alice'}

db = MockUserDatabase()
def get_user_info(user_id):
    data = db.fetch_user(user_id)
    return f'Usuario {data["name"]}'
```
