## Objetivo
Al finalizar esta lección, el desarrollador será capaz de convertir diccionarios y listas de Python a cadenas JSON válidas utilizando la librería estándar json, manejando correctamente los saltos de línea y espacios para generar un formato legible en archivos de configuración o APIs.

## Explicación
La serialización convierte objetos de memoria complejos en texto plano universal. En Python, el módulo 'json' permite transformar diccionarios y listas en cadenas JSON. Es crucial usar indentación para la legibilidad humana al escribir datos, pero omitirla cuando se envían respuestas compactas a APIs. El método 'dumps' genera la cadena cruda, mientras que 'dump' escribe directamente en un archivo. Recuerda que los diccionarios de Python se mapean automáticamente a objetos JSON, preservando las claves como cadenas y los valores numéricos como números, aunque las listas anidadas requieren atención especial para mantener la estructura jerárquica correcta sin errores de sintaxis.

## Ejemplo (no ejecutado automáticamente)
```python
import json

data = {
    "usuario": "dev_junior",
    "proyectos": [
        {"nombre": "api_v1", "estado": "activo"},
        {"nombre": "dashboard", "estado": "pendiente"}
    ],
    "configuracion": {
        "debug": True,
        "version": 2.5
    }
}

# Serializar con indentación para legibilidad
json_str = json.dumps(data, indent=4)
print(json_str)
```

La indentación debe ser exactamente de 2 espacios por nivel de anidación, sin caracteres extraños al inicio o final de la cadena.
