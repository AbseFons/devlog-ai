## Objetivo
Aprender a utilizar el patrón adaptador para integrar componentes con interfaces incompatibles sin modificar su código original, facilitando la evolución del sistema.

## Explicación
El patrón adaptador permite que dos clases con interfaces incompatibles colaboren. Imagina un módulo legacy de facturación que solo acepta objetos 'FacturaV1', pero tu nuevo sistema requiere 'FacturaV2'. En lugar de refacturar el código antiguo, creas una clase adaptadora que encapsula la lógica vieja y expone la nueva interfaz. Esto mantiene el sistema estable mientras modernizas gradualmente. El adaptador actúa como un puente, traduciendo las llamadas del cliente a los métodos internos del objeto legacy, ocultando sus peculiaridades y permitiendo una integración limpia y mantenible en arquitecturas complejas.

## Ejemplo (no ejecutado automáticamente)
Clase adaptadora que traduce una llamada a 'calcularTotal' de un sistema antiguo a la interfaz moderna requerida por el cliente.

```javascript
class LegacyInvoice {
  calcularTotal() { return 100; }
}
class ModernAdapter {
  constructor(legacy) { this.legacy = legacy; }
  getCosto() { return this.legacy.calcularTotal(); }
}
```

## Ejercicio
Crea una clase 'AdaptadorDePago' que acepte un objeto de pago antiguo con el método 'procesarPago()' y exponga la interfaz moderna 'realizarTransaccion()'.

## Criterios de revisión
El código debe instanciar correctamente el adaptador, llamar al método legacy encapsulado y devolver el resultado en la nueva interfaz sin errores.
