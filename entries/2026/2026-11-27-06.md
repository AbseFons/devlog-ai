## Objetivo
Aprender a gestionar recursos como archivos y conexiones usando el patrón context manager con 'with', asegurando su cierre automático incluso si ocurren errores.

## Explicación
En Python, los context managers permiten automatizar la limpieza de recursos. Usamos la sentencia 'with' para abrir un archivo; al salir del bloque, se ejecuta automáticamente el método '__exit__'. Esto evita que los archivos permanezcan abiertos y consuman memoria o bloqueen procesos. Es fundamental en desarrollo web y sistemas para manejar conexiones a bases de datos o sockets. Python implementa esto internamente con la clase 'contextlib', pero escribir nuestra propia lógica de cierre es una habilidad clave para crear código robusto y seguro frente a excepciones inesperadas.

## Ejemplo (no ejecutado automáticamente)
Ejemplo que abre un archivo de texto, escribe datos y lo cierra automáticamente usando el bloque con.

```python
with open('diario.txt', 'w') as f:
    f.write('Entrada del día 6: Aprendiendo context managers.')
print('Archivo cerrado exitosamente')
```
