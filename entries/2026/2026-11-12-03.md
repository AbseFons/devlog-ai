## Objetivo
Aprender a construir consultas seguras utilizando parámetros para evitar que los atacantes inyecten código malicioso en la base de datos mediante entradas de usuario no filtradas.

## Explicación
La inyección SQL ocurre cuando se concatenan directamente las entradas del usuario en una consulta. Para mitigar este riesgo, es fundamental utilizar parametrización o Prepared Statements. Esta técnica separa el código SQL de los datos, obligando a la base de datos a tratar siempre los valores proporcionados como texto literal y no como parte de la lógica de la consulta. En este caso de uso, utilizaremos Python con la librería sqlite3 para demostrar cómo pasar variables mediante placeholders '%s'. Esto asegura que incluso si un atacante intenta inyectar comandos maliciosos, estos se ejecutarán como datos simples dentro de la consulta, neutralizando el ataque sin comprometer la integridad del sistema.

## Ejemplo (no ejecutado automáticamente)
Consulta segura en Python usando placeholders para evitar inyección SQL.

```python
import sqlite3
conn = sqlite3.connect('db.sqlite')
cursor = conn.cursor()
usuario = input('Usuario: ')
password = input('Password: ')
query = "SELECT * FROM usuarios WHERE usuario = ? AND password = ?"
cursor.execute(query, (usuario, password))
```

## Criterios de revisión
El código debe utilizar placeholders (? o %s) correctamente. No debe haber concatenación de strings con los parámetros de entrada. La función debe manejar al menos dos tipos de datos diferentes (ej. texto e entero). El nombre de la tabla también debe ser un parámetro seguro.
