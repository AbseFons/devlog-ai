## Objetivo
Comprender la sintaxis básica de Common Table Expressions para simplificar consultas complejas mediante subconsultas nombradas y mejorar la legibilidad del código SQL.

## Explicación
Las Common Table Expressions o CTE permiten definir una tabla temporal que existe solo durante la ejecución de la consulta actual. Esto facilita el uso de recursión, múltiples referencias a la misma lógica y estructuras más limpias. La sintaxis estándar utiliza WITH antes del SELECT principal. Es ideal para desglosar problemas complejos en pasos lógicos nombrados.

## Ejemplo (no ejecutado automáticamente)
Consulta que calcula el total de ventas por categoría usando una CTE intermedia para filtrar productos activos.

```sql
WITH VentasActivas AS (
  SELECT categoria, SUM(precio) as total
  FROM productos
  WHERE estado = 'activo'
)
SELECT * FROM VentasActivas;
```
