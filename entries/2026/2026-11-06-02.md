## Objetivo
Aprender a usar la función yield para crear iteradores que procesan datos infinitos o muy grandes sin consumir toda la RAM del sistema al instante.

## Explicación
Los generadores permiten pausar y reanudar funciones, devolviendo valores uno a uno mediante yield. Esto es crucial cuando manejas flujos de datos masivos, como logs de servidores o streams de sensores IoT. A diferencia de las listas que cargan todo en memoria, los generadores mantienen el estado interno y solo calculan lo necesario al solicitarlo. En este caso de uso, simularemos la lectura de un archivo gigante línea por línea, evitando errores de desbordamiento de memoria.

## Ejemplo (no ejecutado automáticamente)
Funcion que lee un archivo virtualmente infinito generando números pares hasta un límite alto sin almacenarlos todos.

```python
def generar_pares():
    n = 0
    while True:
        yield n
        n += 2

for par in generar_pares():
    if par > 100:
        break
    print(par)
```
