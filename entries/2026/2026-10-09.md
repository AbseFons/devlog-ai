## Objetivo
Comprender por qué almacenar contraseñas en texto plano es inseguro y cómo las funciones hash unidireccionales protegen los datos de usuarios ante filtraciones, estableciendo la base para prácticas de seguridad robustas.

## Explicación
Almacenar contraseñas en texto plano expone a los sistemas a robos masivos. Si una base de datos se filtra, los atacantes obtienen credenciales directas. El hashing transforma la contraseña en un string irreversiblemente único mediante funciones criptográficas como bcrypt o Argon2. Aunque no podemos recuperar la contraseña original desde el hash, podemos verificar si el usuario ingresó la correcta comparando hashes. Esto asegura que incluso con acceso a la base de datos, los atacantes no puedan usar las contraseñas directamente para iniciar sesión en otros servicios.

## Ejemplo (no ejecutado automáticamente)
Implementación conceptual de hashing usando una función simulada en Python para demostrar la irreversibilidad y la verificación de credenciales sin almacenar texto plano.

```python
import hashlib
password = "mi_contraseña_secreta"
hash_password = hashlib.sha256(password.encode()).hexdigest()
print(f"Hash: {hash_password}")
if hash_password == "e99a18c428cb38d5f260853678922e03":
    print("Acceso concedido")
```
