## Objetivo
Aprender a serializar objetos Python que contienen datos binarios (bytes) utilizando la biblioteca json, aplicando técnicas de codificación base64 para garantizar la compatibilidad con formatos de texto estándar y evitar errores de escritura.

## Explicación
La librería nativa json no soporta directamente el tipo bytes. Para incluir archivos o datos binarios en un archivo JSON, debemos convertirlos a una representación de texto segura mediante codificación base64. Este proceso transforma los bytes en una cadena alfanumérica que puede ser almacenada y transmitida sin corrupción. Al deserializar, la función loads() no reconvierte automáticamente el texto a bytes; es necesario utilizar la librería base64 para decodificarlo previamente antes de procesar el contenido binario original.

## Ejemplo (no ejecutado automáticamente)
Codificación de un archivo pequeño en base64 para su almacenamiento en JSON.

```python
import json
import base64

with open('imagen.png', 'rb') as f:
    datos_binarios = f.read()

datos_codificados = base64.b64encode(datos_binarios).decode('utf-8')

contexto = {
    "nombre_archivo": "logo.png",
    "tipo": "imagen",
    "contenido_base64": datos_codificados
}

with open('salida.json', 'w') as f:
    json.dump(contexto, f)
```
