## Objetivo
Comprender cómo el Event Loop gestiona tareas síncronas y asincrónicas en JavaScript, permitiendo la ejecución no bloqueante de operaciones I/O sin detener la interfaz de usuario.

## Explicación
JavaScript es un lenguaje de un solo hilo que utiliza el modelo de eventos para manejar concurrencia. El Event Loop vigila constantemente dos pilas: la pila de tareas (call stack) y la cola de microtareas/macro-tareas. Las funciones síncronas se ejecutan en la pila; si son pesadas, bloquean el hilo. Cuando una tarea asincrónica (como una petición HTTP) termina, su callback se mueve a la cola correspondiente. El Event Loop verifica si la pila está vacía; si lo está, toma un elemento de la cola y lo ejecuta en la pila. Este mecanismo permite que aplicaciones web respondan inmediatamente al usuario mientras esperan datos externos, evitando bloqueos visuales.

## Ejemplo (no ejecutado automáticamente)
Ejemplo demostrando el orden de ejecución entre tareas síncronas, microtareas y macro-tareas usando setTimeout y Promise.

```javascript
console.log('Inicio');
setTimeout(() => console.log('Timeout'), 0);
Promise.resolve().then(() => console.log('Microtask'));
console.log('Fin');
```
