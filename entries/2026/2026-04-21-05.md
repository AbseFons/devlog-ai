## Objetivo
Comprender la diferencia entre iteradores manuales y generadores para procesar grandes volúmenes de datos sin consumir memoria excesiva, optimizando el rendimiento en aplicaciones de ingeniería.

## Explicación
En Python, los iteradores permiten recorrer secuencias sin almacenar todo el conjunto en memoria. Los generadores, mediante la sentencia yield, son una forma concisa de crear iteradores. A diferencia de las listas que cargan todos los elementos, los generadores calculan valores sobre la marcha (lazy evaluation). Esto es crucial cuando se manejan flujos de datos infinitos o archivos masivos. Un caso típico es leer un log gigante línea por línea en lugar de cargarlo entero. La sintaxis 'for x in generar()' abstrae la lógica interna del iterador, permitiendo escribir código limpio y eficiente que escala mejor con el volumen de información.

## Ejemplo (no ejecutado automáticamente)
Generador que produce números pares infinitos hasta un límite dado para demostrar eficiencia en memoria.

```python
def generar_pares(limite):
    n = 0
    while n < limite:
        yield n * 2
        n += 1

for par in generar_pares(5):
    print(par)
```
