## Objetivo
Al finalizar esta lección, el desarrollador será capaz de utilizar pathlib para construir rutas dinámicas que funcionen tanto en sistemas Windows como Unix, evitando errores comunes al mezclar separadores de directorio y asegurando que las operaciones de archivo sean portables sin depender de cadenas de texto estáticas.

## Explicación
En Python, la librería estándar pathlib ofrece una forma elegante y segura de manejar rutas de archivos. A diferencia de las cadenas de texto tradicionales, los objetos Path manejan automáticamente los separadores correctos para el sistema operativo subyacente. Esta lección se centra en la construcción de rutas relativas que evitan fugas de información al no depender de rutas absolutas del sistema. Aprenderemos a combinar componentes de ruta utilizando operadores como / y /, lo cual permite crear estructuras de directorio complejas de manera legible. Además, exploraremos cómo verificar si una ruta existe antes de intentar acceder a ella, una práctica esencial para prevenir excepciones en producción. Este enfoque garantiza que el código sea robusto frente a diferentes entornos de ejecución.

## Ejemplo (no ejecutado automáticamente)
```python
from pathlib import Path

def procesar_archivo(nombre_base):
    """Crea una ruta segura y verifica su existencia."""
    # Definir la ruta relativa al script actual
    base_ruta = Path(__file__).parent / 'datos'
    archivo_objetivo = base_ruta / f'{nombre_base}.csv'
    
    if not archivo_objetivo.exists():
        print(f'El archivo {archivo_objetivo} no existe.')
        return False
    
    # Leer el contenido del archivo
    try:
        with archivo_objetivo.open('r', encoding='utf-8') as f:
            contenido = f.read()
        print(f'Archivo procesado correctamente: {contenido[:50]}...')
        return True
    except Exception as e:
        print(f'Error al leer el archivo: {e}')
        return False

# Caso de uso: intentar procesar un archivo que podría no existir
procesar_archivo('reporte_mensual')
```
