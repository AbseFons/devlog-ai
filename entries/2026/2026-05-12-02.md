## Objetivo
Aprender a implementar restricciones CHECK para rangos numéricos y UNIQUE para integridad referencial, asegurando la calidad de los datos desde el diseño de la base de datos.

## Explicación
Las restricciones en SQL garantizan la integridad de los datos. La cláusula CHECK valida que un valor cumpla una condición lógica específica, como asegurar que la edad no sea negativa o que un salario esté dentro de un rango razonable. Por otro lado, UNIQUE garantiza que todos los valores en una columna (o conjunto de columnas) sean distintos entre sí, ideal para identificadores secundarios como números de teléfono o correos electrónicos. Ambas restricciones se definen al crear o modificar la tabla mediante ALTER TABLE. Es crucial escribir las condiciones con precisión para evitar errores de sintaxis y asegurar que la base de datos rechace inserciones inválidas automáticamente.

## Ejemplo (no ejecutado automáticamente)
Creación de una tabla de empleados con restricción de edad positiva y número de empleado único.

```sql
CREATE TABLE Empleados (
  id_empleado INT PRIMARY KEY,
  nombre VARCHAR(50),
  edad INT CHECK (edad >= 18 AND edad <= 65),
  telefono VARCHAR(20) UNIQUE
);
```
