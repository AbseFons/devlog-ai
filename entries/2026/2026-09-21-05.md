## Objetivo
Aprender a utilizar context managers para gestionar recursos automáticamente y crear excepciones personalizadas para errores específicos del dominio, mejorando la robustez y claridad del código.

## Explicación
En esta lección exploraremos dos patrones avanzados de manejo de errores. Primero, los context managers (usando 'with') aseguran que recursos como archivos o conexiones se cierren incluso si ocurren excepciones. Segundo, aprenderás a definir tus propias clases de excepción heredando de Exception. Esto permite capturar errores específicos en lugar de usar bloques genéricos try-except, facilitando el diagnóstico y la recuperación controlada.

## Ejemplo (no ejecutado automáticamente)
Ejemplo que define una excepcion personalizada para validar datos numericos y utiliza un context manager para gestionar un archivo temporal.

```python
class ValorInvalido(Exception):
    def __init__(self, valor, motivo):
        super().__init__(f'Valor {valor} invalido: {motivo}')

try:
    with open('datos.txt', 'r') as f:
        datos = [float(line) for line in f if float(line) > 100]
except ValorInvalido as e:
    print(f'Error controlado: {e}')
```
