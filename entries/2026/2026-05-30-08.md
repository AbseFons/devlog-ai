## Objetivo
Comprender la gestión asíncrona mediante promesas y async/await para escribir código legible, evitar callbacks anidados y manejar errores de forma robusta en aplicaciones web modernas.

## Explicación
En JavaScript moderno, las Promesas representan el resultado final de una operación asíncrona. El patrón 'async/await' simplifica la lectura al permitir escribir operaciones secuenciales dentro de funciones asíncronas. Esto evita el 'callback hell'. Es crucial usar try/catch para interceptar errores en lugar de .catch(). Un caso real es leer datos de una API: se espera la respuesta, se procesa y se maneja cualquier fallo de red o formato incorrecto sin bloquear la interfaz del usuario.

## Ejemplo (no ejecutado automáticamente)
Funcion que simula una llamada a API con promesa y manejo de errores con async/await

```javascript
async function obtenerDatos() {
  try {
    const respuesta = await fetch('https://jsonplaceholder.typicode.com/posts/1');
    return await respuesta.json();
  } catch (error) {
    console.error('Error:', error);
  }
}
```
