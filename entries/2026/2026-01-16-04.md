## Objetivo
Comprender cómo la base de datos optimiza consultas complejas mediante el análisis del plan de ejecución, identificando cuellos de botella como escaneos completos o uniones ineficientes para mejorar el rendimiento.

## Explicación
El comando EXPLAIN revela el algoritmo que el motor de SQL utilizará antes de ejecutar la consulta. Esto permite visualizar el orden de las operaciones, los índices empleados y las estimaciones de filas. Un plan eficiente suele mostrar búsquedas por índice en lugar de escaneos secuenciales completos. Al analizar este plan, los desarrolladores pueden reestructurar consultas lentas, añadir índices faltantes o modificar estadísticas de tablas. Es fundamental para la optimización proactiva del rendimiento en aplicaciones de alta carga.

## Ejemplo (no ejecutado automáticamente)
Consulta que busca empleados por departamento con sueldo mínimo, mostrando el plan de ejecución para identificar si se usa un índice compuesto.

```sql
EXPLAIN ANALYZE
SELECT e.nombre, d.nombre_depto
FROM empleados e
JOIN departamentos d ON e.id_depto = d.id
WHERE d.nombre_depto = 'Ventas'
  AND e.sueldo >= 50000;
```

## Ejercicio
Crea una tabla de productos con un campo 'precio' y escribe una consulta que utilice EXPLAIN para verificar si la base de datos usa un índice en lugar de escanear toda la tabla al filtrar por precios superiores a 100.

## Criterios de revisión
El plan debe mostrar 'Index Scan' o 'Index Seek' en lugar de 'Seq Scan'. La consulta debe ser sintácticamente correcta y el análisis debe indicar claramente el uso del índice.
