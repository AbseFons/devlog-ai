## Objetivo
Aprender a definir clases Python concisas con dataclasses, automatizando metadatos como __init__ y __repr__, ideal para representar datos estructurados en aplicaciones modernas.

## Explicación
Los dataclasses simplifican la creación de clases que almacenan datos. Al decorar una clase con @dataclass, Python genera automáticamente los métodos mágicos necesarios. Esto reduce drásticamente el código boilerplate. En este ejemplo, creamos un objeto 'Usuario' con nombre y edad. La sintaxis es limpia y legible. Ideal para modelos de dominio o respuestas de API donde la estructura de datos es más importante que la lógica compleja. Evita errores comunes al olvidar inicializadores.

## Ejemplo (no ejecutado automáticamente)
Definición de una clase Usuario con atributos nombre y edad usando el decorador @dataclass.

```python
from dataclasses import dataclass

@dataclass
class Usuario:
    nombre: str
    edad: int
```
