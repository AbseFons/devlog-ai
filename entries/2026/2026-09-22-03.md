## Objetivo
Comprender el concepto fundamental de las pruebas basadas en propiedades, donde se definen invariantes lógicos que deben cumplirse siempre para cualquier entrada válida, permitiendo detectar errores sutiles sin especificar comportamientos detallados paso a paso.

## Explicación
Las pruebas basadas en propiedades (Property-Based Testing) difieren de las pruebas tradicionales al no depender de casos de uso específicos, sino de reglas generales que el sistema debe obedecer. Por ejemplo, una función de suma nunca debe devolver un valor menor que sus operandos si todos son positivos. Esta técnica automatiza la generación de datos aleatorios para verificar estas propiedades. Si alguna entrada rompe la regla, la prueba falla. Es ideal para lógica matemática, transformaciones de datos y algoritmos donde el comportamiento correcto se define por invariantes más que por flujos de control.

## Ejemplo (no ejecutado automáticamente)
Script en Python que verifica la propiedad de ordenamiento: una lista ordenada nunca debe tener un elemento mayor que el siguiente.

```python
from hypothesis import given, strategies as st

def check_sorted_property(lst):
    assert all(lst[i] <= lst[i+1] for i in range(len(lst)-1))

@given(st.lists(st.integers(min_value=0)))
def test_sorting(lst):
    check_sorted_property(lst)
```
