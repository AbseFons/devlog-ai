## Objetivo
Comprender cómo la propiedad de consistencia garantiza que una transacción base de datos pase de un estado válido a otro, manteniendo las reglas de integridad definidas sin errores lógicos.

## Explicación
La consistencia asegura que cada transacción transforme el sistema desde un estado válido hacia otro. Si una operación falla en medio del proceso, la transacción se aborta completamente para evitar datos corruptos. Por ejemplo, al transferir dinero entre cuentas, si la resta a la cuenta origen no coincide con el incremento en la destino, el sistema debe revertir ambos cambios. Esto previene que el saldo total del banco cambie arbitrariamente. La base de datos verifica restricciones como claves foráneas y valores únicos antes de confirmar la transacción.

## Ejemplo (no ejecutado automáticamente)
Script SQL que simula una transferencia fallida donde se invierte el cambio en la cuenta destino para mantener la consistencia total.

```sql
BEGIN TRANSACTION;
UPDATE cuentas SET saldo = saldo - 100 WHERE id = 1;
UPDATE cuentas SET saldo = saldo + 100 WHERE id = 2;
COMMIT;
```
