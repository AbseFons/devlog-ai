## Objetivo
Comprender y aplicar la primera forma normal (1FN) para eliminar grupos repetidos en columnas, asegurando que cada celda contenga un valor único y atómico.

## Explicación
La normalización es el proceso de organizar una base de datos para reducir la redundancia y mejorar la integridad. La Primera Forma Normal (1FN) exige que cada columna tenga valores atómicos, sin listas o grupos dentro de una celda. Por ejemplo, si una tabla 'Clientes' tiene una columna 'Hobbies' con múltiples intereses separados por comas, no cumple la 1FN. Para corregirlo, debemos dividir esa tabla en dos: una para los clientes y otra para sus hobbies, creando una relación uno a muchos. Esto permite consultas más precisas y evita anomalías de actualización.

## Ejemplo (no ejecutado automáticamente)
Transformación de una tabla con columnas repetidas a una estructura relacional normalizada usando SQL.

```sql
CREATE TABLE Clientes (
  id INT PRIMARY KEY,
  nombre VARCHAR(100)
);

CREATE TABLE Hobbies (
  id_hobby INT PRIMARY KEY,
  cliente_id INT,
  hobby VARCHAR(50),
  FOREIGN KEY (cliente_id) REFERENCES Clientes(id)
);
```
