## Objetivo
Aprender a usar anotaciones opcionales para mejorar la legibilidad del código sin perder la flexibilidad del tipado dinámico, identificando errores potenciales antes de la ejecución.

## Explicación
Python es un lenguaje de tipado dinámico donde las variables no tienen tipo fijo. Sin embargo, desde Python 3.5, se pueden añadir anotaciones para documentar el tipo esperado. Estas anotaciones son ignoradas por el intérprete en tiempo de ejecución estándar, pero herramientas como mypy o Pyright las utilizan para análisis estático. Es crucial diferenciar entre la asignación inicial y la reasignación posterior. Las anotaciones ayudan a prevenir errores lógicos al hacer que el código sea más autoexplicativo para otros desarrolladores. Se recomienda usarlas en funciones, especialmente en parámetros y retornos, aunque no son obligatorias. Este enfoque híbrido combina la rapidez de desarrollo con las ventajas del análisis estático.

## Ejemplo (no ejecutado automáticamente)
Definición de una función que calcula el área de un círculo, donde se anotan los tipos de entrada (float) y salida (float), demostrando cómo Python permite reasignar la variable 'radio' a un entero sin error.

```python
def calcular_area(radio: float) -> float:
    return 3.14159 * radio ** 2

radio = 5.0
print(calcular_area(radio))
radio = 10
print(calcular_area(radio))
```
