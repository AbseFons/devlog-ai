## Objetivo
Comprender el propósito de las pruebas de regresión para asegurar que nuevas modificaciones no rompan funcionalidades preexistentes del sistema, manteniendo la estabilidad del producto ante iteraciones continuas.

## Explicación
Las pruebas de regresión son esenciales en el ciclo de vida del desarrollo de software. Su objetivo principal es verificar que los cambios recientes, como la adición de nuevas características o correcciones de errores, no hayan introducido defectos accidentales en partes del sistema que funcionaban correctamente antes. Estas pruebas se ejecutan periódicamente, especialmente después de cada integración de código. Un conjunto de pruebas de regresión típicamente cubre flujos críticos del negocio y casos de uso fundamentales. Al automatizarlas, los equipos pueden ejecutarlas frecuentemente sin consumir recursos excesivos, permitiendo una entrega más rápida y segura. Ignorar esta etapa puede llevar a fallos en producción difíciles de rastrear, ya que el origen del problema podría estar en un cambio realizado días o semanas atrás.

## Ejemplo (no ejecutado automáticamente)
Script de Python que simula una prueba de regresión verificando que la suma de dos números positivos siempre devuelva el resultado correcto y que el manejo de entradas nulas no cause excepciones inesperadas.

```python
def test_suma_regresion(a, b):
    assert a + b == 5, f"La suma {a} + {b} debe ser 5"

def test_nulo_regresion():
    try:
        result = 0 / 0
        assert False, "Debería lanzar una excepción"
    except ZeroDivisionError:
        pass
```
