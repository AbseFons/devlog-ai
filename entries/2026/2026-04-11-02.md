## Objetivo
Aprender a conectar Python con una base de datos SQLite local, crear un esquema inicial y realizar la primera inserción de datos sin dependencias externas.

## Explicación
En esta lección exploraremos los fundamentos de sqlite3. Primero importamos el módulo nativo del sistema. Luego establecemos una conexión a un archivo 'datos.db'. Usamos execute para crear una tabla 'empleados' con columnas tipo texto e entero. Finalmente, insertamos un registro mediante parametrización para evitar inyecciones SQL. Este flujo básico es esencial antes de manejar consultas complejas o transacciones.

## Ejemplo (no ejecutado automáticamente)
Script que crea la base de datos y una tabla de empleados con un registro inicial.

```python
import sqlite3
conn = sqlite3.connect('datos.db')
cursor = conn.cursor()
cursor.execute('''CREATE TABLE IF NOT EXISTS empleados (id INTEGER PRIMARY KEY, nombre TEXT)''')
cursor.execute("INSERT INTO empleados (nombre) VALUES ('Ana Garcia')")
conn.commit()
```
