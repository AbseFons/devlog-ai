## Objetivo
Aprender a convertir objetos Python complejos, como diccionarios y listas, en cadenas de texto JSON válidas utilizando la biblioteca estándar json para almacenamiento o transmisión de datos.

## Explicación
La serialización transforma estructuras de datos nativas de Python en un formato universal legible por máquinas. Utilizamos el módulo 'json' que ofrece funciones como 'dump()' para escribir directamente en archivos y 'dumps()' para obtener cadenas en memoria. Es crucial manejar correctamente los tipos de datos: las claves deben ser strings, los booleanos se mapean a true/false y None a null. Python 3.7+ garantiza el orden de inserción en diccionarios, lo cual es vital para mantener la consistencia del JSON generado. Este proceso es esencial para APIs REST, configuración de servicios o intercambio de datos entre sistemas heterogéneos.

## Ejemplo (no ejecutado automáticamente)
Conversión de un diccionario de usuario a una cadena JSON compacta usando dumps con indentación.

```python
import json
usuario = {'nombre': 'Ana', 'edad': 30}
print(json.dumps(usuario, indent=2))
```
