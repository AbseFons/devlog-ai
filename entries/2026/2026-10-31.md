## Objetivo
Comparar las diferencias fundamentales entre pytest y unittest en Python, destacando la sintaxis más concisa de pytest para escribir pruebas unitarias eficientes y legibles desde el inicio.

## Explicación
En ingeniería de software moderna, pytest ha desplazado a unittest por su simplicidad. Mientras unittest requiere heredar clases y usar métodos como setUp(), pytest utiliza decoradores simples como @pytest.fixture. Esto reduce la boilerplate code drásticamente. Las aserciones en pytest son implícitas (assert funciona nativamente), mientras que unittest necesita assertEqual(). Además, pytest ofrece un descubrimiento automático de pruebas sin necesidad de definir una clase TestSuite. Para proyectos nuevos, pytest es la elección estándar debido a su flexibilidad y ecosistema rico.

## Ejemplo (no ejecutado automáticamente)
Ejemplo de función simple probada con aserciones nativas en pytest.

```python
def suma(a, b):
    return a + b

def test_suma():
    assert suma(2, 3) == 5
```
