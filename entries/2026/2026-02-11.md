## Objetivo
Comprender por qué almacenar contraseñas en texto plano es inseguro y cómo utilizar funciones hash para proteger credenciales, evitando ataques de fuerza bruta y filtraciones de datos.

## Explicación
Las contraseñas nunca deben guardarse en texto plano. Si una base de datos se filtra, los atacantes obtendrían acceso inmediato a todas las cuentas. El hashing transforma la contraseña en un valor irreversible mediante funciones como bcrypt o Argon2. Esto añade 'sal' aleatoria para evitar ataques de diccionario precalculados. Aunque el hash es público, no se puede recuperar la contraseña original. Este enfoque cumple con normativas de seguridad y protege la privacidad del usuario incluso ante brechas de información.

## Ejemplo (no ejecutado automáticamente)
Implementación básica de hashing en Python usando la librería estándar hashlib para demostrar la diferencia entre texto plano y hash SHA-256.

```python
import hashlib
password = "mi_contraseña_secreta"
hash_value = hashlib.sha256(password.encode()).hexdigest()
print(f"Hash: {hash_value}")
```
