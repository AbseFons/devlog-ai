## Objetivo
Aprender a convertir objetos Python complejos en cadenas JSON legibles y viceversa, utilizando la biblioteca estándar json para intercambiar datos estructurados de manera eficiente.

## Explicación
La serialización permite guardar o transmitir estructuras de datos. En Python, el módulo json convierte diccionarios y listas en texto JSON mediante json.dumps(). Para leerlo, usa json.loads(). Es crucial manejar tipos de datos: las claves deben ser strings, los booleanos son True/False (no camelCase), y None se traduce como null. Este proceso es esencial para APIs REST, almacenamiento local o configuración de servicios.

## Ejemplo (no ejecutado automáticamente)
Conversión de un diccionario de usuario a formato JSON string

```python
import json
usuario = {"nombre": "Ana", "activo": True}
json_str = json.dumps(usuario)
```
