## Objetivo
Comprender cómo las funciones internas acceden a variables del ámbito exterior incluso después de que ese ámbito ha finalizado, permitiendo crear funciones con estado encapsulado y reutilizables sin depender de variables globales.

## Explicación
Un closure en JavaScript es una función que recuerda su entorno léxico original. Cuando una función se define dentro de otra, puede acceder a las variables de la función externa. Aunque la función externa termine de ejecutarse, sus variables no son liberadas inmediatamente si hay referencias activas desde el interior. Esto permite crear funciones con memoria persistente. Por ejemplo, podemos generar un contador simple donde cada llamada devuelve una nueva función que incrementa su propio valor interno sin exponerlo al ámbito global.

## Ejemplo (no ejecutado automáticamente)
Se define una funcion factory que crea contadores personalizados. Cada instancia mantiene su propia variable de estado gracias al closure.

```javascript
function crearContador(inicial) {
  let contador = inicial;
  return function() {
    return ++contador;
  };
}
const miContador = crearContador(10);
console.log(miContador()); // 11
console.log(miContador()); // 12
```
