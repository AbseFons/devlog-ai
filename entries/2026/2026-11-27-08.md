## Objetivo
Aprender a construir consultas seguras utilizando parámetros para evitar que entradas de usuario maliciosas alteren la lógica de la base de datos y comprometan la integridad de los datos almacenados.

## Explicación
La inyección SQL ocurre cuando se concatenan cadenas de texto directamente en las consultas, permitiendo a atacantes ejecutar comandos no deseados. La solución robusta es la parametrización, donde el motor de base de datos trata automáticamente los valores proporcionados como datos y no como código ejecutable. Esto aísla la estructura de la consulta del contenido de entrada. En este caso de uso, utilizaremos Python con un driver de base de datos genérico para demostrar cómo definir placeholders en la sentencia SQL y pasar los argumentos de forma segura a la función de ejecución, garantizando que cualquier carácter especial incluido por el usuario sea interpretado literalmente.

## Ejemplo (no ejecutado automáticamente)
Consulta parametrizada segura que busca un usuario por nombre sin riesgo de inyección.

```python
cursor.execute("SELECT * FROM usuarios WHERE nombre = %s", (nombre_usuario,))
resultados = cursor.fetchall()
```
