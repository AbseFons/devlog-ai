## Objetivo
El desarrollador aplicará técnicas de sanitización para prevenir inyecciones a través de parámetros de arrays, asegurando que cada elemento se verifique antes de procesarse.

## Explicación
La validación de entradas en estructuras complejas como arrays requiere inspeccionar no solo la longitud del conjunto, sino también el contenido individual de cada elemento. Un atacante puede inyectar datos maliciosos dentro de un array legítimo para explotar bucles o alterar la lógica del programa. La estrategia defensiva implica definir esquemas estrictos que limiten el tipo de dato, la longitud máxima y los caracteres permitidos en cada posición. Implementar validación por defecto (fail-safe) garantiza que cualquier entrada no conforme sea rechazada inmediatamente, evitando comportamientos inesperados o vulnerabilidades de inyección.

## Ejemplo (no ejecutado automáticamente)
```python
import re

def validar_array_entrada(datos):
    if not isinstance(datos, list):
        raise ValueError("Solo se permiten listas")
    
    patron = r'^[a-zA-Z0-9_-]{1,20}$'
    for i, item in enumerate(datos):
        if not isinstance(item, str):
            raise TypeError(f"El elemento {i} no es una cadena")
        if not re.match(patron, item):
            raise ValueError(f"El elemento {i} contiene caracteres inválidos o excede la longitud permitida")
    return datos
```
