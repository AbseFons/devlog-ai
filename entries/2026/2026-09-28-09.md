## Objetivo
Aprender a analizar el plan de ejecución con EXPLAIN para identificar cuellos de botella causados por la falta de índices adecuados y mejorar el rendimiento de las consultas.

## Explicación
El comando EXPLAIN revela cómo el motor de base de datos procesa una consulta. En este caso, analizamos una tabla 'ventas' sin índice en la columna 'fecha'. El plan muestra un escaneo completo (Seq Scan), lo que es ineficiente para grandes volúmenes de datos. Al añadir un índice B-tree en 'fecha', el plan cambia a un acceso por índice (Index Scan). Esto permite filtrar registros rápidamente sin leer toda la tabla, reduciendo drásticamente el tiempo de respuesta y el uso de recursos del servidor.

## Ejemplo (no ejecutado automáticamente)
Consulta inicial que sufre bajo rendimiento seguida de la creación del índice optimizador.

```sql
SELECT * FROM ventas WHERE fecha > '2025-01-01';
CREATE INDEX idx_ventas_fecha ON ventas(fecha);
```

## Ejercicio
Crea una tabla de productos con al menos 10.000 filas y ejecuta una consulta que busque por categoría. Luego, añade un índice en la columna de búsqueda y compara los tiempos de ejecución usando EXPLAIN.

## Criterios de revisión
El plan debe mostrar 'Index Scan' después de crear el índice y el tiempo de ejecución debe reducirse significativamente comparado con el escaneo secuencial inicial.
