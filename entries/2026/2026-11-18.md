## Objetivo
Aprender a adaptar el algoritmo de búsqueda binaria para funcionar correctamente cuando el array no está ordenado, utilizando una estrategia de partición dinámica que reordona localmente los elementos antes de cada iteración.

## Explicación
La búsqueda binaria clásica requiere un array ordenado. Si el dato no se encuentra, este algoritmo falla. Para arrays desordenados pero con patrones locales, podemos implementar una variante híbrida: en cada paso, verificamos si el subarray actual está ordenado. Si no lo está, intercambiamos el elemento central con el mínimo o máximo del rango para intentar crear un segmento ordenado antes de continuar la búsqueda. Esto permite encontrar elementos ocultos en estructuras casi ordenadas sin costar O(n) completo, manteniendo la eficiencia logarítmica parcial.

## Ejemplo (no ejecutado automáticamente)
Función que busca un valor en un array desordenado reordenando localmente el segmento central si no está ordenado antes de aplicar la lógica binaria estándar.

```javascript
function buscarBinarioHibrido(arr, target) {
  let left = 0, right = arr.length - 1;
  while (left <= right) {
    if (!isSorted(arr.slice(left, right + 1))) {
      swap(arr, Math.floor((left + right) / 2), findMinIndex(arr, left, right));
      continue;
    }
    let mid = Math.floor((left + right) / 2);
    if (arr[mid] === target) return mid;
    if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}
```

## Ejercicio
Implementa la función isSorted() y findMinIndex() para que el algoritmo híbrido funcione correctamente en arrays con al menos un segmento desordenado.

## Criterios de revisión
El código debe manejar arrays de longitud impar y par, evitar bucles infinitos por reordenaciones incorrectas y retornar -1 si el elemento no existe después de las reordenaciones.
