## Objetivo
Aprender a utilizar anotaciones de tipo para mejorar la legibilidad del código sin sacrificar la flexibilidad dinámica, identificando errores potenciales antes de la ejecución mediante herramientas como mypy.

## Explicación
Python es un lenguaje dinámicamente tipado, lo que significa que las variables no tienen un tipo fijo en tiempo de compilación. Sin embargo, desde Python 3.5, se pueden añadir anotaciones de tipo usando comillas dobles (ej: x: int). Estas anotaciones son opcionales y no afectan la ejecución del programa, pero proporcionan documentación clara para otros desarrolladores y permiten a herramientas estáticas como mypy detectar errores lógicos antes de ejecutar el script. Por ejemplo, declarar una función que devuelve un diccionario con claves específicas ayuda a mantener la integridad de los datos en aplicaciones complejas.

## Ejemplo (no ejecutado automáticamente)
Función que calcula el área de un rectángulo con validación de tipos implícita mediante anotaciones.

```python
def calcular_area(ancho: float, alto: float) -> float:
    return ancho * alto

resultado = calcular_area(5.0, 10.0)
```
