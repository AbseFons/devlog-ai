## Objetivo
Aprender a utilizar la librería estándar argparse en Python para crear scripts que acepten argumentos desde la línea de comandos, facilitando la automatización de tareas y mejorando la usabilidad del software sin necesidad de interfaces gráficas.

## Explicación
La librería argparse permite definir opciones y argumentos para un script. Al ejecutar el programa con parámetros específicos, Python interpreta estos datos según las reglas establecidas en el código. Esto es esencial para herramientas de administración de sistemas o análisis de datos donde los usuarios necesitan pasar rutas de archivos, niveles de detalle o formatos de salida sin modificar el script. El parser genera automáticamente mensajes de ayuda y detecta errores en la sintaxis de los argumentos proporcionados por el usuario, asegurando que el programa reciba exactamente lo que necesita para funcionar correctamente.

## Ejemplo (no ejecutado automáticamente)
Script que calcula el área de un rectángulo recibiendo ancho y alto como argumentos opcionales con valores por defecto.

```python
import argparse
parser = argparse.ArgumentParser()
parser.add_argument('--ancho', type=float, default=5.0)
parser.add_argument('--alto', type=float, default=3.0)
args = parser.parse_args()
print(f'Area: {args.ancho * args.alto}')
```
