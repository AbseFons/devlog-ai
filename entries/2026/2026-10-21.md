## Objetivo
Introducir al estudiante en la concurrencia básica de Python utilizando el módulo threading para ejecutar tareas simultáneas, mejorando la eficiencia en operaciones de E/S.

## Explicación
En Python, el modelo GIL limita la ejecución paralela real en hilos CPU-bound. Sin embargo, para tareas de entrada/salida como leer archivos o consultar APIs, los hilos son ideales. Este ejemplo crea dos hilos que descargan datos de una API simulada. El hilo principal espera a que ambos terminen usando join(). Es fundamental manejar excepciones dentro de cada hilo y evitar bloqueos globales. La concurrencia permite aprovechar el tiempo de espera sin detener la aplicación, manteniendo la interfaz o procesos activos mientras se procesan respuestas externas.

## Ejemplo (no ejecutado automáticamente)
Dos hilos que simulan descargas de datos desde una API externa con tiempos de espera aleatorios.

```python
import threading
import time

def descargar_dato(id):
    print(f'Hilo {id} iniciando descarga...')
    time.sleep(2)
    print(f'Hilo {id} completado.')

hilo1 = threading.Thread(target=descargar_dato, args=(1,))
hilo2 = threading.Thread(target=descargar_dato, args=(2,))
hilo1.start()
hilo2.start()
```
