## Objetivo
Aprender a utilizar la sentencia 'with' en Python para automatizar el cierre de recursos como archivos, garantizando que se liberen correctamente incluso si ocurren errores durante la ejecución del bloque.

## Explicación
Los context managers permiten encapsular lógica de limpieza (como cerrar un archivo) dentro de una estructura 'try-finally'. Al usar 'with open(...) as f:', Python llama automáticamente al método '__enter__' para obtener el recurso y a '__exit__' para liberarlo. Esto previene fugas de recursos comunes en sistemas operativos. Es fundamental para operaciones de E/S, conexiones de base de datos o bloqueos de red. La sintaxis es legible y reduce código boilerplate innecesario.

## Ejemplo (no ejecutado automáticamente)
Script que lee un archivo de texto seguro y maneja errores de lectura sin dejar el archivo abierto.

```python
with open('datos.txt', 'r') as archivo:
    contenido = archivo.read()
    print(contenido)
```
