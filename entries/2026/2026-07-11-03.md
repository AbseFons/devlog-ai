## Objetivo
Aprender a convertir objetos Python complejos, como diccionarios y listas, en cadenas de texto válidas JSON utilizando la biblioteca estándar json. Esto permite almacenar datos estructurados o enviarlos por APIs web de manera eficiente y compatible con otros lenguajes.

## Explicación
La serialización transforma estructuras de datos nativas de Python en un formato universal legible por máquinas. Utilizamos el módulo 'json' para convertir diccionarios a cadenas JSON mediante la función 'dump'. Es crucial entender que las claves del diccionario deben ser cadenas de texto, ya que los números o booleanos no son válidos como identificadores en JSON estándar. Además, Python distingue entre tipos de datos: True/False se convierten en true/false y None en null. Para leer estos datos nuevamente, usamos 'load' o 'loads'. Este proceso es esencial para persistencia de datos local o comunicación remota.

## Ejemplo (no ejecutado automáticamente)
Conversión de un diccionario con claves mixtas a JSON válido

```python
import json

data = {'nombre': 'Ana', 'activo': True, 'edad': None}
json_str = json.dumps(data)
```
