## Objetivo
Aprender a diseñar y ejecutar una prueba de regresión automatizada que verifique que una nueva versión de una API no rompa funcionalidades existentes, asegurando la estabilidad del sistema tras cambios recientes.

## Explicación
Las pruebas de regresión son esenciales para confirmar que las nuevas modificaciones en el código no introducen errores en funciones previamente operativas. En este caso, simularemos un escenario donde se actualiza un endpoint de autenticación. El objetivo es ejecutar un script que llame a la API con credenciales válidas y datos estándar, verificando que la respuesta sea consistente con la versión anterior. Esto implica comparar el estado HTTP, los encabezados y el cuerpo de la respuesta JSON. Si alguna parte falla, la prueba debe reportar un error inmediato para alertar al equipo de desarrollo sobre una posible regresión crítica antes de que llegue a producción.

## Ejemplo (no ejecutado automáticamente)
Script en Python que utiliza la librería requests para llamar a un endpoint de autenticación y validar la respuesta JSON contra un conjunto de datos esperados, asegurando que el cambio no afectó la lógica de login.

```python
import requests
response = requests.post('https://api.ejemplo.com/login', json={'user': 'admin', 'pass': '123'})
assert response.status_code == 200 and response.json()['token'] is not None
```
