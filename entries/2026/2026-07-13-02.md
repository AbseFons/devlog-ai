## Objetivo
Introducir el concepto de programación dinámica resolviendo el problema de Fibonacci mediante memoización para evitar recálculos exponenciales y optimizar la complejidad temporal a lineal.

## Explicación
La programación dinámica es ideal cuando un problema se descompone en subproblemas superpuestos. En la serie de Fibonacci, calcular F(n) requiere F(n-1) y F(n-2). Sin memoria, esto genera una recursión ineficiente O(2^n). Al almacenar resultados intermedios en un array (memoización), cada valor se calcula solo una vez. Este enfoque transforma la complejidad a O(n). Es fundamental para algoritmos de optimización donde el orden de los subproblemas permite construir soluciones óptimas desde casos base simples hasta el problema general, evitando redundancias computacionales costosas en aplicaciones reales.

## Ejemplo (no ejecutado automáticamente)
Implementación recursiva con memoización para calcular el n-ésimo número de Fibonacci usando un array auxiliar que almacena resultados previos.

```javascript
function fibonacci(n, memo = {}) {
  if (memo[n]) return memo[n];
  if (n <= 1) return n;
  memo[n] = fibonacci(n - 1, memo) + fibonacci(n - 2, memo);
  return memo[n];
}
```
