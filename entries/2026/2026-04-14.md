## Objetivo
Aprender a utilizar la sentencia 'with' en Python para automatizar el cierre de recursos como archivos, garantizando que se liberen correctamente incluso si ocurren errores durante la ejecución del bloque.

## Explicación
En Python, los context managers permiten gestionar recursos efímeros. La sentencia 'with' invoca automáticamente el método '__enter__' al entrar y '__exit__' al salir, asegurando la limpieza. Para archivos, esto evita que se queden abiertos accidentalmente. El código debe usar 'open()' dentro de 'with', especificando el modo de lectura o escritura. Este patrón es esencial para evitar fugas de recursos y bloqueos en sistemas operativos.

## Ejemplo (no ejecutado automáticamente)
Lectura segura de un archivo de texto que se cierra automáticamente al finalizar la operación, incluso ante excepciones.

```python
with open('datos.txt', 'r') as f:
    contenido = f.read()
```
