## Objetivo
Aprender a usar decoradores para añadir funcionalidad transversal como logging o timing sin modificar el código original de las funciones, promoviendo una arquitectura más limpia y mantenible.

## Explicación
Los decoradores son funciones especiales que toman otra función como argumento y devuelven una nueva. Esto permite inyectar comportamiento adicional, como validar entradas o medir tiempos de ejecución, manteniendo la lógica principal pura. En Python, se definen con @decorador justo encima de la definición de la función. Este patrón es esencial para crear librerías robustas donde las reglas de negocio o de seguridad se aplican uniformemente sin repetir código en cada método.

## Ejemplo (no ejecutado automáticamente)
Un decorador simple que imprime el nombre de la función antes y después de su ejecución.

```python
def mi_decorador(func):
    def envoltura(*args, **kwargs):
        print(f'Ejecutando {func.__name__}')
        resultado = func(*args, **kwargs)
        print('Función terminada')
        return resultado
    return envoltura

@mi_decorador
def saludar(nombre):
    return f'Hola, {nombre}'
```
