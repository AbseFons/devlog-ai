## Objetivo
Analizar la complejidad espacial y temporal del algoritmo de ordenamiento por mezcla, enfocándose en la estrategia de división y conquista para reducir la profundidad del árbol recursivo.

## Explicación
El ordenamiento por mezcla divide el conjunto original en mitades hasta alcanzar subarrays de tamaño uno. La clave reside en la función de mezcla que fusiona dos sublistas ordenadas en una sola lista ordenada. Este proceso requiere memoria auxiliar proporcional al tamaño del array, resultando en una complejidad espacial de O(n). A diferencia de otros algoritmos in situ, esta estrategia garantiza un tiempo de ejecución estable de O(n log n) incluso en casos peores, evitando la degradación a O(n^2). La recursión se detiene cuando el subarray tiene cero o un elemento. La fusión utiliza dos punteros que avanzan secuencialmente copiando los elementos más pequeños hacia el array temporal antes de copiarlo de vuelta al original.

## Ejemplo (no ejecutado automáticamente)
Implementación iterativa del Merge Sort en Python para ordenar una lista de enteros sin recursividad profunda.

```python
def merge_sort(arr):
    n = len(arr)
    if n <= 1:
        return arr
    mid = n // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
```
