## Objetivo
Aprender a utilizar sets para conjuntos únicos y diccionarios para mapear claves a valores, optimizando búsquedas y almacenamiento de datos estructurados.

## Explicación
En Python, los sets son colecciones no ordenadas de elementos únicos, ideales para operaciones matemáticas como uniones o intersecciones. Los diccionarios, por otro lado, almacenan pares clave-valor, permitiendo acceso rápido O(1) mediante claves. Ambos tipos de datos aprovechan tablas hash internamente. Un caso práctico común es validar la unicidad de usuarios en un registro con sets y almacenar sus perfiles en diccionarios. Es crucial recordar que las claves de los diccionarios deben ser inmutables, mientras que los elementos de un set sí pueden ser mutables si son inmutables ellos mismos.

## Ejemplo (no ejecutado automáticamente)
Creacion de un set con valores duplicados y un diccionario de perfiles de usuario.

```python
usuarios = {'Ana', 'Luis', 'Ana'}
perfiles = {'Ana': 25, 'Luis': 30}
```
