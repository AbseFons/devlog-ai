## Objetivo
Aprender a transformar listas complejas en estructuras de datos más limpias utilizando diccionarios dentro de las comprensiones, optimizando el manejo de metadatos asociados a cada elemento.

## Explicación
En esta lección exploramos cómo simplificar la creación de listas de objetos. En lugar de construir manualmente cada diccionario con bucles anidados o múltiples asignaciones, utilizamos una comprensión de lista que itera sobre un índice y extrae directamente los valores necesarios del array original. Este enfoque reduce drásticamente el código y minimiza errores de tipeo. Es ideal para normalizar datos crudos donde cada posición representa un registro con propiedades específicas como nombre, edad o rol. La sintaxis permite incluir lógica condicional dentro de la expresión, filtrando o modificando dinámicamente los campos antes de insertarlos en la nueva estructura.

## Ejemplo (no ejecutado automáticamente)
Convierte una lista de tuplas (id, nombre) en una lista de diccionarios con campos 'usuario' y 'activo'.

```python
registros = [(1, 'Ana'), (2, 'Luis')]
lista_usuarios = [{'usuario': {"nombre": n, "activo": True}, "id": i} for i, (_, n) in enumerate(registros)]
```
