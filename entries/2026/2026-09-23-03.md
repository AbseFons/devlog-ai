## Objetivo
Aprender a identificar y gestionar vulnerabilidades de seguridad en las dependencias de un proyecto Node.js utilizando la herramienta nativa de auditoría para mitigar riesgos antes de la producción.

## Explicación
Las dependencias de terceros son una fuente común de vulnerabilidades conocidas como CVE. En este caso, utilizaremos el comando 'npm audit' integrado en el gestor de paquetes npm. Este comando escanea el archivo package-lock.json y detecta si alguna dependencia directa o transitiva tiene un reporte de seguridad publicado. Si encuentra problemas, genera un informe detallado con la versión vulnerable y la recomendada. Es crucial ejecutar esto regularmente en CI/CD. El proceso no modifica automáticamente el código, sino que proporciona la información necesaria para actualizar las versiones en package.json o aplicar parches específicos, asegurando que la aplicación cumpla con los estándares de seguridad actuales sin introducir errores de funcionalidad.

## Ejemplo (no ejecutado automáticamente)
Ejecución del comando de auditoría para listar vulnerabilidades detectadas en un proyecto Node.js estándar.

```bash
npm audit
npm audit fix --dry-run
```

## Ejercicio
Ejecuta 'npm audit' en tu repositorio local. Si aparecen advertencias, documenta el CVE más crítico y la versión de parche sugerida.

## Criterios de revisión
El comando debe ejecutarse sin errores de sintaxis. El reporte debe mostrar al menos una vulnerabilidad si existen dependencias obsoletas o indicar 'no found vulnerabilities' en un proyecto limpio.
