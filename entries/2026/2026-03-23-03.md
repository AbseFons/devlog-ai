## Objetivo
Aprender a configurar un registro de eventos en Python que genere salidas en formato JSON, facilitando el análisis automatizado y la integración con sistemas de monitoreo modernos sin necesidad de parsers complejos.

## Explicación
El logging tradicional imprime texto plano difícil de procesar. Para solucionar esto, utilizaremos la librería estándar 'logging' junto con un formateador personalizado que serializa cada registro como un objeto JSON. Esto permite capturar campos clave como 'nivel', 'mensaje', 'funcion' y 'linea'. Al configurar el handler para escribir en consola o archivo con este formato, obtenemos una trazabilidad clara. Este enfoque es esencial para pipelines de datos donde las herramientas downstream esperan entradas estructuradas.

## Ejemplo (no ejecutado automáticamente)
Configuración de un logger que emite mensajes en formato JSON puro al stdout, mostrando nivel, mensaje y metadatos del stack.

```python
import logging
import json

def json_formatter(record):
    return json.dumps({
        'nivel': record.levelname,
        'mensaje': record.getMessage(),
        'funcion': record.funcName,
        'linea': record.lineno
    })

logger = logging.getLogger('mi_app')
logger.setLevel(logging.INFO)
handler = logging.StreamHandler()
formatter = logging.Formatter(json_formatter)
handler.setFormatter(formatter)
logger.addHandler(handler)

logger.info('Inicio de proceso exitoso')
```
