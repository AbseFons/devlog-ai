## Objetivo
Aprender a localizar elementos HTML específicos en el documento utilizando selectores CSS modernos y alterar sus propiedades de estilo o contenido directamente desde JavaScript.

## Explicación
La manipulación del DOM comienza con la selección precisa. El método querySelector acepta cualquier selector CSS válido, permitiendo encontrar el primer elemento que coincida. Por ejemplo, podemos buscar un div con una clase específica o un enlace dentro de una sección. Una vez seleccionado, el objeto retornado permite acceder a sus propiedades como texto o estilos. Para modificarlo, asignamos nuevos valores a atributos como innerText para cambiar el contenido visible o style.backgroundColor para alterar el color. Esta técnica es fundamental para crear interfaces dinámicas donde la estructura HTML se mantiene estática pero su apariencia y comportamiento cambian en respuesta a acciones del usuario o lógica de aplicación.

## Ejemplo (no ejecutado automáticamente)
Selecciona un párrafo con clase 'destacado' y cambia su color de fondo a amarillo suave.

```javascript
const parrafo = document.querySelector('.destacado');
if (parrafo) {
  parrafo.style.backgroundColor = '#fff9c4';
}
```

## Criterios de revisión
El código debe usar addEventListener para la interacción. La selección de los encabezados debe ser robusta usando querySelectorAll. No se deben generar errores si no existen elementos seleccionables.
