## Objetivo
Aprender a auditar el árbol de dependencias de un proyecto para identificar vulnerabilidades conocidas (CVE) antes de la compilación o despliegue, asegurando que las librerías de terceros no introduzcan riesgos críticos en la aplicación final.

## Explicación
Las dependencias externas son una fuente común de vulnerabilidades. Un CVE es un identificador único para una falla de seguridad pública. No basta con actualizar el paquete principal; hay que revisar todo el árbol de dependencias transitivas. Herramientas como npm audit, pip-audit o OWASP Dependency-Check escanean automáticamente las versiones instaladas contra bases de datos de vulnerabilidades. Si se detecta un CVE crítico, la estrategia es: 1) Buscar una versión parcheada del paquete vulnerable. 2) Actualizar el archivo de bloqueo (package-lock.json o requirements.txt). 3) Si no existe parche inmediato, aplicar mitigaciones temporales como reglas de firewall o sandboxing para limitar el impacto hasta que se resuelva la vulnerabilidad.

## Ejemplo (no ejecutado automáticamente)
Ejemplo de script en Python usando pip-audit para escanear un entorno virtual y listar las dependencias con CVEs conocidos, mostrando el ID del paquete, la versión vulnerable y la recomendación.

```python
import subprocess
import sys

def auditar_dependencias():
    try:
        # Ejecuta pip-audit para escanear el entorno actual
        resultado = subprocess.run([sys.executable, '-m', 'pip', 'audit'], capture_output=True, text=True)
        if resultado.returncode == 0:
            print("No se encontraron vulnerabilidades conocidas (CVE) en las dependencias instaladas.")
        else:
            print("Vulnerabilidades detectadas:\n" + resultado.stdout)
    except Exception as e:
        print(f"Error al ejecutar el escaneo: {e}")

if __name__ == "__main__":
    auditar_dependencias()
```
