## Explicación
El ordenamiento por mezcla es un algoritmo clásico que utiliza la estrategia divide y vencerás. Divide recursivamente la lista en mitades hasta alcanzar subconjuntos de tamaño uno, luego combina estas partes ordenadas mediante una función de fusión. Este enfoque garantiza un rendimiento consistente O(n log n) incluso en el peor caso, lo que lo hace ideal para grandes volúmenes de datos. A diferencia de algoritmos como QuickSort, no depende de la elección del pivote, evitando degradaciones a O(n^2). Su implementación requiere manejo cuidadoso de índices y casos base recursivos.

## Ejemplo (no ejecutado automáticamente)
```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

# Caso de uso: Ordenar registros de ventas por monto
ventas = [450, 230, 890, 120, 670]
ordenadas = merge_sort(ventas)
print(ordenadas)  # Salida: [120, 230, 450, 670, 890]
```
