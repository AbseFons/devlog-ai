## Objetivo
Aprender a construir consultas recursivas usando CTEs para navegar estructuras jerárquicas como árboles organizacionales o directorios de archivos, permitiendo obtener rutas completas desde la raíz.

## Explicación
Las Common Table Expressions (CTEs) permiten definir subconsultas temporales que simplifican la lógica compleja. En este caso, utilizaremos una CTE recursiva para recorrer una tabla de empleados con columnas 'id' y 'manager_id'. La consulta comienza con un miembro ancla que selecciona al empleado sin jefe (la raíz). Luego, el miembro recursivo une los datos actuales con los siguientes niveles, añadiendo la ruta acumulada en cada iteración. Esto evita subconsultas anidadas profundas y mejora la legibilidad del código SQL.

## Ejemplo (no ejecutado automáticamente)
Consulta recursiva que devuelve la jerarquía completa de un árbol organizacional con el camino desde el CEO hasta cada empleado.

```sql
WITH RECURSIVE Organigramas AS (
  SELECT id, nombre, manager_id, '/' || CAST(id AS VARCHAR) AS ruta
  FROM empleados
  WHERE manager_id IS NULL
  UNION ALL
  SELECT e.id, e.nombre, e.manager_id, o.ruta || '/' || CAST(e.id AS VARCHAR)
  FROM empleados e
  JOIN Organigramas o ON e.manager_id = o.id
)
```

## Ejercicio
Crea una tabla 'categorias' con columnas id y padre_id. Inserta datos anidados (padre null para la raíz). Escribe un CTE recursivo que liste todas las categorías con su ruta completa desde la categoría principal.

## Criterios de revisión
La consulta debe usar WITH RECURSIVE correctamente, tener un miembro ancla y uno recursivo, y evitar bucles infinitos mediante condiciones de terminación implícitas en el JOIN.
