## Objetivo
Introducir al ingeniero en el concepto de pruebas basadas en propiedades, donde se verifica que un sistema mantenga ciertas invariantes lógicas bajo cualquier entrada, sin especificar casos de prueba exhaustivos.

## Explicación
Las pruebas basadas en propiedades (Property-Based Testing) difieren de las pruebas tradicionales porque no definen estados específicos, sino reglas generales que el software debe cumplir siempre. En lugar de decir 'la suma de dos números positivos debe ser positiva', establecemos la propiedad: 'para cualquier par de enteros a y b, si ambos son mayores que cero, su resultado también lo será'. Herramientas como Hypothesis o QuickCheck generan automáticamente datos aleatorios para intentar romper estas reglas. Si encuentran un caso que viola la propiedad, fallan la prueba. Este enfoque es poderoso porque cubre escenarios inesperados que un ingeniero humano podría pasar por alto al diseñar casos manuales.

## Ejemplo (no ejecutado automáticamente)
Script en Python que define una propiedad para verificar que la suma de dos números positivos siempre resulte en un número positivo, utilizando el generador Hypothesis.

```python
from hypothesis import given, strategies as st

def test_suma_positiva(a, b):
    assert (a > 0 and b > 0) implies (a + b > 0)

given(st.integers(min_value=1), st.integers(min_value=1))
@given()
def prueba_propiedad(x, y):
    assert x + y > 0
```
