## Objetivo
Aprender a implementar el patrón adaptador para integrar servicios externos con interfaces internas distintas, asegurando la compatibilidad sin modificar el código del proveedor.

## Explicación
El patrón adaptador permite que dos interfaces incompatibles trabajen juntas. En este caso, construiremos un adaptador en TypeScript que traduce las respuestas de una API REST antigua (que devuelve objetos con camelCase y fechas como cadenas) al formato interno actualizado (snake_case y objetos Date). Esto protege la lógica de negocio del cambio en el proveedor externo. El adaptador encapsula la lógica de transformación, manteniendo la simplicidad para los consumidores internos que solo necesitan llamar a una interfaz estándar.

## Ejemplo (no ejecutado automáticamente)
Un adaptador que transforma datos de una API legacy (camelCase) al formato interno (snake_case) y parsea fechas de string a objetos Date.

```typescript
const adapter = {
  transform: (data) => ({
    id: data.id,
    created_at: new Date(data.created_at)
  })
};
```

## Ejercicio
Crea un adaptador para una API de clima que devuelve temperaturas en Fahrenheit y la ciudad como 'city_name'. Tu adaptador debe devolver grados Celsius (fórmula: (F-32)*5/9) y el nombre de la ciudad en minúsculas.

## Criterios de revisión
El código debe incluir la lógica de conversión de temperatura, la transformación del nombre de la ciudad y una prueba simple que muestre los resultados transformados.
