## Objetivo
Comprender la lógica recursiva del algoritmo Merge Sort, su estrategia de dividir y conquistar para ordenar listas dividiéndolas en mitades hasta llegar a elementos individuales y fusionándolas de forma ordenada.

## Explicación
El ordenamiento por mezcla es un algoritmo eficiente que utiliza la técnica de dividir y conquistar. Primero, divide recursivamente la lista original en dos mitades iguales hasta obtener sublistas de un solo elemento, las cuales se consideran automáticamente ordenadas. Luego, el proceso de fusión combina estas sublistas pares, comparando sus elementos iniciales para construir una nueva secuencia ordenada. Este método garantiza un tiempo de ejecución constante O(n log n) en todos los casos, independientemente del orden inicial de los datos. Es ideal para grandes volúmenes de información donde la estabilidad del orden relativo es crucial.

## Ejemplo (no ejecutado automáticamente)
Implementación recursiva que divide una lista de números enteros y fusiona las mitades ordenadas devolviendo el resultado final.

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
def merge(left, right):
    result = []
    while left and right:
        if left[0] <= right[0]:
            result.append(left.pop(0))
        else:
            result.append(right.pop(0))
    result.extend(left + right)
    return result
```
