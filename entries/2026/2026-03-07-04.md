## Objetivo
Comprender la función de las claves foráneas para mantener la integridad referencial entre tablas, evitando huérfanos no deseados en bases de datos relacionales.

## Explicación
Una clave foránea establece un vínculo lógico entre dos tablas, asegurando que los valores en una columna de referencia existan realmente en la tabla padre. Esto previene inconsistencias de datos. Al definir esta relación con restricciones como ON DELETE CASCADE o SET NULL, controlamos el comportamiento ante borrados. Es fundamental para modelar esquemas robustos donde las dependencias entre entidades deben reflejar fielmente la realidad del negocio, garantizando que cada registro hijo tenga un padre válido siempre.

## Ejemplo (no ejecutado automáticamente)
Creación de una tabla 'pedidos' con una clave foránea vinculada a 'clientes', configurando que al borrar un cliente, sus pedidos se eliminen automáticamente.

```sql
CREATE TABLE clientes (
  id_cliente INT PRIMARY KEY,
  nombre VARCHAR(100)
);

CREATE TABLE pedidos (
  id_pedido INT PRIMARY KEY,
  id_cliente INT,
  FOREIGN KEY (id_cliente) REFERENCES clientes(id_cliente)
    ON DELETE CASCADE
);
```
