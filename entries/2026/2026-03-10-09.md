## Objetivo
Aprender a usar la clase Path de Python para construir, manipular y normalizar rutas de archivos de manera portable entre sistemas operativos sin depender de cadenas de texto complejas.

## Explicación
La librería estándar pathlib ofrece una interfaz orientada a objetos para trabajar con rutas. En lugar de concatenar strings con barras diagonales o invertidas, creamos objetos Path que se adaptan automáticamente al sistema operativo. Esto evita errores comunes como el uso incorrecto de separadores. Podemos unir directorios y nombres de archivos usando la operación /, normalizar rutas duplicadas con resolve() y verificar existencia con exists(). Este enfoque hace que el código sea más legible y mantenible en proyectos multiplataforma.

## Ejemplo (no ejecutado automáticamente)
Crear un objeto Path para acceder al directorio actual y listar sus archivos sin importar el sistema operativo.

```python
from pathlib import Path
base = Path('.')
archivos = list(base.iterdir())
```
