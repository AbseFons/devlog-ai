## Objetivo
Aprender a prevenir que las excepciones detengan la ejecución del programa mediante bloques try-catch, permitiendo manejar fallos gracefully y registrar detalles para depuración futura sin interrumpir al usuario.

## Explicación
En JavaScript, los errores no manejados pueden colapsar una aplicación. El patrón try-catch permite ejecutar código potencialmente fallido dentro de un bloque 'try'. Si ocurre una excepción, el control se transfiere al bloque 'catch', donde podemos inspeccionar la propiedad 'message' del objeto error para obtener información útil. Es crucial no solo capturar el error, sino registrarlo o mostrar un mensaje amigable, manteniendo la funcionalidad de la app intacta. Este enfoque es esencial en APIs asíncronas y operaciones de E/S.

## Ejemplo (no ejecutado automáticamente)
Intento de división por cero dentro de un bloque try que captura el error y muestra un mensaje alternativo al usuario sin detener la ejecución del script.

```javascript
try {
  const resultado = 10 / 0;
} catch (error) {
  console.log('Error detectado:', error.message);
}
```

## Ejercicio
Crea una función que acepte dos números y devuelva su cociente. Usa un bloque try-catch para manejar la división por cero y lanza un mensaje de alerta al usuario en lugar de dejar que la página se vuelva blanca.

## Criterios de revisión
El código debe incluir un bloque try con la operación aritmética, un catch que capture el objeto error y una instrucción que muestre un mensaje de error legible. No debe haber errores de sintaxis fuera de los bloques.
