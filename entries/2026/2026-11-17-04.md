## Objetivo
Aprender a encapsular código propenso a fallos dentro de bloques try-catch para evitar que las excepciones detengan la ejecución del programa, asegurando una experiencia de usuario robusta.

## Explicación
En JavaScript moderno, el manejo de errores es crucial para la estabilidad de las aplicaciones. Utilizamos la estructura try-catch para atrapar excepciones síncronas. Sin embargo, cuando trabajamos con operaciones asíncronas como fetch o Promesas, los errores no se lanzan directamente; deben capturarse usando .catch() o un bloque finally dentro del método then(). Es vital distinguir entre errores de sintaxis (que detienen el script) y errores lógicos (como respuestas HTTP 404). Un patrón común es envolver la lógica asíncrona en una función asíncrona que retorne una Promesa, permitiendo un manejo centralizado del error. Esto evita que la aplicación se congele ante fallos de red o datos inválidos, permitiendo mostrar mensajes amigables al usuario.

## Ejemplo (no ejecutado automáticamente)
Ejemplo de llamada a una API simulada que lanza un error y lo captura correctamente usando async/await y un bloque try-catch.

```javascript
async function obtenerDatos() {
  try {
    const respuesta = await fetch('https://api.ejemplo.com/datos');
    if (!respuesta.ok) throw new Error('Error de red');
    return await respuesta.json();
  } catch (error) {
    console.error('Capturado:', error.message);
  }
}
```
