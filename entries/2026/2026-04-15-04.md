## Objetivo
Comprender las diferencias fundamentales entre el framework estándar unittest y pytest, destacando la sintaxis más concisa de pytest para escribir pruebas mantenibles y legibles rápidamente.

## Explicación
Python incluye unittest como módulo nativo, pero pytest es un framework externo que ofrece una experiencia superior. Con unittest, debes heredar de TestCase y usar métodos como test_method(), lo cual añade verbosidad innecesaria. Por el contrario, pytest permite escribir pruebas como funciones simples decoradas con @pytest.mark.parametrize o simplemente llamadas a assert. Esto reduce la carga cognitiva y mejora la legibilidad. Además, pytest descubre automáticamente las pruebas sin necesidad de definir una clase base específica, facilitando la integración en proyectos modernos.

## Ejemplo (no ejecutado automáticamente)
Comparación directa mostrando cómo una misma lógica de prueba se escribe con menos código usando pytest en lugar de unittest.

```python
def test_suma():
    assert suma(2, 3) == 5

class TestSuma(unittest.TestCase):
    def test_suma(self):
        self.assertEqual(suma(2, 3), 5)
```
