## Objetivo
Comprender la diferencia entre cobertura de código y límites funcionales en pruebas de software, aprendiendo a diseñar casos que validen no solo el flujo normal sino también los bordes críticos del sistema.

## Explicación
La cobertura de código mide qué porcentaje del código fuente se ejecuta durante las pruebas, pero esto no garantiza la calidad. Un sistema puede tener 100% de cobertura y aún fallar en límites específicos. Los límites funcionales son valores donde el comportamiento cambia, como máximos, mínimos o transiciones entre estados. Es vital probar estos bordes porque los errores suelen ocurrir allí. Por ejemplo, si un campo acepta números del 1 al 100, las pruebas deben incluir 0, 1, 50, 99 y 101. Ignorar estos casos deja vulnerabilidades ocultas que solo se manifiestan bajo condiciones extremas.

## Ejemplo (no ejecutado automáticamente)
Script de Python que valida los límites de un campo numérico entre 1 y 100, incluyendo valores fuera de rango para verificar manejo de errores.

```python
def validar_rango(valor):
    if valor < 1 or valor > 100:
        return False
    return True

print(validar_rango(50))
print(validar_rango(0))
print(validar_rango(101))
```
