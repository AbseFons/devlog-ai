## Objetivo
Comprender la diferencia entre ejecución secuencial y concurrente mediante hilos en Python, identificando cuándo es útil usar threading para tareas de I/O sin bloquear el programa principal.

## Explicación
En Python, debido al GIL (Global Interpreter Lock), los hilos no permiten paralelismo real en CPU para código intensivo, pero son ideales para operaciones de E/S. Esta lección introduce la creación de hilos básicos usando la librería stdlib threading. Aprenderás a definir funciones ejecutables y lanzarlas como tareas concurrentes. El enfoque es entender cómo mantener la interfaz de usuario o el servidor respondiendo mientras se esperan respuestas de red o archivos, evitando que el script se congele durante procesos lentos de entrada/salida.

## Ejemplo (no ejecutado automáticamente)
Un script que descarga dos URLs simultáneamente usando hilos para reducir el tiempo total de ejecución comparado con hacerlo secuencialmente.

```python
import threading
import requests

def descargar(url):
    print(f"Descargando {url}")
    response = requests.get(url)
    print(f"Completado: {url}")

urls = ['https://example.com', 'https://python.org']
hilos = []
for url in urls:
    t = threading.Thread(target=descargar, args=(url,))
    hilos.append(t)
    t.start()
for t in hilos:
    t.join()
```
