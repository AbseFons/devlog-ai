## Objetivo
Introducir al estudiante en las diferencias fundamentales entre pilas (LIFO) y colas (FIFO), explicando sus aplicaciones prácticas en gestión de memoria, llamadas recursivas y procesamiento de tareas asíncronas dentro de sistemas operativos modernos.

## Explicación
Las estructuras de datos lineales son esenciales para la eficiencia algorítmica. Una pila opera bajo el principio 'último en entrar, primero en salir', ideal para deshacer acciones o llamadas recursivas. Por el contrario, una cola sigue 'primero en entrar, primero en salir', siendo crucial para colas de impresión o gestión de procesos. Comprender estas diferencias permite elegir la herramienta adecuada para resolver problemas de sincronización y ordenamiento de tareas sin bloquear recursos del sistema.

## Ejemplo (no ejecutado automáticamente)
Implementación básica de una cola usando un array en JavaScript para simular una fila de clientes esperando servicio.

```javascript
const cola = [];
function agregar(cliente) { cola.push(cliente); }
function atender() { return cola.shift(); }
```
