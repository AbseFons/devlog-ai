## Objetivo
Aprender a utilizar bloques try-except para prevenir la terminación abrupta del programa ante errores comunes como división por cero o archivos inexistentes, permitiendo una ejecución más robusta y controlada.

## Explicación
En Python, las excepciones interrumpen el flujo normal cuando ocurren errores. El bloque try ejecuta código potencialmente arriesgado, mientras que except captura el error específico. Si no se maneja, el programa se detiene con un traceback. Al usar try-except, podemos mostrar mensajes amigables o ejecutar lógica de recuperación. Esto es vital en aplicaciones productivas donde la estabilidad es clave. Python permite capturar excepciones genéricas o específicas, facilitando diagnósticos precisos sin necesidad de reescribir todo el código base.

## Ejemplo (no ejecutado automáticamente)
Intenta dividir dos números; si hay error por división por cero, muestra un mensaje seguro en lugar de colapsar.

```python
try:
    resultado = 10 / 0
except ZeroDivisionError:
    print('No se puede dividir por cero')
```
