## Objetivo
Comprender cómo la selectividad de las columnas indexadas afecta el rendimiento de las consultas, evitando el uso ineficiente de índices en columnas con baja cardinalidad como género o estado.

## Explicación
En esta lección exploramos la importancia de la selectividad al elegir columnas para crear índices. Un índice es útil cuando filtra una porción pequeña de los datos; sin embargo, si indexamos una columna con pocos valores distintos (baja selectividad), el motor de base de datos puede decidir ignorar el índice y escanear toda la tabla en su lugar. Esto ocurre porque el costo de acceder a las páginas del índice supera al de un escaneo secuencial simple. Para consultas eficientes, prioriza columnas como fechas, identificadores únicos o valores numéricos con alta variabilidad. Evita indexar columnas de texto cortos o categorías fijas. Analizar el plan de ejecución ayuda a confirmar si el optimizador está utilizando correctamente la estructura de índices disponible.

## Ejemplo (no ejecutado automáticamente)
Creación de un índice en una columna de alta selectividad (fecha) y comparación con una de baja selectividad (estado).

```sql
CREATE INDEX idx_ventas_fecha ON ventas(fecha_venta);
CREATE INDEX idx_ventas_estado ON ventas(estado_cliente);
```
