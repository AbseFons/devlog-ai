## Objetivo
Aprender a inicializar una base de datos local, establecer una conexión segura con el módulo sqlite3 y definir la estructura básica para almacenar registros de usuarios.

## Explicación
En esta microlección exploraremos los fundamentos de SQLite3 en Python. Comenzaremos importando el módulo nativo y creando un archivo de base de datos persistente. Utilizaremos el método execute() para definir una tabla llamada 'usuarios' con columnas tipo texto e entero. Es crucial recordar cerrar la conexión al finalizar, aunque Python lo hace automáticamente al salir del script. Este enfoque permite gestionar datos locales sin necesidad de servidores externos.

## Ejemplo (no ejecutado automáticamente)
Script que crea un archivo de base de datos y define una tabla de usuarios con dos columnas.

```python
import sqlite3
conn = sqlite3.connect('mi_base.db')
conn.execute('CREATE TABLE usuarios (id INTEGER, nombre TEXT)')
```
