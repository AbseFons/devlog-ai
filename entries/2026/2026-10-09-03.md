## Objetivo
Comprender qué es un decorador, cómo se define con la sintaxis @ y su utilidad para añadir funcionalidad transversal como logging o validación sin modificar el código original de las funciones.

## Explicación
Los decoradores en Python son funciones especiales que toman otra función como argumento y devuelven una nueva función con comportamientos adicionales. Se aplican mediante la sintaxis @decorador encima de la definición de la función. Internamente, el decorador recibe la función original, crea un wrapper que envuelve su lógica y retorna este nuevo objeto. Esto permite inyectar comportamientos como medir tiempos de ejecución, manejar errores o registrar llamadas automáticamente. Es una herramienta poderosa para mantener el código limpio y modular, separando la lógica del negocio de las preocupaciones transversales.

## Ejemplo (no ejecutado automáticamente)
Un decorador simple que imprime un mensaje antes y después de ejecutar una función objetivo.

```python
def mi_decorador(func):
    def wrapper():
        print('Antes de la ejecución')
        func()
        print('Después de la ejecución')
    return wrapper

@mi_decorador
def saludar():
    print('Hola, mundo!')
```
