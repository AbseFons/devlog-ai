## Objetivo
Comprender cómo una función puede llamarse a sí misma para resolver problemas dividiéndolos en casos base y pasos recursivos, aplicando este concepto al cálculo del factorial de un número entero positivo mediante código limpio y seguro.

## Explicación
La recursión permite definir funciones que se resuelven a sí mismas. Para calcular el factorial (n!), la función debe retornar 1 si n es 0 o 1 (caso base). Si n es mayor, retorna n multiplicado por el factorial de n-1. Este enfoque divide el problema complejo en subproblemas más pequeños hasta alcanzar la condición de parada, evitando bucles infinitos y garantizando la terminación correcta del algoritmo.

## Ejemplo (no ejecutado automáticamente)
Función que calcula el factorial de un número entero positivo utilizando recursión simple.

```python
def factorial(n):
    if n <= 1:
        return 1
    else:
        return n * factorial(n - 1)
```
