## Objetivo
Introducir al estudiante en la concurrencia básica de Python utilizando el módulo threading para ejecutar tareas simultáneas, mejorando la eficiencia en procesos I/O.

## Explicación
En Python, la concurrencia permite ejecutar múltiples tareas que parecen ocurrir al mismo tiempo. El módulo threading facilita esto creando hilos ligeros. Ideal para operaciones de entrada/salida como lectura de archivos o llamadas a APIs, evita bloquear el programa mientras espera respuestas externas. A diferencia del multiprocessing, los hilos comparten memoria, lo que simplifica la comunicación entre tareas. Sin embargo, Python tiene Global Interpreter Lock (GIL), limitando la concurrencia real en CPU intensiva. Para ese caso, se recomienda multiprocessing. Aquí aprenderás a definir funciones ejecutables y lanzar hilos con Thread(target=funcion).

## Ejemplo (no ejecutado automáticamente)
Ejemplo de dos hilos que imprimen mensajes con un pequeño retraso simulando trabajo en segundo plano.

```python
import threading

def tarea(nombre):
    for i in range(3):
        print(f'{nombre}: Iteración {i}')
        threading.current_thread().sleep(1)

t1 = threading.Thread(target=tarea, args=('Hilo 1',))
t2 = threading.Thread(target=tarea, args=('Hilo 2',))
t1.start()
t2.start()
```
