## Objetivo
Comparar sintaxis y funcionalidades básicas entre las dos librerías de pruebas más comunes en Python, destacando la concisión de pytest para escribir tests más legibles y mantenibles desde el inicio.

## Explicación
En Python, unittest es parte del estándar pero su estructura basada en clases puede resultar verbosa. pytest, por otro lado, utiliza un enfoque funcional donde las funciones son los propios tests. Esto permite declarar dependencias con decoradores como @pytest.fixture para compartir datos entre pruebas sin repetir código. Además, pytest ofrece reportes de colores automáticos y detección de errores más intuitiva. Para migrar o elegir una herramienta, considera que pytest reduce la boilerplate necesaria, facilitando la adopción en proyectos modernos donde la claridad del código es prioritaria sobre la estricta jerarquía de clases.

## Ejemplo (no ejecutado automáticamente)
Ejemplo comparativo mostrando cómo definir un fixture compartido y ejecutar una prueba simple usando pytest versus unittest.

```python
import pytest

@pytest.fixture
def calculadora():
    return lambda x, y: x + y

def test_suma(calculadora):
    assert calculadora(2, 3) == 5
```
