## Objetivo
Aprender a capturar y gestionar excepciones asíncronas utilizando bloques try/catch para evitar que fallos en operaciones de red o E/S detengan la ejecución del programa, asegurando una experiencia de usuario estable.

## Explicación
En JavaScript moderno, las promesas permiten realizar operaciones asíncronas. Sin embargo, si una función asíncrona falla, la promesa se rechaza y puede propagar el error. El patrón try/catch es esencial para interceptar estos fallos antes de que se vuelvan críticos. Dentro del bloque try, colocamos el código asíncrono; si ocurre un error, este se captura en el bloque catch, donde podemos mostrar mensajes amigables o reintentar la lógica. Esto transforma errores silenciosos en manejos explícitos, mejorando la resiliencia de la aplicación y permitiendo acciones correctivas inmediatas sin colapsar toda la interfaz.

## Ejemplo (no ejecutado automáticamente)
Función asíncrona que simula una llamada a API fallida y captura el error para mostrar un mensaje al usuario.

```javascript
async function obtenerDatos() {
  try {
    const respuesta = await fetch('https://api.ejemplo.com/datos');
    if (!respuesta.ok) throw new Error('Servidor no responde');
    return await respuesta.json();
  } catch (error) {
    console.error('Error de red:', error.message);
  }
}
```

## Ejercicio
Crea una función asíncrona que llame a un endpoint ficticio. Si la respuesta tiene un estado HTTP mayor a 400, lanza un Error personalizado con el mensaje 'Fallo en la solicitud'. Captura este error y registra el código de estado en una variable.

## Criterios de revisión
El código debe usar await dentro de try, lanzar un Error explícito al detectar códigos HTTP > 400, y capturar la excepción en catch para extraer y mostrar el mensaje del error sin detener la ejecución.
