## Objetivo
Aprender a importar módulos ES solo cuando se necesitan recursos pesados, optimizando el rendimiento inicial de la aplicación mediante carga diferida.

## Explicación
En esta lección exploramos cómo utilizar dinamicamente la sintaxis import() para cargar módulos en tiempo de ejecución. A diferencia del import estático que bloquea la evaluación hasta que se resuelve todo el grafo de dependencias, la importación dinámica permite evaluar condiciones antes de traer código al heap. Esto es vital para aplicaciones web donde scripts como gráficos o editores de texto deben cargarse solo si el usuario interactúa con ciertas secciones. Al evitar cargar librerías masivas en el inicio, reducimos el tiempo de respuesta del navegador y mejoramos la experiencia del usuario final.

## Ejemplo (no ejecutado automáticamente)
Se define una función que importa un módulo pesado solo si el usuario hace clic en un botón específico.

```javascript
const heavyModule = () => import('./HeavyComponent.js');
const button = document.getElementById('loadBtn');
button.addEventListener('click', async () => {
  const { render } = await heavyModule();
  render();
});
```

## Ejercicio

## Criterios de revisión
El código debe usar await con import(), manejar errores básicos con try/catch y no tener dependencias circulares.
