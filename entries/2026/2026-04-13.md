## Objetivo
Comprender qué son los hooks en Git y cómo configurar un script pre-commit básico para validar el formato del código antes de cada commit.

## Explicación
Los hooks son scripts que Git ejecuta automáticamente en eventos específicos como push o commit. El hook pre-commit se activa justo antes de guardar cambios, permitiendo automatizar revisiones de estilo o seguridad. En esta lección aprenderás a crear un script simple que verifique si los archivos contienen líneas excesivamente largas, evitando problemas de legibilidad en repositorios compartidos.

## Ejemplo (no ejecutado automáticamente)
Script bash que verifica la longitud de las líneas y aborta el commit si alguna supera los 100 caracteres.

```bash
#!/bin/bash
if grep -qE '.{101,}' "$1"; then
  echo "Error: Línea demasiado larga en $1"
  exit 1
fi
```

## Ejercicio
Crea un archivo .git/hooks/pre-commit con el script anterior y ejecútalo manualmente para probarlo.

## Criterios de revisión
El script debe existir en la carpeta de hooks, abortar el commit al detectar líneas largas y mostrar un mensaje claro.
