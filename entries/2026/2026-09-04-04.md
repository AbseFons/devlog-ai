## Objetivo
Comprender la función del rate limiting para proteger servicios backend de sobrecargas y ataques DDoS, aprendiendo a implementar límites básicos de solicitudes por ventana de tiempo utilizando encabezados HTTP estándar.

## Explicación
El rate limiting es un mecanismo crítico en el diseño de APIs que restringe el número de peticiones que un cliente puede realizar dentro de un periodo determinado. Esto previene el agotamiento de recursos del servidor, mitiga ataques de fuerza bruta y asegura la equidad entre usuarios. Las implementaciones típicas incluyen ventanas deslizantes o fijas, donde se cuenta cada solicitud recibida. Si el límite se excede, el servidor responde con un estado 429 Too Many Requests, indicando al cliente que debe esperar antes de reintentar. Es fundamental comunicar estos límites mediante encabezados como X-RateLimit-Limit y Retry-After para permitir una gestión proactiva del lado del cliente.

## Ejemplo (no ejecutado automáticamente)
Configuración de middleware en Node.js para limitar solicitudes a 10 por minuto usando un mapa de tokens.

```javascript
const rateLimit = require('express-rate-limit');
const limiter = rateLimit({ windowMs: 60 * 1000, max: 10 });
```
