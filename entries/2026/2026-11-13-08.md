## Objetivo
Comprender el uso de códigos de estado 3xx para redirigir clientes a nuevos recursos, manejar sesiones expiradas y optimizar flujos de navegación automática sin intervención manual del usuario.

## Explicación
Los códigos HTTP entre 300 y 399 indican que la solicitud fue recibida pero el servidor no puede responder directamente. El cliente debe realizar una nueva solicitud para obtener la respuesta final. El código 301 (Moved Permanently) indica que la ubicación del recurso ha cambiado permanentemente, permitiendo a los motores de búsqueda actualizar sus índices automáticamente. Por otro lado, el 302 (Found) sugiere un cambio temporal, ideal para redirigir tráfico tras una actualización de versión o mantenimiento breve. El 307 (Temporary Redirect) es crucial porque preserva el método original de la solicitud (GET o POST), evitando que los navegadores cambien automáticamente un POST a GET como ocurría en versiones antiguas del 302. Finalmente, el 308 (Permanent Redirect) actúa como una versión estricta del 301 para métodos no seguros, asegurando que las peticiones complejas se mantengan intactas tras la redirección.

## Ejemplo (no ejecutado automáticamente)
Manejo de redirección temporal en un endpoint de autenticación usando Python y requests.

```python
import requests
response = requests.post('https://api.ejemplo.com/login', json={'user': 'admin'})
if response.status_code == 302:
    print(f'Redirección a: {response.headers.get("Location")}')
```
