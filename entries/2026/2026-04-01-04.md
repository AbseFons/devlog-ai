## Objetivo
Comprender cómo el Event Loop gestiona asíncronía en JavaScript, diferenciando entre ejecución síncrona en el hilo principal y tareas asíncronas en la cola de microtareas y macrotareas.

## Explicación
El Event Loop es el mecanismo que permite a JavaScript ser no bloqueante. Cuando una operación asíncrona (como fetch o setTimeout) se inicia, su callback se registra en una cola específica: microtareas para Promesas o macrotareas para eventos de DOM y timers. El hilo principal ejecuta código síncrono hasta terminar; luego, el Event Loop verifica si la cola de microtareas está vacía. Si lo está, procesa las macrotareas. Este ciclo asegura que operaciones largas no congeleen la interfaz de usuario.

## Ejemplo (no ejecutado automáticamente)
Ejemplo mostrando el orden de ejecución entre callbacks síncronos, Promesas y setTimeout.

```javascript
console.log('Inicio');
Promise.resolve().then(() => console.log('Microtarea'));
setTimeout(() => console.log('Macrotarea'), 0);
console.log('Fin');
```
