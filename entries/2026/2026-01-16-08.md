## Objetivo
Comprender la lógica del algoritmo de búsqueda por anchura (BFS) para encontrar el camino más corto en grafos no ponderados utilizando una cola y un conjunto visitado.

## Explicación
El BFS explora un grafo capa por capa. Comienza en un nodo raíz, lo marca como visitado y lo añade a una cola. Luego, mientras la cola tenga elementos, extrae el primero, revisa sus vecinos no visitados, los marca y los añade al final de la cola. Este proceso garantiza que se encuentre el camino más corto en términos de número de aristas. Es fundamental usar un conjunto para evitar ciclos infinitos en grafos cíclicos.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python que define una matriz de adyacencia simple y ejecuta BFS desde el nodo 0 hasta encontrar el camino a todos los demás nodos.

```python
from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    path = {start: None}
    while queue:
        node = queue.popleft()
        if node not in visited:
            visited.add(node)
            for neighbor in graph.get(node, []):
                if neighbor not in visited:
                    queue.append(neighbor)
                    path[neighbor] = node
    return path
```
