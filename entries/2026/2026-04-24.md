## Objetivo
Aprender a importar el módulo sqlite3, establecer una conexión segura con una base de datos local y crear la primera tabla para almacenar registros de usuarios.

## Explicación
En esta lección exploraremos los fundamentos de Python para interactuar con bases de datos SQLite. Utilizaremos el módulo nativo sqlite3 para abrir una conexión a un archivo de base de datos o crear uno nuevo automáticamente. El proceso implica importar la librería, establecer la conexión y ejecutar comandos SQL mediante el objeto cursor. Es crucial cerrar la conexión correctamente al finalizar para liberar recursos del sistema. Este enfoque permite gestionar datos persistentes de manera sencilla sin necesidad de servidores externos.

## Ejemplo (no ejecutado automáticamente)
Conexión a una base de datos vacía y creación de tabla usuarios con columnas id, nombre y email.

```python
import sqlite3
conn = sqlite3.connect('mi_base.db')
cursor = conn.cursor()
cursor.execute('CREATE TABLE usuarios (id INTEGER PRIMARY KEY, nombre TEXT, email TEXT)')
```
