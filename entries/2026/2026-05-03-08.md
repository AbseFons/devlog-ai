## Objetivo
Introducir al estudiante en la concurrencia básica de Python utilizando el módulo threading para ejecutar tareas simultáneas, mejorando la eficiencia en procesos I/O.

## Explicación
En Python, la concurrencia se logra mediante hilos (threads) para manejar múltiples tareas. El módulo threading permite crear hilos que ejecutan funciones en paralelo. Ideal para operaciones de entrada/salida como leer archivos o consultar APIs, ya que el hilo principal no se bloquea esperando respuestas lentas. A diferencia del multihilo nativo de C++, Python usa GIL, limitando la concurrencia real en CPU intensiva, pero siendo efectiva en I/O. Este enfoque permite estructurar aplicaciones más responsivas y escalables sin complejidad excesiva.

## Ejemplo (no ejecutado automáticamente)
Ejemplo que imprime mensajes desde dos hilos simultáneos para demostrar ejecución paralela básica.

```python
import threading

def tarea(nombre):
    print(f"Hilo {nombre} ejecutándose")

t1 = threading.Thread(target=tarea, args=("A",))
t2 = threading.Thread(target=tarea, args=("B",))
t1.start()
t2.start()
```
