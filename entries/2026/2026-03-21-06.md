## Objetivo
Aprender a implementar restricciones CHECK para rangos válidos y UNIQUE para duplicados únicos, asegurando la integridad referencial en tablas de usuarios.

## Explicación
Las restricciones CHECK y UNIQUE son fundamentales para mantener la calidad de los datos. CHECK valida que una columna cumpla una condición lógica, como un rango de edad entre 18 y 65. UNIQUE garantiza que no existan filas idénticas en una columna específica, ideal para correos electrónicos o IDs. Al combinarlas, se crea una barrera robusta contra errores de entrada. Por ejemplo, en una tabla de usuarios, podemos impedir edades negativas y asegurar que cada correo sea único. Esto previene inconsistencias antes de que ocurran, reduciendo la necesidad de limpieza posterior y mejorando la confiabilidad del sistema.

## Ejemplo (no ejecutado automáticamente)
Creación de una tabla Usuarios con restricciones CHECK para edad y UNIQUE para el correo electrónico.

```sql
CREATE TABLE Usuarios (
  id INT PRIMARY KEY,
  nombre VARCHAR(50),
  email VARCHAR(100) UNIQUE,
  edad INT CHECK (edad >= 18 AND edad <= 65)
);
INSERT INTO Usuarios VALUES (1, 'Ana', 'ana@ejemplo.com', 25);
```
