## Objetivo
Aprender a diseñar casos de prueba que cubran no solo el camino feliz, sino también los límites exactos de entrada y condiciones de error para garantizar la robustez del software ante datos extremos.

## Explicación
La cobertura de pruebas va más allá de ejecutar código; implica validar explícitamente los bordes de los rangos de entrada. Un sistema puede fallar catastróficamente si recibe un valor justo por encima o por debajo del límite permitido, aunque el caso central funcione perfectamente. Por ejemplo, en una función que acepta edades entre 0 y 120, es crucial probar con -1, 0, 120 y 121. Estos casos de borde revelan vulnerabilidades de validación que los tests internos a menudo pasan por alto. Ignorar estos límites expone la aplicación a fallos inesperados en producción cuando usuarios reales introducen datos atípicos o maliciosos.

## Ejemplo (no ejecutado automáticamente)
Función que valida una edad y lanza error si está fuera del rango permitido, probando los casos de borde exactos.

```javascript
function validarEdad(edad) {
  if (edad < 0 || edad > 120) throw new Error('Edad inválida');
  return edad;
}
try { validarEdad(121); } catch(e) { console.log(e.message); }
```

## Ejercicio
Crea una función en Python que acepte un número de intentos y valide que esté entre 1 y 5. Implementa pruebas unitarias que verifiquen el comportamiento correcto al pasar 0, 1, 5 y 6.

## Criterios de revisión
El código debe lanzar una excepción clara para valores fuera del rango [1, 5] y retornar el número de intentos si está dentro. Las pruebas deben cubrir explícitamente los casos de borde 1 y 5.
