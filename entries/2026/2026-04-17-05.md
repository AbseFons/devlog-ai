## Objetivo
Aprender a escribir pruebas unitarias básicas en Python utilizando el framework estándar unittest para validar la lógica de una función simple y asegurar la calidad del código desde el inicio.

## Explicación
En esta lección, exploraremos cómo estructurar pruebas unitarias con la librería nativa unittest. Crearemos un caso de uso realista donde validamos una función que calcula impuestos. Definiremos una clase de prueba heredada de TestCase, instanciándola y ejecutando métodos específicos como test_calcular_impuesto. Cada método debe comenzar por 'test_' para ser detectado automáticamente. Utilizaremos assertEqual para comparar resultados esperados con los obtenidos. Este enfoque modular permite aislar fallos rápidamente. Es fundamental mantener las pruebas independientes y reproducibles. Al finalizar, podrás integrar estas pruebas en tu flujo de desarrollo continuo.

## Ejemplo (no ejecutado automáticamente)
Se define una función que calcula impuestos y se prueban dos escenarios: uno con éxito y otro con error esperado.

```python
def calcular_impuesto(base, tasa):
    return base * (1 + tasa)

class TestImpuestos(unittest.TestCase):
    def test_calculo_correcto(self):
        self.assertEqual(calcular_impuesto(100, 0.2), 120)
```
