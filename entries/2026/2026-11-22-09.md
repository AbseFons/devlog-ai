## Objetivo
Aprender a exportar módulos dinámicamente usando eval para generar código que accede al contexto global, útil en entornos de pruebas o inyección de dependencias donde el nombre del módulo no es conocido previamente.

## Explicación
En esta lección exploramos una técnica avanzada de JavaScript: la exportación dinámica. A diferencia de los módulos estáticos, aquí utilizamos eval para construir cadenas de código que definen funciones dentro del ámbito global. Esto permite inyectar lógica específica en el entorno principal sin necesidad de un archivo de módulo preexistente. Es ideal para sistemas de pruebas automatizadas donde se requiere cargar comportamientos condicionales basados en parámetros externos. La función creada accede a variables globales, demostrando cómo el contexto de ejecución influye en la resolución de dependencias.

## Ejemplo (no ejecutado automáticamente)
Se define una variable global y se crea dinámicamente una función que exporta esa variable al ámbito principal usando eval.

```javascript
let valorGlobal = 42;
const codigoExport = `export const obtenerValor = () => { return ${valorGlobal}; }`;
eval(codigoExport);
```
