## Objetivo
Aprender a crear listas nuevas mediante expresiones condicionales concisas, optimizando el código al filtrar datos o transformar valores sin bucles explícitos.

## Explicación
La comprensión de listas permite generar secuencias eficientes en una sola línea. Sintácticamente, se define la expresión para cada elemento seguido de un iterador y opcionalmente una cláusula 'if'. Por ejemplo, [x*2 for x in numeros if x > 0] crea una lista con el doble de los valores positivos. Este patrón es legible y más rápido que bucles tradicionales. Es ideal para preprocesamiento de datos, limpieza de conjuntos o mapeo simple. Evita acumular código innecesario en funciones auxiliares.

## Ejemplo (no ejecutado automáticamente)
Se filtra una lista de temperaturas para obtener solo las lecturas superiores a cero grados.

```python
temperaturas = [-5, 2, -10, 3, 0, 7]
positivas = [t for t in temperaturas if t > 0]
```
