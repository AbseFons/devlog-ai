## Objetivo
Comprender la estructura jerárquica de las pruebas de software para priorizar casos unitarios, de integración y end-to-end, optimizando el esfuerzo de QA y reduciendo riesgos en el ciclo de desarrollo.

## Explicación
La pirámide de pruebas es un modelo arquitectónico que distribuye los esfuerzos de testing en tres niveles. La base amplia está compuesta por pruebas unitarias, rápidas y aisladas, que validan componentes individuales. El nivel medio corresponde a las pruebas de integración, que verifican la interacción entre módulos. La cúspide estrecha representa las pruebas end-to-end o de aceptación, lentas pero críticas para validar flujos completos del usuario. Este enfoque asegura una cobertura robusta sin depender excesivamente de entornos complejos en la cima.

## Ejemplo (no ejecutado automáticamente)
Script que define funciones unitarias básicas y un caso de integración simple usando Jest.

```javascript
function sumar(a, b) {
  return a + b;
}

describe('Funcion Sumar', () => {
  test('suma dos numeros', () => {
    expect(sumar(2, 3)).toBe(5);
  });
});
```
