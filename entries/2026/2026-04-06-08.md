## Objetivo
Comprender la lógica del algoritmo de búsqueda por anchura para encontrar el camino más corto entre nodos en un grafo no ponderado utilizando una cola y marcadores de visita.

## Explicación
La Búsqueda por Anchura (BFS) es ideal para grafos donde cada arista tiene el mismo costo. Utiliza una estructura de datos tipo cola (FIFO) para explorar los nodos adyacentes nivel por nivel, garantizando así la distancia mínima desde el origen. Se requiere un conjunto de datos de visita para evitar ciclos infinitos en grafos cíclicos. Este enfoque es fundamental para problemas de conectividad y rutas óptimas en redes sociales o mapas simples.

## Ejemplo (no ejecutado automáticamente)
Implementación de BFS en Python que encuentra el camino más corto desde un nodo 'A' a un nodo 'Z' en un grafo definido por listas de adyacencia, mostrando los pasos de exploración nivel por nivel.

```python
from collections import deque

def bfs(graph, start, end):
    visited = set()
    queue = deque([(start, [start])])
    while queue:
        node, path = queue.popleft()
        if node == end:
            return path
        if node not in visited:
            visited.add(node)
            for neighbor in graph[node]:
                if neighbor not in visited:
                    queue.append((neighbor, path + [neighbor]))
    return None
```
