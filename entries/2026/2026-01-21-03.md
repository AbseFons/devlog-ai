## Objetivo
Introducir el concepto de subproblemas y tabulación mediante un caso práctico de optimización de espacio, enseñando a construir soluciones eficientes evitando cálculos redundantes en algoritmos complejos.

## Explicación
La programación dinámica resuelve problemas optimizando la reutilización de resultados de subproblemas. En este ejemplo, calculamos el máximo volumen de ladrillos que caben en un contenedor de altura fija. Definimos una función recursiva que decide si incluir o excluir cada ladrillo según su peso y valor. Al transformar esta recursión en iteración con una tabla bidimensional, evitamos recalculaciones exponenciales. Este enfoque garantiza complejidad polinómica, esencial para sistemas de logística real donde el tiempo de respuesta es crítico.

## Ejemplo (no ejecutado automáticamente)
Cálculo del valor máximo transportable dado un límite de peso y una lista de ladrillos con pesos y valores específicos.

```python
def knapsack(pesos, valores, capacidad):
    n = len(pesos)
    dp = [[0 for _ in range(capacidad + 1)] for _ in range(n + 1)]
    for i in range(1, n + 1):
        for w in range(capacidad + 1):
            if pesos[i-1] <= w:
                dp[i][w] = max(valores[i-1] + dp[i-1][w - pesos[i-1]], dp[i-1][w])
            else:
                dp[i][w] = dp[i-1][w]
    return dp[n][capacidad]
```
