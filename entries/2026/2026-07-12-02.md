## Objetivo
Comprender el concepto de rate limiting mediante un sistema de tokens deslizantes para proteger APIs contra abusos, asegurando la disponibilidad del servicio y distribuyendo equitativamente los recursos entre múltiples clientes concurrentes.

## Explicación
El rate limiting es una técnica crítica para la gestión de tráfico en APIs. Un método común es el algoritmo de tokens deslizantes, que permite un control más suave que las ventanas fijas. Imagina que cada cliente recibe un flujo continuo de 'tokens'. Cada solicitud consume un token; si no hay disponibilidad, se rechaza. Esto evita picos bruscos mientras permite una tasa constante de solicitudes. En este ejemplo, simularemos la generación y consumo de tokens en tiempo real para demostrar cómo se bloquea una petición cuando el límite se alcanza.
