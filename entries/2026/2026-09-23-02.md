## Objetivo
Comprender la inyección de dependencias como patrón de diseño que desacopla componentes, facilitando pruebas unitarias y mantenimiento del código en aplicaciones modernas.

## Explicación
La inyección de dependencias es un patrón arquitectónico donde las dependencias de una clase se proporcionan desde el exterior en lugar de ser creadas internamente. Esto promueve la inversión de control, permitiendo que el sistema controle qué implementaciones se usan. Al separar la creación de objetos del uso de ellos, mejoramos la modularidad y la reutilización del código. Este enfoque es fundamental para construir sistemas escalables donde los componentes son fáciles de sustituir sin alterar su lógica principal.

## Ejemplo (no ejecutado automáticamente)
Un servicio de pago que recibe una implementación de pasarela externa mediante inyección, demostrando el desacoplamiento en JavaScript.

```javascript
class ServicioPago {
  constructor(pasarela) {
    this.pasarela = pasarela;
  }
  procesar(pedido) {
    return this.pasarela.cobrar(pedido);
  }
}
const pago = new ServicioPago(new PasarelaStripe());
```
