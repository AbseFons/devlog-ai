## Objetivo
Aprender a importar el módulo sqlite3, establecer una conexión segura a una base de datos local y crear un archivo de base de datos con una tabla inicial usando comandos SQL básicos dentro de Python.

## Explicación
En esta lección introduciremos la librería estándar sqlite3 para interactuar con bases de datos relacionales sin dependencias externas. El proceso comienza importando el módulo y creando una conexión mediante sqlite3.connect(), lo cual genera un archivo .db si no existe. Posteriormente, utilizamos execute() para enviar instrucciones SQL como CREATE TABLE. Es crucial cerrar la conexión con close() al finalizar para liberar recursos del sistema. Este enfoque permite gestionar datos persistentes de manera sencilla en aplicaciones de escritorio o scripts automatizados.

## Ejemplo (no ejecutado automáticamente)
Script que crea una base de datos 'empleados.db' y una tabla 'empleados' con columnas id, nombre y salario.

```python
import sqlite3
conn = sqlite3.connect('empleados.db')
conn.execute('''CREATE TABLE empleados (id INTEGER PRIMARY KEY, nombre TEXT, salario REAL)''')
conn.close()
```
