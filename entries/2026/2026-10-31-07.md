## Objetivo
Aprender a configurar usuarios con permisos restringidos para acceder solo a recursos específicos, reduciendo la superficie de ataque y cumpliendo con estándares de seguridad modernos sin comprometer la funcionalidad operativa.

## Explicación
El principio de mínimo privilegio exige que cada entidad del sistema tenga únicamente los permisos necesarios para su función. En entornos de producción, evitar cuentas con acceso root es crítico. Este ejemplo muestra cómo crear un usuario dedicado en Linux con permisos limitados a una carpeta específica mediante el comando useradd y chmod. Se define un grupo exclusivo y se asignan permisos de lectura y ejecución solo sobre archivos necesarios. Esto previene que, si las credenciales del servicio son comprometidas, el atacante no pueda navegar por todo el sistema ni modificar configuraciones críticas fuera del alcance autorizado.

## Ejemplo (no ejecutado automáticamente)
Creación de un usuario 'app_worker' con acceso restringido a la carpeta '/var/www/app_data' y prohibición de escritura en otras áreas del sistema.

```bash
useradd -m -s /bin/bash -G app_group app_worker
chmod 750 /var/www/app_data
chown app_worker:app_group /var/www/app_data
```

## Ejercicio
Crea un usuario llamado 'backup_svc' que solo pueda leer archivos en '/home/ops/backups' y no tenga capacidad de ejecutar comandos de sistema.

## Criterios de revisión
El usuario debe existir con su grupo asignado correctamente, la carpeta debe tener permisos 750 o equivalentes, el propietario debe ser 'backup_svc', y no debe poder acceder a directorios fuera del ámbito definido.
