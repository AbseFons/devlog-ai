## Objetivo
Aprender a usar decoradores para añadir funcionalidad transversal como logging o timing sin alterar el código original de las funciones, mejorando la reutilización y claridad del software.

## Explicación
Los decoradores en Python son funciones especiales que toman otra función como argumento y devuelven una nueva función con comportamientos adicionales. Esto permite inyectar lógica transversal, como validaciones o métricas de rendimiento, manteniendo el código limpio. Sintácticamente, se definen con @decorador antes de la definición de la función. Internamente, el decorador envuelve la función original, preservando su nombre y docstring mediante functools.wraps. Este patrón es esencial para crear frameworks escalables donde la lógica de negocio debe separarse de la infraestructura.

## Ejemplo (no ejecutado automáticamente)
Un decorador que calcula el tiempo de ejecución de una función y lo imprime antes de ejecutarla.

```python
import time

def medir_tiempo(func):
    def envoltura(*args, **kwargs):
        inicio = time.time()
        resultado = func(*args, **kwargs)
        fin = time.time()
        print(f"Tiempo de {func.__name__}: {fin - inicio:.4f} segundos")
        return resultado
    return envoltura

@medir_tiempo
def saludar(nombre):
    time.sleep(1)
    return f"Hola, {nombre}"

print(saludar("Ana"))
```
