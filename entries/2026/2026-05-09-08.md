## Objetivo
Aprender a seleccionar múltiples nodos del DOM simultáneamente utilizando selectores CSS avanzados para construir listas dinámicas sin depender de clases repetitivas.

## Explicación
En esta lección exploramos el poder de querySelectorAll, que devuelve una NodeList con todos los elementos que coinciden con un selector. A diferencia de querySelector, este método permite iterar sobre colecciones completas. Imagina una galería de imágenes donde cada foto tiene un atributo data-id único. En lugar de añadir clases a cada imagen manualmente, podemos seleccionar todas las etiquetas img y filtrarlas por sus datos. Esto promueve un código más limpio y mantenible. La iteración se realiza mediante un bucle for tradicional o métodos modernos como forEach. Es crucial recordar que NodeList no es un Array nativo, aunque en la mayoría de los navegadores modernos se comporta similarmente. Esta técnica es fundamental para aplicaciones web complejas donde el contenido se genera dinámicamente y requiere manipulación masiva.

## Ejemplo (no ejecutado automáticamente)
Selecciona todas las imágenes con atributo data-id y crea un array con sus fuentes

```javascript
const imagenes = document.querySelectorAll('img[data-id]');
const fuentes = Array.from(imagenes).map(img => img.src);
```
