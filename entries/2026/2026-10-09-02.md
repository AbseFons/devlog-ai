## Objetivo
Comprender la utilidad de la instrucción EXPLAIN para inspeccionar cómo el motor de base de datos planifica y ejecuta consultas SQL, optimizando así el rendimiento mediante la identificación de cuellos de botella en las operaciones de lectura.

## Explicación
La sentencia EXPLAIN permite visualizar el plan de ejecución generado por el optimizador del sistema antes de realizar una consulta costosa. Este plan detalla el orden de las tablas a escanear, los índices utilizados y las estrategias de unión de datos. Al analizar este esquema, los desarrolladores pueden detectar ineficiencias como escaneos completos innecesarios o uniones mal ordenadas. Es fundamental ejecutar esta instrucción en entornos de desarrollo o pruebas, nunca en producción con datos sensibles, para evitar sobrecargas no deseadas. La interpretación correcta del plan es esencial para escribir consultas eficientes y escalables.

## Ejemplo (no ejecutado automáticamente)
Consulta que busca empleados por departamento usando EXPLAIN para verificar el uso de índices.

```sql
EXPLAIN SELECT * FROM empleados WHERE id_departamento = 5;
SELECT * FROM empleados WHERE id_departamento = 5;
```

## Criterios de revisión
El plan debe mostrar el uso de un índice (Index Scan) en lugar de un escaneo completo de tabla (Seq Scan). La consulta base debe ser sintácticamente correcta y referenciar tablas existentes en un entorno de prueba.
