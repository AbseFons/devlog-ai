## Objetivo
Aprender a definir clases compactas con atributos automáticos, métodos __init__ y __repr__, ideal para representar datos estructurados sin boilerplate excesivo.

## Explicación
Los dataclasses simplifican la creación de clases POJO en Python. Al usar el decorador @dataclass, se generan automáticamente los métodos __init__, __repr__ y __eq__. Esto reduce drásticamente la cantidad de código necesario para definir estructuras de datos simples. Es útil cuando necesitas agrupar campos relacionados como registros de usuario o configuraciones. La sintaxis permite especificar tipos de datos directamente en la definición del atributo, mejorando la seguridad tipada y la legibilidad del código.

## Ejemplo (no ejecutado automáticamente)
Definición de una clase dataclass para representar un producto con nombre y precio.

```python
from dataclasses import dataclass

@dataclass
class Producto:
    nombre: str
    precio: float
```
