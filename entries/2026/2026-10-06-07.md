## Objetivo
Comprender la implementación de un algoritmo recursivo para calcular el factorial de un número entero positivo, identificando claramente la condición base y el caso general en la definición matemática.

## Explicación
La recursión permite resolver problemas complejos dividiéndolos en instancias más pequeñas del mismo problema. Para calcular el factorial de n (n!), definimos que si n es 0 o 1, el resultado es 1 (condición base). En cualquier otro caso, el resultado es n multiplicado por el factorial de n menos uno. Este enfoque evita bucles explícitos y refleja directamente la definición matemática. Es crucial asegurar que la condición base se alcance para evitar desbordamiento de pila.

## Ejemplo (no ejecutado automáticamente)
Función que calcula el factorial de un número usando recursión simple en JavaScript.

```javascript
function factorial(n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}
```
