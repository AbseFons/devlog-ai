## Objetivo
Comprender el significado de los códigos de estado HTTP que comienzan con 2, específicamente 200 OK y 201 Created. Aprenderás cuándo usar cada uno para confirmar operaciones exitosas como lecturas de datos o creación de recursos nuevos en una API RESTful.

## Explicación
Los códigos de respuesta HTTP entre 200 y 299 indican que la solicitud del cliente fue recibida, entendida y procesada correctamente. El código 200 OK es el estándar para respuestas exitosas donde el servidor devuelve los datos solicitados en el cuerpo de la respuesta, como una lista de usuarios o un producto específico. Por otro lado, el código 201 Created se utiliza específicamente cuando el resultado de la solicitud ha creado un nuevo recurso persistente en el servidor, como al enviar un POST para registrar un nuevo usuario. Es crucial distinguirlos: si solo necesitas confirmar que los datos existen sin crear nada nuevo, usa 200; si tu acción principal fue la creación exitosa, responde con 201 y asegúrate de incluir el encabezado Location que apunte a la URI del recurso recién creado.


## Ejercicio
Crea una función en JavaScript que simule una respuesta de API. La función debe recibir un parámetro 'tipo'. Si 'tipo' es 'read', devuelve un objeto con statusCode 200 y datos aleatorios. Si 'tipo' es 'create', devuelve un objeto con statusCode 201, un mensaje de creación y una propiedad 'location' con una URL ficticia.

## Criterios de revisión
La función debe devolver exactamente dos tipos de objetos JSON distintos según el parámetro. El código para el caso 'create' debe incluir obligatoriamente las claves 'statusCode', 'message' y 'location'. No se permiten errores de sintaxis en la estructura JSON devuelta.
