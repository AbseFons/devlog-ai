## Objetivo
Aprender a inicializar una conexión con sqlite3, crear un archivo de base de datos local y definir una tabla simple para almacenar registros de usuarios básicos.

## Explicación
En esta lección exploraremos los fundamentos de la librería estándar sqlite3 en Python. Comenzaremos importando el módulo y estableciendo una conexión a un archivo llamado 'datos.db'. Si no existe, se creará automáticamente. Utilizaremos el cursor para ejecutar comandos SQL DDL (Data Definition Language). Específicamente, creamos una tabla llamada 'usuarios' con columnas para id, nombre y email. La gestión de recursos es crucial; por ello, utilizamos un bloque 'with' que asegura cerrar la conexión correctamente al finalizar, liberando memoria y evitando fugas de recursos en aplicaciones de larga duración.

## Ejemplo (no ejecutado automáticamente)
Script que crea una base de datos local con una tabla de usuarios.

```python
import sqlite3
conn = sqlite3.connect('datos.db')
cursor = conn.cursor()
cursor.execute('''CREATE TABLE usuarios (id INTEGER PRIMARY KEY, nombre TEXT, email TEXT)''')
conn.commit()
```
