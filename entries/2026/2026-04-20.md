## Objetivo
Aprender a modularizar código JavaScript utilizando la sintaxis estándar de módulos ES6 para organizar funciones en archivos separados, mejorando la mantenibilidad y evitando conflictos de variables globales en aplicaciones modernas.

## Explicación
Los módulos ES permiten encapsular lógica en archivos independientes. Para compartir funcionalidad entre archivos, se usa export para definir lo que un módulo ofrece al exterior, e import para consumir esas dependencias. Este sistema evita el problema del scope global y facilita la reutilización de código. En este caso práctico, creamos un archivo utils.js con funciones matemáticas básicas y las importamos en un archivo principal app.js. La estructura asegura que cada función solo esté disponible donde se necesita explícitamente, reduciendo errores y acoplamiento innecesario entre partes del sistema.

## Ejemplo (no ejecutado automáticamente)
Se define una función suma en utils.js y se importa en app.js para ejecutarla inmediatamente.

```javascript
// utils.js
export function sumar(a, b) {
  return a + b;
}

// app.js
import { sumar } from './utils.js';
console.log(sumar(5, 3));
```
