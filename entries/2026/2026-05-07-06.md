## Objetivo
Comprender cómo estructurar un middleware para validar permisos de usuario antes de procesar solicitudes críticas, asegurando que solo roles autorizados puedan acceder a recursos sensibles dentro de una aplicación web.

## Explicación
El control de acceso es fundamental para proteger la integridad de los datos. En esta microlección, exploraremos un enfoque común: el uso de middleware en aplicaciones Node.js para interceptar peticiones HTTP y verificar si el usuario autenticado posee el rol necesario. Este patrón separa la lógica de seguridad del controlador de negocio, promoviendo código más limpio y mantenible. El sistema define roles como 'admin', 'editor' o 'lector'. Al recibir una petición, el middleware consulta un objeto de configuración que mapea rutas a roles permitidos. Si el rol del usuario no coincide con los requeridos para esa ruta específica, la solicitud se rechaza inmediatamente con un código de estado 403 Forbidden. Este mecanismo previene accesos no autorizados sin necesidad de modificar la lógica interna de cada endpoint, centralizando las políticas de seguridad en puntos estratégicos del flujo de la aplicación.

## Ejemplo (no ejecutado automáticamente)
Un middleware de Node.js que verifica si el usuario tiene el rol 'admin' para acceder a una ruta protegida de configuración.

```javascript
const checkAdmin = (req, res, next) => {
  if (req.user && req.user.role === 'admin') {
    return next();
  }
  return res.status(403).json({ error: 'Acceso denegado' });
};
```

## Ejercicio
Crea un archivo llamado authMiddleware.js en tu proyecto. Define una función que acepte un array de roles permitidos como argumento y retorne un middleware que verifique si el usuario actual (almacenado en req.user) posee uno de esos roles. Si no lo tiene, responde con JSON indicando 'Acceso denegado' y estado 403.

## Criterios de revisión
El código debe ser funcional y ejecutable en un entorno Node.js estándar. Debe manejar correctamente el caso donde req.user no existe o es nulo. La función debe aceptar dinámicamente cualquier lista de roles permitidos sin hardcodear valores específicos.
