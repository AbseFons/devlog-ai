## Objetivo
Al finalizar esta lección, el desarrollador podrá diferenciar conceptualmente entre iteradores y generadores, implementando una función generadora para procesar flujos de datos infinitos o grandes sin agotar la memoria del sistema.

## Explicación
En Python, un iterador es cualquier objeto que implementa los métodos next() y __iter__(), permitiendo recorrer secuencias. Los generadores son una forma concisa de crear iteradores utilizando la sentencia yield. Mientras que las funciones normales devuelven un valor final con return, las funciones generadoras pausan su ejecución en cada llamada a next(), manteniendo el estado local. Esto es crucial para manejar grandes volúmenes de datos o flujos infinitos, como leer líneas de un archivo log gigante o generar números primos secuenciales, evitando cargar todo el conjunto en memoria.

## Ejemplo (no ejecutado automáticamente)
```python
import sys

def leer_archivo_seguro(ruta):
    """Generador para leer un archivo línea por línea sin cargarlo todo."""
    try:
        with open(ruta, 'r', encoding='utf-8') as f:
            for linea in f:
                yield linea.strip()
    except FileNotFoundError:
        print(f"Error: El archivo {ruta} no existe.")

# Uso realista: Procesar un archivo grande línea por línea
archivo = 'datos_grandes.log'
contador = 0
for linea in leer_archivo_seguro(archivo):
    if 'ERROR' in linea:
        print(f"Línea {contador + 1}: {linea}")
        contador += 1
        if contador >= 5:  # Limitar salida para demostración
            break
```
