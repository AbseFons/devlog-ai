## Objetivo
Aprender a cancelar peticiones asíncronas en JavaScript para evitar bloqueos de interfaz y optimizar el rendimiento al manejar respuestas lentas o conexiones inestables.

## Explicación
En aplicaciones modernas, las peticiones HTTP pueden tardar demasiado. Si no se cancelan, la UI se congela. La solución es usar AbortController junto con fetch. Primero, instancias un controlador y pasa su señal al segundo argumento de fetch. Si el usuario navega o deja la página, llamas a abortar() en el controlador. Esto lanza una excepción específica dentro del bloque async/await. Debes envolver la petición en try/catch para manejar este error sin que rompa la aplicación. Este patrón es esencial para experiencias de usuario fluidas y aplicaciones responsivas.

## Ejemplo (no ejecutado automáticamente)
Se crea un controlador, se inicia una petición a una API pública con timeout simulado y se cancela manualmente tras 2 segundos.

```javascript
const controller = new AbortController();
fetch('https://jsonplaceholder.typicode.com/posts/1', { signal: controller.signal })
```

## Ejercicio
Crea una función que realice una petición a una URL proporcionada. Incluye un botón en el HTML que, al hacer clic, llame a controller.abort() y muestre un mensaje de 'Cancelado' si la petición estaba activa.

## Criterios de revisión
El código debe instanciar correctamente AbortController, pasar la señal a fetch, manejar la excepción TypeError lanzada por abortar y no mostrar errores en consola al cancelar intencionalmente.
