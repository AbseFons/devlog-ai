## Objetivo
Dominar las restricciones CHECK y UNIQUE para garantizar la integridad referencial y semántica de los datos, evitando valores inválidos o duplicados no deseados en tablas relacionales.

## Explicación
Las restricciones CHECK aseguran que una columna contenga solo valores dentro de un rango definido, como edades mayores a cero. Por otro lado, UNIQUE impide filas idénticas completas o duplicados en columnas específicas, crucial para claves secundarias. Juntas, estas reglas previenen corrupción de datos antes de la inserción. Su implementación directa en el DDL (Data Definition Language) refuerza la consistencia del esquema sin depender de lógica de aplicación.

## Ejemplo (no ejecutado automáticamente)
Creación de una tabla de empleados con restricción de edad y columna única para número de empleado.

```sql
CREATE TABLE Empleados (
    id INT PRIMARY KEY,
    nombre VARCHAR(50),
    edad INT CHECK (edad > 18),
    numero_empleado VARCHAR(10) UNIQUE
);
```
