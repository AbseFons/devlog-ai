## Objetivo
Aprender a crear scripts interactivos que acepten argumentos desde la línea de comandos, facilitando la automatización y el uso profesional de herramientas de scripting.

## Explicación
El módulo argparse permite interpretar los argumentos pasados al script. Al usar ArgumentParser(), se definen subcomandos y opciones con flags como -v o --output. Esto genera automáticamente mensajes de ayuda si falta un parámetro. Es ideal para scripts que necesitan configuraciones dinámicas sin modificar el código fuente. La estructura del programa se mantiene limpia, separando la lógica de negocio de la entrada del usuario.

## Ejemplo (no ejecutado automáticamente)
Script que acepta un nombre de archivo y una opción de verificación para mostrar su contenido o estado.

```python
import argparse
parser = argparse.ArgumentParser()
parser.add_argument('archivo', help='Nombre del archivo a procesar')
args = parser.parse_args()
```
