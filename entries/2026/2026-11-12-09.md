## Objetivo
Aprender a implementar colas con prioridad para gestionar tareas críticas versus rutinarias, mejorando la eficiencia del sistema al procesar primero las operaciones más urgentes sin bloquear el flujo general.

## Explicación
En sistemas complejos, no todas las tareas tienen la misma urgencia. Una cola simple (FIFO) puede causar ineficiencias si una tarea larga y poco importante retrasa una crítica. La solución es usar una estructura de datos que permita insertar elementos con niveles de prioridad. Algoritmos como 'heap' o listas enlazadas ordenadas facilitan esto. En este caso, simularemos un sistema de colas donde las tareas se clasifican por nivel (0=crítico, 1=alto, 2=bajo). El algoritmo extrae siempre el elemento con menor valor numérico primero. Esto garantiza que la latencia del sistema sea mínima para eventos importantes mientras se mantiene el progreso en tareas secundarias. La implementación requiere comparar claves de prioridad antes de cada extracción.

## Ejemplo (no ejecutado automáticamente)
Implementación de una cola con prioridad usando un diccionario ordenado en Python para gestionar tareas de servidor.

```python
import heapq

class PriorityQueue:
    def __init__(self):
        self.heap = []
    
    def push(self, priority, task):
        heapq.heappush(self.heap, (priority, task))
    
    def pop(self):
        return heapq.heappop(self.heap)[1]
```
