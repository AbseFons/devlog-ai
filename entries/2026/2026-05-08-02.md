## Objetivo
Comprender la estructura jerárquica de las pruebas de software, priorizando casos unitarios sobre integración y E2E para optimizar velocidad, costo y detección temprana de errores en el ciclo de desarrollo.

## Explicación
La pirámide de pruebas es un modelo arquitectónico que organiza los tipos de pruebas según su alcance y complejidad. La base amplia está compuesta por las pruebas unitarias, ejecutadas frecuentemente y con alto volumen, enfocadas en validar componentes individuales aislados. Sobre ellas se sitúan las pruebas de integración, que verifican la interacción entre módulos relacionados. En la cúspite, más estrecha, se encuentran las pruebas de aceptación o end-to-end, críticas pero menos frecuentes debido a su costo y lentitud. Este enfoque asegura una cobertura robusta donde los fallos se detectan lo antes posible, reduciendo el riesgo de regresión y facilitando refactoring seguro.

## Ejemplo (no ejecutado automáticamente)
Implementación de una función unitaria en JavaScript que valida la suma de dos números positivos, representando la base de la pirámide.

```javascript
function sumar(a, b) {
  return a + b;
}
const resultado = sumar(2, 3);
console.log(resultado); // Salida: 5
```
