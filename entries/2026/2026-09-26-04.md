## Objetivo
Aprender a definir y aplicar decoradores simples para modificar el comportamiento de funciones sin alterar su código interno, facilitando la reutilización lógica.

## Explicación
Los decoradores son una herramienta poderosa en Python que permite envolver funciones para añadir funcionalidad adicional. Se definen como funciones que toman otra función como argumento y devuelven una nueva. La sintaxis especial @nombre_decorador es un atajo de sintaxis que equivale a asignar el resultado del decorador a la función original. Este mecanismo es ideal para tareas transversales como registro de tiempos, validación de permisos o manejo de errores comunes.

## Ejemplo (no ejecutado automáticamente)
Un decorador simple que imprime un mensaje antes y después de ejecutar una función objetivo.

```python
def mi_decorador(func):
    def envoltura():
        print('Antes de la acción')
        func()
        print('Después de la acción')
    return envoltura

@mi_decorador
def saludar():
    print('Hola, bienvenido')
```
