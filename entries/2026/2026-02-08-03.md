## Objetivo
Aprender a implementar restricciones CHECK para limitar rangos de valores y UNIQUE para garantizar integridad referencial, evitando duplicados innecesarios en tablas relacionales mediante sintaxis estándar.

## Explicación
Las restricciones CHECK y UNIQUE son fundamentales para la integridad de datos. CHECK valida que un valor cumpla una condición lógica específica, como asegurar que el salario sea positivo o que un estado esté dentro de un rango permitido. Por otro lado, UNIQUE garantiza que no existan dos filas con el mismo valor en una columna específica, ideal para identificadores secundarios como números de teléfono o correos electrónicos. Ambas se definen al crear la tabla o mediante ALTER TABLE. Es crucial escribir las condiciones claramente para evitar errores de inserción silenciosos.

## Ejemplo (no ejecutado automáticamente)
Creación de una tabla de empleados con columna de salario validada por CHECK y un número de teléfono único.

```sql
CREATE TABLE Empleados (
  id INT PRIMARY KEY,
  nombre VARCHAR(50),
  salario DECIMAL(10,2) CHECK (salario > 0),
  telefono VARCHAR(20) UNIQUE
);
```
