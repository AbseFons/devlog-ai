## Objetivo
Aprender a implementar colas con prioridad para gestionar tareas críticas versus rutinarias, optimizando el rendimiento del sistema al procesar primero las operaciones más urgentes sin bloquear la ejecución general.

## Explicación
En sistemas operativos y servidores, no todas las tareas tienen la misma urgencia. Una cola simple (FIFO) puede causar que procesos lentos detengan a los críticos. La solución es una Cola con Prioridad, donde cada elemento tiene un nivel de importancia. Al insertar tareas, se asigna un valor numérico: menor número indica mayor prioridad. El algoritmo extrae siempre el elemento con el valor mínimo, asegurando que las interrupciones o procesos en tiempo real se ejecuten antes que las actualizaciones de fondo. Esto requiere modificar la estructura de datos estándar para mantenerla ordenada dinámicamente, garantizando equidad y eficiencia simultáneamente.

## Ejemplo (no ejecutado automáticamente)
Implementación de una cola con prioridad usando un Min-Heap en Python para simular el escalado de procesos del sistema operativo.

```python
import heapq

class PriorityQueue:
    def __init__(self):
        self.heap = []
    
    def push(self, priority, task):
        heapq.heappush(self.heap, (priority, task))
    
    def pop(self):
        return heapq.heappop(self.heap)[1]

# Simulación: 0 es crítico, 1 es normal, 2 es bajo
pq = PriorityQueue()
pq.push(0, "Interrupcion Hardware")
pq.push(2, "Backup de disco")
pq.push(1, "Respuesta web")
print(pq.pop()) # Salida: Interrupcion Hardware
```
