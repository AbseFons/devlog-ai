## Objetivo
Aprender a usar el comando git reflog para recuperar accidentalmente eliminados commits, ramas o estados de trabajo perdidos sin necesidad de repositorios remotos.

## Explicación
El comando git reflog registra cada cambio en la referencia HEAD localmente. Es vital cuando se ejecutan operaciones como reset --hard o rm -rf que borran historial visible pero dejan rastro en el reflog. Para recuperar un estado, primero ejecuta git reflog para ver la lista de hashes y mensajes recientes. Identifica el hash del commit o estado deseado. Luego, usa git reset --hard <hash> para restaurar el directorio a ese punto exacto. Este mecanismo es seguro porque no afecta al historial compartido en remoto, solo reescribe localmente tu índice y árbol de objetos. Úsalo con precaución antes de compartir código.

## Ejemplo (no ejecutado automáticamente)
Recuperar un commit eliminado accidentalmente usando el reflog para restaurar el estado del repositorio.

```bash
git reflog
HEAD@{1} git reset --hard HEAD@{1}
```

## Ejercicio
Ejecuta un comando que borre accidentalmente tu último commit con 'git reset --hard HEAD~1'. Luego, usa el reflog para encontrar el hash perdido y restaura el estado original.

## Criterios de revisión
El usuario debe identificar correctamente el hash del estado anterior en el reflog y ejecutar el comando de recuperación sin perder datos locales.
