## Objetivo
Comprender la función de los hooks en Git, específicamente el pre-commit, para automatizar validaciones antes de cada commit y mantener un historial limpio.

## Explicación
Los hooks son scripts que Git ejecuta automáticamente en momentos específicos del flujo de trabajo. El hook 'pre-commit' se activa justo antes de realizar un commit. Su utilidad principal es validar el código o los archivos que se van a guardar, evitando errores comunes como falta de formato, ausencia de pruebas unitarias o inclusiones accidentales de archivos binarios no deseados. Al escribir este script en la carpeta '.git/hooks/', puedes definir reglas personalizadas para tu equipo. Por ejemplo, podrías integrar formateadores de código o linters que corran localmente antes de permitir el commit. Esto asegura que cada contribución al repositorio cumpla con los estándares de calidad definidos, reduciendo la carga de revisión en las pull requests y manteniendo el historial de cambios ordenado y predecible.

## Ejemplo (no ejecutado automáticamente)
Script bash básico que verifica si un archivo .py existe antes de permitir el commit.

```bash
#!/bin/bash
if [ -f "src/app.py" ]; then
  echo "Archivo Python detectado. Validando..."
fi
```
