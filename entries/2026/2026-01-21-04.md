## Objetivo
Aprender a seleccionar elementos del documento HTML utilizando selectores CSS y modificar sus propiedades de estilo o contenido directamente desde JavaScript, sentando las bases para la interactividad.

## Explicación
La manipulación del DOM permite interactuar dinámicamente con el contenido web. Utilizamos métodos como document.querySelector() para obtener un único elemento basado en un selector CSS, lo cual es más eficiente que querySelectorAll cuando solo necesitamos uno. Una vez obtenido el nodo, podemos acceder a sus propiedades de estilo mediante style.propiedad o modificar su texto usando innerText. Es crucial entender que los selectores CSS son poderosos y reutilizables; por ejemplo, seleccionar todos los párrafos con una clase específica permite aplicar cambios globales sin escribir código repetitivo para cada elemento individual.

## Ejemplo (no ejecutado automáticamente)
Selecciona un botón con la clase 'btn-primario' y cambia su fondo a azul al hacer clic.

```javascript
const boton = document.querySelector('.btn-primario');
boton.addEventListener('click', () => {
  boton.style.backgroundColor = '#007bff';
});
```
