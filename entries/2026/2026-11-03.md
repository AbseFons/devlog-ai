## Objetivo
Comprender la estructura jerárquica de un árbol binario, sus nodos raíz e hijos, y dominar los métodos básicos de recorrido (inorden) para extraer datos ordenados de manera eficiente.

## Explicación
Un árbol binario es una estructura de datos donde cada nodo tiene como máximo dos hijos: izquierdo y derecho. La raíz es el punto de entrada. El recorrido inorden (izquierdo, raíz, derecho) permite procesar los elementos en orden ascendente si el árbol está balanceado. Este patrón es fundamental para implementar tablas hash o índices en bases de datos. Se utiliza recursión para visitar cada nodo sin necesidad de apilar manualmente la pila de llamadas.
