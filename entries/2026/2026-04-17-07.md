## Objetivo
Comprender el concepto de clave foránea, su función para mantener la integridad referencial entre tablas relacionadas y cómo definir restricciones en SQL estándar.

## Explicación
Una clave foránea es una columna o conjunto de columnas en una tabla que hace referencia a la clave primaria de otra tabla. Su propósito principal es garantizar la integridad referencial, asegurando que los datos en la tabla hija siempre correspondan a registros existentes en la tabla padre. Esto previene inconsistencias como referencias a entidades inexistentes. Al definir esta relación mediante CONSTRAINT FOREIGN KEY, se establece un vínculo lógico que el motor de base de datos utiliza para validar operaciones de inserción y actualización. Sin este mecanismo, sería posible introducir datos huérfanos o rotos en la estructura de la base de datos.

## Ejemplo (no ejecutado automáticamente)
Definición de una tabla 'pedidos' con una clave foránea que referencia a la tabla 'clientes', asegurando que cada pedido pertenezca a un cliente válido.

```sql
CREATE TABLE pedidos (
  id_pedido INT PRIMARY KEY,
  id_cliente INT NOT NULL,
  fecha DATE,
  CONSTRAINT fk_cliente FOREIGN KEY (id_cliente)
    REFERENCES clientes(id_cliente)
    ON DELETE CASCADE
);
```
