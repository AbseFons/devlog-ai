## Objetivo
Aprender a gestionar transacciones atómicas en bases de datos SQLite usando el módulo sqlite3 de Python, asegurando la integridad de los datos mediante bloqueos de escritura y confirmación explícita.

## Explicación
En esta lección exploraremos cómo las transacciones garantizan que una serie de operaciones se ejecuten como una unidad indivisible. Si falla cualquier paso, todas se descartan automáticamente. Usaremos el método execute() para realizar cambios y commit() o rollback() para controlar su finalización. Es crucial entender que SQLite mantiene un estado de escritura por defecto en modo autocommit hasta que se llama a commit(). Sin embargo, para operaciones complejas como transferencias bancarias simuladas, es necesario agrupar las sentencias SQL dentro de una transacción explícita. Esto previene inconsistencias donde el saldo total no coincida con la suma de saldos individuales tras un error parcial.

## Ejemplo (no ejecutado automáticamente)
Script que simula una transferencia entre dos cuentas bancarias en SQLite, asegurando que si la segunda operación falla, la primera se deshace automáticamente mediante rollback.

```python
import sqlite3
conn = sqlite3.connect('banco.db')
cursor = conn.cursor()
cursor.execute("BEGIN")
cursor.execute("UPDATE cuentas SET saldo = saldo - 100 WHERE id = 1")
cursor.execute("UPDATE cuentas SET saldo = saldo + 100 WHERE id = 2")
conn.commit()
```
