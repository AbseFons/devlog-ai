## Objetivo
Aprender a cancelar peticiones asíncronas en JavaScript utilizando AbortController para evitar bloqueos de UI y mejorar la experiencia del usuario al cambiar entre pestañas o navegar rápidamente.

## Explicación
En aplicaciones modernas, las peticiones que tardan demasiado pueden causar tiempos de espera innecesarios. La API fetch no tiene un método nativo para cancelar operaciones, pero podemos usar el objeto AbortController. Este controlador genera una señal (signal) que se pasa a fetch como segundo argumento. Si llamamos a abort() antes de que la respuesta llegue, la petición falla inmediatamente con un error específico. Esto es crucial en interfaces donde el usuario cambia de ruta mientras cargan datos; sin cancelación, el navegador seguiría consumiendo ancho de banda y bloqueando el hilo principal hasta completar la tarea.

## Ejemplo (no ejecutado automáticamente)
Se crea un controlador, se inicia una petición a una URL simulada con timeout y se aborta manualmente tras 2 segundos para demostrar la cancelación efectiva.

```javascript
const controller = new AbortController();
fetch('https://jsonplaceholder.typicode.com/posts/1', { signal: controller.signal })
```
