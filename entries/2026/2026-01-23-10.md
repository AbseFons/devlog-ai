## Objetivo
Aprender a seleccionar múltiples nodos del DOM simultáneamente utilizando querySelectorAll para iterar y modificar colecciones de elementos, mejorando la eficiencia en aplicaciones web complejas.

## Explicación
En esta lección exploramos el método querySelectorAll, que devuelve una NodeList con todos los elementos que coinciden con un selector CSS. A diferencia de querySelector, este retorna múltiples nodos. Es ideal para aplicar estilos globales o manipular listas completas sin escribir bucles manuales repetitivos. La sintaxis permite combinadores como hijos directos o descendientes. Al iterar sobre el NodeList, podemos actualizar propiedades como clase, contenido o atributos en cada elemento seleccionado, facilitando la creación de interfaces responsivas y dinámicas.

## Ejemplo (no ejecutado automáticamente)
Selecciona todos los párrafos dentro de un contenedor específico y les añade una clase para resaltarlos visualmente al cargar la página.

```javascript
const container = document.getElementById('lista-articulos');
const parrafos = container.querySelectorAll('p');
parrafos.forEach(p => p.classList.add('texto-resaltado'));
```
