## Objetivo
Comprender cómo la recursión permite descomponer problemas complejos en subproblemas idénticos, utilizando el cálculo de la serie de Fibonacci como caso práctico fundamental para entender bases y casos base.

## Explicación
La recursión es una técnica donde una función se llama a sí misma. En la serie de Fibonacci, cada número es la suma de los dos anteriores (0, 1, 1, 2, 3...). La función debe definir un caso base para evitar bucles infinitos: si el índice es 0 o 1, retorna el valor directamente. Para índices mayores, la función invoca a sí misma con n-1 y n-2. Este enfoque divide el problema original en instancias más pequeñas hasta alcanzar los casos base. Aunque menos eficiente que la iteración por memoria dinámica, ilustra claramente la estructura de llamada pila y es esencial para dominar patrones recursivos en algoritmos.

## Ejemplo (no ejecutado automáticamente)
Implementación de una función recursiva que calcula el n-ésimo número de Fibonacci. El usuario ingresa un entero positivo y recibe el resultado correspondiente a la serie.

```python
def fibonacci(n):
    if n <= 1:
        return n
    else:
        return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(10))
```
