## Objetivo
Aprender a utilizar conjuntos para operaciones matemáticas rápidas y diccionarios para almacenar datos relacionales de manera eficiente en Python.

## Explicación
Los sets son colecciones no ordenadas de elementos únicos, ideales para eliminar duplicados o realizar intersecciones. Los diccionarios mapean claves a valores, permitiendo acceso O(1). En este ejemplo, creamos un set con nombres y lo limpiamos de repeticiones. Luego, definimos un diccionario con datos de empleados, accediendo a la clave 'nombre' para obtener el valor asociado. Esta combinación es vital en procesamiento de datos.

## Ejemplo (no ejecutado automáticamente)
Creación de un set sin duplicados y acceso a valores en un diccionario de empleados.

```python
nombres = {'Ana', 'Luis', 'Ana', 'Sofia'}
nombres.add('Luis')
print(nombres)

empleados = {'id': 101, 'nombre': 'Carlos', 'rol': 'Dev'}
print(empleados['nombre'])
```
