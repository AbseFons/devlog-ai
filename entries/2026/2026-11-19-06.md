## Objetivo
Aprender a crear decoradores que acepten parámetros configurables, permitiendo modificar el comportamiento de funciones dinámicamente sin alterar su implementación interna.

## Explicación
Los decoradores estándar son poderosos, pero a menudo necesitamos flexibilidad. Al añadir argumentos al decorador (ej. @mi_decorador(tipo='log')), envuelves la función original en una nueva que recibe esos parámetros. Internamente, el decorador debe aceptar *args y **kwargs para delegar correctamente a la función original. Esto permite crear herramientas genéricas como medidores de tiempo con umbrales variables o validadores de entrada adaptables. La clave está en anidar funciones: el decorador toma los argumentos externos, define una función interna que recibe los argumentos de la función decorada y finalmente aplica la lógica de envoltura.

## Ejemplo (no ejecutado automáticamente)
Un decorador que registra la ejecución de una función solo si el tiempo de ejecución supera un umbral configurado en segundos.

```python
import time

def registro_lento(umbral):
    def decorador(func):
        def envoltura(*args, **kwargs):
            inicio = time.time()
            resultado = func(*args, **kwargs)
            fin = time.time()
            if (fin - inicio) > umbral:
                print(f'Funcion {func.__name__} tardó {(fin-inicio):.2f}s')
            return resultado
        return envoltura
    return decorador

@registro_lento(umbral=1)
def tarea_pesada():
    time.sleep(0.5)
    return 'Completado'

print(tarea_pesada())
```
