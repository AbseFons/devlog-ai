## Objetivo
Aprender a utilizar la clase Path de pathlib para construir rutas absolutas y relativas de forma segura, evitando errores comunes de codificación de caracteres en sistemas operativos diferentes.

## Explicación
En Python, el módulo pathlib ofrece una interfaz orientada a objetos para manipular rutas de archivos. A diferencia de las cadenas con forward slashes, Path permite construir rutas automáticamente adaptándose al sistema operativo (Windows usa backslashes, Linux/Mac usan forward slashes). Esto es crucial para escribir código portable. Utilizamos Path.joinpath() o la sintaxis / para concatenar componentes sin preocuparnos por el separador incorrecto. Además, métodos como resolve() obtienen la ruta absoluta real, resolviendo enlaces simbólicos y rutas relativas al directorio de trabajo actual.

## Ejemplo (no ejecutado automáticamente)
Construcción de una ruta segura a un archivo de configuración en subdirectorios anidados usando pathlib.

```python
from pathlib import Path
config_path = Path('proyectos') / 'api' / 'config.json'
```
