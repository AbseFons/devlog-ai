## Objetivo

## Explicación
La programación dinámica resuelve problemas complejos descomponiéndolos en subproblemas más simples y almacenando sus resultados. En este caso, analizamos el problema del cambio: dado un monto objetivo y un conjunto de monedas, hallar la mínima cantidad de monedas necesarias. La clave es construir una tabla donde cada índice representa un monto acumulado y su valor guarda el mínimo de monedas para alcanzarlo hasta ese punto. Al iterar sobre cada moneda disponible, actualizamos los valores de la tabla si usar esa moneda resulta en menos monedas totales que lo anterior. Este enfoque garantiza encontrar la solución óptima global evitando la explosión combinatoria típica de las soluciones recursivas ingenuas.

## Ejemplo (no ejecutado automáticamente)
Cálculo del mínimo número de monedas para obtener $6 usando denominaciones de $1, $2 y $5.

```python
def min_coins(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for coin in coins:
        for x in range(coin, amount + 1):
            dp[x] = min(dp[x], dp[x - coin] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1
```
