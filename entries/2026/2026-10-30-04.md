## Objetivo
Aprender a construir consultas seguras utilizando parámetros para evitar que los datos del usuario alteren la lógica de la consulta y comprometan la base de datos.

## Explicación
La inyección SQL ocurre cuando se concatenan directamente las entradas del usuario en una consulta. Para mitigar esto, los lenguajes modernos ofrecen APIs de parametrización. Estas herramientas envían la estructura de la consulta y los datos por separado al motor de base de datos. El motor interpreta siempre los parámetros como valores literales y nunca como parte del código SQL, bloqueando así cualquier intento de inyección maliciosa. Este enfoque es esencial para proteger aplicaciones web que manejan formularios de login o búsquedas.

## Ejemplo (no ejecutado automáticamente)
Consulta segura en Python usando un cursor parametrizado para buscar un usuario por nombre sin riesgo de inyección.

```python
cursor.execute("SELECT * FROM usuarios WHERE nombre = %s", (nombre_usuario,))
resultados = cursor.fetchall()
```
