## Objetivo
Comprender qué son los hooks en Git y cómo configurar un script pre-commit básico para validar el formato del código antes de cada envío, mejorando la calidad del repositorio desde el inicio.

## Explicación
Los hooks son scripts que Git ejecuta automáticamente en eventos específicos como commits o merges. El hook pre-commit se activa justo antes de guardar un commit. Este mecanismo permite automatizar tareas de calidad como formateo, detección de vulnerabilidades o verificación de tipos. En esta lección aprenderás a crear un script simple que use el comando 'prettier' para formatear archivos JavaScript automáticamente. Al configurar esto en tu proyecto, todos los desarrolladores recibirán feedback inmediato sobre errores de estilo sin necesidad de revisar manualmente cada archivo antes de enviar cambios.

## Ejemplo (no ejecutado automáticamente)
Script bash que invoca prettier para formatear todos los archivos js antes del commit

```bash
#!/bin/bash
find . -name '*.js' -exec prettier --write {} \;
```

## Ejercicio
Crea un archivo llamado .git/hooks/pre-commit en tu repositorio local. Copia el código del ejemplo dentro de este archivo, asegúrate de que sea ejecutable y prueba realizar un commit con archivos JavaScript desordenados para observar la corrección automática.

## Criterios de revisión
El archivo debe existir en la ruta correcta, tener permisos de ejecución y corregir automáticamente el formato de los archivos JS al intentar hacer un commit.
