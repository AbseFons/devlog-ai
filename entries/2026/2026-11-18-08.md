## Objetivo
Aprender a manipular rutas relativas y absolutas en Python utilizando la librería estándar pathlib, evitando errores comunes de separación de directorios entre sistemas operativos.

## Explicación
En esta microlección exploramos el uso de Path para construir rutas dinámicas. A diferencia de las cadenas simples, Path permite operaciones como unir componentes con / y detectar si un archivo existe sin lanzar excepciones inmediatas. Utilizaremos la propiedad .resolve() para obtener una ruta absoluta normalizada, lo cual es crucial cuando se trabaja con enlaces simbólicos o rutas relativas complejas. Este enfoque garantiza que tu código funcione tanto en Windows como en Linux sin modificaciones.

## Ejemplo (no ejecutado automáticamente)
Construcción de ruta absoluta y verificación de existencia para un archivo de configuración.

```python
from pathlib import Path
config = Path('app').resolve() / 'settings.json'
if config.exists():
    print(f'Archivo encontrado en: {config}')
```
