## Objetivo
Aprender a prevenir inyecciones SQL y XSS validando y sanitizando todas las entradas del usuario antes de procesarlas, asegurando la integridad de los datos y la seguridad de la aplicación.

## Explicación
La validación de entradas es la primera línea de defensa en seguridad. Consiste en verificar que los datos recibidos cumplan con un formato esperado (longitud, tipo, caracteres permitidos) y luego sanitizarlos para eliminar o escapar caracteres peligrosos. Por ejemplo, si una entrada espera un número entero, cualquier letra debe ser rechazada inmediatamente. Si se permite texto libre, se deben filtrar etiquetas HTML maliciosas antes de almacenarlas en la base de datos. Esta práctica reduce drásticamente el riesgo de ataques como SQL Injection o Cross-Site Scripting (XSS). Implementa siempre reglas estrictas y nunca confíes ciegamente en lo que envía el cliente.

## Ejemplo (no ejecutado automáticamente)
Función en JavaScript que valida si una entrada es un número entero positivo y la sanitiza antes de usarla en una consulta SQL parametrizada.

```javascript
function validarEntrada(entrada) {
  const regex = /^\d+$/;
  if (!regex.test(entrada)) throw new Error('Formato inválido');
  return parseInt(entrada, 10);
}
```
