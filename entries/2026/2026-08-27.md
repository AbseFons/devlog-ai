## Objetivo
El desarrollador podrá crear un archivo de prueba funcional que importe una clase existente, defina métodos de test decorados con @unittest.TestCase y verifique comportamientos específicos usando aserciones estándar sin depender de frameworks externos.

## Explicación
En esta microlección aprenderás a estructurar pruebas unitarias utilizando el framework nativo unittest de Python. Comenzaremos importando la clase que queremos probar y heredando de unittest.TestCase para habilitar las funcionalidades de prueba. Definiremos métodos que comienzan con 'test_' para que sean descubiertos automáticamente por el runner de pruebas. Utilizaremos aserciones como assertEqual o assertTrue para validar que la lógica interna funcione correctamente bajo diferentes escenarios. Este enfoque permite aislar funciones individuales, facilitando la detección temprana de errores y mejorando la calidad del código antes de integrarlo en sistemas más grandes.

## Ejemplo (no ejecutado automáticamente)
```python
import unittest

class Calculadora:
    def sumar(self, a, b):
        return a + b

class TestCalculadora(unittest.TestCase):
    def test_suma_positivos(self):
        calc = Calculadora()
        self.assertEqual(calc.sumar(2, 3), 5)
    
    def test_suma_con_cero(self):
        calc = Calculadora()
        self.assertEqual(calc.sumar(0, 10), 10)

if __name__ == '__main__':
    unittest.main()
```
