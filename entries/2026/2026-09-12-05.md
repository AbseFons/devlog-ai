## Objetivo
Comprender la definición de árbol binario, sus nodos raíz e hijos, y aplicar el algoritmo de recorrido preorden para visualizar la estructura jerárquica del árbol mediante una función recursiva básica.

## Explicación
Un árbol binario es una estructura de datos no lineal donde cada nodo tiene como máximo dos hijos: izquierdo y derecho. El recorrido preorden visita primero la raíz, luego el subárbol izquierdo y finalmente el derecho. Este método es útil para copiar árboles o generar expresiones prefixadas. La implementación recursiva simplifica la lógica al reducir el problema a subárboles más pequeños hasta llegar a nodos nulos.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python de un árbol binario simple con recorrido preorden que imprime los valores visitados en orden.

```python
class Nodo:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None

def preorden(nodo):
    if nodo is not None:
        print(nodo.valor)
        preorden(nodo.izquierdo)
        preorden(nodo.derecho)
```
