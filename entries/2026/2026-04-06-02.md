## Objetivo
Aprender a utilizar el patrón adaptador para permitir la interoperabilidad entre componentes con interfaces incompatibles, facilitando la integración de librerías legacy o sistemas externos sin modificar su código original.

## Explicación
El patrón adaptador actúa como un puente que permite que dos clases con interfaces incompatibles colaboren. Imagina una API de pago externa que solo acepta métodos síncronos, mientras tu sistema moderno usa asíncrono. El adaptador encapsula la lógica del proveedor externo y expone una interfaz compatible con tu arquitectura interna. Esto promueve el principio de sustitución de Liskov: el cliente interactúa con la nueva interfaz sin saber que detrás hay un componente antiguo. La clave reside en traducir las llamadas, manejar los tiempos de espera y normalizar los errores, asegurando que la funcionalidad subyacente se mantenga intacta mientras se adapta al nuevo contexto tecnológico.

## Ejemplo (no ejecutado automáticamente)
Clase adaptadora que envuelve una API REST síncrona antigua para exponerla como un servicio asíncrono moderno en JavaScript.

```javascript
class LegacyAdapter {
  constructor(oldApi) { this.oldApi = oldApi; }
  async process(data) { return this.oldApi.processSync(data); }
```
