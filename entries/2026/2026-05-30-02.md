## Objetivo
Diferenciar el uso de iteradores manuales con next() frente a la sintaxis lazy de los generadores para procesar flujos de datos infinitos o grandes sin consumir memoria excesiva.

## Explicación
En Python, un iterador es cualquier objeto que implementa next(), permitiendo recorrer secuencias. Sin embargo, cuando se manejan conjuntos masivos o datos ilimitados, los generadores (con yield) son superiores. A diferencia de las funciones que devuelven listas completas en memoria, los generadores producen elementos uno a uno bajo demanda. Esto reduce drásticamente el consumo RAM. Por ejemplo, leer millones de líneas de un log es viable con un generator expression, mientras que una lista convencional fallaría por falta de memoria. La sintaxis yield pausa la ejecución y guarda el estado local, retomándolo en la siguiente llamada.

## Ejemplo (no ejecutado automáticamente)
Generador que produce números pares infinitos hasta un límite definido por el usuario.

```python
def pares_infinitos(limite):
    n = 0
    while True:
        if n <= limite:
            yield n
            n += 2
        else:
            break

gen = pares_infinitos(10)
print(next(gen)) # 0
print(next(gen)) # 2
```
