## Objetivo
Aprender a identificar vulnerabilidades en librerías externas mediante escaneo automatizado, priorizar parches según la severidad del CVE y aplicar mitigaciones inmediatas sin interrumpir el flujo de trabajo del equipo de desarrollo.

## Explicación
Las dependencias de terceros son una fuente común de riesgos de seguridad. Un CVE (Common Vulnerabilities and Exposures) describe una vulnerabilidad específica. Para gestionarlas, primero se debe escanear el árbol de dependencias usando herramientas como npm audit o OWASP Dependency-Check. Al encontrar un CVE crítico, evalúa si la librería es esencial; si lo es, busca una versión parcheada disponible en el repositorio oficial. Si no hay parche inmediato, implementa reglas de firewall para bloquear tráfico malicioso asociado a esa vulnerabilidad o utiliza contenedores con imágenes personalizadas que eliminen la librería afectada. Documenta cada acción tomada y establece un proceso regular de revisión mensual.

## Ejemplo (no ejecutado automáticamente)
Ejecución de escaneo de dependencias en Node.js para detectar CVEs activos y generar reporte de vulnerabilidades críticas.

```bash
npm audit
npm install npm@latest --save-exact
```

## Ejercicio
Instala una aplicación web con librerías antiguas, ejecuta el comando de auditoría y documenta los CVEs encontrados junto con su nivel de riesgo.

## Criterios de revisión
Identificar al menos dos CVEs reales en dependencias comunes, proponer una solución técnica viable para mitigar uno de ellos y justificar la decisión basada en la severidad del impacto.
