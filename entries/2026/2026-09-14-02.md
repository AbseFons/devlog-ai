## Objetivo
Dominar la sintaxis básica para compartir código entre archivos en JavaScript utilizando módulos ES6, evitando la polución del ámbito global y promoviendo una arquitectura de software más modular y mantenible.

## Explicación
Los módulos ES permiten encapsular lógica en archivos independientes. Utilizamos 'export' para definir qué variables o funciones son accesibles desde fuera del archivo, y 'import' para traer esas dependencias a otros scripts. Esto crea un sistema de tipos implícito donde cada módulo es una unidad aislada. Al usar nombres por defecto o asignados con as, controlamos cómo se inyectan las funcionalidades en el contexto actual. Esta práctica es fundamental para construir aplicaciones escalables, ya que facilita la reutilización de componentes y simplifica la depuración al contener errores dentro del módulo específico donde ocurren.

## Ejemplo (no ejecutado automáticamente)
Un archivo calculadora.js exporta funciones matemáticas básicas que son importadas en un archivo principal para realizar operaciones sin afectar el ámbito global.

```javascript
export function sumar(a, b) {
  return a + b;
}

import { sumar } from './calculadora.js';
console.log(sumar(5, 3));
```
