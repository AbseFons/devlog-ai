## Objetivo
Comprender cómo las funciones anidadas acceden a variables del ámbito exterior incluso después de que la función externa haya terminado su ejecución, aprovechando el cierre del entorno léxico.

## Explicación
Un closure es una función que recuerda y mantiene acceso a sus variables de ámbito encerrante, incluso cuando se ejecuta fuera de ese contexto. En JavaScript, esto ocurre porque cada función lleva consigo su propio entorno léxico. Imagina una función 'crearSaludo' que recibe un nombre y devuelve otra función que imprime el mensaje. Aunque la función externa termine, la interna conserva la referencia al nombre. Esto permite crear funciones genéricas o callbacks personalizados sin pasar parámetros explícitamente en cada llamada, facilitando patrones como factories de funciones o controladores de eventos con estado persistente.

## Ejemplo (no ejecutado automáticamente)
Se define una función que genera un contador personalizado. Cada vez que se invoca la función devuelta, incrementa su propio valor interno gracias al closure que captura la variable 'contador'.

```javascript
function crearContador(inicial) {
  let contador = inicial;
  return function() {
    return ++contador;
  };
}
const miContador = crearContador(10);
console.log(miContador()); // 11
console.log(miContador()); // 12
```
