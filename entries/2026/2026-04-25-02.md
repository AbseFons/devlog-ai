## Objetivo
Comprender la definición y beneficios de las funciones puras, que dependen exclusivamente de sus argumentos y siempre retornan el mismo resultado para los mismos inputs, facilitando pruebas unitarias y mantenimiento del código.

## Explicación
Una función pura en Python es aquella donde el valor de retorno está determinado únicamente por sus parámetros de entrada. No produce efectos secundarios como modificar variables globales, escribir en consola o alterar objetos externos. Esto garantiza que la función sea predecible y aislada. Por ejemplo, una función que suma dos números siempre devolverá la misma suma sin importar cuándo se ejecute. Esta propiedad simplifica enormemente el proceso de depuración y permite refactorizar código con confianza, ya que cada unidad lógica opera de forma independiente del contexto global.

## Ejemplo (no ejecutado automáticamente)
Implementación de una función pura para calcular el área de un círculo basada únicamente en el radio.

```python
import math

def area_circulo(radio):
    return math.pi * radio ** 2

print(area_circulo(5))
```
