## Objetivo
Aprender a configurar un logger en Python que genere registros estructurados en formato JSON, facilitando el análisis de datos con herramientas modernas como Kibana o Splunk, e implementar rotación automática para gestionar volúmenes grandes.

## Explicación
En esta microlección avanzamos desde la configuración básica hasta la creación de un logger robusto. Utilizaremos el diccionario 'handlers' y 'formatters' del módulo logging para definir una salida JSON. Es crucial incluir campos como 'timestamp', 'level', 'logger_name' y 'message'. Para manejar grandes volúmenes, configuraremos un archivo con rotación por tamaño (MaxBytes=1048576) y backup limitado. Esto previene el llenado del disco y permite reconstruir eventos en orden cronológico sin perder contexto de la aplicación.

## Ejemplo (no ejecutado automáticamente)
Configuración de un logger que escribe en un archivo JSON con rotación automática por tamaño, ideal para entornos de producción.

```python
import logging
import json
from logging.handlers import RotatingFileHandler

logger = logging.getLogger('mi_app')
logger.setLevel(logging.INFO)
handler = RotatingFileHandler('app.log', maxBytes=1048576, backupCount=3)
formatter = logging.Formatter('%(asctime)s | %(levelname)s | %(name)s | %(message)s')
handler.setFormatter(formatter)
```
