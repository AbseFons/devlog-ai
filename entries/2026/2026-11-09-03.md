## Objetivo
Comprender cómo las funciones internas acceden a variables externas incluso después que la función externa ha terminado de ejecutarse, aprovechando el cierre del entorno lexical para crear datos persistentes sin estado global.

## Explicación
Un closure en JavaScript es una función que recuerda su entorno léxico original. Cuando una función se define dentro de otra, puede acceder a las variables de la función exterior. Al finalizar la ejecución de la función externa, esas variables no se liberan inmediatamente si hay referencias activas desde el interior. Esto permite encapsular lógica y datos privados. Por ejemplo, podemos crear un contador simple donde cada llamada devuelve una nueva función que incrementa su propio estado interno sin exponerlo al ámbito global. Esta técnica es fundamental para patrones como factories, currying y controladores de eventos en frameworks modernos.

## Ejemplo (no ejecutado automáticamente)
Se define una función 'crearContador' que retorna una función interna capaz de incrementar un valor privado cada vez que se invoca, demostrando la persistencia del estado gracias al closure.

```javascript
function crearContador() {
  let contador = 0;
  return function() {
    contador++;
    return contador;
  };
}
const miContador = crearContador();
console.log(miContador()); // 1
console.log(miContador()); // 2
```
