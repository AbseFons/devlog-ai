## Objetivo
Aprender a utilizar la biblioteca estándar argparse en Python para definir argumentos de línea de comandos, permitiendo que los usuarios pasen opciones como nombre de archivo o nivel de detalle sin modificar el código fuente del script.

## Explicación
La biblioteca argparse facilita la creación de interfaces de línea de comandos robustas. Permite definir parámetros posicionales y opcionales con descripciones claras. Al ejecutar el script, Python genera automáticamente un mensaje de ayuda detallado si se omite información. Este enfoque es esencial para herramientas de automatización donde los usuarios necesitan flexibilidad al invocar programas desde la terminal. Se manejan errores de uso incorrecto mostrando mensajes personalizados antes de detener la ejecución.

## Ejemplo (no ejecutado automáticamente)
Script que acepta un nombre de archivo y una flag opcional para mostrar estadísticas.

```python
import argparse
parser = argparse.ArgumentParser()
parser.add_argument('archivo', help='Nombre del archivo a procesar')
args = parser.parse_args()
```
