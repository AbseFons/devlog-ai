## Objetivo
Comprender la diferencia entre imagen (plantilla inmutable) y contenedor (instancia ejecutable), aprendiendo a construir una imagen básica y ejecutar un contenedor desde ella.

## Explicación
En Docker, la imagen es el archivo de plantillas que contiene todo lo necesario para ejecutar una aplicación: código, librerías y dependencias. Es inmutable. El contenedor es una instancia ligera y efímera creada a partir de esa imagen. Cuando ejecutas un comando 'run', Docker crea un contenedor basado en la imagen más reciente disponible. Las capas del sistema de archivos se comparten entre todos los contenedores derivados de la misma imagen, optimizando el uso de recursos. Esta arquitectura permite que las aplicaciones sean portables y consistentes entre diferentes entornos.

## Ejemplo (no ejecutado automáticamente)
Se crea una imagen personalizada 'mi-app' con un archivo simple en su interior y luego se ejecuta un contenedor interactivo basado en esa imagen para probarla.

```bash
echo '# Hola Mundo' > /tmp/app.txt
docker build -t mi-app .
docker run --rm -it mi-app cat /tmp/app.txt
```
