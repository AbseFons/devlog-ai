## Objetivo
Aprender a utilizar el patrón adaptador para integrar componentes con interfaces incompatibles sin modificar su código original, facilitando la evolución del sistema.

## Explicación
El patrón adaptador permite que dos clases con interfaces incompatibles colaboren. Imagina un módulo legacy que devuelve datos en formato 'LegacyResponse' y una nueva capa de negocio que espera 'ModernDTO'. En lugar de reescribir el código antiguo, creamos un adaptador que encapsula la clase legacy y traduce su salida al formato moderno. Esto promueve la coexistencia de sistemas antiguos con arquitecturas nuevas, reduciendo riesgos de regresión y manteniendo la inversión en código heredado.

## Ejemplo (no ejecutado automáticamente)
Clase adaptador que convierte una respuesta JSON antigua a un objeto DTO moderno.

```javascript
class LegacyAdapter {
  constructor(legacyService) { this.legacy = legacyService; }
  request() { return this.legacy.fetch().then(data => new ModernDTO(data.id, data.value)); }
}
```

## Ejercicio
Crea una clase 'LegacyAdapter' que acepte un servicio legacy y devuelva objetos 'ModernDTO' con las propiedades 'id' y 'value' extraídas de la respuesta del servicio.

## Criterios de revisión
El adaptador debe encapsular correctamente el servicio legacy, no modificar su código original y garantizar que la salida sea compatible con la nueva capa de negocio.
