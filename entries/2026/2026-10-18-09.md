## Objetivo
Diferenciar el uso de PUT para reemplazar recursos completos contra PATCH para actualizaciones parciales, asegurando integridad de datos en arquitecturas RESTful modernas.

## Explicación
En la serie de métodos HTTP Serie 3, PUT y PATCH son fundamentales para la actualización de recursos. PUT es idempotente y reemplaza el recurso entero con los datos enviados; si faltan campos, se pierden. Es ideal para sincronización total. Por otro lado, PATCH permite modificar solo los atributos específicos proporcionados en el cuerpo de la solicitud, dejando intactos los demás campos. Esto reduce el volumen de transferencia y minimiza riesgos de sobrescritura no intencionada. Ambos métodos requieren un verbo HTTP específico y suelen usarse con JSON. La elección depende de si la operación es total o parcial.

## Ejemplo (no ejecutado automáticamente)
Actualización parcial del estado de una tarea usando PATCH en Python con requests.

```python
import requests
response = requests.patch('https://api.ejemplo.com/tareas/123', json={'estado': 'pendiente'})
```
