## Objetivo
Aprender a encapsular código propenso a fallos dentro de bloques try-catch para prevenir la interrupción del flujo principal, permitiendo manejar excepciones específicas y mantener la estabilidad de la aplicación.

## Explicación
En JavaScript, el manejo de errores es crucial para la robustez. El bloque 'try' ejecuta código que podría fallar; si ocurre un error, se salta a 'catch'. Es vital no solo capturar la excepción genérica, sino inspeccionar el objeto error para entender su causa. Esto permite mostrar mensajes amigables al usuario o registrar detalles técnicos sin detener todo el sistema. Evita usar console.error en producción sin contexto; encapsula la lógica de recuperación dentro del catch para restaurar estados previos o ofrecer alternativas seguras.

## Ejemplo (no ejecutado automáticamente)
Intenta dividir un número por cero y captura el error específico para mostrar un mensaje personalizado al usuario en lugar de dejar la página en blanco.

```javascript
function dividirSeguro(a, b) {
  try {
    return a / b;
  } catch (error) {
    if (error instanceof RangeError) {
      console.log('No se puede dividir por cero');
      return null;
    }
    throw error;
  }
}
```

## Ejercicio
Crea una función que acepte un string y lo convierta a número. Usa try-catch para manejar el caso en que el string no sea numérico, logueando 'Entrada inválida' y devolviendo -1.

## Criterios de revisión
El código debe incluir bloques try y catch correctamente anidados. Debe verificar si el error es de tipo TypeError o SyntaxError antes de lanzar una excepción genérica. El mensaje de error debe ser claro y no exponer detalles internos del motor.
