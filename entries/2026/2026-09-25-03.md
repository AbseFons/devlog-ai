## Objetivo
Comprender la diferencia entre procesos y hilos, identificar cuándo usar threading para tareas I/O intensivas y reconocer las limitaciones de GIL en operaciones CPU pesadas.

## Explicación
En Python, el módulo threading permite ejecutar múltiples flujos de ejecución simultáneos dentro de un mismo proceso. A diferencia de los procesos, los hilos comparten memoria, lo que facilita la comunicación pero requiere cuidado con las variables compartidas. Es crucial entender que el GIL (Global Interpreter Lock) impide la ejecución real paralela de código CPU intensivo en hilos, haciendo que threading sea ideal para operaciones de E/S como redes o archivos. Para tareas computacionales pesadas, se recomienda multiprocessing. Este concepto es fundamental para construir aplicaciones escalables y responsivas.

## Ejemplo (no ejecutado automáticamente)
Script que descarga dos URLs simultáneamente usando hilos para reducir el tiempo total de espera comparado con la ejecución secuencial.

```python
import threading
import requests

def descargar(url):
    print(f"Descargando {url}")
    response = requests.get(url)
    return response.status_code

urls = ['https://example.com', 'https://httpbin.org/get']
hilos = []
for url in urls:
    t = threading.Thread(target=descargar, args=(url,))
    hilos.append(t)
    t.start()

for t in hilos:
    t.join()
```
