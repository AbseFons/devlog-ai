## Objetivo
Aprender a definir clases con atributos automáticos, métodos especiales y validaciones simples usando la herramienta dataclass de Python para agilizar el desarrollo de modelos de datos.

## Explicación
Los dataclasses permiten crear clases con atributos automáticamente, reduciendo código repetitivo. Se importan desde el módulo dataclasses y se decoran las clases con @dataclass. Esto genera automáticamente __init__, __repr__ y otros métodos útiles. Es ideal para representar entidades como usuarios o productos sin escribir boilerplate innecesario. Además, se pueden añadir parámetros como frozen=True para inmutabilidad o order=True para ordenar atributos en el string de representación.

## Ejemplo (no ejecutado automáticamente)
Definición de una clase dataclass simple que representa un producto con nombre y precio.

```python
from dataclasses import dataclass

@dataclass
class Producto:
    nombre: str
    precio: float
```
