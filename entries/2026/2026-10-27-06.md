## Objetivo
Aprender a encadenar Common Table Expressions para filtrar datos complejos antes de realizar agregaciones, mejorando la legibilidad del código al separar lógica de negocio de operaciones matemáticas.

## Explicación
Las CTEs permiten definir subconsultas temporales que se pueden referenciar múltiples veces. En este caso, utilizaremos una CTE intermedia para filtrar registros de ventas superiores a un umbral específico y otra para calcular métricas agregadas sobre ese conjunto filtrado. Este enfoque modular evita la anidación excesiva de cláusulas WHERE dentro de funciones de agregación, haciendo el SQL más mantenible.

## Ejemplo (no ejecutado automáticamente)
Se define una CTE llamada 'ventas_alta' que filtra pedidos con monto mayor a 500, y luego se usa para calcular el total promedio por categoría en la consulta final.

```sql
WITH ventas_alta AS (
    SELECT categoria, cantidad
    FROM pedidos
    WHERE monto > 500
)
SELECT categoria, AVG(cantidad) as promedio_cantidad
FROM ventas_alta
GROUP BY categoria;
```
