## Objetivo
Comprender cómo las claves foráneas vinculan tablas mediante la integridad referencial, asegurando que los datos en una tabla correspondan a registros existentes en otra, previniendo inconsistencias en bases de datos relacionales.

## Explicación
Una clave foránea es un campo o conjunto de campos en una tabla que hace referencia a la clave primaria de otra tabla. Su función principal es mantener la integridad referencial, garantizando que no existan registros huérfanos. Por ejemplo, si tenemos una tabla 'Pedidos' y una tabla 'Clientes', la columna 'cliente_id' en 'Pedidos' debe contener valores que coincidan con los existentes en 'clientes'. Al definir esta relación, el motor de base de datos controla las operaciones de inserción y actualización para evitar violaciones. Esto es fundamental en el diseño de esquemas robustos donde los datos dependen unos de otros.

## Ejemplo (no ejecutado automáticamente)
Definición de una clave foránea en una tabla de pedidos que referencia a la tabla de clientes, incluyendo restricciones de cascada.

```sql
CREATE TABLE Pedidos (
    id_pedido INT PRIMARY KEY,
    cliente_id INT NOT NULL,
    FOREIGN KEY (cliente_id) REFERENCES Clientes(id_cliente)
        ON DELETE CASCADE
        ON UPDATE CASCADE
);
```
