## Objetivo
Comprender y aplicar el principio de mínimo privilegio (PoLP) para reducir la superficie de ataque en sistemas, asegurando que cada entidad solo acceda a los recursos estrictamente necesarios para su funcionamiento específico.

## Explicación
El principio de mínimo privilegio establece que cualquier proceso, usuario o servicio debe poseer únicamente las autorizaciones mínimas requeridas para realizar sus tareas. Esto limita el daño potencial ante una brecha: si un componente comprometido intenta escalar privilegios o acceder a datos sensibles no autorizados, fallará automáticamente. En entornos modernos de microservicios y contenedores, es vital definir roles granulares en lugar de usar cuentas administrativas globales. Al aplicar PoLP, se fomenta una arquitectura defensiva donde la confianza no es implícita sino verificada por diseño, reduciendo significativamente el riesgo de propagación lateral de amenazas dentro de la infraestructura.

## Ejemplo (no ejecutado automáticamente)
Definición de un usuario con permisos restringidos para leer logs en un servidor Linux usando sudoers.

```bash
# Crear usuario 'auditor' sin acceso root
sudo useradd -m auditor
# Permitir solo lectura al directorio /var/log
sudo usermod -aG logreaders auditor
# Configurar regla en /etc/sudoers.d/auditor
printf '%s\n' 'auditor ALL=(ALL) NOPASSWD: /usr/bin/tail /var/log/*.log' | sudo tee /etc/sudoers.d/auditor > /dev/null
```
