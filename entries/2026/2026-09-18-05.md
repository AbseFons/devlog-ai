## Objetivo
Aprender a filtrar elementos complejos en listas utilizando expresiones condicionales anidadas y funciones integradas, optimizando el código sin bucles explícitos.

## Explicación
La comprensión de listas permite crear nuevas colecciones iterando sobre existentes. En esta serie 2, exploramos filtros múltiples. Sintaxis: [expresion for elemento in iterable if condicion1 if condicion2]. Esto es útil para limpiar datos con reglas estrictas. Ejemplo: extraer usuarios activos mayores de 18 años y con saldo positivo. Evita bucles 'for' tradicionales, haciendo el código más legible y conciso. Python evalúa condiciones de izquierda a derecha, cortando la iteración si una falla. Ideal para preprocesamiento de datos en análisis o ETL ligero.

## Ejemplo (no ejecutado automáticamente)
Filtrar usuarios activos mayores de 18 con saldo positivo desde un diccionario de registros.

```python
registros = [{'nombre': 'Ana', 'edad': 20, 'activo': True, 'saldo': 50}, {'nombre': 'Luis', 'edad': 17, 'activo': True, 'saldo': 30}]
usuarios_validos = [u for u in registros if u['edad'] > 18 and u['activo'] and u['saldo'] > 0]
```
