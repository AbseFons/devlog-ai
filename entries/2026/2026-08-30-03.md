## Objetivo
Al finalizar esta lección, el desarrollador será capaz de configurar un registro básico en Python utilizando diccionarios para estructurar mensajes, facilitando la filtración y análisis de logs sin dependencias externas complejas.

## Explicación
El logging estructurado transforma registros de texto plano en datos JSON legibles por máquinas. Esto permite a los sistemas de monitoreo extraer métricas automáticamente. En Python, podemos lograr esto manualmente formateando cada mensaje como una cadena JSON dentro del logger estándar o usando librerías especializadas. Para esta serie 1, nos enfocaremos en la implementación nativa: crear un diccionario con metadatos como timestamp, nivel y servicio, convertirlo a string JSON y pasarlo al método log(). Este enfoque evita dependencias pesadas y enseña los fundamentos de la serialización antes de migrar a herramientas avanzadas.

## Ejemplo (no ejecutado automáticamente)
```python
import logging
import json
from datetime import datetime

def crear_log_estructurado(mensaje, nivel='INFO', servicio='app-principal'):
    datos = {
        'timestamp': datetime.now().isoformat(),
        'nivel': nivel,
        'servicio': servicio,
        'mensaje': mensaje
    }
    logging.basicConfig(format='%(message)s', level=logging.INFO)
    logging.info(json.dumps(datos))

crear_log_estructurado('Usuario autenticado exitosamente')
```

1. Cada salida debe ser una línea única válida JSON.
2. El campo 'timestamp' debe estar en formato ISO 8601.
3. No se deben incluir caracteres extraños fuera del bloque JSON.
4. El nivel de log debe coincidir con el tipo de evento descrito.
