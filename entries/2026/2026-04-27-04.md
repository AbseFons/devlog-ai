## Objetivo
Aprender a utilizar bloques try-except para prevenir que errores inesperados detengan la ejecución del programa, permitiendo un flujo de control más robusto y amigable para el usuario final.

## Explicación
En Python, las excepciones interrumpen la ejecución normal cuando ocurren errores como división por cero o acceso a archivos inexistentes. El bloque try ejecuta el código potencialmente arriesgado. Si surge una excepción específica, el bloque except captura el error y permite manejarlo sin detener la aplicación. Esto es crucial para crear software resiliente. Por ejemplo, podemos mostrar un mensaje de error personalizado en lugar de un traceback crudo. Es fundamental ser específico con los tipos de excepción capturados cuando sea posible, aunque a veces se usa una cláusula genérica como Exception para capturar cualquier fallo no manejado previamente.

## Ejemplo (no ejecutado automáticamente)
Intenta dividir dos números; si el denominador es cero, muestra un mensaje amigable en lugar de colapsar.

```python
def segura_dividir(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        print("Error: No se puede dividir por cero.")

resultado = segura_dividir(10, 2)
print(f"Resultado: {resultado}")
```
