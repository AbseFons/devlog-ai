## Objetivo
Implementar un hook pre-commit que impida el commit si faltan dependencias críticas en el archivo package.json, asegurando la integridad del entorno de desarrollo antes de fusionar código.

## Explicación
Este ejercicio crea un script bash que se ejecuta automáticamente antes de cada commit. El script lee el archivo package.json del repositorio actual y verifica si existen nodulos definidos en 'dependencies' o 'devDependencies'. Si el archivo no existe o está vacío, el hook aborta el proceso con un mensaje claro indicando la falta de configuración básica. Esto previene commits accidentales en repositorios nuevos o mal configurados, obligando al desarrollador a inicializar correctamente el proyecto npm antes de continuar. La implementación utiliza comandos estándar del sistema para evitar dependencias externas complejas.

## Ejemplo (no ejecutado automáticamente)
Script bash que verifica la existencia y contenido mínimo de package.json antes de permitir un commit.

```bash
# Verificar si existe package.json
if [ ! -f "package.json" ]; then
  echo "Error: Falta package.json. Inicializa el proyecto primero." >&2
  exit 1
fi
# Validar que tenga al menos una dependencia
deps=$(jq '.dependencies | keys | length' package.json)
if [ "$deps" -eq 0 ] && [ -z "$(jq '.devDependencies | keys | length' package.json)" ]; then
  echo "Error: No se encontraron dependencias definidas." >&2
  exit 1
fi
```

## Ejercicio
Crea un repositorio Git vacío, ejecuta 'npm init -y' para generar un archivo básico, luego modifica el hook pre-commit existente para que falle si el package.json no tiene al menos una entrada en 'dependencies'. Prueba intentando hacer commit sin dependencias y luego con una.

## Criterios de revisión
El script debe detener el commit con mensaje de error legible si falta package.json o si este no contiene dependencias. Debe permitir el commit cuando se añada una dependencia válida.
