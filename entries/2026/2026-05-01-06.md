## Objetivo
Comprender la definición de idempotencia en APIs REST y su importancia para garantizar que múltiples solicitudes idénticas produzcan el mismo efecto, evitando duplicidad de datos o errores de estado.

## Explicación
La idempotencia es una propiedad crítica en las APIs REST donde realizar la misma operación múltiples veces con los mismos parámetros produce un resultado único e indistinguible. Esto es vital para operaciones como crear recursos (POST) o actualizar estados (PUT/PATCH). Si un cliente reenvía una solicitud debido a una pérdida de red, el servidor no debe ejecutar la acción dos veces. Por ejemplo, enviar dos peticiones para 'pagar' una factura debería resultar en un solo cobro exitoso, no en dos. Las operaciones seguras suelen ser GET y HEAD, mientras que POST y PUT requieren mecanismos como cabeceras 'Idempotency-Key' para lograr esta propiedad sin comprometer la integridad de los datos.

Implementación de un endpoint POST con soporte para idempotencia usando una cabecera personalizada en Node.js.

const express = require('express');
const app = express();
app.post('/transferir', (req, res) => {
  const key = req.headers['idempotency-key'];
  if (!key) return res.status(400).json({ error: 'Falta Idempotency-Key' });

});

## Criterios de revisión
El código debe validar la presencia de la cabecera 'Idempotency-Key'. Al enviar la misma solicitud dos veces con la misma clave, la segunda respuesta no debe ejecutar la lógica de negocio principal ni generar efectos secundarios en la base de datos.
