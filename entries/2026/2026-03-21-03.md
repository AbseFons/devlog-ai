## Objetivo
Comprender que una operación idempotente produce el mismo resultado final independientemente de cuántas veces se ejecute. Aprender a diseñar endpoints POST y PUT que manejen correctamente solicitudes repetidas sin efectos secundarios no deseados, protegiendo la integridad de los datos en sistemas distribuidos.

## Explicación
La idempotencia es un principio fundamental en APIs REST para operaciones de escritura. Significa que realizar una acción múltiples veces tiene el mismo efecto que ejecutarla una sola vez. Por ejemplo, enviar dos peticiones POST para crear un usuario debe resultar en la creación de un solo registro, no en duplicados. Esto es crucial ante fallos de red o reintentos automáticos. Los métodos GET y HEAD son idempotentes por definición, pero los métodos de escritura como POST, PUT y DELETE requieren diseño consciente. Un endpoint PUT actualizando un recurso debe ignorar cambios si el estado del servidor ya coincide con la solicitud. Implementar cabeceras como 'Idempotency-Key' permite a los clientes garantizar que una operación específica no se repita, incluso si el servidor responde erróneamente.

## Ejemplo (no ejecutado automáticamente)
Endpoint PUT que actualiza un usuario verificando si el estado ya coincide con la solicitud para evitar duplicados o cambios innecesarios.

```javascript
async function actualizarUsuario(id, datos) {
  const respuesta = await fetch(`/api/usuarios/${id}`, { method: 'PUT', body: JSON.stringify(datos) });
  if (respuesta.status === 409) throw new Error('Conflicto de recursos');
  return respuesta.json();
}
```

## Ejercicio
Crea un endpoint POST que registre una transacción financiera. Asegúrate de que si se envía la misma solicitud dos veces, el saldo final del usuario sea idéntico al resultado de una sola ejecución.

## Criterios de revisión
El código debe verificar la unicidad de la transacción antes de procesarla o devolver un estado 200/204 indicando éxito sin duplicar registros. Debe manejar errores de red simulados reintentando la operación con lógica idempotente.
