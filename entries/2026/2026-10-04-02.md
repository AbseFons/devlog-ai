## Objetivo
Comprender cómo el Event Loop gestiona la concurrencia en JavaScript, diferenciando entre ejecución síncrona en el hilo principal y tareas asíncronas en la cola de macrotareas.

## Explicación
El Event Loop es el mecanismo que permite a JavaScript ser no bloqueante. Cuando una función asíncrona se ejecuta, su callback se coloca en la cola de macrotareas (Task Queue). El hilo principal ejecuta código síncrono inmediatamente; si encuentra una operación asíncrona, la delega y continúa. Una vez que el pila de llamadas (Call Stack) está vacío, el Event Loop verifica si hay tareas pendientes en la cola. Si es así, mueve el callback a la pila para su ejecución. Este ciclo constante asegura que las operaciones I/O no detengan la interfaz de usuario.

## Ejemplo (no ejecutado automáticamente)
Ejemplo mostrando la diferencia entre setTimeout (macrotarea) y una función síncrona dentro del mismo script.

```javascript
console.log('Inicio');
setTimeout(() => console.log('Tarea asíncrona'), 0);
console.log('Fin');
```
