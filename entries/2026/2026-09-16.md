## Objetivo
Comprender cómo las funciones internas acceden a variables externas incluso después de que la función externa ha terminado de ejecutarse, aprovechando el cierre del entorno léxico.

## Explicación
Un closure es una función que recuerda su contexto léxico original. En JavaScript, cuando una función se define dentro de otra, puede acceder a las variables de la función exterior. Al ejecutarse la función externa y retornar la interna, esta última mantiene viva la referencia a esas variables externas en la memoria. Esto permite crear funciones con estado privado o configuraciones dinámicas sin exponer datos innecesarios al ámbito global. Es fundamental para patrones como factories o controladores de eventos asincrónicos.

## Ejemplo (no ejecutado automáticamente)
Se crea una función que devuelve otra capaz de incrementar un contador privado, demostrando cómo el closure preserva el estado entre llamadas.

```javascript
function crearContador() {
  let cuenta = 0;
  return function() { cuenta++; return cuenta; };
}
const miContador = crearContador();
console.log(miContador()); // 1
console.log(miContador()); // 2
```
