## Objetivo
Comprender el concepto de atomicidad en bases de datos, asegurando que las operaciones se ejecuten completamente o no se ejecuten en absoluto para mantener la integridad del sistema.

## Explicación
La atomicidad es la primera propiedad de las transacciones ACID. Garantiza que una transacción sea tratada como una unidad indivisible: todas sus operaciones deben completarse con éxito o ninguna debe aplicarse. Si ocurre un fallo durante el proceso, el sistema utiliza mecanismos de rollback para revertir los cambios parciales, evitando estados inconsistentes. Esto es crucial en sistemas financieros donde un movimiento de dinero entre cuentas debe reflejarse simultáneamente en ambas; si falla en una cuenta, no debe afectar a la otra.

## Ejemplo (no ejecutado automáticamente)
Script SQL que simula una transferencia atómica entre dos cuentas usando bloques transaccionales básicos.

```sql
BEGIN TRANSACTION;
UPDATE cuentas SET saldo = saldo - 100 WHERE id = 1;
UPDATE cuentas SET saldo = saldo + 100 WHERE id = 2;
```
