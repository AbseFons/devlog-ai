## Objetivo
Aprender a almacenar contraseñas utilizando funciones de hash lentas y salts únicos para prevenir ataques de fuerza bruta y diccionario, asegurando la integridad del sistema de autenticación en aplicaciones modernas.

## Explicación
Para proteger las contraseñas, nunca se deben guardar en texto plano. Se utiliza una función de hashing diseñada para ser computacionalmente costosa, como Argon2 o bcrypt, que incluye un 'salt' único por usuario. Este sal es una cadena aleatoria que se combina con la contraseña antes del hash, impidiendo que ataques de diccionario funcionen contra múltiples usuarios simultáneamente. Al registrar el hash y el salt en la base de datos, al momento del login, el sistema recalcula el hash con el mismo salt y lo compara. Esto garantiza que incluso si dos usuarios tienen la misma contraseña, sus hashes sean distintos, protegiendo la confidencialidad de las credenciales frente a filtraciones de datos.

## Ejemplo (no ejecutado automáticamente)
Generación de un hash seguro para una contraseña usando Python con la librería bcrypt.

```python
import bcrypt
password = 'MiContraseñaSegura123'
salt = bcrypt.gensalt()
hashed_password = bcrypt.hashpw(password.encode('utf-8'), salt)
print(hashed_password.decode('utf-8'))
```
