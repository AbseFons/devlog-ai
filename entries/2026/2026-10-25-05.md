## Objetivo
Aprender a importar módulos JavaScript solo cuando se necesitan recursos específicos, optimizando el rendimiento inicial de la aplicación mediante carga diferida.

## Explicación
En lugar de cargar todos los módulos al inicio, podemos utilizar funciones de fábrica para crear importadores dinámicos. Esto permite evaluar condiciones en tiempo de ejecución antes de requerir un módulo pesado, como librerías gráficas o procesadores de datos complejos. Al encapsular la lógica de importación dentro de una función, evitamos errores de referencia y mantenemos el código limpio. Este patrón es esencial para aplicaciones escalables donde no todos los usuarios utilizan todas las funcionalidades disponibles.

## Ejemplo (no ejecutado automáticamente)
Función que importa un módulo de gráficos solo si la propiedad 'visualizar' es verdadera, evitando carga innecesaria.

```javascript
const cargarGraficos = (necesario) => {
  if (necesario) { return import('./graficos.js'); }
}
```

## Ejercicio
Crea un archivo 'utils.js' con una función 'procesarDatos()' y otro 'app.js'. En 'app.js', define una variable 'modoRendimiento' como false. Usa la función de importación dinámica para cargar 'utils.js' solo si 'modoRendimiento' es true.

## Criterios de revisión
El código debe importar el módulo condicionalmente sin errores de referencia, y la función de carga debe retornar una promesa válida cuando la condición se cumple.
