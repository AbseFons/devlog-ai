## Objetivo
Comprender cómo el Event Loop gestiona tareas síncronas y asincrónicas en JavaScript, permitiendo la no bloqueante ejecución de código asíncrono como lecturas de archivos o peticiones HTTP sin detener la interfaz del usuario.

## Explicación
JavaScript es un lenguaje de ejecución única hilos. Para manejar operaciones lentas como llamadas a servidores, utiliza el Event Loop. Este mecanismo coordina el Call Stack (tareas síncronas) con el Callback Queue (tareas asincrónicas completadas). Cuando una tarea asíncrona termina, su callback se mueve al Callback Queue. El Event Loop verifica constantemente si el Call Stack está vacío; si lo está, toma un callback de la cola y lo ejecuta. Esto evita que la aplicación se congele mientras espera respuestas externas, manteniendo la interfaz reactiva.

## Ejemplo (no ejecutado automáticamente)
Ejemplo demostrativo de cómo una promesa resuelta mueve el callback al Callback Queue antes de ser procesada por el Event Loop una vez vacío el Call Stack.

```javascript
const delay = (ms) => new Promise(resolve => setTimeout(resolve, ms));

console.log('Inicio');
delay(1000).then(() => console.log('Finalizado después de 1s'));
console.log('Continuando...');
```
