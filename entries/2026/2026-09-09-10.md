## Objetivo
Comprender cómo estructurar una aplicación separando la lógica de negocio de la persistencia de datos para mejorar la escalabilidad y el mantenimiento del código en arquitecturas modernas.

## Explicación
En esta lección exploramos la implementación de una arquitectura por capas donde el controlador recibe peticiones HTTP, delega la lógica a un servicio de dominio y consulta una base de datos externa. Esta separación permite que cada capa evolucione independientemente. El ejemplo utiliza JavaScript con Node.js para simular una API REST simple. Observaremos cómo encapsular la conexión a la base de datos en una capa dedicada, evitando acoplarla directamente al controlador. Esto facilita las pruebas unitarias y el despliegue escalable.

## Ejemplo (no ejecutado automáticamente)
Implementación de un endpoint GET que consulta usuarios desde una capa de acceso a datos separada.

```javascript
const db = require('./data-layer');
app.get('/users', async (req, res) => {
  const users = await db.fetchAllUsers();
  res.json(users);
});
```

## Ejercicio
Crea una función en la capa de datos que simule un retraso de red y luego devuelva un array de objetos con id y nombre.

## Criterios de revisión
El código debe mostrar claramente la separación entre el controlador y la capa de datos, utilizando promesas para manejar la asincronía.
