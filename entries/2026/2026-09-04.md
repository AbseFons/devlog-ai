## Objetivo
Aprender a definir clases con atributos y métodos automáticos usando la función dataclass, simplificando el boilerplate de código para modelos de datos simples.

## Explicación
Los dataclasses permiten crear clases donde los atributos se definen como parámetros de una función. Al decorar la clase con @dataclass, Python genera automáticamente el constructor __init__, métodos __repr__ y __eq__. Esto reduce drásticamente la cantidad de código necesario para representar entidades como registros de usuario o productos. Es ideal para estructuras de datos inmutables o casi inmutables donde no se requiere lógica compleja de negocio dentro de la clase, manteniendo el código limpio y legible.

## Ejemplo (no ejecutado automáticamente)
Definición de una clase Product usando dataclass con atributos nombre, precio y stock.

```python
from dataclasses import dataclass

@dataclass
class Product:
    name: str
    price: float
    stock: int
```
