## Objetivo
Aprender a identificar vulnerabilidades en librerías de terceros mediante escaneo automatizado, interpretar reportes de CVE y aplicar parches o mitigaciones inmediatas para proteger la integridad del software.

## Explicación
Las dependencias externas son una fuente común de vulnerabilidades. Un CVE (Common Vulnerabilities and Exposures) identifica una falla específica. El flujo de trabajo incluye: escanear el árbol de paquetes con herramientas como npm audit o pip-audit, revisar la severidad del CVE y decidir entre actualizar la librería afectada, forzar una versión segura o aplicar un parche temporal en el código. Ignorar estos avisos expone la aplicación a ataques remotos. La responsabilidad recae en el ingeniero de mantener el inventario actualizado.

## Ejemplo (no ejecutado automáticamente)
Script de bash que ejecuta un escaneo de vulnerabilidades en un proyecto Node.js y filtra resultados críticos.

```bash
npm install -g npm-check-updates
ncu --upgrade && npm audit --audit-level=high
```

## Ejercicio
Ejecuta el comando proporcionado en un entorno de Node.js. Revisa la salida y documenta al menos una dependencia con CVE crítico, su versión vulnerable y la versión recomendada para mitigar el riesgo.

## Criterios de revisión
Identificación correcta del comando de escaneo, interpretación precisa del nivel de severidad del CVE reportado y propuesta viable de actualización o mitigación basada en la documentación oficial.
