## Objetivo
Aprender a seleccionar elementos HTML específicos mediante selectores CSS y alterar sus propiedades en tiempo real, sentando las bases para la interactividad dinámica.

## Explicación
La manipulación del DOM permite interactuar con el contenido de una página web. Utilizamos métodos como document.querySelector para obtener un elemento único basado en su selector CSS. Una vez obtenido el nodo, podemos acceder a sus propiedades o modificarlas directamente. Por ejemplo, cambiar el estilo visual o el texto contenido. Es crucial entender que los selectores deben ser precisos y que las modificaciones se reflejan instantáneamente en el navegador, permitiendo crear interfaces reactivas sin recargar la página.

## Ejemplo (no ejecutado automáticamente)
Seleccionamos un párrafo por su ID y cambiamos su color de fondo al hacer clic en un botón.

```javascript
const parrafo = document.getElementById('texto');
parrafo.style.backgroundColor = 'lightblue';
```
