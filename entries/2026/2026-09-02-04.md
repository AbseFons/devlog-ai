## Objetivo
Al finalizar esta lección, el desarrollador será capaz de crear un script en Python que utilice la librería estándar argparse para definir y capturar al menos dos argumentos posicionales obligatorios, validando su uso mediante mensajes de error claros si faltan.

## Explicación
La librería argparse facilita la creación de interfaces de línea de comandos robustas. En esta primera entrega, nos enfocamos en los argumentos posicionales, que se pasan al script sin precederlos por un guion (-) o dos puntos (:). Para definirlos, utilizamos el método add_argument() dentro del objeto ArgumentParser. Es crucial especificar si un argumento es obligatorio (default=None) y proporcionar una descripción clara para la ayuda automática. argparse procesa estos datos en orden; si falta uno obligatorio, detiene la ejecución e informa al usuario qué falta. Esta estructura base permite construir scripts reutilizables donde el orden de los parámetros define su significado, ideal para herramientas de procesamiento de archivos o análisis de datos simples.

## Ejemplo (no ejecutado automáticamente)
```python
import argparse

def main():
    parser = argparse.ArgumentParser(description='Procesa dos archivos de texto.')
    parser.add_argument('archivo_origen', help='Nombre del archivo a leer.')
    parser.add_argument('archivo_destino', help='Nombre del archivo donde escribir el resultado.')
    args = parser.parse_args()
    
    print(f'Lee: {args.archivo_origen}')
    print(f'Escribe: {args.archivo_destino}')

if __name__ == '__main__':
    main()
```
