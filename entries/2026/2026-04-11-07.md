## Objetivo
Comprender cómo las funciones internas acceden a variables del ámbito exterior incluso después de que esa función haya terminado de ejecutarse, permitiendo crear funciones con estado privado.

## Explicación
Un closure es una función que recuerda su entorno léxico original. En JavaScript, cuando una función se define dentro de otra, puede acceder a las variables de la función externa. Aunque la función externa termine, la interna mantiene referencias a esas variables. Esto permite encapsular datos y lógica sin exponerlos globalmente. Es fundamental para patrones como factories o módulos simples.

## Ejemplo (no ejecutado automáticamente)
Se define una función que crea un contador privado incrementando su valor interno en cada llamada, demostrando el estado persistente gracias al closure.

```javascript
function crearContador() {
  let cuenta = 0;
  return function() {
    cuenta++;
    return cuenta;
  };
}
```
