## Objetivo
Comprender la asincronía en JavaScript mediante Promesas, aprender a estructurar código asíncrono legible con async/await y evitar el uso excesivo de callbacks.

## Explicación
En JavaScript moderno, las Promesas son objetos que representan el resultado eventual de una operación asíncrona. Pueden estar pendientes, resueltas o rechazadas. El método async/await simplifica la escritura de código asíncrono, permitiendo tratar llamadas asíncronas como si fueran sincrónicas. Esto mejora la legibilidad y evita la pirámide del infierno de callbacks. Se recomienda usar try/catch para manejar errores en operaciones asíncronas.

## Ejemplo (no ejecutado automáticamente)
Ejemplo de llamada a una API simulada con async/await para obtener datos de usuario.

```javascript
async function obtenerUsuario() {
  const respuesta = await fetch('https://jsonplaceholder.typicode.com/users/1');
  return respuesta.json();
}
```
