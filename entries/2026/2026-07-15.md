## Objetivo
Diferenciar claramente entre autenticación (quién eres) y autorización (qué puedes hacer) en el contexto de APIs REST, estableciendo la base para diseñar sistemas seguros.

## Explicación
En seguridad de APIs, autenticación verifica la identidad del usuario mediante credenciales como tokens JWT o sesiones. Autorización determina los permisos específicos de ese usuario identificado sobre recursos protegidos. Una API puede autenticar exitosamente a un usuario pero denegar acceso si no tiene el rol adecuado. Por ejemplo, un token válido para leer perfiles públicos no debería permitir editar datos privados. Implementar ambos mecanismos por separado asegura que la identidad sea verificada antes de evaluar permisos, evitando vulnerabilidades donde usuarios maliciosos accedan a funciones no asignadas.
