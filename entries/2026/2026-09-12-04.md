## Objetivo
Introducir al desarrollo concurrente en Python utilizando el módulo threading para ejecutar tareas simultáneas, mejorando la eficiencia en operaciones de E/S.

## Explicación
En Python, la concurrencia se logra mediante hilos (threads) gracias a su naturaleza interpretada y el bloqueo del GIL. Este enfoque es ideal para tareas de entrada/salida como lecturas de red o disco. El código crea dos hilos independientes que imprimen mensajes con un pequeño retraso simulado. Al finalizar, se espera la terminación de ambos hilos antes de cerrar el programa principal. Esta estructura permite aprovechar mejor los recursos del sistema sin bloquear la ejecución de otras tareas mientras una espera a completar su proceso.

## Ejemplo (no ejecutado automáticamente)
Ejemplo de creación y ejecución de dos hilos que imprimen mensajes con un retraso simulado.

```python
import threading
import time
def tarea(nombre, retardo):
    print(f'{nombre} comienza')
    time.sleep(retardo)
    print(f'{nombre} termina')
t1 = threading.Thread(target=tarea, args=('Hilo 1', 2))
t2 = threading.Thread(target=tarea, args=('Hilo 2', 1))
t1.start()
t2.start()
```
