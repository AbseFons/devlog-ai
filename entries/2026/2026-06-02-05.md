## Objetivo
Dominar la sintaxis básica de Common Table Expressions (CTE) para simplificar consultas complejas, mejorar la legibilidad y reutilizar lógica en SQL moderno.

## Explicación
Las CTE permiten definir un conjunto de resultados temporalmente antes de ejecutar una consulta principal. Se declaran con la palabra clave WITH seguida del nombre y la definición entre paréntesis. Esto facilita desglosar operaciones complejas como joins múltiples o cálculos recursivos en pasos lógicos claros. A diferencia de las subconsultas anidadas, las CTE se leen de arriba a abajo, mejorando la mantenibilidad del código sin sacrificar rendimiento en la mayoría de los sistemas modernos.

## Ejemplo (no ejecutado automáticamente)
Consulta que utiliza una CTE para calcular el salario total por departamento antes de filtrar los resultados finales.

```sql
WITH SalariosPorDept AS (
    SELECT id_departamento, SUM(sueldo) as total_sueldo
    FROM empleados
    GROUP BY id_departamento
)
SELECT * FROM SalariosPorDept WHERE total_sueldo > 50000;
```

## Ejercicio
