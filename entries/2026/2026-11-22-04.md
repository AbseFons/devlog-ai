## Objetivo
Aprender a utilizar Common Table Expressions (CTEs) para calcular métricas de ventaneamiento dinámicas, como el promedio móvil de ventas por usuario, mejorando la legibilidad del código frente a subconsultas anidadas complejas.

## Explicación
Las CTEs permiten definir conjuntos de datos temporales que se pueden referenciar múltiples veces dentro de una consulta principal. En este caso, utilizaremos una CTE para calcular el promedio móvil de ventas de cada cliente en los últimos 3 meses. Primero, filtramos las transacciones recientes y calculamos la suma total por usuario. Luego, en la consulta final, agrupamos estos datos por fecha y aplicamos una ventana que mira hacia atrás tres periodos. Este enfoque modular hace que el código sea más fácil de mantener y depurar que las subconsultas anidadas tradicionales.

## Ejemplo (no ejecutado automáticamente)
Consulta SQL que calcula el promedio móvil de ventas de los últimos 3 meses por cliente usando una CTE.

```sql
WITH VentasRecientes AS (
    SELECT cliente_id, fecha_venta, SUM(monto) as total_ventas
    FROM transacciones
    WHERE fecha_venta >= DATE_SUB(CURDATE(), INTERVAL 3 MONTH)
    GROUP BY cliente_id, fecha_venta
)
SELECT *, AVG(total_ventas) OVER (PARTITION BY cliente_id ORDER BY fecha_venta ROWS BETWEEN 2 PRECEDING AND CURRENT ROW) as promedio_movil
FROM VentasRecientes;
```
