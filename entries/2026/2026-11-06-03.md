## Objetivo
Aprender a implementar paginación eficiente utilizando cursores para evitar problemas de ordenamiento y manejar grandes volúmenes de datos sin sobrecargar la memoria del cliente.

## Explicación
La paginación por cursor es superior a la paginación numérica cuando los datos no están estrictamente ordenados o cambian frecuentemente. En lugar de usar un índice numérico, se extrae el valor más pequeño (o mayor) del último elemento devuelto en la respuesta anterior como parámetro de filtrado para la siguiente solicitud. Este método garantiza que nunca se pierdan registros ni se dupliquen, incluso si hay inserciones o actualizaciones entre peticiones. Es ideal para feeds de noticias, logs de auditoría o catálogos dinámicos donde el orden cronológico lógico puede alterarse por actualizaciones en tiempo real.

## Ejemplo (no ejecutado automáticamente)
Solicitud GET a una API ficticia que devuelve usuarios paginados usando un cursor basado en el ID del último elemento.

```javascript
const response = await fetch('https://api.ejemplo.com/usuarios?cursor=105&limit=20');
const data = await response.json();
console.log(data.items);
if (data.next_cursor) {
  const nextResponse = await fetch(`https://api.ejemplo.com/usuarios?cursor=${data.next_cursor}&limit=20`);
  const nextItems = await nextResponse.json();
  console.log(nextItems.items);
}
```

## Ejercicio
Crea un script que simule una API local devolviendo un array de objetos con IDs consecutivos. Implementa una función 'fetchPagina' que acepte un cursor y un límite, devuelva los datos y actualice el cursor para la siguiente llamada si existen más elementos.

## Criterios de revisión
El código debe manejar correctamente el caso base (primer página sin cursor), la lógica de actualización del cursor usando el último ID recibido y detenerse cuando no haya más datos. Debe incluir manejo básico de errores de red.
