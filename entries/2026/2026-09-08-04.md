## Objetivo
Comprender cómo el motor V8 gestiona la ejecución asíncrona mediante colas de tareas (macrotareas) y microtareas, diferenciando su impacto en el orden de renderizado del DOM.

## Explicación
El Event Loop es el mecanismo que permite a JavaScript ser no bloqueante. Cuando se ejecuta una función asíncrona como fetch o setTimeout, el código principal continúa mientras la tarea se mueve a la cola de macrotareas. Sin embargo, las promesas (async/await) colocan sus callbacks en la cola de microtareas. El motor prioriza siempre la cola de microtareas sobre la de macrotareas antes de volver al hilo principal. Esto significa que un setTimeout con 0ms puede ejecutarse después de una promesa resuelta, ya que esta última tiene mayor prioridad. Entender este orden es crucial para depurar problemas de renderizado donde el DOM no se actualiza inmediatamente tras una operación asíncrona.

## Ejemplo (no ejecutado automáticamente)
Ejemplo demostrando la diferencia de ejecución entre setTimeout y Promise.then en el hilo principal.

```javascript
console.log('Inicio');
setTimeout(() => console.log('Timeout'), 0);
promise.then(() => console.log('Promise'));
console.log('Fin');
```
