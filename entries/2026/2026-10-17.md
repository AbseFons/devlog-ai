## Objetivo
Comprender cómo el motor de JavaScript maneja tareas síncronas y asincrónicas mediante la cola de tareas y la pila, diferenciando ejecución bloqueante de operaciones no bloqueantes.

## Explicación
JavaScript es un lenguaje de un solo hilo que utiliza una pila de ejecución para gestionar tareas síncronas. Cuando una función asíncrona como setTimeout se ejecuta, su callback se mueve a la cola de tareas macro. El Event Loop vigila constantemente si la pila está vacía; si lo está, transfiere el primer elemento de la cola al contexto de ejecución. Esto permite que operaciones I/O no bloqueen la interfaz del usuario. Sin este mecanismo, cada llamada asíncrona detendría el hilo hasta completarse, haciendo la aplicación lenta e inestable.

## Ejemplo (no ejecutado automáticamente)
Un script que demuestra cómo setTimeout se ejecuta después de las tareas síncronas inmediatas gracias al Event Loop.

```javascript
console.log('Inicio');
setTimeout(() => console.log('Tarde'), 0);
console.log('Fin');
```

El código debe mostrar primero los logs síncronos, luego los callbacks asíncronos en orden FIFO. Debe incluir al menos una llamada a setTimeout o Promise con .then(). No debe usar async/await para este ejemplo básico.
