## Objetivo
El desarrollador comprenderá el propósito de las pruebas de integración, diferenciándolas de las unitarias, y aprenderá a diseñar un caso de prueba que verifique la interacción exitosa entre dos módulos dependientes sin requerir infraestructura compleja.

## Explicación
Las pruebas de integración verifican que los componentes individuales del sistema funcionen correctamente cuando se combinan. A diferencia de las pruebas unitarias, estas detectan fallos en las interfaces, formatos de datos y flujos de control entre módulos. En este caso, simularemos la comunicación entre un servicio de autenticación y uno de gestión de usuarios. El objetivo es asegurar que una credencial válida generada por el primer servicio sea reconocida correctamente por el segundo, validando así la integridad del flujo de datos completo.

## Ejemplo (no ejecutado automáticamente)
```python
from unittest.mock import patch

def test_integracion_login_y_usuario():
    # Simula la respuesta del servicio de autenticación exitosa
    with patch('servicios.auth.login') as mock_auth:
        mock_auth.return_value = {'token': 'xyz123', 'user_id': 101}
        
        # Ejecuta el flujo que conecta ambos servicios
        resultado = sistema.login_y_obtener_perfil('usuario@test.com', 'clave_secreta')
        
        # Valida que la integración funcionó correctamente
        assert resultado['estado'] == 'exito'
        assert resultado['perfil']['nombre'] == 'Ana Garcia'
```
