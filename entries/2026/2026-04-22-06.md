## Objetivo
Comprender la naturaleza del tipado dinámico en Python y aprender a utilizar anotaciones opcionales para mejorar la legibilidad, documentar intenciones explícitas y facilitar el uso de herramientas de análisis estático sin comprometer la flexibilidad del lenguaje.

## Explicación
Python es un lenguaje de tipado dinámico donde las variables no tienen un tipo fijo en su declaración; el tipo se infiere al momento de la asignación. Esto permite reasignar una variable a diferentes tipos durante su ciclo de vida, lo que ofrece flexibilidad pero puede ocultar errores hasta la ejecución. Para mitigar esto, Python 3 introdujo las anotaciones de tipo (ej: x: int). Estas son opcionales y no afectan el comportamiento del código en tiempo de ejecución, sino que sirven como documentación para humanos y herramientas externas. Utilizarlas es una buena práctica en proyectos colaborativos o grandes, ya que ayuda a identificar errores potenciales antes de la prueba y mejora la mantenibilidad del software al hacer explícitos los contratos de las funciones.

## Ejemplo (no ejecutado automáticamente)
Definición de una función que calcula el área de un círculo, utilizando anotaciones para especificar que el radio debe ser un número flotante y que el resultado será también un flotante. Se incluye una llamada a la función con un valor válido.

```python
def calcular_area(radio: float) -> float:
    return 3.14159 * radio ** 2

radio = 5.0
area = calcular_area(radio)
print(f"El área es: {area}")
```
