## Objetivo
Aprender a validar datos y ejecutar lógica tras la creación automática de instancias en dataclasses, asegurando integridad sin sobrecargar el constructor.

## Explicación
Los dataclasses simplifican la definición de clases POJO, pero a veces requieren validación post-construcción. El método __post_init__ se ejecuta automáticamente después de que Python asigna los valores a los atributos definidos en el decorador @dataclass. Esto permite realizar cálculos derivados, normalizar cadenas o lanzar excepciones si los datos no cumplen reglas de negocio específicas. Es ideal para inyectar valores por defecto calculados dinámicamente basados en otros campos, evitando repetir lógica en cada inicialización manual.

## Ejemplo (no ejecutado automáticamente)
Clase Usuario que valida que el email tenga '@' y calcula la edad exacta desde la fecha de nacimiento.

```python
from dataclasses import dataclass
from datetime import date

@dataclass
class Usuario:
    nombre: str
    email: str
    fecha_nacimiento: date
    
    def __post_init__(self):
        if '@' not in self.email:
            raise ValueError("Email inválido")
        edad = (date.today() - self.fecha_nacimiento).days // 365
```
