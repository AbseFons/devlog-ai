## Objetivo
Comprender la estructura de la pirámide de pruebas para priorizar casos unitarios, integraciones y end-to-end, optimizando el tiempo de feedback y la estabilidad del software en proyectos modernos.

## Explicación
La pirámide de pruebas es un modelo arquitectónico que organiza las pruebas por capas. La base amplia está compuesta por pruebas unitarias, rápidas y aisladas, que validan componentes individuales. Sobre ellas se sitúan las pruebas de integración, que verifican la interacción entre módulos. Finalmente, en la cúspite estrecha, residen las pruebas end-to-end o de aceptación, lentas pero críticas para el flujo completo del usuario. Este enfoque asegura que fallos tempranos sean detectados con bajo costo y alto volumen de cobertura, evitando la dependencia excesiva de suites de prueba complejas que rompen frecuentemente.

## Ejemplo (no ejecutado automáticamente)
Script en Python que define una clase simple y ejecuta una prueba unitaria para validar su constructor, demostrando la base de la pirámide.

```python
class Calculadora:
    def __init__(self, a, b):
        self.a = a
        self.b = b

calc = Calculadora(2, 3)
assert calc.a == 2
```
