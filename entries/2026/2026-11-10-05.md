## Objetivo
Aprender a implementar un algoritmo de ventana deslizante usando tokens para controlar la tasa de solicitudes en APIs, evitando bloqueos masivos y mejorando la resiliencia del sistema ante picos de tráfico repentinos.

## Explicación
El rate limiting protege los recursos del servidor limitando el número de peticiones por unidad de tiempo. En esta serie, exploramos la ventana deslizante con tokens, una técnica más precisa que las ventanas fijas. Imagina un contenedor virtual que se mueve a través del historial de solicitudes; cada vez que entra una nueva petición, verificamos si hay espacio para un token dentro de la ventana actual. Si el token existe, permitimos la solicitud y consumimos el espacio; si no, rechazamos la petición con un código 429. Este enfoque es ideal para APIs públicas donde los patrones de uso son impredecibles. Utilizamos estructuras de datos como colas o listas ordenadas para rastrear las marcas de tiempo de las solicitudes recientes, asegurando que solo se cuenten aquellas dentro del intervalo permitido.

## Ejemplo (no ejecutado automáticamente)
Script en Python que simula un contador de tokens deslizante usando una lista de marcas de tiempo y verifica si una nueva solicitud debe ser permitida o rechazada basándose en la ventana temporal configurada.

```python
import time
from collections import deque
def check_rate_limit(timestamps, window_size, max_requests):
    current_time = time.time()
    cutoff = current_time - window_size
    timestamps = [t for t in timestamps if t > cutoff]
    if len(timestamps) < max_requests:
        timestamps.append(current_time)
        return True
    else:
        return False
```
