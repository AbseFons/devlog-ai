## Objetivo
Aprender a convertir objetos de Python (diccionarios y listas) en cadenas JSON válidas utilizando la biblioteca estándar json, comprendiendo el proceso de codificación para almacenamiento o transmisión de datos estructurados.

## Explicación
La serialización transforma estructuras complejas de Python en texto legible. Utilizamos el módulo 'json' para convertir diccionarios a cadenas mediante la función 'dump()'. Este proceso es esencial para guardar configuraciones, intercambiar datos entre servicios o persistir estado temporal. Es crucial manejar correctamente los tipos de datos: booleanos, nulos y listas se mapean directamente, mientras que las claves de los diccionarios deben ser siempre cadenas en el formato final.

## Ejemplo (no ejecutado automáticamente)
Conversión de un diccionario de usuario a texto JSON

```python
import json
usuario = {'nombre': 'Ana', 'activo': True}
json_str = json.dumps(usuario)
```
