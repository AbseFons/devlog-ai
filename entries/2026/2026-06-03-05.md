## Objetivo
Comprender la función del rate limiting para proteger servicios backend de sobrecargas y ataques DDoS, aprendiendo a implementar límites básicos de solicitudes por segundo.

## Explicación
El rate limiting es un mecanismo esencial que restringe el número de peticiones que un cliente puede realizar a una API en un periodo determinado. Esto previene el agotamiento de recursos del servidor y mitiga ataques de fuerza bruta o denegación de servicio. Las estrategias comunes incluyen ventanas deslizantes, tokens bucket o límites fijos por IP. En esta lección, exploraremos cómo configurar un límite simple usando encabezados HTTP como X-RateLimit-Limit para informar al cliente sobre su cuota actual.

## Ejemplo (no ejecutado automáticamente)
Configuración de headers de rate limiting en una respuesta HTTP simulada con Node.js Express

```javascript
app.get('/api/data', (req, res) => {
  const limit = 10;
  res.set('X-RateLimit-Limit', limit);
  res.json({ data: 'success' });
});
```
