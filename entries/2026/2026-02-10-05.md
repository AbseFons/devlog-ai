## Objetivo
Aprender a usar la clase Path de Python para construir rutas absolutas y relativas de forma legible, evitando errores comunes con separadores de directorios y caracteres especiales en diferentes sistemas operativos.

## Explicación
En Python, el módulo pathlib ofrece una interfaz orientada a objetos para manipular rutas de archivos. A diferencia de las cadenas de texto tradicionales, Path permite construir rutas de manera intuitiva usando operadores como / o \. Esto garantiza compatibilidad entre Windows, Linux y macOS sin necesidad de escapar caracteres manualmente. Por ejemplo, Path('proyectos')/analisis crea una ruta relativa segura. Además, métodos como .resolve() obtienen la ruta absoluta real del sistema, eliminando enlaces simbólicos ambiguos. Esta aproximación reduce bugs en scripts que se ejecutan en entornos heterogéneos y mejora la mantenibilidad del código al separar lógica de datos de lógica de archivos.

## Ejemplo (no ejecutado automáticamente)
Crear una ruta relativa segura para un archivo de configuración sin depender del sistema operativo.

```python
from pathlib import Path
config = Path('datos') / 'config.json'
```
