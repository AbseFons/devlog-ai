## Objetivo
Comprender el concepto de recursión mediante un caso clásico: el cálculo del factorial de un número entero positivo, identificando claramente las condiciones de base y la llamada recursiva en un contexto de programación funcional.

## Explicación
La recursión permite que una función se llame a sí misma para resolver problemas más pequeños hasta alcanzar un caso base. En este ejemplo, calculamos el factorial (n!) multiplicando n por el factorial de n-1. El proceso detiene su ejecución cuando llega al cero o uno, devolviendo 1. Es vital definir esta condición final para evitar bucles infinitos que agotarían la memoria del sistema. Este patrón es fundamental en algoritmos como árboles y grafos.

## Ejemplo (no ejecutado automáticamente)
Función recursiva en Python que calcula el factorial de un número dado, mostrando cómo se descompone el problema paso a paso hasta llegar al caso base.

```python
def factorial(n):
    if n == 0 or n == 1:
        return 1
    else:
        return n * factorial(n - 1)
```
