## Explicación
El algoritmo de ordenamiento por mezcla (Merge Sort) es un método recursivo basado en el principio 'divide y vencerás'. Primero, divide el array original en dos mitades hasta alcanzar subarrays de tamaño uno. Luego, fusiona estas mitades devolviendo arrays ordenados. La fusión compara los elementos de cada mitad y los coloca en un nuevo array en orden ascendente. Este enfoque garantiza una complejidad temporal O(n log n) en todos los casos, lo que lo hace estable y predecible para grandes volúmenes de datos.

## Ejemplo (no ejecutado automáticamente)
Implementación recursiva en Python que divide el array hasta elementos individuales y fusiona comparando valores para construir la secuencia ordenada final.

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
def merge(left, right):
    result = []
    while left and right:
        if left[0] <= right[0]:
            result.append(left.pop(0))
        else:
            result.append(right.pop(0))
    result.extend(left + right)
    return result
```
