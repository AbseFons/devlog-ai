## Objetivo
Aprender a identificar y gestionar vulnerabilidades de seguridad en las dependencias de un proyecto Node.js utilizando la herramienta nativa de auditoría para mitigar riesgos antes de la producción.

## Explicación
En ingeniería de software moderna, las dependencias externas son una fuente común de vulnerabilidades. Herramientas como npm audit escanean el árbol de paquetes del proyecto y reportan CVEs conocidos. Este proceso es esencial en la serie de seguridad sobre dependencias. Al ejecutar el comando en el directorio raíz, se obtiene un informe detallado con niveles de severidad. Si existen vulnerabilidades críticas, el sistema sugiere versiones actualizadas o paqueterías alternativas. Es vital integrar estas auditorías en el pipeline CI/CD para bloquear despliegues inseguros. Mantener las dependencias al día reduce la superficie de ataque y cumple con estándares de seguridad corporativa sin necesidad de reescribir código propio.

## Ejemplo (no ejecutado automáticamente)
Ejecución del comando de auditoría en un proyecto Node.js estándar para detectar vulnerabilidades reportadas por el registro de seguridad.

```bash
npm audit
npm audit fix --audit-level=high
```

## Ejercicio
Ejecuta 'npm audit' en tu repositorio local. Analiza la salida y documenta al menos una vulnerabilidad encontrada, su nivel de riesgo y la acción recomendada según el reporte.

## Criterios de revisión
Identificar correctamente al menos una dependencia vulnerable; proponer una solución válida basada en la actualización del paquete o exclusión controlada; evitar ignorar advertencias de seguridad sin justificación técnica.
