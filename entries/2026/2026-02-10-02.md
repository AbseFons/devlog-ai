## Objetivo
Introducir al estudiante en la concurrencia básica de Python utilizando el módulo threading para ejecutar tareas simultáneas, mejorando la eficiencia en procesos I/O.

## Explicación
En Python, la concurrencia permite manejar múltiples tareas que se entrelazan. El módulo threading facilita esto creando hilos ligeros. A diferencia del multiprocessing, threading es ideal para operaciones de entrada/salida como leer archivos o hacer peticiones web, aprovechando el tiempo de espera. Sin embargo, debido a la GIL (Interpretador Global), no aprovecha múltiples núcleos CPU para tareas intensivas en cálculo. Este enfoque es fundamental para aplicaciones que requieren respuesta rápida sin bloquear la interfaz.

## Ejemplo (no ejecutado automáticamente)
Script que imprime mensajes de dos hilos con un pequeño retraso simulado.

```python
import threading
import time
def tarea(nombre, duracion):
    print(f'{nombre} comienza')
    time.sleep(duracion)
    print(f'{nombre} termina')
t1 = threading.Thread(target=tarea, args=('Hilo A', 2))
t2 = threading.Thread(target=tarea, args=('Hilo B', 1))
t1.start()
t2.start()
```
