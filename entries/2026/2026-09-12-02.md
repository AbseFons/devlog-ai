## Objetivo
Aprender a configurar un registrador de eventos en Python que emita registros en formato JSON nativo, facilitando la integración con sistemas de monitoreo modernos y el análisis automatizado de datos sin necesidad de parsers externos complejos.

## Explicación
El logging estructurado transforma las cadenas de texto tradicionales en objetos JSON legibles por máquinas. Esto permite filtrar errores específicos, rastrear flujos de transacciones y correlacionar eventos entre microservicios. En Python, se logra mediante la configuración del diccionario 'format' o el uso de formateadores personalizados que convierten cada registro en un objeto serializado. Este enfoque es esencial para plataformas como ELK Stack o Datadog, donde el formato JSON es el estándar de facto. Al estructurar los datos desde el origen, se garantiza consistencia y eficiencia en el procesamiento posterior.
