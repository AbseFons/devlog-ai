## Objetivo
Aprender a crear listas concisas y eficientes en Python utilizando la sintaxis de comprensión, evitando bucles explícitos para transformar datos de manera elegante y legible.

## Explicación
La comprensión de listas permite generar secuencias iterando sobre una iterable existente. Sintácticamente, se define una expresión que procesa cada elemento seguido de un filtro opcional. Por ejemplo, al elevar al cuadrado números pares de un rango, la sintaxis es compacta. Esta técnica mejora la legibilidad del código comparada con bucles for tradicionales y reduce líneas innecesarias. Es fundamental dominarla para escribir Python moderno y eficiente.

## Ejemplo (no ejecutado automáticamente)
Generar una lista con los cuadrados de los números pares entre 0 y 9.

```python
numeros = [x**2 for x in range(10) if x % 2 == 0]
print(numeros)
```
