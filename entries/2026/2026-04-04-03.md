## Objetivo
Aprender a utilizar bloques try, catch y finally para prevenir que fallos inesperados detengan la ejecución del programa, permitiendo manejar excepciones como errores de sintaxis o tipos de datos incorrectos de manera segura y controlada.

## Explicación
En JavaScript, los errores no manejados pueden detener una aplicación. El patrón estándar consiste en envolver el código potencialmente fallido dentro de un bloque try. Si ocurre una excepción, se captura en el bloque catch, donde se puede registrar el error o mostrar un mensaje amigable al usuario. Finalmente, el bloque finally asegura que ciertas tareas (como cerrar conexiones) se ejecuten siempre, independientemente de si hubo error o no. Este enfoque mejora la robustez del software.

## Ejemplo (no ejecutado automáticamente)
Intento de dividir por cero capturado y manejado para mostrar un mensaje personalizado en lugar de romper la aplicación.

```javascript
try {
  const resultado = 10 / 0;
} catch (error) {
  console.log('Error detectado:', error.message);
}
```

Crea una función que acepte dos números y devuelva su división. Usa try-catch para manejar el caso de división por cero y lanza un Error personalizado con el mensaje 'No se puede dividir por cero'.
