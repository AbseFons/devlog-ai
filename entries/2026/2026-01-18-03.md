## Objetivo
Aprender a usar la biblioteca estándar argparse en Python para crear scripts que acepten argumentos desde la línea de comandos, definiendo opciones y valores por defecto de manera segura y profesional.

## Explicación
La biblioteca argparse facilita la creación de interfaces de línea de comandos robustas. Permite definir parámetros como nombres de archivos o flags booleanos sin escribir código manual complejo. Al ejecutar el script, Python analiza los argumentos pasados y construye un objeto Namespace con los valores extraídos. Esto evita errores comunes al pasar variables directamente en el código y mejora la reutilización del software. Es esencial para cualquier herramienta automatizada que necesite flexibilidad en su ejecución.

## Ejemplo (no ejecutado automáticamente)
Script que calcula el área de un círculo recibiendo el radio como argumento numérico.

```python
import argparse
parser = argparse.ArgumentParser()
parser.add_argument('radio', type=float, help='Radio del circulo')
args = parser.parse_args()
print(f'Area: {3.14159 * args.radio**2}')
```
