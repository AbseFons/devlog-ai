## Objetivo
Comprender por qué almacenar contraseñas en texto plano es inseguro y cómo las funciones hash con sal protegen los datos de usuarios ante filtraciones, estableciendo una base sólida para prácticas de seguridad modernas.

## Explicación
Almacenar contraseñas en texto plano expone a la aplicación a riesgos críticos si se filtra la base de datos. La solución estándar es utilizar funciones hash criptográficas unidireccionales como bcrypt o Argon2. Estas funciones transforman cualquier entrada única en una cadena compleja irreversible. Crucialmente, cada hash debe incluir una 'sal' aleatoria única por usuario, lo que impide ataques de diccionario masivo y rainbow tables. Nunca utilices MD5 o SHA-1 para contraseñas debido a su vulnerabilidad computacional. El objetivo es garantizar que, incluso con acceso al almacenamiento, un atacante no pueda recuperar la contraseña original ni comparar dos usuarios fácilmente.

## Ejemplo (no ejecutado automáticamente)
Implementación de hashing seguro usando la librería estándar 'hashlib' en Python, aplicando una sal única por usuario y evitando funciones débiles como MD5.

```python
import hashlib
import os
sal = os.urandom(16)
contrasena = "mi_password_secreta"
hash_final = hashlib.pbkdf2_hmac('sha256', contrasena.encode(), sal, 100000)
```
