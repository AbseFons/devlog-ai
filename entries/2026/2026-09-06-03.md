## Objetivo
Comprender y aplicar la primera forma normal (1FN) para eliminar grupos repetidos en columnas, asegurando que cada celda contenga un único valor atómico y facilitando consultas eficientes.

## Explicación
La normalización es el proceso de organizar una base de datos para reducir la redundancia y mejorar la integridad. La Primera Forma Normal (1FN) exige que cada columna en una tabla tenga valores atómicos, es decir, no puede contener listas o arrays dentro de una sola celda. Por ejemplo, si una tabla 'Clientes' tiene una columna 'Hobbies' con valores como 'Lectura,Musica', esto viola la 1FN. Para corregirlo, debemos dividir esa tabla en dos: una para los clientes y otra para sus hobbies, creando una relación uno a muchos. Esto permite agregar nuevos hobbies sin modificar la estructura de la tabla original y evita anomalías de actualización.

## Ejemplo (no ejecutado automáticamente)
Transformación de una tabla con columnas repetidas a una estructura relacional normalizada en SQL.

```sql
CREATE TABLE Clientes (
  id INT PRIMARY KEY,
  nombre VARCHAR(100)
);

CREATE TABLE Hobbies (
  id_hobby INT PRIMARY KEY,
  cliente_id INT,
  hobby VARCHAR(50),
  FOREIGN KEY (cliente_id) REFERENCES Clientes(id)
);
```
