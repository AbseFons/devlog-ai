## Objetivo
Comprender la estructura fundamental del Control de Acceso Basado en Roles (RBAC) mediante la definición de roles, permisos y asignación a usuarios para proteger recursos críticos en una aplicación web.

## Explicación
El Control de Acceso Basado en Roles (RBAC) es un modelo de seguridad que otorga permisos a usuarios según sus funciones dentro de una organización. En este ejemplo, definiremos dos roles: 'admin' con acceso total y 'lector' con solo lectura. Utilizaremos JavaScript para simular la lógica de autorización. Primero, creamos un objeto de configuración que mapea cada rol a una lista de permisos específicos. Luego, definimos los usuarios y les asignamos un único rol principal. Finalmente, implementamos una función de verificación que compara el rol del usuario actual con los permisos requeridos para una acción determinada. Este enfoque centraliza la gestión de seguridad, reduciendo errores humanos al evitar la configuración manual de permisos individuales para cada recurso.

## Ejemplo (no ejecutado automáticamente)
Script en JavaScript que define roles, asigna usuarios y verifica si un usuario puede ejecutar una acción específica.

```javascript
const roles = { admin: ['read', 'write', 'delete'], lector: ['read'] };
const usuario = { nombre: 'ana', rol: 'lector' };
const accionRequerida = 'write';
const tienePermiso = roles[usuario.rol].includes(accionRequerida);
console.log(tienePermiso ? 'Acceso concedido' : 'Acceso denegado');
```
