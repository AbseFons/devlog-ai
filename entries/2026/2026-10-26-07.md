## Objetivo
Aprender a resolver colisiones en tablas hash utilizando la técnica de encadenamiento, donde cada posición almacena una lista enlazada de elementos que comparten el mismo índice.

## Explicación
Cuando dos claves distintas generan el mismo índice, se produce una colisión. El encadenamiento resuelve esto almacenando múltiples nodos en un solo bucket mediante listas enlazadas. Cada nodo contiene la clave y su valor. Al insertar, calculamos el hash del módulo de la longitud de la tabla para obtener el índice inicial. Si ese índice ya tiene elementos, simplemente añadimos un nuevo nodo al inicio o final de la lista existente. La búsqueda recorre cada elemento de la lista hasta encontrar la clave coincidente o agotar los nodos. Esta técnica es sencilla de implementar y eficiente cuando las colisiones son frecuentes.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python de una tabla hash con encadenamiento usando listas para manejar colisiones, insertando pares clave-valor y recuperando valores específicos.

```python
class HashTable:
    def __init__(self, size):
        self.size = size
        self.table = [[] for _ in range(size)]
    
    def insert(self, key, value):
        index = hash(key) % self.size
        self.table[index].append({'key': key, 'value': value})
    
    def get(self, key):
        index = hash(key) % self.size
        for item in self.table[index]:
            if item['key'] == key:
                return item['value']
        return None
```
