## Objetivo
Aprender a implementar restricciones de integridad referencial y lógica en bases de datos relacionales para garantizar la calidad de los datos.

## Explicación
Las restricciones CHECK y UNIQUE son fundamentales para mantener la consistencia de los datos. La cláusula CHECK permite definir rangos válidos o condiciones lógicas, como asegurar que una edad sea mayor a cero. Por otro lado, UNIQUE garantiza que no existan duplicados en una columna específica, ideal para identificadores secundarios. Ambas se definen al crear la tabla con CREATE TABLE o mediante ALTER TABLE. Es crucial entender que UNIQUE permite un valor NULL, mientras que CHECK evalúa expresiones booleanas antes de insertar o actualizar registros.

## Ejemplo (no ejecutado automáticamente)
Creación de una tabla de empleados donde la edad debe ser mayor a 18 y el departamento_id sea único.

```sql
CREATE TABLE empleados (
    id INT PRIMARY KEY,
    nombre VARCHAR(50),
    edad INT CHECK (edad > 18),
    departamento_id INT UNIQUE
);
```
