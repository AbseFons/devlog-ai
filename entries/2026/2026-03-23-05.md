## Objetivo
Introducir al estudiante en la concurrencia básica de Python utilizando el módulo threading para ejecutar tareas simultáneas, mejorando la eficiencia del procesamiento en aplicaciones que requieren I/O.

## Explicación
En Python, el modelo GIL limita la paralelización real de CPU con hilos nativos. Sin embargo, para operaciones de E/S como lectura de archivos o llamadas a red, threading es ideal. Este ejemplo crea dos hilos: uno descarga datos y otro procesa logs. Se utiliza Thread para iniciar cada tarea y join para esperar su finalización antes de imprimir el resultado final. Es fundamental entender que los hilos comparten memoria pero requieren sincronización si acceden a recursos compartidos.

## Ejemplo (no ejecutado automáticamente)
Dos hilos ejecutan funciones de E/S simuladas en paralelo, demostrando cómo la concurrencia reduce el tiempo total de ejecución comparado con la secuencia.

```python
import threading
import time
def tarea():
    print('Hilo trabajando...')
    time.sleep(2)
threads = []
for i in range(2):
    t = threading.Thread(target=tarea)
    threads.append(t)
    t.start()
for t in threads:
    t.join()
print('Tareas finalizadas')
```
