## Objetivo
Aprender a diseñar pruebas que verifiquen la comunicación efectiva entre componentes internos y servicios externos, asegurando la resiliencia del sistema ante fallos de terceros sin depender de su disponibilidad real.

## Explicación
En esta lección exploramos cómo validar la integración con APIs externas utilizando mocks. El objetivo es aislar el sistema bajo prueba para evitar dependencias inestables. Crearemos un servicio que simula una respuesta de pasarela de pagos, verificando que nuestro código maneje correctamente estados como 'timeout' o 'error'. Esto permite detectar regresiones en la lógica de negocio antes de desplegar cambios críticos. La clave reside en definir contratos claros y comportamientos de error realistas dentro del mock.

## Ejemplo (no ejecutado automáticamente)
Simulación de respuesta de API de pagos con estados de error para validar manejo de excepciones.

```javascript
const mockPaymentResponse = {
  status: 'error',
  message: 'Gateway timeout'
};
if (mockPaymentResponse.status === 'error') throw new Error('Pago fallido');
```
