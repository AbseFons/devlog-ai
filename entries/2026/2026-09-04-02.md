## Objetivo
Comprender la diferencia estructural entre pilas (LIFO) y colas (FIFO), identificando sus aplicaciones prácticas en gestión de tareas y procesamiento de datos secuenciales dentro de sistemas informáticos modernos.

## Explicación
Las estructuras de datos lineales son esenciales para organizar procesos. Una pila opera bajo el principio 'último en entrar, primero en salir', ideal para deshacer acciones o recursión. Una cola sigue 'primero en entrar, primero en salir', crucial para colas de impresión o gestión de solicitudes web. Python ofrece listas nativas y módulos como collections.deque para implementar ambas eficientemente. La elección depende del flujo lógico: si el orden de salida debe coincidir con la entrada, usamos cola; si necesitamos revertir el último estado, usamos pila.

## Ejemplo (no ejecutado automáticamente)
Implementación comparativa de una cola y una pila usando deque para simular un sistema de tickets en una cafetería versus una función de deshacer en un editor de texto.

```python
from collections import deque

cola_tickets = deque()
pila_deshacer = []

# Simulación cola: cliente A entra primero
cola_tickets.append('Cliente A')
print(f'Cola: {list(cola_tickets)}')

# Simulación pila: usuario escribe 'H' luego 'K'
pila_deshacer.append('H')
pila_deshacer.append('K')
print(f'Pila: {pila_deshacer}')
```
