## Objetivo
Introducir al estudiante en la concurrencia básica de Python mediante el módulo threading, explicando cómo ejecutar tareas simultáneas para mejorar la eficiencia del programa sin bloquear la ejecución principal.

## Explicación
En Python, el modelo de programación concurrente se basa comúnmente en hilos (threads) gracias a su GIL. Aunque el GIL limita la concurrencia real con CPU, es ideal para I/O. Usamos Thread para lanzar funciones independientes. Cada hilo tiene su propia pila y memoria local, pero comparten el espacio global. Es crucial usar locks o queues para evitar condiciones de carrera. Este enfoque permite que una aplicación responda mientras espera datos externos, optimizando tiempos de respuesta en servicios web o scraping.

## Ejemplo (no ejecutado automáticamente)
Ejemplo de dos hilos imprimiendo mensajes con un pequeño retraso simulado.

```python
import threading
import time
def tarea(nombre):
    for i in range(3):
        print(f'{nombre}: Iteración {i}')
        time.sleep(1)
t1 = threading.Thread(target=tarea, args=('Hilo A',))
t2 = threading.Thread(target=tarea, args=('Hilo B',))
t1.start()
t2.start()
```
