## Objetivo
Comprender cómo las funciones internas acceden a variables del ámbito exterior incluso después que esa función ha terminado de ejecutarse, permitiendo crear funciones con estado privado.

## Explicación
Un closure es una función que recuerda su entorno léxico original. En JavaScript, cuando una función se define dentro de otra, puede acceder a las variables de la función externa. Aunque la función externa termine, la interna mantiene referencias a esas variables en la memoria. Esto permite encapsular datos y lógica sin exponerlos globalmente. Por ejemplo, podemos crear un contador simple donde el valor interno nunca es accesible directamente desde fuera, solo mediante métodos expuestos.

## Ejemplo (no ejecutado automáticamente)
Se define una función que crea un contador privado usando un closure para mantener el estado en una variable local inaccesible externamente.

```javascript
function crearContador() {
  let cuenta = 0;
  return function() {
    cuenta++;
    return cuenta;
  };
}
const miContador = crearContador();
console.log(miContador()); // 1
console.log(miContador()); // 2
```
