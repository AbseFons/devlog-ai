## Objetivo
Al finalizar, el desarrollador podrá implementar conexiones a bases de datos SQLite en Python utilizando context managers para garantizar el cierre automático de recursos y la integridad de las transacciones mediante commit o rollback.

## Explicación
La librería estándar sqlite3 permite crear bases de datos locales sin dependencias externas. Es crucial usar 'with' para gestionar la conexión, asegurando que se cierren correctamente incluso ante errores. Dentro del bloque, ejecutar consultas SQL y llamar a commit() confirma los cambios; si ocurre una excepción, el contexto invoca rollback() automáticamente, deshaciendo operaciones parciales. Este patrón previene fugas de memoria y mantiene la consistencia de datos. Evita abrir conexiones explícitas sin cerrarlas manualmente, ya que el sistema operativo liberará los archivos eventualmente, pero no se garantizará la integridad transaccional.

## Ejemplo (no ejecutado automáticamente)
```python
import sqlite3

def crear_tabla_usuarios():
    conn = None
    try:
        conn = sqlite3.connect('usuarios.db')
        cursor = conn.cursor()
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS usuarios (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                nombre TEXT NOT NULL,
                email TEXT UNIQUE NOT NULL
            )
        ''')
        conn.commit()
        print('Tabla creada o ya existente.')
    except sqlite3.Error as e:
        if conn:
            conn.rollback()
        print(f'Error al crear tabla: {e}')
    finally:
        if conn:
            conn.close()

crear_tabla_usuarios()
```
