## Objetivo
Introducir el concepto de subproblemas superpuestos y memorización en programación dinámica mediante un caso práctico de optimización de recursos, evitando recálculos innecesarios para mejorar la eficiencia algorítmica.

## Explicación
La programación dinámica resuelve problemas complejos dividiéndolos en subproblemas más simples. En este caso, calculamos el máximo valor que podemos obtener con un peso limitado usando ladrillos de diferentes pesos y valores. Sin memoria, la función recursiva recalcula soluciones repetidamente, generando una complejidad exponencial. Al almacenar los resultados de cada subproblema en una tabla (memorización), reducimos la complejidad a lineal. Este enfoque es esencial cuando las decisiones actuales dependen de estados anteriores optimizados.

## Ejemplo (no ejecutado automáticamente)
Calcula el valor máximo obtenible con un peso máximo de 5 usando ladrillos de pesos [2,3,4] y valores [3,4,5].

```python
def knapsack_dp(w_max, weights, values):
    n = len(weights)
    dp = [[0 for _ in range(w_max + 1)] for _ in range(n + 1)]
    for i in range(1, n + 1):
        for w in range(w_max + 1):
            dp[i][w] = dp[i-1][w]
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i][w], dp[i-1][w - weights[i-1]] + values[i-1])
    return dp[n][w_max]
```
