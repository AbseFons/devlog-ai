## Objetivo
Comprender por qué almacenar contraseñas en texto plano es inseguro y cómo las funciones hash unidireccionales protegen los datos de usuarios ante filtraciones, estableciendo una base sólida para prácticas de seguridad modernas.

## Explicación
Las contraseñas nunca deben guardarse en texto plano. Si una base de datos es comprometida, los atacantes obtendrían acceso inmediato a todas las cuentas. La solución es usar funciones hash criptográficas como bcrypt o Argon2. Estas transforman la contraseña en un string irreversiblemente largo y único. Incluso si dos usuarios tienen la misma contraseña, sus hashes serán distintos debido a 'salts' aleatorios que se añaden antes de procesar. Esto impide ataques de diccionario masivos y rainbow tables. El sistema solo verifica si el hash del nuevo ingreso coincide con el almacenado, sin conocer la contraseña original.

## Ejemplo (no ejecutado automáticamente)
Implementación conceptual en Python utilizando la librería bcrypt para generar un hash seguro con una sal automática.

```python
import bcrypt
password = 'MiContraseñaSegura123'
saltado_hash = bcrypt.hashpw(password.encode('utf-8'), bcrypt.gensalt())
print(saltado_hash.decode('utf-8'))
```
