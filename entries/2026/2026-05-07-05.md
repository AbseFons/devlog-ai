## Objetivo
Comprender cómo las funciones internas acceden a variables de su contexto exterior incluso después de que esa función externa haya terminado de ejecutarse, aprovechando el cierre del entorno léxico.

## Explicación
Un closure en JavaScript es una función que recuerda y mantiene acceso a sus variables externas, incluso cuando se ejecuta fuera del ámbito donde fueron definidas. Esto ocurre porque la función interna captura el entorno léxico (scope) de su padre al momento de su creación, no solo al ejecutarse. Imagina una fábrica de funciones: cada vez que llamas a la función externa, esta crea un nuevo entorno con sus propias variables y devuelve una nueva función especializada. Esa función devuelta conserva una referencia a esas variables específicas. Es útil para crear funciones genéricas que se especializan dinámicamente, como contadores privados o generadores de saludos personalizados, sin necesidad de pasar parámetros repetidamente en cada llamada.

## Ejemplo (no ejecutado automáticamente)
Se define una función 'crearContador' que devuelve otra función. Cada vez que se llama a 'crearContador', se crea un nuevo entorno con su propia variable 'contador'. Las funciones devueltas acceden y modifican esa variable específica, logrando contar de forma aislada.

```javascript
function crearContador() {
  let contador = 0;
  return function() {
    contador++;
    return contador;
  };
}
const c1 = crearContador();
console.log(c1()); // 1
console.log(c1()); // 2
```
