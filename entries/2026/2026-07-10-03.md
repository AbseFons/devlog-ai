## Objetivo
Comprender cómo una función hash transforma claves arbitrarias en índices numéricos para acceso directo O(1) en tablas hash, evitando colisiones iniciales mediante un mapeo eficiente.

## Explicación
Una tabla hash utiliza una función de enmascaramiento para convertir cualquier clave (como una cadena de texto o un número grande) en un índice entero válido dentro del rango de la tabla. Este proceso permite recuperar datos instantáneamente sin recorrer elementos secuencialmente. La elección de la función es crítica; si es demasiado simple, puede causar muchas colisiones. Un ejemplo común es usar el operador módulo con una potencia de dos para aprovechar el registro binario del procesador, o aplicar un polinomio abierto que mezcla los bits de la clave antes de calcular el índice final.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python de una función hash simple usando el operador modulo para mapear claves a índices dentro de un tamaño de tabla fijo.

```python
def hash_func(clave, tamano_tabla):
    return hash(clave) % tamano_tabla

clave = "usuario123"
tamano = 1000
indice = hash_func(clave, tamano)
print(f"Clave: {clave} -> Indice: {indice}")
```
