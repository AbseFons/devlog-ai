## Objetivo
Introducir el concepto de pruebas basadas en propiedades, donde se verifica que una función mantenga ciertas invariantes lógicas (como no devolver null) sin especificar casos de prueba exhaustivos.

## Explicación
Las pruebas basadas en propiedades son técnicas formales que validan si un sistema cumple con reglas generales o invariantes en lugar de probar cada escenario individual. En esta serie, exploraremos cómo definir una propiedad como 'la suma de dos números nunca es null'. Esto permite detectar errores sutiles como divisiones por cero o desbordamientos de memoria automáticamente. A diferencia del testing tradicional, no necesitamos enumerar todos los inputs posibles; basta con asegurar que la lógica interna respete las reglas matemáticas o lógicas fundamentales.

## Ejemplo (no ejecutado automáticamente)
Script en Python que define una propiedad para verificar que la suma de dos enteros siempre retorna un entero válido y nunca es null.

```python
def suma(a, b):
    return a + b

def verificar_propiedad():
    assert suma(2, 3) is not None
```

## Ejercicio
Crea una función 'dividir' que tome dos números y retorne su cociente. Luego, escribe una prueba basada en propiedades que asegure que el resultado nunca sea un objeto de tipo 'None' ni genere errores si el divisor es distinto de cero.

## Criterios de revisión
El código debe incluir la definición de la función de división y una afirmación (assert) que valide que el retorno no sea None para entradas válidas.
