## Objetivo
Comprender y aplicar principios básicos de RBAC para restringir operaciones sensibles a roles específicos, garantizando que solo usuarios autorizados puedan ejecutar acciones críticas dentro de una aplicación web.

## Explicación
El control de acceso basado en roles es un modelo fundamental para la seguridad informática. En lugar de verificar permisos individualmente para cada usuario, se asignan roles como 'Administrador', 'Editor' o 'Lector'. Cada rol posee un conjunto definido de permisos. Por ejemplo, el rol 'Editor' puede crear y modificar artículos, pero no puede eliminarlos ni acceder a la configuración del servidor. Este enfoque simplifica la gestión de privilegios y reduce el riesgo de errores humanos al asignar permisos excesivos. En este caso de uso, simularemos una verificación de acceso antes de permitir la ejecución de una función crítica como la eliminación de un recurso.

## Ejemplo (no ejecutado automáticamente)
Script en Python que simula la validación de un rol para permitir o denegar la eliminación de un registro.

```python
def verificar_permiso(rol_usuario, accion_requerida):
    permisos_rol = {'admin': ['leer', 'escribir', 'eliminar'], 'editor': ['leer', 'escribir']}
    if rol_usuario in permisos_rol and accion_requerida in permisos_rol[rol_usuario]:
        return True
    return False
```

## Ejercicio
Crea un script que defina tres roles: 'analista', 'gerente' y 'director'. Asigna permisos de lectura a todos, escritura al gerente y director, y eliminación solo al director. Luego, escribe una función que reciba el rol del usuario y la acción deseada, devolviendo un mensaje claro si la acción está permitida o denegada.

## Criterios de revisión
El código debe definir correctamente los roles y sus permisos asociados. La función de validación debe devolver 'Acceso concedido' solo si el rol posee el permiso específico solicitado. Debe manejar casos donde el rol no existe o el permiso no está asignado, devolviendo un mensaje de denegación apropiado sin exponer detalles internos del sistema.
