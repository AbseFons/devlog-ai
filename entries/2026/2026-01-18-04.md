## Objetivo
Comprender el rol de la función hash en tablas hash, su impacto en el rendimiento O(1) y cómo las colisiones iniciales se gestionan mediante técnicas básicas como encadenamiento o direccionamiento abierto.

## Explicación
Una tabla hash es una estructura de datos que mapea claves a valores utilizando una función hash. Esta función transforma cualquier clave arbitraria en un índice numérico dentro del array subyacente, permitiendo accesos constantes. Sin embargo, múltiples claves pueden generar el mismo índice, provocando colisiones. Para resolverlas, existen estrategias como encadenamiento (listas enlazadas por celda) o direccionamiento abierto (probar índices siguientes). La elección de la función hash es crítica para minimizar colisiones y mantener la eficiencia del sistema.

## Ejemplo (no ejecutado automáticamente)
Implementación básica de una tabla hash con encadenamiento en JavaScript que inserta pares clave-valor y maneja colisiones mediante listas enlazadas simples.

```javascript
class HashTable {
  constructor(size) { this.table = new Array(size).fill(null).map(() => []); }
  hash(key) { return key % this.table.length; }
  insert(key, value) { const index = this.hash(key); this.table[index].push({ key, value }); }
```
