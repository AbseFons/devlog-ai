## Objetivo
Aprender a definir subconsultas temporales legibles usando la sintaxis WITH para simplificar consultas complejas de múltiples niveles en bases de datos relacionales.

## Explicación
Las Common Table Expressions (CTE) permiten crear un conjunto de resultados temporal que puede ser referenciado dentro de una consulta SQL posterior. Se declaran con la palabra clave WITH seguida del nombre y el bloque SELECT. Esto mejora enormemente la legibilidad al desglosar lógica compleja en pasos lógicos. A diferencia de las subconsultas anidadas, las CTE se leen de arriba a abajo, facilitando el mantenimiento. Son ideales para cálculos recursivos o cuando una misma subconsulta se utiliza varias veces en un SELECT principal.

## Ejemplo (no ejecutado automáticamente)
Consulta que calcula el total de ventas por categoría usando una CTE intermedia para filtrar productos activos antes de agrupar los resultados finales.

```sql
WITH VentasActivas AS (
  SELECT categoria, SUM(cantidad) as total
  FROM pedidos
  WHERE estado = 'completado'
)
SELECT categoria, total FROM VentasActivas;
```
