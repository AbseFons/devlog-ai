## Objetivo
Comprender cómo evitar mutaciones de estado global y efectos secundarios para garantizar que las funciones sean predecibles, fáciles de probar y componibles en aplicaciones Python robustas.

## Explicación
Una función pura debe devolver el mismo resultado para los mismos argumentos sin alterar ningún estado externo. En Python, esto implica no modificar listas globales ni variables compartidas dentro del cuerpo de la función. Por ejemplo, en lugar de usar append() sobre una lista global, creamos una nueva lista con los elementos deseados y la devolvemos. Esta práctica simplifica el control de flujo y permite paralelización segura. Al eliminar efectos secundarios como I/O o mutaciones, reducimos la complejidad cognitiva del código y facilitamos la detección de errores.

## Ejemplo (no ejecutado automáticamente)
Función que calcula un nuevo conjunto de precios aplicando impuestos sin modificar el diccionario original de productos.

```python
def calcular_precios_con_iva(productos, tasa):
    nuevos_precios = {}
    for id_prod, precio in productos.items():
        nuevos_precios[id_prod] = precio * (1 + tasa)
    return nuevos_precios

productos_originales = {"A": 100}
resultados = calcular_precios_con_iva(productos_originales, 0.21)
```
