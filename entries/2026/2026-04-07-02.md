## Objetivo
Aprender a encapsular lógica en archivos independientes usando export default y export const, e importarlos correctamente con require o import para mantener el código modular y escalable en aplicaciones JavaScript modernas.

## Explicación
Los módulos ES permiten dividir una aplicación en archivos reutilizables. En un archivo 'utils.js', podemos exportar funciones específicas como 'export const sumar = (a, b) => a + b'. Para usar esta lógica en otro archivo principal, escribimos 'import { sumar } from './utils.js''. Este mecanismo evita la polución del ámbito global y facilita el mantenimiento. Es fundamental recordar que las importaciones deben coincidir exactamente con las exportaciones definidas. La sintaxis es clara: 'export' declara lo que se comparte, mientras que 'import' consume esos recursos externos. Esta separación de responsabilidades es clave para arquitecturas robustas.

## Ejemplo (no ejecutado automáticamente)
Archivo utils.js exporta una función suma y el archivo main.js la importa para calcular un total.

```javascript
export const sumar = (a, b) => a + b;
const resultado = sumar(5, 3);
console.log(resultado);
```
