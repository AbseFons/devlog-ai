## Objetivo
Aprender a crear scripts interactivos que acepten argumentos desde la línea de comandos utilizando el módulo estándar argparse, facilitando la reutilización y claridad del código.

## Explicación
El módulo argparse permite interpretar los argumentos pasados al script. Define opciones como flags o valores posicionales con descripciones claras. Al ejecutar el programa, si faltan parámetros requeridos, muestra un mensaje de ayuda automático. Esto evita errores de ejecución silenciosos y mejora la experiencia del usuario final sin necesidad de librerías externas complejas.

## Ejemplo (no ejecutado automáticamente)
Script que calcula el área de un rectángulo recibiendo ancho y alto como argumentos opcionales con valores por defecto.

```python
import argparse
parser = argparse.ArgumentParser()
parser.add_argument('--ancho', type=float, default=1.0)
parser.add_argument('--alto', type=float, default=1.0)
```
