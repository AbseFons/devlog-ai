## Objetivo
Comprender la sintaxis fundamental para crear y consumir módulos JavaScript utilizando las palabras clave import y export, facilitando el reutilizado de código limpio y organizado en aplicaciones modernas.

## Explicación
Los módulos ES permiten encapsular lógica y datos. Para compartir funciones desde un archivo, se usa 'export default' para la principal o 'export const' para variables específicas. En el archivo que las necesita, se utiliza 'import' seguido del nombre y de la ruta relativa. Es crucial recordar que los módulos solo se cargan una vez por sesión, evitando recálculos costosos. Esta estructura promueve un diseño modular donde cada archivo tiene una responsabilidad clara, mejorando la mantenibilidad del proyecto sin depender de sistemas de paquetes externos complejos inicialmente.

## Ejemplo (no ejecutado automáticamente)
Un archivo calculadora.js exporta funciones matemáticas y otro las importa para usarlas en la interfaz.

```javascript
export function sumar(a, b) {
  return a + b;
}

import { sumar } from './calculadora.js';
console.log(sumar(2, 3));
```
