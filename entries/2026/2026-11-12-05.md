## Objetivo
Comprender cómo las funciones puras evitan efectos secundarios al no modificar variables externas ni depender de estado mutante, garantizando que la salida sea siempre predecible para una misma entrada.

## Explicación
En esta lección exploramos la inmutabilidad como pilar de las funciones puras. A diferencia de funciones impuras que alteran el estado global o modifican argumentos pasados por referencia, una función pura devuelve un nuevo objeto sin tocar el original. Esto permite transparencia referencial: puedes reemplazar la llamada a la función por su valor sin cambiar el comportamiento del programa. En Python, aunque los objetos son mutables por defecto, podemos diseñar funciones que siempre devuelvan nuevas listas o diccionarios. Por ejemplo, en lugar de usar append() sobre una lista compartida, creamos una copia y agregamos elementos a la nueva instancia. Esta disciplina facilita pruebas unitarias sencillas, ya que no es necesario configurar mocks para estados globales ni limpiar variables entre ejecuciones.

## Ejemplo (no ejecutado automáticamente)
Funcion que calcula el precio total de un carrito aplicando impuestos sin modificar los datos del usuario original.

```python
def calcular_total_precios(carrito, tasa_impuesto):
    subtotal = sum(item['precio'] * item['cantidad'] for item in carrito)
    return {'subtotal': subtotal, 'impuestos': subtotal * tasa_impuesto, 'total': subtotal + subtotal * tasa_impuesto}
```
