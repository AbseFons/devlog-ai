## Objetivo
Comprender cómo las claves foráneas mantienen la consistencia de datos entre tablas relacionales, evitando referencias inválidas mediante restricciones ON DELETE y ON UPDATE.

## Explicación
Las claves foráneas vinculan una tabla hija a una tabla padre, asegurando que cada valor en la columna foránea exista realmente en la clave primaria del lado opuesto. Sin embargo, las bases de datos también permiten definir comportamientos ante cambios o eliminaciones en la tabla padre. Las cláusulas ON DELETE y ON UPDATE definen estas acciones: CASCADE elimina o actualiza registros hijos automáticamente; SET NULL establece el valor a nulo si permitido; RESTRICT impide la operación si existen dependencias; y NO ACTION permite la operación ignorando las restricciones (dependiendo del motor). Elegir la acción correcta es vital para la integridad lógica de la aplicación.

## Ejemplo (no ejecutado automáticamente)
Definición de una tabla 'pedidos' con clave foránea a 'clientes' que elimina el pedido automáticamente si el cliente se borra.

```sql
CREATE TABLE pedidos (
  id_pedido INT PRIMARY KEY,
  id_cliente INT NOT NULL,
  FOREIGN KEY (id_cliente) REFERENCES clientes(id_cliente)
    ON DELETE CASCADE
);
```
