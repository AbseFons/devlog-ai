## Objetivo
Aprender a configurar un registro de eventos en Python utilizando diccionarios JSON para facilitar el análisis automatizado y la depuración eficiente en aplicaciones modernas.

## Explicación
El logging tradicional con cadenas de texto dificulta el filtrado automático de errores. La solución es estructurar los registros como objetos JSON dentro del mensaje. Esto permite que herramientas externas extraigan campos específicos como 'usuario', 'accion' o 'codigo_errore' sin parsear patrones complejos. En esta microlección, utilizaremos la librería estándar logging para inyectar datos estructurados en cada entrada, asegurando consistencia y legibilidad inmediata en los logs de producción.

## Ejemplo (no ejecutado automáticamente)
Configuración básica de un logger que emite mensajes como diccionarios JSON en lugar de texto plano.

```python
import logging
import json
logger = logging.getLogger('app')
logger.info({'evento': 'inicio', 'usuario': 'admin'})
```
