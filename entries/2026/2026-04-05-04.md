## Objetivo
Comprender la diferencia entre ejecución secuencial y concurrente en Python, identificando cuándo es necesario utilizar hilos para mejorar la respuesta de aplicaciones bloqueantes sin violar el GIL.

## Explicación
Python utiliza un modelo de concurrencia basado en hilos (threads) para manejar tareas I/O intensivas como lecturas de red o disco. Debido al Global Interpreter Lock (GIL), los hilos no ejecutan código CPU en paralelo, pero permiten que el programa responda mientras espera operaciones externas. Esta lección introduce la creación básica de hilos usando la clase Thread y la función run. Se explica cómo estructurar una tarea asíncrona separándola del hilo principal para evitar bloqueos en la interfaz de usuario o en servidores web simples.

## Ejemplo (no ejecutado automáticamente)
Un script que imprime mensajes en dos hilos distintos simultáneamente para demostrar concurrencia básica.

```python
import threading

def tarea(nombre):
    for i in range(3):
        print(f'{nombre}: Iteración {i}')

hilo1 = threading.Thread(target=tarea, args=('Hilo A',))
hilo2 = threading.Thread(target=tarea, args=('Hilo B',))
hilo1.start()
hilo2.start()
```
