## Objetivo
Aprender a utilizar el comando git cherry-pick para aplicar un commit específico desde otra rama al flujo actual sin fusionar todo su historial, manteniendo la integridad del proyecto.

## Explicación
El comando git cherry-pick permite seleccionar y aplicar uno o más commits individuales de una rama remota o local a tu rama actual. Esto es útil cuando necesitas integrar un cambio concreto (como una corrección de seguridad) sin traer consigo otros cambios no deseados de esa rama. El proceso implica identificar el hash del commit deseado, ejecutar el comando y resolver manualmente posibles conflictos de archivos si existen. Es fundamental entender que cherry-pick crea un nuevo commit con el mismo contenido pero en un contexto diferente, lo que preserva la línea de tiempo original.

## Ejemplo (no ejecutado automáticamente)
Aplicar una corrección de seguridad específica desde la rama feature-auth a la rama main sin fusionar todo el historial de desarrollo.

```bash
git cherry-pick abc1234567890
# Si hay conflictos, edita los archivos afectados y ejecuta:
# git add <archivo>
# git cherry-pick --continue
```

## Ejercicio

## Criterios de revisión
El usuario debe ejecutar correctamente el comando con el hash válido, manejar conflictos si los hubiera usando git add y continuar el proceso, y confirmar visualmente en el historial que solo se aplicó el commit seleccionado.
