## Objetivo
Aprender a utilizar bloques try-except para prevenir que errores inesperados detengan la ejecución del programa, permitiendo un flujo de control más robusto y amigable para el usuario final.

## Explicación
En Python, las excepciones interrumpen el flujo normal cuando ocurren errores como división por cero o archivos inexistentes. El bloque try ejecuta código potencialmente arriesgado, mientras que except captura la excepción específica. Esto permite mostrar mensajes personalizados sin colapsar la aplicación. Es fundamental especificar el tipo de excepción para manejar casos distintos con lógica diferente. Sin este mecanismo, un error simple podría terminar todo el proceso abruptamente, frustrando al usuario y ocultando detalles útiles sobre qué salió mal durante la operación.

## Ejemplo (no ejecutado automáticamente)
Intenta dividir dos números; si hay error por división por cero, muestra un mensaje amigable en lugar de detenerse.

```python
try:
    resultado = 10 / 0
except ZeroDivisionError:
    print('No se puede dividir por cero.')
```
