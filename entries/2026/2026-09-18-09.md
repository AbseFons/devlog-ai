## Objetivo
Aprender a combinar múltiples CTEs para filtrar datos complejos antes de realizar agregaciones finales, mejorando la legibilidad del código frente a subconsultas anidadas profundas.

## Explicación
Las Common Table Expressions (CTEs) permiten estructurar consultas SQL complejas en pasos lógicos. En esta lección, utilizaremos dos CTEs: una para filtrar registros de ventas superiores a un umbral específico y otra para calcular métricas agregadas sobre ese subconjunto filtrado. Este enfoque modular evita la anidación excesiva de subconsultas, haciendo el código más mantenible. Primero, definimos 'ventas_alto' para seleccionar filas clave, luego 'metricas_finales' para sumar totales y promedios. Finalmente, unimos todo en una consulta principal que devuelve solo los resultados procesados.

## Ejemplo (no ejecutado automáticamente)
Consulta SQL que utiliza dos CTEs para filtrar ventas altas y calcular métricas agregadas.

```sql
WITH ventas_alto AS (
    SELECT id, monto FROM ventas WHERE monto > 1000
),
metricas_finales AS (
    SELECT COUNT(*) as total_ventas, AVG(monto) as promedio_monto FROM ventas_alto
)
SELECT * FROM metricas_finales;
```
