## Objetivo
Comprender los fundamentos de la paginación en APIs REST para manejar grandes volúmenes de datos de manera eficiente, evitando sobrecargar la memoria del cliente y optimizando el rendimiento de la red mediante la división de respuestas.

## Explicación
Las APIs modernas a menudo devuelven conjuntos de datos extensos que no caben en una sola respuesta. La paginación divide estos resultados en páginas manejables, típicamente controladas por parámetros como 'page' y 'limit'. Este enfoque reduce el tiempo de transferencia y mejora la experiencia del usuario al permitir un renderizado progresivo. Los encabezados HTTP como 'Link' o los campos JSON 'next_page_url' guían al cliente hacia los siguientes recursos. Implementar paginación desde el inicio es crucial para escalabilidad.

## Ejemplo (no ejecutado automáticamente)
Consulta a una API de usuarios filtrando por nombre y solicitando solo la primera página con un límite de 10 registros, obteniendo metadatos sobre la paginación en la respuesta JSON.

```javascript
const response = await fetch('https://api.ejemplo.com/users?name=juan&limit=10');
const data = await response.json();
console.log(data.items.length, 'registros en esta página');
```
