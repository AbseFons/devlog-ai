## Objetivo
Aprender a configurar un registro de eventos en Python utilizando diccionarios para capturar datos clave como IDs, mensajes y niveles, facilitando el análisis posterior con herramientas modernas.

## Explicación
El logging tradicional imprime texto plano que es difícil de filtrar. La solución es estructurar los registros como diccionarios JSON dentro del objeto Logger. Esto permite extraer automáticamente campos como 'id_transaccion' o 'usuario_id'. Se utiliza un formateador personalizado que convierte cada registro en una cadena JSON válida antes de escribirla en el archivo. Este enfoque mejora la depuración y la monitorización al mantener la integridad de los datos sin necesidad de parsear cadenas complejas manualmente.

## Ejemplo (no ejecutado automáticamente)
Configuración de un logger que registra una transacción de compra con formato JSON estructurado en consola.

```python
import logging
import json

def formateador_json(record):
    return json.dumps(record)

logger = logging.getLogger('mi_app')
logger.setLevel(logging.INFO)
handler = logging.StreamHandler()
handler.setFormatter(logging.Formatter('%(message)s'))
logger.addHandler(handler)

registro = {'nivel': 'INFO', 'id': 101, 'accion': 'compra_exitosa', 'monto': 50.0}
logger.info(json.dumps(registro))
```
