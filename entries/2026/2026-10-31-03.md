## Objetivo
Aprender a identificar y probar casos borde en la validación de fechas, asegurando que el sistema maneje correctamente límites como años bisiestos, transiciones de siglo y valores mínimos/máximos permitidos para evitar errores lógicos en producción.

## Explicación
Los casos borde son entradas críticas donde un pequeño cambio en los datos altera el comportamiento del sistema. En validación de fechas, esto incluye verificar que el año 2024 sea tratado como bisiesto correctamente (febrero tiene 29 días), que la fecha mínima aceptable no permita valores negativos ni años anteriores a la creación del sistema, y que la fecha máxima respete los límites hardware o lógicos definidos. También se debe probar la transición entre meses con diferente número de días, como de junio a julio, o entre años bisiestos y normales. Un caso borde típico es ingresar '2024-02-29' en un sistema que solo soporta fechas hasta 2023; el sistema debe rechazarlo o mostrar un mensaje claro sin colapsar.

## Ejemplo (no ejecutado automáticamente)
Script de Python que valida si una fecha dada es válida considerando años bisiestos y límites definidos, lanzando excepciones para casos borde como febrero en año no bisiesto o fechas fuera del rango permitido.

```python
from datetime import date

def validar_fecha(fecha_str):
    try:
        fecha = date.fromisoformat(fecha_str)
        if fecha.year < 2000 or fecha.year > 2100:
            raise ValueError("Fuera de rango permitido")
        return True
    except ValueError as e:
        print(f"Error: {e}")
        return False

validar_fecha('2024-02-29')  # Debe funcionar
validar_fecha('2023-02-29')  # Debe fallar
```
