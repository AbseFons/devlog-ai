## Objetivo
En esta microlección, analizamos la implementación crítica del algoritmo de ordenamiento por mezcla (Quicksort). Nos enfocaremos en la lógica de la función recursiva, específicamente en cómo definir el caso base para detener la recursión y evitar pilas infinitas. También exploraremos la estrategia de partición que reorganiza los elementos alrededor de un pivote seleccionado.

## Explicación
El Quicksort divide y conquista. Primero seleccionamos un pivote, luego reordenamos el array para que todos los elementos menores estén a la izquierda y los mayores a la derecha. El caso base es esencial: si el subarray tiene cero o un elemento, ya está ordenado, por lo que retornamos inmediatamente sin recursión adicional. Esta condición evita errores de desbordamiento de pila. La partición suele realizarse con dos punteros que convergen, intercambiando elementos hasta encontrar una inválida. Una vez completada la partición, el algoritmo se llama recursivamente en los subarrays izquierdo y derecho del pivote. Es vital elegir un buen pivote para evitar peores casos de complejidad O(n^2).

## Ejemplo (no ejecutado automáticamente)
Implementación de Quicksort en Python que incluye la función de partición y el caso base recursivo, ordenando una lista de números enteros aleatorios.

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)
```
