## Objetivo
Aprender a identificar y probar valores extremos en entradas numéricas para prevenir errores de desbordamiento, división por cero o lógica incorrecta cuando los datos se sitúan justo antes o después del rango esperado.

## Explicación
Los casos borde son fundamentales en la ingeniería de software porque los fallos suelen ocurrir en los límites de los rangos definidos. En este ejercicio, analizaremos una función que calcula un descuento basado en el número de compras. El caso borde crítico ocurre cuando el contador de compras es exactamente cero (división por cero o lógica inválida) o alcanza el límite superior del sistema. También debemos probar valores negativos si la especificación no los permite. La prueba debe cubrir: entrada mínima válida, valor justo antes del mínimo, valor máximo permitido y un valor que exceda el máximo. Esto asegura que la aplicación maneje gracefully estas situaciones sin colapsar ni mostrar datos erróneos.

## Ejemplo (no ejecutado automáticamente)
Script en Python que define una función de descuento y ejecuta pruebas unitarias para los casos borde de cero, negativo y valores extremos del rango permitido.

```python
def calcular_descuento(compras):
    if compras < 0:
        return 'Error: Compras negativas'
    if compras == 0:
        return 'Sin descuento'
    return f'Descuento del {min(10, compras * 2)}%'

print(calcular_descuento(-1))
print(calcular_descuento(0))
print(calcular_descuento(5))
```
