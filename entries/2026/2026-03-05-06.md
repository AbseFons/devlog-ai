## Objetivo
Comprender la estructura fundamental de una aplicación modular donde cada capa tiene responsabilidades únicas, facilitando el mantenimiento y la escalabilidad del sistema.

## Explicación
En esta primera lección de la serie sobre arquitectura por capas, exploraremos cómo dividir una aplicación en niveles lógicos: presentación, lógica de negocio y acceso a datos. Esta separación permite que cada componente evolucione independientemente. La capa de presentación maneja la interacción con el usuario, mientras que la lógica de negocio encapsula las reglas críticas del sistema. Finalmente, la capa de datos se encarga exclusivamente de persistir información. Este enfoque reduce la complejidad acoplada y mejora la reutilización del código en diferentes contextos.

## Ejemplo (no ejecutado automáticamente)
Implementación básica de una clase de servicio que valida un usuario antes de guardar sus datos, demostrando la separación entre lógica de negocio y acceso a datos.

```python
class UserService:
    def validate_user(self, user_data):
        return user_data.get('email') and len(user_data.get('password', '')) > 6
```
