## Objetivo
Aprender a diseñar pruebas de integración que verifiquen la comunicación entre servicios externos y la base de datos, asegurando que los flujos de datos funcionales operen correctamente en un entorno de desarrollo.

## Explicación
Las pruebas de integración evalúan la interacción entre componentes del sistema. En este caso, simularemos una llamada a una API pública para obtener datos climáticos y validar que la respuesta se procesa adecuadamente en nuestra aplicación local. El objetivo es confirmar que el cliente HTTP envía las peticiones correctas, interpreta los códigos de estado y maneja errores como respuestas 404 o 500 sin colapsar. Este enfoque garantiza que los módulos independientes funcionen bien cuando se combinan.

## Ejemplo (no ejecutado automáticamente)
Script en Bash que utiliza curl para llamar a una API pública de clima, guarda la respuesta y verifica el código de estado HTTP antes de imprimir un mensaje de éxito o error.

```bash
# Definir URL de la API y parámetros
URL="https://api.open-meteo.com/v1/forecast?latitude=40.4167&longitude=-3.7000&current=temperature_2m"
# Realizar la petición HTTP y capturar respuesta y estado
RESPUESTA=$(curl -s -w "\n%{http_code}" "$URL")
CODIGO=$(echo "$RESPUESTA" | tail -n1)
# Verificar si el código de estado indica éxito (2xx)
if [ "$CODIGO" -ge 200 ] && [ "$CODIGO" -lt 300 ]; then
    echo "Prueba exitosa: Código HTTP $CODIGO"
else
    echo "Error en la integración: Código HTTP $CODIGO"
fi
```
