## Objetivo
Aprender a crear listas nuevas iterando sobre una existente, aplicando condiciones para filtrar elementos o transformándolos mediante expresiones concisas que mejoran la legibilidad del código.

## Explicación
La comprensión de listas permite construir colecciones eficientes en una sola línea. Sintácticamente, se define una variable igual a un corchete con una expresión seguida de 'para' y una iteración, opcionalmente condicionada por un 'si'. Este patrón es ideal para limpiar datos o preparar entradas para algoritmos. Por ejemplo, podemos extraer solo los números pares de una lista grande multiplicándolos por dos al mismo tiempo. Evita bucles explícitos innecesarios y reduce la carga cognitiva al mantener la lógica en una estructura compacta y declarativa.

## Ejemplo (no ejecutado automáticamente)
Se crea una lista con números del uno al diez y se genera una nueva lista conteniendo solo los valores pares elevados al cuadrado.

```python
numeros = list(range(1, 11))
resultados_pares_cuadrados = [x**2 for x in numeros if x % 2 == 0]
```
