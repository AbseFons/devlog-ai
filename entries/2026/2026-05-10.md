## Objetivo
Comprender cómo el Event Loop gestiona tareas síncronas y asincrónicas, permitiendo a JavaScript ser no bloqueante. Aprenderás la diferencia entre el stack de ejecución y la cola de tareas para escribir código más eficiente y predecible.

## Explicación
JavaScript es un lenguaje de un solo hilo que utiliza el Event Loop para manejar operaciones asíncronas sin bloquear la ejecución principal. Las tareas síncronas se ejecutan en el Stack; si son largas, congelan la interfaz. Las asincrónicas (como lecturas de red) se mueven a una cola y esperan su turno. El Event Loop verifica constantemente si el Stack está vacío para procesar las tareas pendientes en la Cola de Tareas. Este mecanismo permite que aplicaciones web respondan fluidamente mientras cargan datos pesados en segundo plano, optimizando el rendimiento del navegador.

## Ejemplo (no ejecutado automáticamente)
Ejemplo práctico mostrando cómo setTimeout empuja una tarea a la cola de microtareas o tareas estándar, ejecutándose después de las operaciones síncronas inmediatas.

```javascript
console.log('Inicio sincrono');
setTimeout(() => console.log('Tarea asincrona'), 0);
console.log('Fin sincrono');
```
