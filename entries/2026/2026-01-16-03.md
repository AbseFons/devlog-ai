## Objetivo
Comprender por qué nunca almacenar contraseñas en texto plano y cómo utilizar funciones derivadas como Argon2id o bcrypt para proteger credenciales contra ataques de fuerza bruta y diccionario.

## Explicación
El almacenamiento de contraseñas en texto plano es una vulnerabilidad crítica. Si la base de datos se filtra, los atacantes obtienen acceso inmediato a todas las cuentas. La solución estándar es usar funciones de hash lentas como Argon2id, bcrypt o scrypt. Estas funciones introducen un factor de trabajo (iteraciones) que ralentiza el cálculo intencionalmente, haciendo inviable probar millones de contraseñas por segundo. Además, cada contraseña debe tener una 'sal' única y aleatoria, evitando que hashes idénticos revelen patrones en las contraseñas originales. Nunca utilices MD5 o SHA-256 para este fin, ya que son demasiado rápidos y vulnerables a tablas arcoíriz.

## Ejemplo (no ejecutado automáticamente)
Generación de un hash seguro usando la librería bcrypt en Python con una sal automática.

```python
import bcrypt
password = 'MiContraseñaSegura123'
hashed = bcrypt.hashpw(password.encode('utf-8'), bcrypt.gensalt())
print(hashed.decode('utf-8'))
```
