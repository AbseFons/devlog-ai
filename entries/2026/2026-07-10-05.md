## Objetivo
Aprender a usar la función yield para crear generadores que producen elementos bajo demanda, optimizando el uso de memoria al evitar almacenar listas completas en sistemas con recursos limitados.

## Explicación
Los iteradores permiten recorrer colecciones sin cargarlas todas en memoria. Los generadores son una forma concisa de definir iteradores usando la palabra clave yield. A diferencia de las funciones que retornan un valor final, yield pausa la ejecución y devuelve un elemento, guardando el estado local para reanudarse luego. Esto es ideal para flujos de datos infinitos o grandes conjuntos. En Python, al llamar a una función con yield, esta retorna un objeto generator. Cada invocación del iterador ejecuta el código hasta encontrar el siguiente yield. Este patrón es esencial en procesamiento de streams y análisis de datos masivo donde la memoria es crítica.

## Ejemplo (no ejecutado automáticamente)
Un generador que produce números pares infinitos bajo demanda, demostrando cómo yield permite pausar y reanudar la ejecución sin consumir memoria extra por cada elemento generado.

```python
def generar_pares():
    n = 0
    while True:
        yield n
        n += 2

for i in range(5):
    print(next(generar_pares()))
```
