## Objetivo
Comprender la separación de responsabilidades en una aplicación web básica, identificando las capas de presentación, lógica de negocio y datos para construir sistemas mantenibles y escalables.

## Explicación
En el diseño por capas, cada nivel tiene un propósito único. La capa de presentación maneja la entrada del usuario (HTML/JS). La capa de lógica de negocio contiene la regla de negocio y los algoritmos. Finalmente, la capa de datos se encarga de persistir información en bases de datos o archivos. Esta separación permite que el equipo de frontend trabaje independientemente del backend, facilita las pruebas unitarias y hace que el código sea más legible. Al evitar mezclar estas responsabilidades, reducimos la complejidad cognitiva y prevenimos errores comunes como cálculos de negocio dentro de funciones de renderizado.

## Ejemplo (no ejecutado automáticamente)
Función pura en JavaScript que calcula el precio final aplicando un descuento basado en la lógica de negocio definida en una capa separada.

```javascript
function calcularPrecioFinal(precioBase, porcentajeDescuento) {
  const descuento = precioBase * (porcentajeDescuento / 100);
  return precioBase - descuento;
}
```

## Ejercicio

## Criterios de revisión
