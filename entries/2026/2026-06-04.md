## Objetivo
Comprender la diferencia fundamental entre las operaciones de lectura (GET) y creación (POST) en una API REST, identificando sus verbos, códigos de estado asociados y patrones de diseño estándar para construir servicios web seguros y predecibles.

## Explicación
En el diseño de APIs RESTful, los métodos HTTP definen la naturaleza de la operación. El verbo GET se utiliza exclusivamente para recuperar recursos existentes sin efectos secundarios en el servidor; si falla, suele devolver un 404. Por otro lado, POST inicia una acción que cambia el estado del recurso, típicamente creando un nuevo elemento en una colección. Este método es idempotente respecto a la creación de datos duplicados si no se valida previamente. Ambos métodos deben respetar la estructura JSON en los cuerpos de respuesta y solicitudes para garantizar interoperabilidad entre clientes y servidores heterogéneos.

## Ejemplo (no ejecutado automáticamente)
Solicitud de creación de un nuevo usuario mediante POST con validación básica de campos requeridos.

```javascript
const response = await fetch('https://api.ejemplo.com/usuarios', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ nombre: 'Ana', email: 'ana@ejemplo.com' })
});
const nuevoUsuario = await response.json();
```
