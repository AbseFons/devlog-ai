## Objetivo
Comprender la lógica de reducción del espacio de búsqueda en arrays ordenados mediante comparación iterativa, logrando una complejidad temporal O(log n) para localizar elementos eficientemente.

## Explicación
La búsqueda binaria es un algoritmo fundamental que requiere que los datos estén preordenados. A diferencia de la búsqueda lineal, divide el rango de búsqueda a la mitad en cada paso. Comparamos el elemento central con el objetivo: si coinciden, terminamos; si el objetivo es menor, buscamos en la mitad izquierda; si es mayor, en la derecha. Este proceso se repite hasta encontrar el elemento o agotar las opciones. Es crucial manejar correctamente los índices para evitar bucles infinitos o errores de acceso.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python que busca un valor en una lista ordenada devolviendo su índice o -1 si no existe.

```python
def buscar_binario(lista, objetivo):
    izq, der = 0, len(lista) - 1
    while izq <= der:
        centro = (izq + der) // 2
        if lista[centro] == objetivo:
            return centro
        elif lista[centro] < objetivo:
            izq = centro + 1
        else:
            der = centro - 1
    return -1
```
