## Objetivo
Dominar la sintaxis moderna de JavaScript para manejar operaciones asíncronas, evitando el uso de callbacks anidados y mejorando la legibilidad del código mediante promesas y await.

## Explicación
En JavaScript, las operaciones asíncronas como llamadas a APIs requieren un manejo especial. Las Promesas representan el valor eventual de una operación que aún no se ha completado. La sintaxis async/await simplifica enormemente este proceso, permitiendo escribir código secuencial en lugar de usar callbacks o .then(). Esto hace que el flujo sea más lineal y fácil de depurar. Es crucial manejar errores con bloques try/catch para evitar que la aplicación falle silenciosamente.

## Ejemplo (no ejecutado automáticamente)
Ejemplo de llamada a una API simulada usando async/await con manejo de errores básico.

```javascript
async function obtenerDatos() {
  try {
    const respuesta = await fetch('https://jsonplaceholder.typicode.com/posts/1');
    return await respuesta.json();
  } catch (error) {
    console.error('Error:', error);
  }
}
```

## Ejercicio
Crea una función asíncrona que simule una llamada a API con setTimeout, devuelva el resultado y maneje un error simulado lanzando un Error si el tiempo excede los 2 segundos.

## Criterios de revisión
El código debe usar la palabra clave async antes de la función, await dentro del cuerpo, y un bloque try/catch para capturar errores. El mensaje de error debe incluir el texto 'Tiempo agotado'.
