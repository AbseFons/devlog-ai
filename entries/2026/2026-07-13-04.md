## Objetivo
Aprender a crear listas nuevas filtrando elementos existentes mediante expresiones condicionales concisas, optimizando el código sin bucles explícitos.

## Explicación
La comprensión de listas permite construir colecciones eficientes en una sola línea. Sintaxis: [expresion for elemento in iterable if condicion]. Esto filtra y transforma datos simultáneamente. Ejemplo práctico: extraer números pares de una lista grande. Es más legible que un bucle for tradicional cuando la lógica es simple. Python evalúa la expresión para cada elemento que cumple la condición, generando el resultado final instantáneamente.

## Ejemplo (no ejecutado automáticamente)
Se crea una lista con números del 1 al 10 y se filtra solo los pares usando comprensión de listas.

```python
numeros = list(range(1, 11))
pares = [x for x in numeros if x % 2 == 0]
print(pares)
```
