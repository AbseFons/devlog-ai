## Objetivo
Comparar las diferencias fundamentales entre el framework estándar unittest y la librería pytest, destacando la sintaxis más concisa de pytest para escribir pruebas legibles y mantenibles rápidamente.

## Explicación
En Python, unittest es parte del estándar pero utiliza una estructura jerárquica rígida con clases que heredan de TestCase. Por el contrario, pytest permite definir funciones simples como casos de prueba, eliminando la necesidad de heredar clases. Esto reduce la boilerplate code y mejora la legibilidad. pytest también ofrece fixtures automáticos para configuración de entorno y un runner más rápido con reportes detallados por defecto. Para proyectos modernos, pytest es preferible por su flexibilidad y ecosistema rico en plugins.

## Ejemplo (no ejecutado automáticamente)
Función de prueba simple usando pytest que verifica una suma básica sin necesidad de heredar clases.

```python
def test_suma():
    assert suma(2, 3) == 5
```
