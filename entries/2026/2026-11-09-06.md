## Objetivo
Aprender a serializar estructuras de datos anidadas, listas y objetos personalizados utilizando el módulo json de Python, asegurando la integridad de los datos al convertirlos a texto.

## Explicación
En esta lección profundizamos en la capacidad del módulo json para manejar diccionarios con valores heterogéneos. A diferencia de formatos binarios como pickle, JSON es un estándar universal que soporta nativamente cadenas, números, booleanos, nulos y estructuras anidadas. Python convierte automáticamente las listas a arrays JSON y los diccionarios a objetos JSON. Es crucial recordar que los diccionarios en Python no tienen un orden garantizado hasta la versión 3.7, pero el módulo json respeta el orden de inserción desde entonces. Para serializar datos complejos, se utiliza la función json.dumps(), pasando el objeto estructurado como argumento. Este proceso es fundamental para APIs REST y almacenamiento de configuración.

## Ejemplo (no ejecutado automáticamente)
Serialización de un diccionario con lista anidada y valores mixtos

```python
import json

data = {
    "usuario": "Ana",
    "edades_hermanos": [10, 12, 14],
    "activo": True,
    "saldo": 0.0
}

json_string = json.dumps(data)
```
