## Objetivo
Analizar cómo la elección del punto medio afecta el rendimiento del algoritmo de ordenamiento por mezcla, enfocándose en la división equitativa de subarrays para garantizar una complejidad logarítmica óptima.

## Explicación
En esta lección exploramos la implementación recursiva del Merge Sort. El núcleo del algoritmo reside en dividir el array hasta obtener sublistas de longitud uno y luego fusionarlas ordenadamente. Es crucial calcular el índice medio correctamente para evitar sesgos que incrementen la profundidad del árbol de recursión. Una división desigual puede degradar el rendimiento, aunque la complejidad asintótica permanezca inalterada. Este enfoque asegura estabilidad y eficiencia en grandes volúmenes de datos.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python que divide un array impar usando floor para garantizar subarrays balanceados durante la fusión recursiva.

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
```
