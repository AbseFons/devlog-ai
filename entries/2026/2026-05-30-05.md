## Objetivo
Comprender por qué almacenar contraseñas en texto plano es inseguro y cómo las funciones hash con sal protegen la integridad de los datos de autenticación en sistemas modernos.

## Explicación
Almacenar contraseñas en texto plano expone a los usuarios a robos masivos si se filtra la base de datos. La solución estándar es usar funciones hash criptográficas como bcrypt o Argon2, que son lentas por diseño para dificultar ataques de fuerza bruta. Es crucial añadir una 'sal' aleatoria única por usuario antes de hashear; esto neutraliza las tablas rainbow y asegura que dos usuarios con la misma contraseña tengan hashes distintos. Nunca uses MD5 o SHA-1 sin sal, ya que son vulnerables a colisiones y ataques precalculados. El hash debe ser irreversible: nunca intentes recuperar la contraseña original desde el valor almacenado.

## Ejemplo (no ejecutado automáticamente)
Generación de un hash seguro para una contraseña usando Python con la librería bcrypt, incluyendo una sal automática.

```python
import bcrypt
password = "MiContraseñaSegura123"
sal = bcrypt.gensalt()
hash_password = bcrypt.hashpw(password.encode(), sal)
print(hash_password.decode())
```
