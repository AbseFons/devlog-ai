## Objetivo
Aprender a utilizar el patrón adaptador para permitir que una clase con una interfaz incompatible trabaje con un cliente existente sin modificar su código original.

## Explicación
El patrón adaptador actúa como un puente entre dos interfaces incompatibles. Imagina un sistema legado que usa métodos síncronos y tu nuevo módulo requiere asíncrono. El adaptador envuelve la clase antigua, traduce las llamadas de entrada a su formato interno y luego adapta los resultados devueltos al formato esperado por el cliente. Esto permite integrar componentes heredados en arquitecturas modernas sin reescribir todo el sistema, manteniendo la coherencia del diseño y facilitando pruebas unitarias aisladas.

## Ejemplo (no ejecutado automáticamente)
Un adaptador que envuelve una calculadora síncrona antigua para exponerla como un servicio asíncrono moderno.

```javascript
class LegacyCalculator {
  add(a, b) { return a + b; }
}

async class AsyncAdapter {
  constructor(legacy) { this.legacy = legacy; }
  async add(a, b) { return await Promise.resolve(this.legacy.add(a, b)); }
}
```

## Ejercicio
Crea un adaptador para una clase 'LegacyPrinter' que imprime texto en consola de forma síncrona, exponiendo una interfaz asíncrona 'printAsync(texto)' que resuelva la operación real tras 50ms simulados.

## Criterios de revisión
El código debe instanciar el adaptador con la clase original y llamar al método asíncrono sin errores. La salida en consola debe coincidir exactamente con el texto ingresado.
