## Objetivo
Aprender a definir y aplicar decoradores simples para extender la funcionalidad de funciones sin modificar su código interno, utilizando @ como sintaxis de azúcar.

## Explicación
Los decoradores son funciones especiales que toman otra función como argumento y devuelven una nueva versión con comportamientos adicionales. En Python, se usan el símbolo @ antes del nombre de la función para aplicarlos automáticamente. Por ejemplo, podemos crear un decorador que registre cada vez que una función se ejecuta. Esto es útil para añadir logging, control de acceso o medición de tiempo sin ensuciar la lógica principal. La estructura básica implica definir una función externa que recibe la función objetivo, crea una envoltura interna y devuelve esa envuelta.

## Ejemplo (no ejecutado automáticamente)
Un decorador simple que imprime un mensaje antes y después de ejecutar una función.

```python
def mi_decorador(func):
    def envoltura(*args, **kwargs):
        print("Antes de la ejecución")
        func(*args, **kwargs)
        print("Después de la ejecución")
    return envoltura

@mi_decorador
def saludar(nombre):
    print(f"Hola {nombre}")

saludar("Ana")
```
