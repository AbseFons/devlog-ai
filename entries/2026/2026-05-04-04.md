## Objetivo
Comprender la diferencia fundamental entre iteradores y generadores, aprendiendo a usar 'yield' para crear funciones que producen valores de forma eficiente y bajo demanda, optimizando el uso de memoria en procesamiento de datos secuenciales.

## Explicación
En Python, los iteradores son objetos que implementan el protocolo __iter__ y __next__, permitiendo recorrer colecciones. Los generadores son una forma concisa de crear iteradores usando la palabra clave 'yield'. Mientras un bucle 'for' sobre una lista carga todos los datos en memoria, un generador produce elementos uno a uno. Esto es crucial cuando se manejan flujos infinitos o archivos grandes. La función 'range()' devuelve un objeto iterador, no una lista completa. Al usar 'yield', la ejecución de la función se pausa y reanuda, manteniendo el estado local entre llamadas.

## Ejemplo (no ejecutado automáticamente)
Funcion que genera numeros pares infinitos usando yield para demostrar eficiencia en memoria.

```python
def pares_infinitos():
    n = 0
    while True:
        yield n
        n += 2

for i in pares_infinitos():
    if i > 10:
        break
    print(i)
```
