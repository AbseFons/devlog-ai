## Objetivo
Aprender a seleccionar elementos HTML dinámicamente en JavaScript y modificar sus propiedades, estilos o contenido para crear interfaces interactivas sin recargar la página.

## Explicación
La manipulación del DOM permite interactuar con el contenido web. Utilizamos selectores como document.getElementById o querySelector para localizar nodos específicos. Una vez seleccionados, podemos cambiar su texto mediante node.textContent, ajustar estilos visuales usando node.style.propiedad y añadir eventos de interacción. Es fundamental entender que cada elemento HTML es un objeto en memoria accesible desde el script. Esta capacidad transforma páginas estáticas en aplicaciones dinámicas donde los datos se actualizan en tiempo real según la acción del usuario, mejorando la experiencia sin necesidad de recargar.

## Ejemplo (no ejecutado automáticamente)
Selecciona un botón por su ID y cambia su texto al hacer clic, demostrando manipulación básica de contenido y eventos.

```javascript
const btn = document.getElementById('miBoton');
btn.addEventListener('click', () => {
  btn.textContent = '¡Texto actualizado!';
});
```
