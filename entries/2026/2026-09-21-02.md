## Objetivo
Comprender el concepto de recursión mediante la implementación de un algoritmo clásico para calcular factoriales, identificando claramente las condiciones de parada y la llamada recursiva en un contexto de programación funcional.

## Explicación
La recursión permite que una función se llame a sí misma para resolver subproblemas más pequeños. En este caso, calculamos el factorial de un número entero positivo n (n!). La lógica implica dos partes esenciales: la condición base, donde n es 1 o 0 y el resultado es 1, evitando bucles infinitos; y el paso recursivo, que multiplica n por el factorial de n-1. Este enfoque descompone el problema original en instancias más simples hasta alcanzar la condición base. Es fundamental asegurar que cada llamada recursiva se acerque a la condición de parada para garantizar la terminación correcta del programa.

## Ejemplo (no ejecutado automáticamente)
Función que calcula el factorial de un número entero positivo utilizando recursión, devolviendo el producto acumulado hasta llegar al caso base.

```python
def factorial(n):
    if n == 0 or n == 1:
        return 1
    else:
        return n * factorial(n - 1)
```
