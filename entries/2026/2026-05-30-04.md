## Objetivo
Aprender a utilizar el patrón adaptador para integrar componentes con interfaces incompatibles sin modificar su código original, facilitando la evolución del sistema manteniendo la coherencia arquitectónica.

## Explicación
El patrón adaptador permite que dos clases con interfaces incompatibles colaboren. Imagina un módulo legacy que expone datos mediante una API síncrona antigua y un nuevo servicio que requiere llamadas asíncronas modernas. En lugar de refacturar el código heredado, creamos un adaptador que envuelve la lógica existente. Este wrapper intercepta las solicitudes del nuevo cliente, traduce los parámetros al formato antiguo, invoca la función legacy y luego mapea la respuesta devuelta al formato esperado por el sistema actual. Esta estrategia protege la inversión en código existente mientras se introduce gradualmente nuevas dependencias, reduciendo riesgos de regresión y permitiendo una integración suave entre sistemas heterogéneos.

## Ejemplo (no ejecutado automáticamente)
Clase adaptador que envuelve un servicio HTTP síncrono para exponer una interfaz asíncrona moderna.

```javascript
class LegacyAdapter {
  constructor(legacyService) { this.legacy = legacyService; }
  async fetchData(id) { return this.legacy.getData(id); }
```

## Ejercicio
Crea una clase 'LegacyAdapter' que acepte un objeto con el método 'getData'. Implementa un método asíncrono 'fetchData' que llame a 'getData' y retorne la promesa resultante.

## Criterios de revisión
El código debe ser funcional, usar TypeScript o JavaScript moderno, no modificar la clase legacy original y manejar correctamente las promesas.
