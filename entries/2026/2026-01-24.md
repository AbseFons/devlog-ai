## Objetivo
Aprender a utilizar la sentencia 'with' en Python para garantizar que los recursos, como archivos, se cierren automáticamente al finalizar su uso, evitando errores comunes y fugas de memoria.

## Explicación
En Python, los context managers permiten automatizar tareas de limpieza. La sentencia 'with' invoca el método '__enter__' al entrar al bloque y '__exit__' al salir, incluso si hay excepciones. Esto es crucial para archivos: asegura que el puntero se cierre correctamente sin necesidad de bloques 'try-except-finally' manuales complejos. Python implementa esto internamente en clases como 'open'. Usar 'with open(...)' es la práctica estándar para lectura/escritura segura. Evita dejar archivos abiertos accidentalmente, lo que puede bloquear recursos del sistema o causar corrupción de datos si el programa se interrumpe abruptamente durante la operación.

## Ejemplo (no ejecutado automáticamente)
Lectura segura de un archivo de texto y cierre automático del recurso al finalizar el bloque 'with'.

```python
with open('datos.txt', 'r') as f:
    contenido = f.read()
    print(contenido)
```

## Ejercicio
Crea un archivo llamado 'registro.log' con tres líneas de texto. Luego, escribe un script que utilice 'with open' para leer el contenido y lo imprima en pantalla sin dejar el archivo abierto.

## Criterios de revisión
El código debe usar la sentencia 'with', abrir el archivo en modo lectura ('r'), asignar la variable al contexto 'as f', leer todo el contenido con 'read()' e imprimirlo. No debe existir código fuera del bloque 'with' que manipule el mismo archivo abierto.
