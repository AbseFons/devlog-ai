## Objetivo
Comprender y aplicar el principio de mínimo privilegio (PoLP) configurando roles con permisos estrictos para reducir la superficie de ataque en entornos cloud, asegurando que cada servicio solo acceda a los recursos necesarios para su funcionamiento específico.

## Explicación
El principio de mínimo privilegio establece que cualquier entidad de seguridad, como un usuario o servicio, debe tener únicamente los permisos mínimos requeridos para realizar sus funciones. En ingeniería de software moderna, esto es crítico para mitigar riesgos ante brechas de credenciales. Por ejemplo, un servicio de procesamiento de imágenes no necesita acceso a la base de datos de usuarios ni capacidad de eliminar recursos. Al asignar roles con políticas granulares en plataformas como AWS IAM o Azure RBAC, limitamos el daño potencial si una instancia es comprometida. Esta práctica fomenta una arquitectura defensiva donde cada componente opera dentro de un perímetro de seguridad bien definido, facilitando auditorías y cumplimiento normativo sin sacrificar la operatividad del sistema.

## Ejemplo (no ejecutado automáticamente)
Definición de una política IAM en JSON que otorga a un servicio Lambda solo lectura sobre un bucket S3 específico para procesamiento de logs, evitando acceso administrativo o escritura no autorizada.

```json
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": ["s3:GetObject", "s3:ListBucket"],
    "Resource": [
      "arn:aws:s3:::logs-prod-app",
      "arn:aws:s3:::logs-prod-app/*"
    ]
  }]
}
```

## Ejercicio
Crea un archivo de política IAM en tu entorno local que otorgue a una función serverless solo los permisos necesarios para escribir logs en un bucket específico, sin incluir acciones de administración o lectura de datos sensibles.

## Criterios de revisión
La política debe especificar exactamente las acciones permitidas (máximo 3), el recurso objetivo completo y no incluir permisos genéricos como 's3:*' ni 'iam:PassRole'. El archivo debe ser válido JSON sin errores de sintaxis.
