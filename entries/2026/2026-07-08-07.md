## Objetivo
Comprender la lógica del algoritmo de búsqueda por anchura (BFS) para encontrar el camino más corto en grafos no ponderados utilizando una cola y un conjunto visitado.

## Explicación
La Búsqueda por Anchura (BFS) es fundamental para explorar estructuras de datos tipo grafo. A diferencia de DFS, que profundiza, BFS expande nivel a nivel. Utilizamos una cola FIFO para procesar nodos: primero entramos la raíz, luego sus vecinos inmediatos, y así sucesivamente. Es crucial marcar los nodos como visitados al ingresarlos a la cola para evitar ciclos infinitos en grafos cíclicos. Este enfoque garantiza que el primer camino encontrado hacia un nodo sea el de menor longitud en términos de número de aristas, lo cual es vital en redes sociales o mapas de transporte.

## Ejemplo (no ejecutado automáticamente)
Implementación de BFS para encontrar el camino más corto desde el nodo 'A' hasta el 'D' en un grafo no ponderado simple.

```python
from collections import deque

def bfs(graph, start):
    queue = deque([start])
    visited = {start}
    path = {start: None}
    while queue:
        node = queue.popleft()
        if node == 'D': return path
        for neighbor in graph.get(node, []):
            if neighbor not in visited:
                visited.add(neighbor)
                path[neighbor] = node
                queue.append(neighbor)
```
