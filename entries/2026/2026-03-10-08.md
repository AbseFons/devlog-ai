## Objetivo
Aprender a prevenir inyecciones SQL y XSS validando y sanitizando datos entrantes antes de procesarlos, asegurando la integridad del sistema y protegiendo la información sensible de los usuarios.

## Explicación
La seguridad de las aplicaciones web depende críticamente de validar todas las entradas externas. Un error común es confiar ciegamente en el usuario o en la base de datos. La estrategia correcta implica dos pasos: primero, validar que el dato sea del tipo y formato esperado (ej. un email debe tener '@'); segundo, sanitizarlo eliminando caracteres peligrosos como comillas simples o guiones antes de insertarlo en consultas SQL o renderizarlo en HTML. Por ejemplo, si un campo espera un número entero, cualquier letra debe ser rechazada inmediatamente. Si se permite texto, se deben escapar caracteres especiales según el contexto. Esto reduce la superficie de ataque y cumple con principios de defensa en profundidad.

## Ejemplo (no ejecutado automáticamente)
Función que valida que una entrada sea un número entero positivo antes de usarlo en una consulta SQL segura.

```javascript
function validarEntrada(texto) {
  const regex = /^\d+$/;
  if (!regex.test(texto)) throw new Error('Formato inválido');
  return parseInt(texto);
}
```
