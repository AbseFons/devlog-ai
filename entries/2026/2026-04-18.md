## Objetivo
Aprender a configurar un registro estructurado en Python usando diccionarios para facilitar la búsqueda y el análisis de datos mediante herramientas como JSON o Elasticsearch, mejorando la legibilidad de los logs.

## Explicación
El logging tradicional imprime texto plano que es difícil de filtrar. La solución es registrar diccionarios (JSON) directamente. Usaremos la librería estándar 'logging' con un formateador personalizado. Primero importamos las funciones necesarias y creamos un logger. Luego, definimos un formateador que convierta el registro a JSON antes de escribirlo en consola o archivo. Esto permite extraer campos como 'nivel', 'mensaje' o 'usuario' fácilmente sin parsear texto.

## Ejemplo (no ejecutado automáticamente)
Configuración de un logger que registra eventos como diccionarios JSON en lugar de cadenas de texto, permitiendo una filtrado eficiente por nivel o módulo.

```python
import logging
import json

def json_format(record):
    return json.dumps(record)

logger = logging.getLogger('mi_app')
logger.setLevel(logging.INFO)
handler = logging.StreamHandler()
handler.setFormatter(logging.Formatter(json_format))
logger.addHandler(handler)
logger.info({'nivel': 'INFO', 'mensaje': 'Inicio del sistema', 'usuario': 'admin'})
```
