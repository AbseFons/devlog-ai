## Objetivo
Comprender la lógica recursiva del algoritmo Merge Sort, su complejidad temporal garantizada de O(n log n) y cómo divide el problema en subconjuntos ordenables para fusionarlos eficientemente sin modificar el array original.

## Explicación
El Merge Sort es un algoritmo de ordenamiento estable basado en la estrategia 'divide y vencerás'. Primero, divide recursivamente la lista hasta que cada sublista contiene un solo elemento, considerado automáticamente ordenado. Luego, fusiona pares de sublistas adyacentes comparando sus elementos más pequeños para construir una nueva lista ordenada. Este proceso se repite hasta obtener una sola lista completa. Su principal ventaja es el rendimiento consistente en todos los casos (mejor, promedio y peor), lo que lo hace ideal para estructuras de datos grandes donde la estabilidad del orden relativo es crítica.

## Ejemplo (no ejecutado automáticamente)
Implementación recursiva en Python que divide un array numérico desordenado hasta obtener subarrays de longitud uno y los fusiona comparando elementos por valor ascendente.

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```
