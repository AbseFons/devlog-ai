## Objetivo
Dominar la implementación iterativa de la búsqueda binaria para arrays ordenados, reduciendo el uso de memoria en comparación con la recursión y mejorando el rendimiento en entornos de recursos limitados.

## Explicación
La búsqueda binaria es un algoritmo fundamental que divide repetidamente el rango de búsqueda a la mitad. En esta lección, nos enfocamos en la versión iterativa. Comenzamos definiendo los límites izquierdo e inferior del array. Calculamos el punto medio y comparamos el valor objetivo con el elemento en ese índice. Si coinciden, retornamos el índice; si el objetivo es menor, ajustamos el límite superior al punto medio menos uno; si es mayor, ajustamos el límite inferior al punto medio más uno. Este proceso se repite hasta que los límites se crucen, indicando que el elemento no existe. La ventaja clave de la iteración sobre la recursión es evitar el desbordamiento de pila y el sobrecostoso uso de memoria para llamadas de función.

## Ejemplo (no ejecutado automáticamente)
Función en JavaScript que busca un número entero en un array ordenado devolviendo su índice o -1 si no se encuentra, utilizando bucle while.

```javascript
function binarySearch(arr, target) {
  let left = 0;
  let right = arr.length - 1;
  while (left <= right) {
    const mid = Math.floor((left + right) / 2);
    if (arr[mid] === target) return mid;
    else if (arr[mid] < target) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}
```
