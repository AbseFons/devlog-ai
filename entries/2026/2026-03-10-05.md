## Objetivo
Comprender la importancia de las pruebas de integración para verificar que los módulos individuales interactúan correctamente, detectando fallos en la comunicación entre servicios y asegurando la integridad de los datos en flujos complejos antes del despliegue.

## Explicación
Las pruebas de integración evalúan la interacción entre componentes de software distintos. A diferencia de las pruebas unitarias, aquí se valida que el intercambio de datos sea coherente y que los errores se manejen adecuadamente. En este caso, simularemos una transacción bancaria donde un servicio calcula intereses y otro actualiza el saldo. Si uno falla, la otra operación debe abortarse para mantener la consistencia. Este enfoque revela problemas de interfaz, protocolos de comunicación o inconsistencias de datos que las pruebas aisladas no capturan.
