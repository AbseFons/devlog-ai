## Objetivo
Aprender las diferencias clave entre sets (conjuntos) y diccionarios, sus operaciones nativas y cómo utilizarlos para optimizar búsquedas y almacenar datos relacionales de manera eficiente en aplicaciones reales.

## Explicación
En Python, los sets son colecciones no ordenadas de elementos únicos, ideales para verificar membresía rápida o eliminar duplicados. Los diccionarios, por otro lado, mapean claves a valores, ofreciendo acceso O(1) promedio mediante sus claves. Mientras que un set usa hash interno para unicidad, un dict gestiona pares clave-valor. Ambos aprovechan la inmutabilidad de los hashes subyacentes (siempre que las claves sean inmutables). Utiliza sets para filtrar listas de usuarios activos y diccionarios para configurar opciones de servidor donde cada configuración es única.

## Ejemplo (no ejecutado automáticamente)
Creación de un set con elementos únicos y un diccionario con configuraciones de red, demostrando la inserción y acceso a datos.

```python
# Crear un set de puertos abiertos sin duplicados
puertos = {80, 443, 22, 80}
# Crear un diccionario con configuraciones de servidor
config = {'host': '192.168.1.1', 'timeout': 30}
```
