## Objetivo
Aprender a diseñar una prueba de integración que verifique la comunicación correcta entre un servicio frontend y un backend, asegurando que los datos se transformen y transmitan sin errores en el flujo completo de la aplicación.

## Explicación
Las pruebas de integración evalúan la interacción entre componentes distintos. En este caso, simularemos una petición HTTP a un endpoint REST. El objetivo es confirmar que el cliente envía los datos correctos, el servidor procesa la lógica de negocio y devuelve una respuesta con el estado esperado. Utilizaremos herramientas como Postman o scripts automatizados para validar códigos de estado 200 OK y la estructura JSON del cuerpo de la respuesta. Es crucial verificar no solo la funcionalidad, sino también la robustez ante errores de red o formatos de datos incorrectos.

## Ejemplo (no ejecutado automáticamente)
Script en Python usando la librería requests para enviar una petición POST a un endpoint ficticio y validar la respuesta JSON recibida.

```python
import requests
response = requests.post('https://api.ejemplo.com/v1/usuarios', json={'nombre': 'Ana'})
assert response.status_code == 201 and response.json()['id'] is not None
```
