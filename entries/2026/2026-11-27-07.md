## Objetivo
Comprender la implementación eficiente del algoritmo de ordenamiento por mezcla, enfocándose en la selección estratégica del pivote y la condición de parada recursiva para evitar desbordamiento de pila.

## Explicación
El ordenamiento por mezcla divide el problema dividiendo el arreglo alrededor de un elemento pivot. En esta serie, analizamos cómo elegir el pivot (por ejemplo, el último elemento) y manejar el caso base donde el subarreglo tiene uno o cero elementos, lo que detiene la recursión. La función particiona el array en dos: elementos menores a la izquierda y mayores a la derecha. Es crucial implementar correctamente los punteros de intercambio para garantizar O(n log n) promedio. Un error común es olvidar verificar si el índice izquierdo es mayor o igual al derecho antes de llamar recursivamente, lo que causaría un error infinito.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python que ordena una lista de enteros utilizando la estrategia de pivot final y detección correcta del caso base para subarreglos de longitud uno.

```python
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[-1]
    left = [x for x in arr[:-1] if x < pivot]
    right = [x for x in arr[:-1] if x >= pivot]
    return quicksort(left) + [pivot] + quicksort(right)
```
