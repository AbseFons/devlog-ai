## Objetivo
Aprender a definir subconsultas temporales legibles usando la sintaxis WITH para simplificar consultas complejas de múltiples niveles.

## Explicación
Las Common Table Expressions (CTE) permiten declarar una tabla temporal nombrada que existe solo durante la ejecución de la consulta actual. Esto mejora enormemente la legibilidad al reemplazar subconsultas anidadas profundas por bloques lógicos claros. Se utiliza la cláusula WITH seguida del nombre y la definición entre paréntesis. Es ideal para cálculos recursivos o cuando se necesita referenciar una lógica intermedia varias veces en un SELECT principal, evitando duplicar código y facilitando el mantenimiento del script SQL.

## Ejemplo (no ejecutado automáticamente)
Consulta que calcula el total de ventas por categoría usando una CTE para filtrar productos primero.

```sql
WITH VentasFiltradas AS (
  SELECT categoria, precio FROM productos WHERE stock > 0
)
SELECT categoria, SUM(precio) as total_ventas FROM VentasFiltradas GROUP BY categoria;
```
