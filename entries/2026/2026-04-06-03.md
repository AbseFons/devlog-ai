## Objetivo
Comprender por qué almacenar contraseñas en texto plano es inseguro y cómo las funciones hash unidireccionales protegen los datos de usuarios ante filtraciones, garantizando la integridad sin permitir la recuperación directa.

## Explicación
Almacenar contraseñas en texto plano expone a los sistemas a robos masivos. Si una base de datos se filtra, los atacantes obtienen las credenciales inmediatamente. La solución es usar funciones hash criptográficas como bcrypt o Argon2. Estas transforman la contraseña en un string irreversible. Incluso si el atacante accede al hash, no puede deducir la contraseña original fácilmente. Además, se añade una 'sal' aleatoria a cada hash para evitar ataques de diccionario precalculados. Esto asegura que dos usuarios con la misma contraseña tengan hashes distintos. El sistema verifica contraseñas comparando el hash ingresado con el almacenado, nunca revelando la clave real.

## Ejemplo (no ejecutado automáticamente)
Implementación básica en Python usando la librería bcrypt para hashear una contraseña de ejemplo antes de guardarla en una base de datos simulada.

```python
import bcrypt
password = "MiContraseñaSegura123"
salt = bcrypt.gensalt()
hashed_password = bcrypt.hashpw(password.encode('utf-8'), salt)
print(hashed_password.decode('utf-8'))
```
