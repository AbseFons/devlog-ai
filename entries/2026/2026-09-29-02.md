## Objetivo
Comprender la sintaxis básica de las Common Table Expressions para simplificar consultas complejas y mejorar la legibilidad del código SQL en entornos de producción.

## Explicación
Las Common Table Expressions o CTE permiten definir un conjunto de resultados temporalmente disponible dentro de una consulta principal. Esto facilita el uso de subconsultas recursivas o múltiples referencias a datos intermedios sin necesidad de crear vistas permanentes. La sintaxis utiliza la cláusula WITH seguida del nombre de la tabla virtual y su definición entre paréntesis. Posteriormente, se puede consultar esta tabla como si fuera real en la sentencia SELECT, INSERT o DELETE. Este enfoque promueve un código más modular y fácil de mantener, especialmente útil cuando se analizan grandes volúmenes de datos jerárquicos o relaciones complejas entre tablas.

## Ejemplo (no ejecutado automáticamente)
Consulta que utiliza una CTE para filtrar empleados con salario superior a un promedio calculado previamente en la misma consulta.

```sql
WITH alto_salario AS (
  SELECT AVG(salario) as promedio FROM empleados
)
SELECT * FROM empleados WHERE salario > (SELECT promedio FROM alto_salario);
```
