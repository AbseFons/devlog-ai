## Objetivo
Comprender la diferencia entre iteradores manuales y generadores, aprendiendo a crear secuencias de memoria eficiente para procesar grandes volúmenes de datos sin cargar todo el conjunto en RAM.

## Explicación
En Python, los iteradores son objetos que implementan el protocolo __iter__ y __next__, permitiendo recorrer colecciones. Los generadores, definidos con 'yield', automatizan la creación de iteradores. A diferencia de las listas que almacenan todos los elementos en memoria, los generadores calculan cada valor sobre la marcha. Esto es crucial para procesar flujos infinitos o archivos masivos. Al usar un bucle 'for' sobre una función con 'yield', el programa pausa y reanuda la ejecución, manteniendo el estado local entre llamadas. Esta técnica optimiza el rendimiento y reduce el consumo de recursos en aplicaciones de datos intensivas.

## Ejemplo (no ejecutado automáticamente)
Funcion que genera números pares infinitos usando yield para demostrar memoria eficiente.

```python
def generar_pares():
    n = 0
    while True:
        yield n
        n += 2

for num in generar_pares():
    if num > 10:
        break
    print(num)
```
