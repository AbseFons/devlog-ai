## Objetivo
Comprender cómo el Event Loop gestiona asíncronía en JavaScript, diferenciando entre ejecución síncrona en el hilo principal y tareas asíncronas en la cola de macrotareas.

## Explicación
El motor de JavaScript utiliza un modelo de ejecución basado en hilos únicos. El Event Loop es el mecanismo que permite ejecutar código asíncrono sin bloquear la interfaz. Cuando se ejecuta una función síncrona, el código se procesa inmediatamente. Si hay operaciones asíncronas como setTimeout o fetch, estas se delegan al sistema operativo y sus callbacks se colocan en la cola de macrotareas. El Event Loop verifica constantemente si la pila de llamadas está vacía; si lo está, toma la primera tarea de la cola y la ejecuta. Esto permite que la aplicación responda mientras espera por datos externos o temporizadores.

## Ejemplo (no ejecutado automáticamente)
Ejemplo demostrando el orden de ejecución entre código síncrono y una promesa setTimeout.

```javascript
console.log('Inicio');
setTimeout(() => console.log('Timeout'), 0);
console.log('Fin');
```
