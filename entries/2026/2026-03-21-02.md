## Objetivo
Aprender a utilizar la clase Path de Python para construir rutas de archivos de manera portable, evitando errores comunes relacionados con separadores de directorios y concatenación de strings.

## Explicación
En Python, el módulo pathlib ofrece una interfaz orientada a objetos para trabajar con rutas de sistema. A diferencia de las cadenas de texto tradicionales, Path permite construir rutas de forma segura usando operadores como / o .joinpath(), que adaptan automáticamente los separadores correctos para Windows, Linux o macOS. Esto elimina la necesidad de usar os.sep o str.replace(). Además, métodos como exists() y is_file() permiten verificar la existencia de recursos sin lanzar excepciones. En este caso, creamos un objeto Path base y añadimos subdirectorios dinámicamente.

## Ejemplo (no ejecutado automáticamente)
Se define una ruta relativa al proyecto y se accede a un archivo de configuración dentro de una carpeta logs.

```python
from pathlib import Path
base = Path('mi_proyecto')
config_ruta = base / 'logs' / 'app.json'
```
