## Objetivo
Aprender a configurar un registro de eventos en Python que genere salidas en formato JSON, facilitando la integración con herramientas modernas de análisis de datos y monitoreo sin necesidad de parsers complejos.

## Explicación
El logging tradicional imprime texto plano difícil de procesar automáticamente. La solución es utilizar el diccionario 'extra' del método log() junto con un formateador personalizado que convierta cada registro a JSON. Esto permite capturar metadatos como IDs de usuario, códigos de error o timestamps de manera consistente. Al exportar estos logs, se pueden cargar directamente en bases de datos NoSQL o sistemas de observabilidad para correlacionar fallos y métricas de rendimiento en tiempo real.

## Ejemplo (no ejecutado automáticamente)
Configuración básica de un logger que emite mensajes estructurados en formato JSON al escribir en consola.

```python
import logging
import json

def json_format(record):
    return json.dumps({"timestamp": record.created, "level": record.levelname, "message": record.getMessage()})

logging.basicConfig(format=json_format)
```
