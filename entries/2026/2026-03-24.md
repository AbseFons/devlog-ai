## Objetivo
Diferenciar entre iteradores manuales y generadores para manejar flujos de datos eficientes sin cargar memoria innecesaria.

## Explicación
En Python, los iteradores permiten recorrer secuencias elemento por elemento. Los generadores, definidos con 'yield', son una forma concisa de crear iteradores que generan valores bajo demanda. Esto es crucial para procesar grandes volúmenes de datos o flujos infinitos sin consumir toda la RAM. Mientras un bucle 'for' sobre una lista carga todo el contenido, un generador lo produce al instante. Este enfoque optimiza el rendimiento en aplicaciones de ETL o análisis de logs masivos.

## Ejemplo (no ejecutado automáticamente)
Generador que produce números pares infinitos hasta un límite específico para demostrar la eficiencia de memoria.

```python
def generar_pares(limite):
    n = 2
    while n <= limite:
        yield n
        n += 2

for par in generar_pares(10):
    print(par)
```
