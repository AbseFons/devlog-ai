## Objetivo
Al finalizar esta lección, el desarrollador será capaz de diferenciar la lógica de una función recursiva de una iterativa, identificar el caso base necesario para evitar pilas infinitas y escribir código seguro que calcule factoriales utilizando Python sin depender de librerías externas.

## Explicación
La recursión permite resolver problemas dividiéndolos en subproblemas idénticos hasta alcanzar un caso base. En este ejemplo, calculamos el factorial de un número entero positivo. Es crucial definir una condición de parada (n == 0 o n == 1) para que la función se detenga y no cause un error de desbordamiento de pila. Python tiene un límite de profundidad por defecto; si el número es muy grande, la recursión fallará. Para casos reales con grandes volúmenes de datos, se recomienda la iteración o técnicas como memoización. Este enfoque enseña a estructurar funciones que se llaman a sí mismas de manera controlada y eficiente.

## Ejemplo (no ejecutado automáticamente)
```python
def factorial_recursivo(n):
    if n <= 1:
        return 1
    return n * factorial_recursivo(n - 1)

# Caso de uso: Calcular el factorial de 5
resultado = factorial_recursivo(5)
print(f"El factorial de 5 es: {resultado}")
```
