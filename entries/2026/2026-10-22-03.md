## Objetivo
Aprender a capturar excepciones específicas en operaciones asíncronas usando bloques try-catch para evitar que fallos inesperados detengan la ejecución del programa y permitan una recuperación elegante.

## Explicación
En JavaScript moderno, las promesas permiten escribir código asíncrono de forma secuencial con async/await. Sin embargo, si una promesa se resuelve en estado 'rejected', el flujo se interrumpe a menos que esté protegido. El bloque try-catch es esencial aquí: permite aislar errores como timeouts o respuestas inválidas del servidor. Dentro del catch, puedes registrar el error en un servicio de monitoreo, mostrar un mensaje amigable al usuario o reintentar la operación con parámetros distintos. Esta práctica mejora la resiliencia de la aplicación y evita que se caiga toda la interfaz por un solo fallo local.

## Ejemplo (no ejecutado automáticamente)
Llamada a una API ficticia que puede fallar; captura el error específico de timeout y muestra un mensaje alternativo sin detener la app.

```javascript
const fetchUser = async () => {
  try {
    const response = await fetch('https://api.ejemplo.com/usuario');
    if (!response.ok) throw new Error('Usuario no encontrado');
    return await response.json();
  } catch (error) {
    console.log('Fallo controlado:', error.message);
    return null;
  }
}
```
