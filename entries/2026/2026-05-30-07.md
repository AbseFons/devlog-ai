## Objetivo
Comprender la función de los decoradores para extender el comportamiento de funciones sin modificar su código interno, aprendiendo a usar @ y crear decoradores simples.

## Explicación
Los decoradores son una herramienta poderosa en Python que permite añadir funcionalidad adicional a funciones o métodos existentes. Funcionan envolviendo la definición de una función con otra que se ejecuta antes, después o durante su ejecución principal. Esto es ideal para tareas como medir tiempos de ejecución, validar argumentos o gestionar permisos. Sintácticamente, se utiliza el símbolo @ seguido del nombre del decorador justo encima de la definición de la función. Internamente, esto equivale a asignar el resultado de llamar al decorador con la función como argumento a la variable que define la función.

## Ejemplo (no ejecutado automáticamente)
Este ejemplo define un decorador llamado 'mi_decorador' que imprime un mensaje antes y después de ejecutar la función objetivo. Luego, se aplica este decorador a una función llamada 'saludar'.

```python
def mi_decorador(func):
    def envoltura(*args, **kwargs):
        print('Antes de ejecutar')
        func(*args, **kwargs)
        print('Después de ejecutar')
    return envoltura

@mi_decorador
def saludar(nombre):
    print(f'Hola {nombre}')
```
