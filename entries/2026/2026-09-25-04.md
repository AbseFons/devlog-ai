## Objetivo
Comprender la definición formal de árbol binario, sus componentes nodales (raíz, hijos, hojas) y cómo realizar recorridos básicos como preorden para extraer datos estructurados de manera eficiente.

## Explicación
Un árbol binario es una estructura jerárquica donde cada nodo tiene a lo sumo dos hijos: izquierdo y derecho. La raíz es el punto de entrada. Cada nivel representa un paso más profundo en la jerarquía. Los nodos sin hijos se llaman hojas. Para navegar, utilizamos recursión o pilas. El recorrido preorden (Raíz, Izquierdo, Derecho) permite copiar el árbol completo visitando primero cada nodo y luego sus subárboles. Esta técnica es fundamental para serializar datos en formatos como JSON o XML, permitiendo reconstruir la estructura original desde una secuencia plana de valores.

Implementación recursiva de un recorrido preorden en Python que imprime los valores de un árbol binario simple con nodos numéricos.

```python
class Nodo:
    def __init__(self, valor):
        self.valor = valor
        self.izquierdo = None
        self.derecho = None

def preorden(nodo):
    if nodo is not None:
        print(nodo.valor)
        preorden(nodo.izquierdo)

```
