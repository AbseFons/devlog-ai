## Objetivo
Comprender la función de los decoradores para extender el comportamiento de funciones sin modificar su código interno, aprendiendo a usar @ y crear decoradores básicos.

## Explicación
Los decoradores son una herramienta poderosa en Python que permite modificar o ampliar el comportamiento de funciones existentes sin alterar su implementación original. Funcionan envolviendo la función objetivo con otra que añade lógica adicional antes o después de su ejecución. Se definen usando la sintaxis @nombre_decorador, que es un atajo para asignar el resultado de una llamada a función a la variable actual. Este patrón es esencial para implementar características como logging automático, control de acceso o medición de tiempo de ejecución de manera limpia y reutilizable.

## Ejemplo (no ejecutado automáticamente)
Un decorador simple que imprime mensajes antes y después de ejecutar una función.

```python
def mi_decorador(func):
    def envoltura(*args, **kwargs):
        print('Antes de la ejecución')
        func(*args, **kwargs)
        print('Después de la ejecución')
    return envoltura

@mi_decorador
def saludar(nombre):
    print(f'Hola, {nombre}')
```
