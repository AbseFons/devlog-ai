## Objetivo
Al finalizar, el desarrollador identificará cuándo usar códigos 2xx y 3xx, diferenciando entre creación exitosa (201) y redirección permanente (301), aplicando estos conceptos para diseñar respuestas de API coherentes con las expectativas del cliente.

## Explicación
Los códigos HTTP de la serie 1 indican que la solicitud fue procesada correctamente o requiere una acción específica del cliente. El código 200 OK confirma que la operación se completó sin errores, mientras que 201 Created señala que un recurso nuevo fue generado tras una petición POST exitosa. Por otro lado, los códigos 3xx son redirecciones; el 301 Moved Permanently indica que la ubicación del recurso ha cambiado para siempre, obligando al navegador o cliente a actualizar sus registros de caché. Usar estos códigos correctamente evita confusiones en flujos de datos y asegura que las aplicaciones clientes interpreten las respuestas tal como se diseñó.
