## Objetivo
Introducir el concepto de programación dinámica mediante la optimización de un contenedor rectangular, enseñando a descomponer problemas complejos en subproblemas solubles y almacenar sus resultados para evitar recálculos innecesarios.

## Explicación
La programación dinámica resuelve problemas optimizando decisiones secuenciales. En este caso, determinaremos la máxima altura de un muro construido con ladrillos de diferentes anchos y alturas, asegurando que cada capa sea estable. La clave reside en construir una tabla donde cada celda representa la mejor solución para una subestructura específica. Al iterar sobre las opciones disponibles, seleccionamos la combinación que maximiza el volumen total sin violar restricciones de estabilidad. Este enfoque transforma un problema combinatorio exponencial en uno polinomial eficiente.

## Ejemplo (no ejecutado automáticamente)
Cálculo de la máxima altura alcanzable con un conjunto limitado de ladrillos disponibles para construir una pared estable.

```python
def max_altura(ladrillos):
    dp = [0] * (len(ladrillos) + 1)
    for i in range(1, len(ladrillos) + 1):
        for j in range(i):
            if ladrillos[j][0] <= ladrillos[i-1][0]:
                dp[i] = max(dp[i], dp[j] + ladrillos[i-1][1])
    return dp[len(ladrillos)]
```
