## Objetivo
Aprender a implementar paginación eficiente utilizando cursores para evitar problemas de ordenamiento y manejar grandes volúmenes de datos sin sobrecargar la memoria del cliente.

## Explicación
La paginación por cursor es superior a la paginación tradicional basada en índices cuando los conjuntos de datos no están estrictamente ordenados o cambian frecuentemente. En lugar de enviar un offset y un límite, el servidor devuelve un token único que representa la posición exacta del último elemento procesado. El cliente utiliza este token en la cabecera 'Next' o parámetro para solicitar los siguientes resultados. Este método garantiza consistencia incluso si se insertan nuevos registros entre peticiones. Es ideal para feeds de noticias, historiales de logs o catálogos dinámicos donde el orden temporal es relativo y no absoluto.

## Ejemplo (no ejecutado automáticamente)
Solicitud GET que utiliza un token de cursor en la cabecera 'X-Cursor' para obtener los siguientes 10 registros de una lista de usuarios.

```bash
curl -H "Accept: application/json" \
     -H "X-Cursor: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpZCI6MTAwfQ"
```

## Ejercicio
Crea un endpoint en tu servidor que devuelva un token de cursor basado en el ID del último elemento y actualiza la lógica del cliente para solicitar los siguientes datos usando ese token.

## Criterios de revisión
El código debe manejar correctamente la respuesta con el token, no debe usar offsets numéricos y debe validar la existencia del token antes de hacer la siguiente petición.
