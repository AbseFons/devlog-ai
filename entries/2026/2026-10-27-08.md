## Objetivo
Aprender a diseñar y ejecutar pruebas de regresión enfocadas en verificar que las nuevas implementaciones no rompan funcionalidades existentes, asegurando la estabilidad continua del sistema ante cambios en la lógica de negocio.

## Explicación
Las pruebas de regresión son esenciales cuando se modifica el código para confirmar que los errores introducidos no afectan a otras partes del sistema. En este contexto, nos centraremos en validar endpoints de una API tras actualizar un algoritmo de cálculo. El proceso implica seleccionar casos de prueba representativos que cubran escenarios normales y excepcionales. Se ejecutan automáticamente en cada integración continua para detectar regresiones tempranamente. Es crucial mantener un conjunto de pruebas estable y documentado, evitando la duplicidad y asegurando que los datos de prueba sean realistas pero seguros. La automatización es clave aquí, permitiendo ejecutar suites completas en minutos sin intervención manual constante.

## Ejemplo (no ejecutado automáticamente)
Script para ejecutar una suite de regresión básica en un endpoint de API usando Python y la librería requests.

```python
import requests

def test_regresion_calculo():
    url = "https://api.ejemplo.com/v1/calcular"
    payload = {"tipo": "suma", "valores": [10, 20]}
    response = requests.post(url, json=payload)
    assert response.status_code == 200
    assert response.json()["resultado"] == 30
```
