## Objetivo
Comprender la función básica de los hooks de Git, específicamente el pre-commit, para automatizar tareas de validación antes de cada commit y mejorar la calidad del código en equipo.

## Explicación
Los hooks son scripts que Git ejecuta automáticamente en momentos específicos del flujo de trabajo. El hook 'pre-commit' se activa justo antes de realizar un commit. Su utilidad principal es validar el contenido que se va a guardar, por ejemplo, verificando si faltan pruebas unitarias o detectando vulnerabilidades básicas. Esto evita que código no probado o inseguro entre al repositorio compartido. Al configurar este hook en tu máquina local, puedes asegurar un estándar de calidad consistente sin depender de revisiones manuales exhaustivas para cada detalle menor.

## Ejemplo (no ejecutado automáticamente)
Script simple en Bash que verifica si existe un archivo llamado 'tests' antes de permitir el commit.

```bash
# Verifica si existe una carpeta de tests
if [ ! -d "tests" ]; then
  echo "Error: Falta la carpeta de pruebas."
  exit 1
fi
```
