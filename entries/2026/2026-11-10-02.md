## Objetivo
Aprender a sobrescribir métodos mágicos como __str__ y __repr__ en dataclasses para mejorar la legibilidad de la salida al consol y el depuración, aplicando esto a un modelo de usuario realista.

## Explicación
Los dataclasses generan automáticamente representaciones por defecto que pueden ser insuficientes. Sobrescribiendo __str__, controlamos cómo se muestra el objeto en logs o salidas estándar, ideal para usuarios finales. Por otro lado, __repr__ debe devolver una representación técnica precisa, útil para desarrolladores al depurar. En este caso de uso, creamos un modelo 'Usuario' donde el string visual incluye un saludo personalizado y el estado de cuenta, mientras que la representación interna mantiene la estructura de datos cruda con sus atributos y tipos, facilitando la reconstrucción del objeto desde una cadena de texto.

## Ejemplo (no ejecutado automáticamente)
Definición de un dataclass Usuario con métodos personalizados para mostrar un mensaje amigable en consola y una representación técnica detallada para depuración.

```python
from dataclasses import dataclass

@dataclass
class Usuario:
    nombre: str
    saldo: float
    
    def __str__(self):
        return f"Hola {self.nombre}, tu saldo es ${self.saldo:.2f}"
    
    def __repr__(self):
        return f"Usuario(nombre='{self.nombre}', saldo={self.saldo})"
```
