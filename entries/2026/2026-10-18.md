## Objetivo
Introducir al desarrollador en el concepto de pruebas basadas en propiedades, explicando cómo verificar comportamientos generales sin especificar casos exactos, fomentando la robustez del software ante entradas inesperadas.

## Explicación
Las pruebas basadas en propiedades son una técnica avanzada que valida que un sistema cumpla ciertas reglas lógicas o invariantes, independientemente de los datos específicos. A diferencia de las pruebas tradicionales que prueban casos concretos, aquí definimos qué debe ser siempre cierto (por ejemplo, 'la suma de salidas nunca excede la entrada'). Esta serie explorará herramientas como QuickCheck para automatizar la generación de casos de prueba y detectar errores sutiles en algoritmos complejos.

## Ejemplo (no ejecutado automáticamente)
Definición de una propiedad que asegura que el promedio de un conjunto de números no supere el valor máximo del conjunto, utilizando un generador aleatorio para probar miles de casos automáticamente.

```python
from hypothesis import given, strategies as st

def promedio_no_supera_maximo(lista):
    return sum(lista) / len(lista) <= max(lista)

@given(st.lists(st.integers(), min_size=1))
def test_promedio(lista):
    assert promedio_no_supera_maximo(lista)
```
