## Objetivo
Comprender cómo las claves foráneas vinculan tablas relacionadas manteniendo la integridad de los datos, evitando referencias a registros inexistentes y asegurando consistencia en bases de datos relacionales.

## Explicación
Una clave foránea es una columna o conjunto de columnas en una tabla que hace referencia a la clave primaria de otra tabla. Su función principal es establecer una relación lógica entre tablas, permitiendo consultas complejas como JOINs. Al definir esta restricción, se garantiza que no existan registros huérfanos; es decir, no se puede insertar un pedido si el cliente no existe en la tabla de clientes. Además, permite configurar reglas de cascada para eliminar o actualizar registros relacionados automáticamente. Esta estructura es fundamental para modelar datos complejos y asegurar que la información permanezca coherente a lo largo del tiempo.

## Ejemplo (no ejecutado automáticamente)
Creación de una tabla 'pedidos' con una clave foránea que referencia a la tabla 'clientes', impidiendo la inserción de pedidos para clientes inexistentes.

```sql
CREATE TABLE pedidos (
  id_pedido INT PRIMARY KEY,
  id_cliente INT,
  fecha DATE
);
ALTER TABLE pedidos ADD CONSTRAINT fk_cliente FOREIGN KEY (id_cliente) REFERENCES clientes(id_cliente);
```
