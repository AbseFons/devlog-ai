## Objetivo
Diferenciar el uso de iteradores manuales frente a generadores para optimizar la memoria y controlar explícitamente la lógica de iteración en flujos de datos grandes.

## Explicación
En Python, los iteradores son objetos que implementan __next__(), permitiendo un control granular sobre cada paso de la iteración. Los generadores, definidos con yield, automatizan este proceso creando una secuencia inmemoriale. Mientras un iterador manual es útil para lógica compleja dentro del bucle, los generadores son ideales para transformaciones de datos simples o flujos infinitos. Esta lección explora cuándo priorizar la sobrecarga de un iterador personalizado frente a la simplicidad de un generador anidado, equilibrando legibilidad y eficiencia computacional en aplicaciones de procesamiento de streams.

## Ejemplo (no ejecutado automáticamente)
Un generador que filtra números primos infinitamente usando yield, demostrando ahorro de memoria comparado con una lista completa.

```python
def generar_primos():
    num = 2
    while True:
        if all(num % i for i in range(2, int(num**0.5) + 1)):
            yield num
            num += 1
```
