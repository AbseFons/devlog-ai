## Objetivo
Comprender cómo una función hash transforma claves arbitrarias en índices numéricos para acceso O(1) eficiente, identificando la importancia de la uniformidad y el manejo básico de colisiones mediante encadenamiento simple.

## Explicación
Una tabla hash es una estructura de datos que mapea claves a valores almacenados en posiciones específicas. El núcleo reside en la función de dispersión, que calcula un índice basado en la clave. Si usamos enteros como claves, el índice suele ser la clave módulo la capacidad del array. Este proceso debe ser uniforme para evitar concentraciones de datos (colisiones). Cuando dos claves generan el mismo índice, se produce una colisión. Una estrategia común es el encadenamiento, donde cada posición contiene una lista enlazada de elementos que comparten ese índice. Esto permite almacenar múltiples registros sin perder integridad, aunque puede degradar el rendimiento si la carga es alta.
