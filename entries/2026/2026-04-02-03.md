## Objetivo
Aprender a utilizar conjuntos para operaciones matemáticas rápidas y diccionarios para almacenar datos relacionales de manera eficiente, optimizando la gestión de información única.

## Explicación
En Python, los sets son colecciones no ordenadas que almacenan elementos únicos, ideales para eliminar duplicados o realizar intersecciones. Los diccionarios mapean claves a valores, permitiendo acceso rápido O(1). Un caso práctico es filtrar usuarios activos: un set de IDs permite verificar existencia instantáneamente. Por ejemplo, si tenemos una lista de registros con nombres repetidos, convertirla a set elimina duplicados automáticamente. Los diccionarios son esenciales para configuraciones o índices. Combinar ambos tipos de datos mejora la legibilidad y el rendimiento en scripts de procesamiento de datos.

## Ejemplo (no ejecutado automáticamente)
Creación de un set con elementos únicos y un diccionario que mapea nombres a edades, demostrando la sintaxis básica y la inmutabilidad del set frente a la mutabilidad del diccionario.

```python
mi_set = {1, 2, 3, 2}
print(mi_set)
diccionario = {'nombre': 'Ana', 'edad': 30}
print(diccionario['nombre'])
```
