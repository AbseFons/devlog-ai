## Objetivo
Dominar el uso de Union, Literal y tipos opcionales para crear interfaces de API robustas que prevengan errores en tiempo de compilación y mejoren la autocompletado del IDE.

## Explicación
En esta segunda parte de la serie sobre tipado, exploraremos cómo las anotaciones avanzadas de Python permiten modelar datos complejos. Utilizaremos 'Union' para manejar múltiples formatos de respuesta y 'Literal' para restringir valores específicos como estados de servidor. Esto es crucial en el desarrollo de APIs donde la estructura de los datos debe ser estricta. Al definir tipos precisos, el editor detectará errores antes de ejecutar el código, acelerando el ciclo de desarrollo.

## Ejemplo (no ejecutado automáticamente)
Definición de un modelo de respuesta API que acepta estados específicos y campos opcionales utilizando tipos avanzados.

```python
from typing import Literal, Optional

def obtener_estado_servicio(id: int, estado: Literal['activo', 'mantenimiento']) -> dict:
    return {'id': id, 'estado': estado, 'alerta': None}
```
