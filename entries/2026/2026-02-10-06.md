## Objetivo
Comprender que una operación idempotente produce el mismo resultado final independientemente de cuántas veces se ejecute, protegiendo contra reintentos fallidos o llamadas duplicadas en sistemas distribuidos.

## Explicación
La idempotencia es un principio fundamental en APIs REST para operaciones de estado cambiante como POST y PUT. Garantiza que si un cliente envía una solicitud dos veces debido a una falla de red, el servidor procese la acción solo una vez. Esto previene errores como cobros duplicados o creación múltiple de registros. Para implementar esto, los desarrolladores pueden usar cabeceras HTTP como 'Idempotency-Key', donde el servidor almacena temporalmente la clave y el resultado; si recibe otra petición con la misma clave, devuelve inmediatamente la respuesta guardada sin reejecutar la lógica.

## Ejemplo (no ejecutado automáticamente)
Implementación de un endpoint POST que verifica una cabecera 'Idempotency-Key' para evitar duplicidad en la creación de un pedido.

```javascript
const idempotencyKey = req.headers['idempotency-key'];
if (idempotencyKey && cache.has(idempotencyKey)) {
  return res.status(200).json(cache.get(idempotencyKey));
}
```
