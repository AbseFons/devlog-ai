## Objetivo
Aprender a convertir objetos Python complejos, como diccionarios y listas, en cadenas de texto válidas JSON utilizando el módulo json para almacenamiento o transmisión de datos.

## Explicación
La serialización transforma estructuras nativas de Python en un formato universal legible por máquinas. El módulo 'json' permite exportar objetos a texto mediante la función 'dump'. Este proceso es esencial para guardar configuraciones, enviar respuestas a APIs web o intercambiar datos entre sistemas heterogéneos. Es crucial manejar correctamente los tipos de datos: las claves deben ser cadenas, los booleanos se mapean a true/false y None a null. La indentación mejora la legibilidad al escribir archivos locales.

## Ejemplo (no ejecutado automáticamente)
Conversión de un diccionario con datos mixtos a formato JSON

```python
import json

datos = {'usuario': 'Ana', 'activo': True, 'edad': None}
json_str = json.dumps(datos)
```
