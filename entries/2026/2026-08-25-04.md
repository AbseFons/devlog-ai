## Objetivo
Distinguir claramente entre autenticación (quién eres) y autorización (qué puedes hacer), implementando patrones básicos de seguridad para proteger endpoints sensibles sin exponer credenciales.

## Explicación
En el desarrollo de APIs, confundir autenticación con autorización es un error crítico. La autenticación verifica la identidad del usuario mediante tokens o sesiones, respondiendo a '¿Quién eres?'. La autorización determina los permisos específicos de ese usuario sobre recursos, respondiendo a '¿Qué puedes hacer?'. Mientras la primera protege el acceso al sistema, la segunda limita el alcance dentro del mismo. Una API segura debe validar primero la identidad y luego consultar una política de permisos antes de procesar cualquier solicitud sensible.

## Ejemplo (no ejecutado automáticamente)
```python
from flask import Flask, request, jsonify
import jwt

app = Flask(__name__)
SECRET_KEY = 'clave_secreta_segura'

@app.route('/api/datos', methods=['GET'])
def obtener_datos():
    token = request.headers.get('Authorization')
    if not token:
        return jsonify({'error': 'Falta autenticacion'}), 401
    
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=['HS256'])
        usuario_id = payload['sub']
        permisos = payload['roles']
        
        if 'admin' not in permisos:
            return jsonify({'error': 'No autorizado'}), 403
            
        return jsonify({'mensaje': 'Datos sensibles obtenidos', 'usuario': usuario_id})
    except jwt.ExpiredSignatureError:
        return jsonify({'error': 'Token expirado'}), 401
```

## Ejercicio
Crea un endpoint protegido que requiera un token JWT válido. Asegúrate de devolver un error 403 si el usuario tiene identidad pero carece del rol necesario para acceder al recurso.

## Criterios de revisión
El código debe validar la presencia del token, decodificarlo correctamente y verificar explícitamente los permisos antes de exponer datos. No debe incluir credenciales en el cuerpo de la respuesta ni permitir acceso sin autenticación previa.
