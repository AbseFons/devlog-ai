## Objetivo
Aprender a importar módulos en JavaScript utilizando require para encapsular lógica y evitar colisiones de variables, mejorando la organización del código.

## Explicación
En JavaScript, los módulos permiten dividir el código en archivos independientes. El comando require() carga un módulo desde un archivo local o una dependencia externa. Al exportar funciones o constantes con module.exports, se crea un punto único de entrada para otros archivos. Esto evita que variables globales contaminen el ámbito principal. Es fundamental usar rutas relativas correctas y entender la diferencia entre módulos CommonJS (requerido en Node.js) y ES Modules. Este enfoque promueve una arquitectura escalable donde cada archivo tiene una responsabilidad clara, facilitando el mantenimiento y las pruebas unitarias.

## Ejemplo (no ejecutado automáticamente)
Un archivo calculadora.js exporta funciones matemáticas básicas que son importadas en un script principal para realizar operaciones sin afectar el ámbito global.

```javascript
module.exports = {
  sumar: (a, b) => a + b
}
```
