## Objetivo
Comprender el concepto central de las tablas hash, que es mapear claves arbitrarias a índices numéricos mediante una función de enfoque para permitir accesos O(1). Aprenderás cómo se distribuyen los datos y por qué la elección de la función afecta directamente el rendimiento del sistema al evitar colisiones innecesarias.

## Explicación
Una tabla hash es una estructura de datos que utiliza una función de enfoque para transformar una clave (como un nombre o ID) en un índice numérico específico dentro de un array. Este proceso permite recuperar información casi instantáneamente, independientemente del tamaño de la colección. La eficiencia depende de que los datos estén uniformemente distribuidos; si múltiples claves generan el mismo índice, ocurre una colisión. Existen diversas estrategias para resolver estas colisiones, como encadenamiento o direccionamiento abierto. En este nivel inicial, nos enfocamos en entender cómo la función de enfoque determina la ubicación y por qué un buen diseño minimiza los conflictos, asegurando que las operaciones de búsqueda e inserción mantengan su complejidad constante.

## Ejemplo (no ejecutado automáticamente)
Implementación básica de una tabla hash usando un array simple y módulo para manejar colisiones en JavaScript.

```javascript
const tabla = new Array(10);
function enfoque(clave) {
  return clave % tabla.length;
}
tabla[enfoque('usuario1')] = 'Juan';
tabla[enfoque('usuario2')] = 'Maria';
```
