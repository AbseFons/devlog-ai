## Objetivo
Comprender la distinción funcional entre mocks y stubs para escribir pruebas de integración más robustas y mantenibles, evitando acoplamientos innecesarios con dependencias externas.

## Explicación
En ingeniería de software, los stubs son respuestas predefinidas que simulan el comportamiento básico de una dependencia externa sin verificar cómo se usa. Los mocks, en cambio, no solo responden, sino que también validan que la unidad bajo prueba interactúe con ellos de la manera esperada. Utiliza stubs cuando necesitas aislar lógica compleja de un servicio lento, pero emplea mocks para asegurar que las llamadas a APIs o bases de datos se realicen correctamente dentro del flujo de negocio.

## Ejemplo (no ejecutado automáticamente)
Un stub simple en JavaScript que devuelve un valor fijo sin validar la entrada, ideal para pruebas unitarias rápidas.

```javascript
const mockService = {
  fetchData: () => ({ id: 1, name: 'Producto A' })
};
```

## Ejercicio
Crea una función que acepte un objeto stub como argumento y verifique que el resultado retornado coincida con los datos esperados sin depender de una red real.

## Criterios de revisión
El código debe incluir al menos una llamada a la función stub, asignar el resultado a una variable y realizar una comparación estricta para validar la respuesta.
