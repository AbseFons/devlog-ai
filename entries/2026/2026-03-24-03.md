## Objetivo
Aprender a utilizar el patrón adaptador para integrar servicios externos con interfaces internas distintas, asegurando la compatibilidad sin modificar el código del proveedor.

## Explicación
El patrón adaptador permite que dos interfaces incompatibles trabajen juntas. Imagina un sistema legacy que espera objetos de tipo 'LegacyUser' y una nueva API REST que devuelve 'ModernProfile'. En lugar de cambiar la API externa o reescribir todo el cliente, creamos una clase adaptadora. Esta clase encapsula la lógica de conversión: recibe los datos modernos, mapea los campos relevantes (como nombre, email e ID) y construye el objeto legacy requerido. Esto aísla las dependencias externas, haciendo que el sistema principal sea agnóstico a los cambios en la API del proveedor. Es crucial mantener esta capa de traducción actualizada cuando la API externa evoluciona.

## Ejemplo (no ejecutado automáticamente)
Clase adaptadora en Python que convierte un diccionario de una API moderna en un objeto LegacyUser compatible con el sistema interno.

```python
class LegacyAdapter:
    def __init__(self, api_client):
        self.api = api_client
    
    def get_user(self, user_id):
        raw_data = self.api.fetch(f'/users/{user_id}')
        return LegacyUser(raw_data['name'], raw_data['email'])
```
