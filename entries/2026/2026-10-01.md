## Objetivo
Aprender a inicializar una base de datos local, crear una tabla con tipos de datos básicos y realizar la primera inserción de registros utilizando el módulo nativo sqlite3.

## Explicación
En esta lección exploraremos los fundamentos de SQLite en Python. Comenzaremos importando el módulo sqlite3 y estableciendo una conexión a un archivo de base de datos, o creando uno nuevo si no existe. Posteriormente, utilizaremos la sentencia SQL CREATE TABLE para definir una estructura de datos simple con columnas como id, nombre y edad. Es crucial recordar cerrar la conexión al finalizar las operaciones. Este enfoque permite gestionar datos persistentes sin necesidad de servidores externos, ideal para prototipado rápido o aplicaciones de escritorio.

## Ejemplo (no ejecutado automáticamente)
Script que crea una base de datos 'empleados.db' con una tabla 'personal' y agrega un empleado de prueba.

```python
import sqlite3
conn = sqlite3.connect('empleados.db')
cursor = conn.cursor()
cursor.execute('''CREATE TABLE personal (id INTEGER PRIMARY KEY, nombre TEXT, edad INTEGER)''')
cursor.execute("INSERT INTO personal VALUES (1, 'Ana', 28)")
conn.commit()
conn.close()
```
