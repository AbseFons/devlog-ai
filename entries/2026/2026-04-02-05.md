## Objetivo
Introducir las ventajas de pytest sobre unittest en Python, destacando su simplicidad, descubrimiento automático de pruebas y poderosas herramientas de fixtures para escribir código más limpio y mantenible desde el inicio.

## Explicación
Aunque unittest es parte del estándar de la librería, pytest ofrece una experiencia superior con menos boilerplate. Las pruebas se descubren automáticamente al nombrar archivos como test_*.py y funciones como test_*. Esto elimina la necesidad de definir clases TestCase manualmente. Los fixtures en pytest permiten configurar y limpiar el entorno antes y después de cada prueba de forma declarativa y concisa, a diferencia de setUp/tearDown de unittest. Además, pytest proporciona reportes detallados por defecto y plugins que extienden su funcionalidad sin esfuerzo.

## Ejemplo (no ejecutado automáticamente)
Comparación directa entre un test simple en unittest y su equivalente en pytest, mostrando la sintaxis reducida y el uso de fixtures automáticos.

```python
import unittest

class TestUnittest(unittest.TestCase):
    def setUp(self):
        self.valor = 10
    def test_suma(self):
        self.assertEqual(self.valor + 5, 15)

# pytest version
import pytest

@pytest.fixture
def valor():
    return 10

def test_suma(valor):
    assert valor + 5 == 15
```
