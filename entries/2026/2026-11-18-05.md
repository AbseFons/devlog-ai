## Objetivo
Comprender las limitaciones del GIL en Python y cuándo utilizar threading versus multiprocessing para tareas de E/S intensivas, mejorando la eficiencia sin violar restricciones de seguridad.

## Explicación
En Python, el GIL (Global Interpreter Lock) impide que múltiples hilos ejecuten código CPU simultáneamente en un solo núcleo. Sin embargo, para operaciones de entrada/salida como leer archivos o consultar APIs, threading sigue siendo útil porque libera el hilo mientras espera. Este ejemplo crea dos hilos: uno descarga datos de una URL simulada y otro procesa localmente. Aunque el GIL bloquea la ejecución paralela real de CPU, permite que las tareas de E/S se solapen, mejorando la respuesta total del sistema. Para cálculos pesados, se recomienda multiprocessing.

## Ejemplo (no ejecutado automáticamente)
Dos hilos ejecutan tareas de E/S simuladas para demostrar cómo el GIL no bloquea completamente la concurrencia en operaciones de entrada/salida.

```python
import threading
import time
def tarea_ei():
    print('Hilo 1: Iniciando E/S')
    time.sleep(2)
    print('Hilo 1: Finalizado')
def tarea_cpu():
    print('Hilo 2: Procesando datos')
    time.sleep(1)
    print('Hilo 2: Completado')
t1 = threading.Thread(target=tarea_ei)
t2 = threading.Thread(target=tarea_cpu)
t1.start()
t2.start()
```
