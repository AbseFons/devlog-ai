## Objetivo
Aprender a utilizar el patrón Adaptador para permitir que clases con interfaces incompatibles colaboren, facilitando la integración de sistemas heredados sin modificar su código original.

## Explicación
El patrón Adaptador permite hacer compatible una clase existente (adaptado) con una interfaz requerida (target). Imagina un sistema legacy que usa `ConectorSerial` pero tu arquitectura moderna necesita `ConectorUSB`. En lugar de reescribir el hardware, creas una clase adaptadora que implementa la interfaz USB y delega las llamadas al método serial. Esto encapsula la lógica de traducción, manteniendo la integridad del código heredado y promoviendo un diseño flexible donde los componentes pueden intercambiarse fácilmente.

## Ejemplo (no ejecutado automáticamente)
Clase adaptadora que traduce una llamada a 'enviarSerial' en una llamada a 'transmitirUSB'.

```javascript
class AdaptadorSerialAUSB {
  constructor(serial) { this.serial = serial; }
  enviarUSB(datos) { return this.serial.enviarSerial(datos); }
}
```

## Ejercicio
Crea una clase `AdaptadorViejoANuevo` que adapte un objeto con el método `procesarAntiguo()` para que sea compatible con una interfaz que exige `procesarNuevo()`.

## Criterios de revisión
El código debe instanciar correctamente la clase adaptadora, pasar un objeto legacy válido y demostrar que la llamada al método nuevo delega exitosamente a la implementación antigua.
