## Objetivo
Aprender a usar la clase Path de Python para construir rutas absolutas y relativas, evitando errores comunes con separadores de directorios y mejorando la portabilidad del código entre sistemas operativos.

## Explicación
La librería estándar pathlib ofrece una forma moderna y limpia de manipular rutas de archivos. En lugar de concatenar cadenas con barras diagonales o invertidas, usamos Path().joinpath() para unir componentes. Esto garantiza que el código funcione igual en Windows, Linux y macOS. Utilizamos .resolve() para obtener la ruta absoluta completa sin dependencias del sistema actual. Es crucial evitar rutas relativas inseguras que puedan llevar a lecturas de archivos fuera del directorio esperado. Siempre valida si un archivo existe antes de abrirlo con Path().exists().

## Ejemplo (no ejecutado automáticamente)
Construcción segura de una ruta absoluta para un archivo de configuración usando pathlib y verificación de existencia.

```python
from pathlib import Path
config_path = Path.home() / '.myapp' / 'settings.json'
if config_path.exists():
    print(f"Archivo encontrado en: {config_path}")
```
