## Objetivo
Comprender la importancia de añadir una cadena aleatoria única a cada contraseña antes de hashearla, neutralizando ataques de diccionario masivos y protegiendo usuarios ante brechas de datos.

## Explicación
El salting es una técnica crítica en seguridad informática. Consiste en concatenar una cadena aleatoria, llamada 'sal', con la contraseña del usuario antes de aplicar la función hash. Esto asegura que dos usuarios con la misma contraseña generen hashes completamente diferentes. Sin sal, un atacante podría usar tablas precalculadas (lluvia de lluvia) para descifrar contraseñas comunes instantáneamente. Con sal, cada hash es único y específico del usuario, haciendo inviables los ataques de diccionario masivos. Además, la sal debe ser almacenada junto con el hash en la base de datos, ya que su propósito no es ocultar la contraseña, sino dificultar su cruce con tablas públicas.

## Ejemplo (no ejecutado automáticamente)
Generación de un hash seguro para una contraseña usando Python y la librería hashlib con una sal aleatoria de 16 bytes.

```python
import hashlib
import os
password = 'mi_contraseña_secreta'
sal = os.urandom(16)
hash_final = hashlib.pbkdf2_hmac('sha256', password.encode(), sal, 100000).hex()
print(f'Hash: {hash_final} | Sal (hex): {sal.hex()}')
```
