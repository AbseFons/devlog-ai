## Objetivo
Comprender y aplicar los principios básicos de la normalización en bases de datos relacionales, específicamente enfocándose en la eliminación de grupos repetidos para garantizar la integridad referencial y optimizar el almacenamiento de datos.

## Explicación
La normalización es un proceso sistemático para organizar las tablas de una base de datos. En esta primera lección, nos centramos en la Primera Forma Normal (1FN). El objetivo principal es asegurar que cada celda contenga exactamente un valor atómico y evitar grupos repetidos. Por ejemplo, si tienes una tabla de pedidos donde cada fila representa un producto dentro de un pedido, pero los datos están apilados en una sola columna separada por comas, esto viola la 1FN. Para corregirlo, debes crear una tabla hija relacionada con la clave foránea del pedido principal. Esto transforma datos denormalizados en una estructura relacional limpia, facilitando consultas precisas y manteniendo la consistencia de los datos a medida que crece el volumen de información.

## Ejemplo (no ejecutado automáticamente)
Transformación de una tabla desnormalizada con columnas repetidas a una estructura normalizada mediante clave foránea.

```sql
CREATE TABLE pedidos (
  id_pedido INT PRIMARY KEY,
  fecha DATE
);

CREATE TABLE items_pedidos (
  id_item INT PRIMARY KEY,
  id_pedido INT,
  producto VARCHAR(50),
  cantidad INT,
  FOREIGN KEY (id_pedido) REFERENCES pedidos(id_pedido)
);
```
