## Objetivo
Comprender cómo las funciones anidadas acceden al ámbito léxico exterior para generar funciones personalizadas, aplicando este concepto a la creación de un sistema de cálculo de impuestos dinámico.

## Explicación
Un closure permite que una función retenga referencia a variables de su contexto externo incluso después de que ese contexto haya terminado. En este caso, creamos una función 'crearCalculadora' que recibe una tasa impositiva y devuelve una nueva función específica para calcular precios finales. Esto evita repetir código y permite configurar comportamientos distintos con la misma estructura base.

## Ejemplo (no ejecutado automáticamente)
Se define una función que acepta una tasa de impuesto y retorna otra función capaz de multiplicar cualquier precio por dicha tasa, demostrando el encapsulamiento del estado.

```javascript
const crearCalculadora = (tasa) => {
  return (precio) => precio * (1 + tasa);
};
const calcularIVA = crearCalculadora(0.21);
```
