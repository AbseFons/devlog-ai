## Objetivo
Comprender cómo la base de datos decide ejecutar consultas y aprender a interpretar los planes de ejecución para optimizar el rendimiento de las aplicaciones.

## Explicación
El comando EXPLAIN revela el plan de ejecución que el motor SQL utilizará antes de procesar una consulta. Esto permite visualizar operaciones como escaneos de tabla, índices utilizados o uniones de tablas. Al analizar la salida, identificamos cuellos de botella como lecturas secuenciales innecesarias o falta de índices adecuados. Esta herramienta es fundamental para el mantenimiento preventivo y la optimización proactiva de bases de datos relacionales.

## Ejemplo (no ejecutado automáticamente)
Consulta que busca empleados con salario mayor a 50000 mostrando su plan de ejecución.

```sql
EXPLAIN SELECT id, nombre, salario
FROM empleados
WHERE salario > 50000;

SELECT * FROM usuarios WHERE activo = true;
```

## Ejercicio
Ejecuta EXPLAIN en una consulta compleja de tu base de datos local y compara el plan con la versión optimizada añadiendo un índice.

## Criterios de revisión
El plan debe mostrar el uso correcto de índices, evitar escaneos completos innecesarios y tener tiempos de estimación razonables.
