## Objetivo
Comprender la lógica del recorrido en anchura (BFS) para visitar nodos de un grafo nivel por nivel, utilizando una cola y detectando ciclos.

## Explicación
El algoritmo BFS explora un grafo visitando primero todos los vecinos de un nodo antes de avanzar. Se usa una cola FIFO: al extraer un nodo, se añaden sus no visitados a la cola. Esto garantiza el camino más corto en grafos no ponderados. Es fundamental marcar nodos como visitados para evitar bucles infinitos en grafos cíclicos. Ideal para búsqueda de rutas mínimas o descubrimiento de componentes conectados.

## Ejemplo (no ejecutado automáticamente)
Recorrido BFS en un grafo simple con nodos A, B, C y D, mostrando el orden de visita.

```python
from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    order = []
    while queue:
        node = queue.popleft()
        if node not in visited:
            visited.add(node)
            order.append(node)
            for neighbor in graph[node]:
                if neighbor not in visited:
                    queue.append(neighbor)
    return order

grafo = {'A': ['B', 'C'], 'B': ['D'], 'C': [], 'D': []}
print(bfs(grafo, 'A'))
```
