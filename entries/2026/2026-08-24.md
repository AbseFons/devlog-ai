## Objetivo
Al finalizar, el desarrollador podrá identificar errores de ejecución comunes en Python utilizando bloques try-except para prevenir fallos catastróficos y garantizar la estabilidad del programa al manejar entradas inválidas o recursos no disponibles sin detener la aplicación abruptamente.

## Explicación
En Python, las excepciones interrumpen el flujo normal cuando ocurren errores como división por cero o archivos inexistentes. El patrón estándar consiste en envolver código potencialmente arriesgado dentro de un bloque try, seguido de uno o más bloques except que especifican qué tipo de error manejar. Esto permite ejecutar lógica de recuperación, como mostrar mensajes amigables o usar valores por defecto. Es crucial ser específico con los tipos de excepción para evitar ocultar errores graves. Si no se captura ninguna excepción y ocurre un error, el programa se detendrá mostrando la pila de trazas. Este enfoque defensivo es esencial en producción para mantener la integridad del sistema y mejorar la experiencia del usuario final al transformar fallos técnicos en interacciones controladas.

## Ejemplo (no ejecutado automáticamente)
```python
import os

def leer_archivo_seguro(nombre):
    try:
        with open(nombre, 'r') as archivo:
            contenido = archivo.read()
            return contenido
    except FileNotFoundError:
        print(f"El archivo '{nombre}' no existe en el sistema.")
        return ""
    except PermissionError:
        print(f"No tienes permisos para leer '{nombre}'.")
        return ""

# Uso realista con un archivo que probablemente no exista
resultado = leer_archivo_seguro('configuracion_2026.json')
if resultado:
    print("Contenido cargado correctamente.")
else:
    print("No se pudo cargar el contenido, usando valores por defecto.")
```
