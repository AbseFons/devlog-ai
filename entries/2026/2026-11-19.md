## Objetivo
Comprender la diferencia fundamental entre iteradores y generadores, aplicando esta distinción para optimizar el uso de memoria al procesar grandes volúmenes de datos sin cargarlos completos en RAM.

## Explicación
En Python, los iteradores son objetos que implementan el protocolo __iter__ y __next__, permitiendo la iteración secuencial. Los generadores, definidos con 'yield', son una forma concisa de crear iteradores. Mientras un iterador tradicional requiere definir clases o funciones complejas, un generador pausa su ejecución al encontrar 'yield', devolviendo valores uno a uno. Esto es crucial para flujos de datos infinitos o archivos masivos. Al usar 'yield', el código se ejecuta bajo demanda, liberando memoria inmediatamente después de cada paso. Este enfoque transforma scripts que fallan por limitaciones de RAM en aplicaciones escalables y eficientes.

## Ejemplo (no ejecutado automáticamente)
Lectura eficiente de un archivo gigante línea por línea usando un generador para evitar cargar todo el contenido a la memoria.

```python
def leer_archivo_grande(ruta):
    with open(ruta, 'r') as f:
        for linea in f:
            yield linea.strip()

for texto in leer_archivo_grande('datos.txt'):
    print(texto)
```
