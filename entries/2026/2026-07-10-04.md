## Objetivo
Aprender a detener operaciones de red largas usando AbortController para evitar bloqueos y mejorar la experiencia del usuario en aplicaciones web modernas.

## Explicación
En JavaScript, las peticiones fetch pueden colgar indefinidamente si el usuario abandona la página o cambia de ruta. La solución nativa es usar AbortController junto con un signal. Este controlador genera una señal que se pasa al segundo argumento de fetch. Si llamas a abort() antes de que la respuesta llegue, la promesa rechazará inmediatamente con un error específico. Esto permite limpiar recursos y actualizar la interfaz sin esperar resultados obsoletos. Es esencial para formularios dinámicos o carga diferida.

## Ejemplo (no ejecutado automáticamente)
Se crea un controlador, se inicia una petición a una API pública de retraso simulado y se aborta tras 1 segundo si no ha respondido.

```javascript
const controller = new AbortController();
fetch('https://httpbin.org/delay/5', { signal: controller.signal })
```
