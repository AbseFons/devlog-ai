## Objetivo
Comprender la lógica fundamental del Algoritmo de Búsqueda en Anchura (BFS) para encontrar el camino más corto en grafos no ponderados utilizando una cola y un conjunto visitado.

## Explicación
El BFS explora un grafo capa por capa, partiendo desde un nodo raíz. Utiliza una estructura de datos tipo cola (FIFO): se añade el nodo actual y sus vecinos no visitados a la cola. Antes de procesar cualquier nodo, se verifica si ya fue visitado para evitar ciclos infinitos en grafos cíclicos. Este método garantiza que el primer camino encontrado hacia un destino sea el de menor número de aristas, ideal para redes sociales o mapeo de rutas simples.

## Ejemplo (no ejecutado automáticamente)
Implementación básica de BFS en Python que recorre un grafo adyacente representado como diccionario y devuelve la distancia mínima desde el nodo 'A' hasta el resto.

```python
from collections import deque

def bfs(graph, start):
    visited = {node: False for node in graph}
    queue = deque([start])
    distances = {start: 0}
    while queue:
        current = queue.popleft()
        if current not in visited:
            visited[current] = True
            for neighbor in graph[current]:
                if neighbor not in distances:
                    distances[neighbor] = distances[current] + 1
                    queue.append(neighbor)
    return distances
```
