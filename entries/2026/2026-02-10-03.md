## Objetivo
Comprender la definición formal de árbol binario, sus propiedades estructurales básicas como el grado máximo de nodos por nivel y dominar los patrones fundamentales de recorrido (orden preorden) para manipular datos jerárquicos eficientemente.

## Explicación
Un árbol binario es una estructura de datos no lineal donde cada nodo tiene a lo sumo dos hijos: izquierdo y derecho. Esta restricción permite organizar información de manera jerárquica, facilitando búsquedas rápidas si se mantiene la propiedad de ordenación. En este nivel introductorio, analizaremos cómo se construye recursivamente un árbol vacío o con nodos raíz. La navegación implica recorrer el árbol visitando nodos en secuencias específicas, como el preorden (raíz-izquierda-derecha), esencial para serializar estructuras o realizar copias profundas. Es fundamental distinguir entre la altura del árbol y la profundidad de los nodos individuales.

## Ejemplo (no ejecutado automáticamente)
Implementación de un nodo en JavaScript con propiedades izquierda y derecha, inicializando un árbol binario simple con valores numéricos.

```javascript
class NodoBinario {
  constructor(valor) {
    this.valor = valor;
    this.izquierda = null;
    this.derecha = null;
  }
}
const raiz = new NodoBinario(10);
raiz.izquierda = new NodoBinario(5);
```

## Ejercicio
Crea un árbol binario con un nodo raíz de valor 20, un hijo izquierdo de 10 y un hijo derecho de 30. Luego, escribe una función que imprima los valores en orden preorden.

## Criterios de revisión
El código debe definir correctamente la clase NodoBinario, establecer las referencias a los hijos sin errores de sintaxis y la función de recorrido debe visitar primero el nodo actual antes de sus descendientes.
