## Objetivo
Aprender a identificar y ejecutar pruebas de regresión para asegurar que nuevas modificaciones no rompan funcionalidades existentes en el sistema, manteniendo la estabilidad del software ante iteraciones continuas.

## Explicación
Las pruebas de regresión son esenciales cuando se introduce un cambio en el código. Su propósito es verificar que las características previamente funcionales sigan operando correctamente después de la modificación. Se ejecutan automáticamente tras cada despliegue o actualización significativa. Este proceso evita la acumulación de errores ocultos y reduce el riesgo de regresiones críticas. En este contexto, se prioriza la cobertura de casos de uso frecuentes para detectar fallos rápidamente sin necesidad de probar todo el sistema desde cero.

## Ejemplo (no ejecutado automáticamente)
Script en Python que simula una prueba de regresión verificando que un usuario pueda iniciar sesión y que el saldo de su cuenta no cambie tras una actualización del backend.

```python
def test_login_regression():
    assert login("user", "pass") == True
    assert get_balance("user") == 100.0
```

## Ejercicio
