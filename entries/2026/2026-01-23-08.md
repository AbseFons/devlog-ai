## Objetivo
Aprender a importar la librería estándar, establecer conexión, crear cursor y ejecutar una consulta SELECT simple para recuperar datos de una tabla existente sin modificar el esquema.

## Explicación
En esta microlección exploraremos los fundamentos de interactuar con bases de datos SQLite en Python. Utilizaremos el módulo nativo sqlite3 para abrir una conexión a un archivo de base de datos local. Es crucial recordar cerrar la conexión al finalizar, aunque en scripts pequeños esto puede omitirse temporalmente. Crearemos un cursor para ejecutar comandos SQL. Ejecutaremos una consulta SELECT para listar todos los registros de una tabla 'usuarios', demostrando cómo Python maneja las cadenas de texto y los resultados devueltos por la base de datos.

## Ejemplo (no ejecutado automáticamente)
Conexión a SQLite, creación de cursor y ejecución de SELECT

```python
import sqlite3
conn = sqlite3.connect('mi_base.db')
cursor = conn.cursor()
resultados = cursor.execute('SELECT * FROM usuarios').fetchall()
```
