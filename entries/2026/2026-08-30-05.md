## Objetivo
Al finalizar esta lección, el desarrollador será capaz de diferenciar entre procesos y hilos en Python, identificar cuándo usar la librería threading para tareas I/O intensivas y comprender las limitaciones impuestas por la GIL al ejecutar código CPU intensivo en paralelo.

## Explicación
En Python, la concurrencia se maneja principalmente mediante hilos (threads) o procesos. Debido a la Global Interpreter Lock (GIL), los hilos no permiten el paralelismo real de CPU para tareas computacionalmente pesadas, pero son ideales para operaciones de E/S como llamadas a APIs o lectura de archivos. Este módulo introduce el uso básico del módulo threading para ejecutar múltiples tareas de forma asíncrona sin bloquear la ejecución principal. Aprenderás a crear hilos, definir funciones ejecutables y gestionar su ciclo de vida. Es fundamental entender que sincronizar hilos requiere mecanismos como locks o semáforos para evitar condiciones de carrera, aunque en esta serie 1 nos enfocaremos en la creación y supervisión básica de tareas concurrentes.

## Ejemplo (no ejecutado automáticamente)
```python
import threading
import time

def tarea(nombre, duracion):
    print(f"Hilo {nombre} iniciado.")
    time.sleep(duracion)
    print(f"Hilo {nombre} completado.")

if __name__ == "__main__":
    hilos = []
    for i in range(3):
        t = threading.Thread(target=tarea, args=(f'Hilo-{i}', 2))
        hilos.append(t)
        t.start()
    
    for t in hilos:
        t.join()
    print("Todas las tareas terminaron.")
```
