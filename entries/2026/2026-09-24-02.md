## Objetivo
Aprender a utilizar bloques try-catch para prevenir que fallos inesperados detengan la ejecución del programa, permitiendo manejar excepciones de forma elegante y mantener la estabilidad de la aplicación.

## Explicación
En JavaScript, los errores no controlados pueden detener una aplicación. El patrón estándar es envolver código potencialmente fallido en un bloque try. Si ocurre un error, se ejecuta el bloque catch para procesarlo. Esto evita que la página se vuelva blanca. Es crucial no ocultar errores críticos sin registro, sino transformar excepciones técnicas en mensajes de usuario comprensibles o acciones correctivas automáticas, asegurando una experiencia fluida.

## Ejemplo (no ejecutado automáticamente)
Intento de división por cero capturado y manejado para mostrar un mensaje amigable.

```javascript
try {
  const resultado = 10 / 0;
} catch (error) {
  console.log('Error detectado: ' + error.message);
}
```

## Ejercicio
Crea una función que acepte dos números y devuelva su cociente. Usa try-catch para manejar la división por cero e imprime un mensaje de alerta en lugar de dejar que el script falle.

## Criterios de revisión
El código debe incluir un bloque try con la operación matemática, un catch que capture el objeto error y loguee un mensaje específico sin usar console.error directo del sistema operativo.
