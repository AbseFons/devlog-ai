## Objetivo
Comprender el concepto de atomicidad en bases de datos, asegurando que las operaciones transaccionales se ejecuten completamente o no se ejecuten en absoluto para mantener la integridad del sistema.

## Explicación
La atomicidad es la primera propiedad ACID, garantizando que una transacción sea indivisible. Si una parte falla, toda la transacción se deshace. Imagina transferir dinero: si el saldo del remitente baja pero no sube al destinatario, el sistema debe revertir todo. SQL usa 'COMMIT' para confirmar y 'ROLLBACK' para cancelar. Sin atomicidad, los datos quedarían en estados inconsistentes, como saldos negativos o duplicados.

## Ejemplo (no ejecutado automáticamente)
Script SQL que simula una transferencia atómica entre dos cuentas con rollback automático ante error.

```sql
BEGIN TRANSACTION;
UPDATE cuentas SET saldo = saldo - 100 WHERE id = 1;
UPDATE cuentas SET saldo = saldo + 100 WHERE id = 2;
COMMIT;
```
