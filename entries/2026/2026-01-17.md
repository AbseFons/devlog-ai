## Objetivo
Comprender la naturaleza del tipado dinámico en Python y aprender a utilizar anotaciones para mejorar la legibilidad del código sin alterar su ejecución.

## Explicación
Python es un lenguaje de tipado dinámico, lo que significa que el tipo de una variable se determina en tiempo de ejecución y puede cambiar. Las anotaciones, introducidas con PEP 484, son opcionales y sirven como documentación para herramientas estáticas. Por ejemplo, declarar 'x: int' no convierte a x en entero automáticamente; solo indica la intención del programador. Esto permite que los editores de código detecten errores potenciales antes de ejecutar el script. Es crucial entender que las anotaciones no afectan al comportamiento del programa, sino que facilitan el mantenimiento y la colaboración en proyectos grandes.

## Ejemplo (no ejecutado automáticamente)
Definición de una función con parámetros tipados explícitamente para calcular el área de un rectángulo.

```python
def calcular_area(ancho: float, alto: float) -> float:
    return ancho * alto
```
