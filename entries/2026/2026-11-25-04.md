## Objetivo
Aprender a identificar y eliminar efectos secundarios como mutación de estado global o I/O, asegurando que las funciones dependan únicamente de sus entradas y devuelvan resultados consistentes sin alterar el entorno externo.

## Explicación
Una función pura en Python debe garantizar que su salida sea idéntica para los mismos argumentos de entrada y nunca modificar variables externas. En la práctica, esto implica evitar mutar listas globales, escribir directamente a archivos o realizar llamadas a APIs dentro del cuerpo de la función lógica. Por ejemplo, en lugar de actualizar una lista compartida globalmente, se debe devolver una nueva lista transformada. Esto facilita las pruebas unitarias y el razonamiento sobre el flujo del programa. Al mantener la inmutabilidad implícita en los datos pasados por valor, reducimos acoplamiento y errores sutiles derivados de estados inesperados.

## Ejemplo (no ejecutado automáticamente)
Transformación de una lista de precios aplicando un impuesto sin modificar la lista original ni realizar I/O.

```python
def calcular_con_iva(precios_base, porcentaje):
    return [p * (1 + porcentaje / 100) for p in precios_base]

precios = [100, 200, 300]
resultados = calcular_con_iva(precios, 21)
print(f'Original: {precios}, Con IVA: {resultados}')
```
