## Objetivo
Aprender a utilizar la librería estándar argparse en Python para definir argumentos de línea de comandos, permitiendo crear scripts robustos y fáciles de usar que aceptan parámetros configurables sin necesidad de modificar el código fuente.

## Explicación
La librería argparse facilita la creación de interfaces de línea de comandos. Permite definir opciones obligatorias y opcionales, así como valores por defecto. Al ejecutar el script, Python genera automáticamente un mensaje de ayuda detallado si el usuario no proporciona los argumentos correctos. Este enfoque es esencial para herramientas de automatización donde se necesitan diferentes comportamientos según la entrada del usuario, mejorando la mantenibilidad y la claridad del software.

## Ejemplo (no ejecutado automáticamente)
Script que calcula el área de un rectángulo basándose en argumentos pasados por línea de comandos.

```python
import argparse
parser = argparse.ArgumentParser()
parser.add_argument('ancho', type=float)
args = parser.parse_args()
```

## Ejercicio
Crea un script Python que acepte dos argumentos obligatorios: nombre y edad. El programa debe imprimir un saludo personalizado incluyendo la edad del usuario.

## Criterios de revisión
El código debe importar argparse, definir un ArgumentParser con dos add_argument para nombre y edad, y ejecutar parse_args(). La salida debe mostrar el mensaje de ayuda si faltan argumentos y el saludo correcto si se proporcionan.
