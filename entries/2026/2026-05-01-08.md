## Objetivo
Aprender a identificar vulnerabilidades en librerías de terceros mediante escaneo automatizado, priorizar parches críticos y aplicar el principio de menor privilegio para mitigar riesgos sin interrumpir la operación del servicio.

## Explicación
Las dependencias externas son una fuente común de vectores de ataque. Un CVE (Common Vulnerabilities and Exposures) describe una vulnerabilidad específica. El proceso comienza escaneando el árbol de dependencias con herramientas como OWASP Dependency-Check o Snyk. Al encontrar un CVE, se debe verificar su severidad (CVSS), el impacto real en la aplicación y si existe una versión parcheada disponible. La estrategia no es siempre actualizar inmediatamente; a veces se requiere evaluar la compatibilidad o aplicar parches de seguridad específicos. Se recomienda mantener un registro de todos los CVEs encontrados, su estado y las acciones tomadas para cumplir con normativas de seguridad.

## Ejemplo (no ejecutado automáticamente)
Script en Python que utiliza la librería 'pip' para escanear un proyecto y listar dependencias con vulnerabilidades conocidas reportadas en el registro NVD.

```python
import subprocess
import json
result = subprocess.run(['pip', 'list', '--format=json'], capture_output=True, text=True)
print(json.dumps(json.loads(result.stdout), indent=2))
```

## Criterios de revisión
Identificar al menos tres dependencias vulnerables, clasificarlas por severidad y proponer una ruta de actualización segura sin romper la funcionalidad existente.
