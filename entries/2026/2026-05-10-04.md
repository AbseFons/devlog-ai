## Objetivo
Comprender los fundamentos del algoritmo de ordenamiento por mezcla, su estrategia divide y vencerás, y analizar su complejidad temporal y espacial en el contexto de estructuras de datos.

## Explicación
El ordenamiento por mezcla es un algoritmo recursivo que aplica la estrategia 'divide y vencerás'. Divide el arreglo original en dos mitades hasta llegar a subarreglos de tamaño uno, luego los combina ordenados. Su complejidad temporal promedio y peor caso es O(n log n), mientras que el espacio auxiliar es O(n). Ideal para grandes volúmenes de datos donde la estabilidad del orden relativo es crucial.

## Ejemplo (no ejecutado automáticamente)
Implementación recursiva en Python que divide una lista, ordena las mitades y las fusiona correctamente.

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```
