## Objetivo
Comprender el propósito de las pruebas de regresión para asegurar que nuevas modificaciones no rompan funcionalidades existentes, manteniendo la estabilidad del sistema ante iteraciones continuas.

## Explicación
Las pruebas de regresión son esenciales cuando se introduce un cambio en el código. Su objetivo es verificar que las características previamente funcionales sigan operando correctamente después de la modificación. En esta serie, exploraremos cómo diseñar suites de prueba automatizadas que cubran flujos críticos sin necesidad de ejecutar todo el test suite manualmente. Esto permite detectar errores introducidos accidentalmente y facilita la integración continua en entornos ágiles.

## Ejemplo (no ejecutado automáticamente)
Script de Python que ejecuta una prueba de regresión simple verificando que un usuario pueda iniciar sesión con credenciales válidas tras una actualización del backend.

```python
def test_login_regression():
    assert login('usuario_valido', 'password123') == True
```
