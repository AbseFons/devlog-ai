## Objetivo
Aprender a anidar Common Table Expressions para filtrar registros intermedios antes de realizar agregaciones complejas, mejorando la legibilidad del código SQL frente a subconsultas repetitivas.

## Explicación
Las CTEs permiten definir conjuntos de datos temporales nombrados que se pueden referenciar múltiples veces. En esta lección, exploraremos cómo anidar CTEs para realizar un filtrado preliminar en una tabla de ventas y luego agrupar los resultados por región. Primero, creamos una CTE llamada 'ventas_filtradas' que selecciona solo las transacciones superiores a un monto determinado. Posteriormente, utilizamos otra CTE o la misma para agrupar estos datos filtrados por categoría de producto. Este enfoque modular facilita el mantenimiento del código y evita la duplicación de lógica de filtrado dentro de las cláusulas WHERE principales, haciendo que las consultas complejas sean más fáciles de depurar y entender.

## Ejemplo (no ejecutado automáticamente)
Consulta SQL que utiliza una CTE anidada para filtrar ventas mayores a 100 y luego agrupa por categoría.

```sql
WITH ventas_filtradas AS (
    SELECT categoria, monto FROM transacciones WHERE monto > 100
),
resumen_regional AS (
    SELECT categoria, SUM(monto) as total_ventas FROM ventas_filtradas GROUP BY categoria
)
SELECT * FROM resumen_regional;
```
