## Objetivo
Comprender cómo evitar mutaciones de estado global y efectos secundarios para garantizar que las funciones sean predecibles, fáciles de probar y componibles en aplicaciones Python robustas.

## Explicación
Una función pura no solo debe devolver el mismo resultado para los mismos argumentos, sino que tampoco debe modificar ningún estado externo. En Python, esto implica evitar alterar listas globales o variables del ámbito exterior dentro de la función. Por ejemplo, en lugar de pasar una lista y modificarla in situ con append(), se devuelve una nueva lista transformada. Esta disciplina reduce acoplamiento entre módulos y facilita el razonamiento sobre el flujo de datos. Al mantener las funciones aisladas de efectos secundarios como I/O o acceso a bases de datos, simplificamos enormemente la depuración y la implementación de pruebas unitarias automatizadas.

## Ejemplo (no ejecutado automáticamente)
Transforma una lista de precios crudos sumando un impuesto sin alterar la lista original, devolviendo una nueva estructura de datos limpia.

```python
def aplicar_iva(precios_base):
    return [p * 1.21 for p in precios_base]

precios = [100, 200, 300]
nuevos_precios = aplicar_iva(precios)
print(nuevos_precios)
```

## Criterios de revisión
La función no debe usar .update() ni asignar directamente a la clave del diccionario pasado por referencia. Debe devolver una nueva lista construida con comprensión de listas o map(). El código debe incluir al menos un caso de prueba que verifique que el diccionario original permanece intacto después de la llamada.
