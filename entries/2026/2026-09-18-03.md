## Objetivo
Introducir el concepto de programación dinámica mediante un ejemplo clásico de secuencia recursiva, enseñando a optimizar cálculos evitando recomputaciones innecesarias y mejorando la complejidad temporal de algoritmos básicos.

## Explicación
La programación dinámica resuelve problemas complejos dividiéndolos en subproblemas más simples y almacenando sus resultados para evitar recalcularlos. En este caso, utilizaremos la secuencia de Fibonacci como ejemplo introductorio. La versión recursiva pura tiene una complejidad exponencial porque recalcula los mismos valores múltiples veces. Al implementar una tabla (memoización o tabulación), guardamos cada resultado en un array. Esto transforma la solución a una complejidad lineal, permitiendo calcular términos lejanos de la serie instantáneamente. Este patrón es fundamental para optimizar algoritmos en ingeniería de software.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python que calcula el n-ésimo número de Fibonacci utilizando un array para almacenar resultados previos, evitando la recursión ineficiente.

```python
def fibonacci(n):
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]
```
