## Objetivo
Analizar cómo la elección del punto medio afecta el rendimiento del algoritmo y evitar desequilibrios en árboles de recursión que podrían degradar la complejidad temporal.

## Explicación
En esta segunda serie sobre ordenamiento por mezcla, profundizamos en la implementación robusta del pivote. Aunque dividir siempre al centro parece óptimo, en arrays con datos repetidos o patrones específicos, un cálculo de índice incorrecto puede generar subarrays desiguales. Esto rompe el equilibrio del árbol de recursión, transformando la complejidad O(n log n) en O(n^2). El código presentado utiliza una función auxiliar para calcular el punto medio exacto, asegurando que cada llamada recursiva procese aproximadamente la mitad de los elementos restantes. Este enfoque garantiza estabilidad y eficiencia incluso ante entradas mal distribuidas, siendo crucial para sistemas de alta carga donde la consistencia del rendimiento es vital.

## Ejemplo (no ejecutado automáticamente)
Implementación en Python que calcula el índice central exacto para dividir un array de enteros desordenados, demostrando cómo se maneja la recursión base y la combinación de subarrays.

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)
```
