## Objetivo
Aprender a seleccionar múltiples nodos del DOM simultáneamente utilizando querySelectorAll para iterar y modificar colecciones de elementos en interfaces web complejas.

## Explicación
La propiedad querySelectorAll devuelve una NodeList con todos los elementos que coinciden con un selector CSS. A diferencia de querySelector, este método permite obtener varios resultados. Es fundamental entender que NodeList no es un Array nativo, por lo que métodos como map o filter no funcionan directamente sin convertirlo primero a Array. En esta lección exploraremos cómo seleccionar todos los párrafos dentro de una sección específica y aplicarles un estilo condicional basado en su contenido. Este enfoque es esencial para construir interfaces reactivas donde el estado del usuario afecta la presentación visual de múltiples componentes al mismo tiempo.

## Ejemplo (no ejecutado automáticamente)
Selecciona todos los elementos con clase 'item' y les añade una clase 'activo' si contienen texto mayor a cinco caracteres.

```javascript
const items = document.querySelectorAll('.item');
items.forEach(item => {
  if (item.textContent.length > 5) {
    item.classList.add('activo');
  }
});
```
