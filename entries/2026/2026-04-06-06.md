## Objetivo
Comprender la asincronía básica mediante promesas y aprender a escribir código legible con async/await para manejar operaciones no bloqueantes de forma eficiente.

## Explicación
En JavaScript, las promesas representan el resultado final de una operación asíncrona: pueden estar pendientes, resueltas o rechazadas. Async/await simplifica la escritura al permitir tratar estas operaciones como secuencias lineales. Este enfoque evita el uso excesivo de callbacks anidados (pirámide del infierno). Se recomienda siempre manejar errores con bloques try/catch para garantizar la robustez del código.

## Ejemplo (no ejecutado automáticamente)
Ejemplo que simula una llamada a API y maneja tanto éxito como error usando async/await.

```javascript
const obtenerDatos = async () => {
  try {
    const respuesta = await fetch('https://jsonplaceholder.typicode.com/posts/1');
    return await respuesta.json();
  } catch (error) {
    console.error('Error:', error);
  }
};
```
