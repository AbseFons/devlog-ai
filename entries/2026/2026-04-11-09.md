## Objetivo
Aprender a utilizar Common Table Expressions para simplificar consultas complejas, mejorar la legibilidad y reutilizar lógica en SQL Server.

## Explicación
Las Common Table Expressions o CTE permiten definir un conjunto de resultados temporalmente antes de ejecutar una consulta principal. Esto facilita el desglose de operaciones complejas en pasos lógicos claros. A diferencia de las subconsultas anidadas, las CTE se leen de arriba a abajo, mejorando la mantenibilidad del código. Son ideales para cálculos recursivos o cuando se necesita referenciar un conjunto de datos intermedio en múltiples partes de una sentencia SELECT.

## Ejemplo (no ejecutado automáticamente)
Consulta que calcula el total de ventas por categoría utilizando una CTE para filtrar productos primero.

```sql
WITH VentasPorCategoria AS (
    SELECT Categoria, SUM(Precio) as TotalVentas
    FROM Productos
    WHERE Activo = 1
    GROUP BY Categoria
)
SELECT * FROM VentasPorCategoria ORDER BY TotalVentas DESC;
```

## Ejercicio
