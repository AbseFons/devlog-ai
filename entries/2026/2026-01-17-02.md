## Objetivo
Dominar la sintaxis estándar para compartir código entre archivos en JavaScript, evitando dependencias globales y promoviendo una arquitectura modular limpia y mantenible.

## Explicación
Los módulos ES permiten encapsular lógica en archivos independientes. Para exportar funciones o variables desde un archivo 'utils.js', se usa 'export function'. En el archivo principal, se importa con 'import { funcion } from utils.js'. Esto crea un ámbito de ejecución aislado, evitando colisiones de nombres y garantizando que los cambios internos no afecten al exterior. Es fundamental recordar que las exportaciones son evaluadas una sola vez al cargar el módulo.

## Ejemplo (no ejecutado automáticamente)
Se define una utilidad para calcular el área de un círculo en un archivo separado y se importa en el script principal.

```javascript
export function areaCirculo(radio) {
  return Math.PI * radio * radio;
}

import { areaCirculo } from './utils.js';
console.log(areaCirculo(5));
```
