## Objetivo
Aprender a implementar un sistema de control de acceso basado en roles (RBAC) utilizando middleware en una aplicación web moderna, asegurando que solo los usuarios autorizados puedan acceder a recursos protegidos.

## Explicación
El Control de Acceso Basado en Roles (RBAC) es un modelo de seguridad donde el acceso a recursos se otorga según el rol del usuario. En esta microlección, implementaremos un middleware en Node.js que verifica si el usuario autenticado posee el rol necesario para acceder a una ruta específica. El flujo consiste en extraer los roles del token JWT o sesión, compararlos con los requeridos por la ruta y devolver un error 403 si no coinciden. Este enfoque centraliza la lógica de seguridad, evitando repetir validaciones en cada controlador y reduciendo errores humanos. Es fundamental definir roles granulares (ej. 'editor', 'admin') y evitar conceder permisos excesivos para mantener el principio de menor privilegio.

## Ejemplo (no ejecutado automáticamente)
Middleware que verifica si el usuario tiene el rol 'admin' antes de permitir el acceso a una ruta protegida.

```javascript
const checkRole = (requiredRole) => {
  return (req, res, next) => {
    const userRoles = req.user.roles;
    if (!userRoles.includes(requiredRole)) {
      return res.status(403).json({ error: 'Acceso denegado' });
    }
    next();
  };
};
```

## Ejercicio
Crea una ruta protegida en tu servidor Express que requiera el rol 'analista'. Implementa el middleware anterior y prueba accediendo sin autenticación y con un token de usuario normal.
