## Objetivo
Aprender a definir clases compactas con atributos automáticos, métodos __init__ y __repr__ usando la función dataclass de Python 3.7+, ideal para modelos de datos simples.

## Explicación
Los dataclasses simplifican la definición de clases POJO (Plain Old Java Objects) en Python. Al decorar una clase con @dataclass, el compilador genera automáticamente el constructor __init__, el método __repr__ y métodos de comparación si se especifica. Esto reduce drásticamente la boilerplate code. Es útil para representar entidades como usuarios o productos donde solo importa la estructura de datos. Se puede personalizar añadiendo parámetros como field(default=...) o ordenar los campos con order=True.

## Ejemplo (no ejecutado automáticamente)
Definición de una clase Producto con atributos nombre, precio y stock usando decorador dataclass.

```python
from dataclasses import dataclass

@dataclass
class Producto:
    nombre: str
    precio: float
    stock: int = 0
```
