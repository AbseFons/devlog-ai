## Objetivo
Aprender a identificar vulnerabilidades críticas en librerías de terceros utilizando herramientas de escaneo como npm audit para mitigar riesgos de seguridad antes del despliegue.

## Explicación
Las dependencias de terceros son una fuente común de vulnerabilidades. Cuando se publica un CVE (Common Vulnerabilities and Exposures), los paquetes afectados pueden ser explotados para robar datos o tomar el control del servidor. En ecosistemas como Node.js, la herramienta nativa npm audit escanea el árbol de dependencias y reporta fallos de seguridad conocidos. El proceso implica ejecutar el comando en el directorio del proyecto, revisar la salida detallada que incluye el nivel de severidad, el paquete vulnerable y la versión comprometida. Posteriormente, se debe actualizar el paquete a una versión segura o agregar un parche específico si no existe una actualización mayor disponible. Ignorar estas alertas puede llevar a brechas de seguridad graves en la aplicación final.

## Ejemplo (no ejecutado automáticamente)
Ejecución del comando npm audit para detectar vulnerabilidades en un proyecto de Node.js y revisión de los resultados en consola.

```bash
npm audit
npm install <paquete>@<version-segura>
```

## Ejercicio
Ejecuta npm audit en tu proyecto local. Si detecta fallos, actualiza cada uno con su versión más reciente o aplica un parche específico.

## Criterios de revisión
Detectar al menos una vulnerabilidad reportada por la herramienta y aplicar la corrección correspondiente para eliminar el riesgo.
