## Objetivo
Comprender cómo EXPLAIN revela la estrategia del motor de base de datos para escanear tablas, identificando índices no utilizados y permitiendo ajustar consultas lentas mediante el análisis del plan de ejecución.

## Explicación
El comando EXPLAIN descompone una consulta SQL en un árbol de operaciones que el motor planea ejecutar. Al analizar este plan, puedes detectar si se están utilizando índices efectivos o si el sistema realiza escaneos completos (table scans) innecesarios. Por ejemplo, si ves 'Seq Scan' en lugar de 'Index Scan', es probable que falte un índice adecuado o que la consulta no esté optimizada para usarlo. Esta herramienta es fundamental para el rendimiento, ya que permite visualizar el flujo de datos antes de ejecutar la consulta real, ahorrando recursos y tiempo.

## Ejemplo (no ejecutado automáticamente)
Consulta que busca clientes activos con EXPLAIN para verificar el uso del índice en la columna estado.

```sql
EXPLAIN SELECT * FROM clientes WHERE estado = 'activo';

-- Observa si aparece Index Scan o Seq Scan en el plan de salida
```
