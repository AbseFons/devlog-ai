## Objetivo
Comprender el concepto fundamental de inyección de dependencias y cómo la inversión de control desacopla las clases, facilitando pruebas unitarias y un mantenimiento más sencillo en aplicaciones modernas.

## Explicación
La inyección de dependencias (DI) es un patrón de diseño que permite a una clase recibir sus dependencias desde el exterior en lugar de crearlas internamente. Este enfoque promueve la inversión de control, donde el flujo de control se invierte respecto al modelo tradicional. Al delegar la creación de objetos a un contenedor o framework, logramos un acoplamiento bajo y alta cohesión. Esto es crucial para escribir código modular, escalable y fácil de probar sin necesidad de instancias complejas o datos en memoria difíciles de gestionar.

## Ejemplo (no ejecutado automáticamente)
Clase Cliente que recibe su servicio de notificaciones a través de un constructor inyectado, demostrando el desacoplamiento inicial.

```java
public class Cliente {
    private Notificador notificador;

    public Cliente(Notificador notificador) {
        this.notificador = notificador;
    }
}
```
