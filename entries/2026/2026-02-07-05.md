## Objetivo
Aprender a identificar y probar valores límite en la validación de datos numéricos para prevenir errores de desbordamiento o lógica incorrecta al procesar montos financieros.

## Explicación
Los casos borde son pruebas críticas que verifican el comportamiento del sistema justo antes y después de los límites definidos. En este ejemplo, simulamos la validación de un campo de ingreso monetario. El objetivo es asegurar que valores como cero negativo, el mínimo permitido, el máximo exacto y uno superior al máximo sean tratados correctamente. Esto evita fallos en transacciones bancarias o cálculos salariales donde una diferencia de un centavo puede ser catastrófica. La prueba debe cubrir la entrada válida máxima, la mínima aceptable y los valores inmediatamente fuera de rango para confirmar que el sistema rechaza datos inválidos sin colapsar.

## Ejemplo (no ejecutado automáticamente)
Script en Python que valida si un monto está dentro del rango permitido (0 a 1000) y maneja casos borde como -1, 0, 1000 y 1001.

```python
def validar_monto(monto):
    if monto < 0 or monto > 1000:
        return False
    return True
```
