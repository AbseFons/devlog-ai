## Objetivo
Aprender a crear scripts profesionales en Python utilizando la librería estándar argparse para gestionar argumentos de línea de comandos, definiendo opciones y valores por defecto de manera segura y legible.

## Explicación
La librería argparse facilita la creación de interfaces de línea de comandos robustas. Permite definir parámetros posicionales y opciones con flags (como -v o --output) que el usuario puede pasar al ejecutar el script. Al usar add_argument, se especifica el nombre corto, largo, tipos de datos y valores por defecto. El parser procesa los argumentos pasados desde la terminal y devuelve un objeto Namespace con los valores extraídos. Esto evita errores de ejecución y mejora la usabilidad del software, permitiendo configurar comportamientos sin modificar el código fuente directamente.

## Ejemplo (no ejecutado automáticamente)
Script que suma dos números proporcionados como argumentos posicionales con una opción para mostrar ayuda.

```python
import argparse
parser = argparse.ArgumentParser()
parser.add_argument('num1', type=int)
parser.add_argument('num2', type=int)
args = parser.parse_args()
print(args.num1 + args.num2)
```
