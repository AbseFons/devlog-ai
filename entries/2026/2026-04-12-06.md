## Objetivo
Aprender a definir clases con atributos y métodos automáticos usando el decorador @dataclass, simplificando la creación de estructuras de datos en Python.

## Explicación
Los dataclasses permiten generar automáticamente los métodos __init__, __repr__ y __eq__ al decorar una clase. Esto reduce drásticamente la boilerplate code. Se definen atributos con tipo y valores por defecto opcionales. Ideal para representar entidades de negocio simples como registros o configuraciones. La importación se realiza desde el módulo dataclasses. Es fundamental usar type hints para que el decorador funcione correctamente.

## Ejemplo (no ejecutado automáticamente)
Definición de una clase Usuario con nombre y edad, incluyendo un método personalizado get_info.

```python
from dataclasses import dataclass

@dataclass
class Usuario:
    nombre: str
    edad: int = 0
    
    def get_info(self):
        return f'{self.nombre} tiene {self.edad} años'
```
